## Вопрос, с которого всё начинается

В задаче картинка с искажённым текстом, а в ответе нужны эти символы. Или нужно автоматизировать вход на сайт с CAPTCHA. Как из «картинки с шумом» получить текст? Разберём пайплайн распознавания CAPTCHA.

## Наш пример

Возьмём изображение с текстом, поверх которого линии и точки (шум). Прямое OCR даст мусор. Задача — **предобработать** изображение так, чтобы символы стали чёткими, и только потом распознать.

## Шаг 1: что такое CAPTCHA и зачем её ломать

**CAPTCHA** — тест «человек ли ты», обычно искажённый текст или картинки. Ломают её для автоматизации (в CTF — чтобы получить флаг) и для обхода защиты. Простейший вид — текстовые CAPTCHA с шумом.

## Шаг 2: предобработка — первый шаг

Сырое изображение почти всегда надо чистить:
- **Оттенки серого** — убрать цвет.
- **Бинаризация (порог)** — оставить только чёрное/белое.
- **Удаление шума** — медианный фильтр, удаление мелких объектов.
- **Усиление** — эрозия/дилатация для утолщения или утоньшения линий.

Цель — сделать символы однородными на однотонном фоне.

## Шаг 3: сегментация

Если символы слиплись, их надо **разделить**. Приёмы:
- По вертикальным «пробелам» (столбцы без пикселей).
- По компонентам связности (connected components).
- По проекции (профиль яркости по столбцам).

Иногда CAPTCHA намеренно не даёт разделить символы — тогда распознают целиком (модель на последовательность).

## Шаг 4: распознавание

После чистки:
- **OCR** (Tesseract) — если символы стандартного шрифта.
- **Шаблонный матчинг** — сравнение с эталонными символами.
- **Нейросеть** — для сложных CAPTCHA.

Для простых CTF-задач хватает бинаризации + Tesseract.

## Шаг 5: инструменты

- Python: PIL/Pillow, OpenCV, numpy.
- `tesseract` — OCR-движок.
- `pytesseract` — обёртка.
- Онлайн-сервисы распознавания (осторожно с приватностью).

## Шаг 6: практический пайплайн

1. Открыть изображение (Pillow).
2. Перевести в grayscale.
3. Применить порог (например, 128).
4. Убрать шум (медиана).
5. Подать в `pytesseract.image_to_string`.
6. Проверить результат, при необходимости подкрутить порог.

## Шаг 7: когда не работает

- Сильное искажение (волны, перекрытие) — нужен ML.
- Цветной фон — нужна цветовая фильтрация.
- Разный размер символов — нужна нормализация.
- Шум, неотличимый от текста — предобработка не поможет.

## Шаг 8: защита (обратная сторона)

Если ты защищаешь CAPTCHA: добавляй перекрытие символов, случайные линии через текст, вращение, неоднородный фон. Но помни: CAPTCHA не панацея — современные модели ломают многие из них.

## Частые ошибки

- Сразу гнать OCR без предобработки.
- Один фиксированный порог для всех изображений.
- Забывать про инверсию (белый текст на чёрном).

## Что мы теперь знаем

- CAPTCHA ломают через предобработку + распознавание.
- Бинаризация, удаление шума, сегментация — ключевые шаги.
- Tesseract годится для простых CAPTCHA.
- Сложные требуют ML.
- Защита — искажение и перекрытие символов.
