## Вопрос, с которого всё начинается

Тебе дают строку из символов `⠁⠃⠉` — это не «мусор», а **шрифт Брайля**. Или картинку с человечками с флажками — **семафор**. Задача начинается не с дешифровки, а с **опознания алфавита**: понять, какой системой кодирования это записано. Разберём, как это делать.

## Наш пример

Возьмём символ `⠓` (U+2808... на самом деле U+2813). Он выглядит как точки в ячейке. В Unicode Брайль занимает диапазон U+2800–U+28FF: каждый символ — 8 точек (2×4), где биты кодируют, какие точки выпуклые. Числовое значение символа минус U+2800 даёт битовую маску. Это ключ к декодированию.

## Шаг 1: Брайль как битовая маска

Символ Брайля в Unicode = 0x2800 + маска. Младшие 8 бит маски — это 8 точек ячейки. Смещение (offset) 0x2800 (десятичное 10240) превращает код в байт. Значит, декодирование: `ord(ch) - 0x2800` даёт число, а его биты — рисунок точек.

## Шаг 2: соответствие буквам

В стандартном Брайле для латиницы каждой букве соответствует определённая комбинация точек. Таблица фиксирована (a = точка 1, b = точки 1–2, ...). Значит, имея маску, можно сопоставить её с буквой по таблице. Часто в CTF используют «компьютерный Брайль» — 8-точечный.

## Шаг 3: семафор

**Флажный семафор** кодирует буквы положением двух флажков (8 позиций, 28 комбинаций). Это не текст и не биты — это **позиции**. Распознать можно по изображению с человечками/линиями; декодировать — по таблице «пара позиций → буква». В CTF часто дают список пар чисел (1–8, 1–8) — это позиции флажков.

## Шаг 4: Морзе и другие

Рядом стоят: **азбука Морзе** (точки/тире, разделители), **Бэкон** (A/B, 5 бит), **Полибий** (пары 1–5), **семафор** (пары 1–8). Общий принцип: есть конечный алфавит символов-примитивов и правило группировки. Опознание — по виду символов: только `.`/`-` → Морзе; только две буквы → Бэкон; пары чисел → Полибий/семафор.

## Шаг 5: как опознавать

- Только два различных символа → Бэкон/бинарное.
- Точки и тире → Морзе.
- Пары маленьких чисел (1–5) → Полибий.
- Пары чисел 1–8 → семафор.
- Символы U+2800–28FF → Брайль.
- Квадратная сетка точек → пиксельный/QR-подобный код.

## Шаг 6: инструменты

- Python + таблицы соответствия (пишутся в 10 строк).
- `dCode`, CyberChef — онлайн-декодеры для Брайля/Морзе/семафора.
- Для семафора — таблица из 28 позиций.

## Шаг 7: как защищаться (и зачем)

Это скорее головоломки, чем атаки. Но принцип «опознай кодировку прежде чем декодировать» универсален: в реальных задачах это распознавание base64/base32/hex, а в CTF — расширение до экзотики. Навык «сначала классифицируй» экономит часы.

## Шаг 8: мини-скрипт

Брайль-декодер: для каждого символа вычесть 0x2800, взять биты, сопоставить с таблицей. Две строки кода плюс словарь. Именно так решается большинство «брайль»-задач.

## Частые ошибки

- Пытаться «прочитать» Брайль глазами вместо кода.
- Путать 6-точечный и 8-точечный Брайль.
- Принимать семафор за Морзе.

## Разбор кейса: декодер Брайля на Python

Брайль — самый механический из «нестандартных алфавитов»: каждый символ — это битовая маска. Ключ в том, что Unicode-диапазон Брайля начинается с `U+2800`, а младшие 8 бит кода символа — это маска точек.

```python
# стандартный латинский Брайль: точка -> бит
# dot1=0x01 dot2=0x02 dot3=0x04 dot4=0x08 dot5=0x10 dot6=0x20
LETTERS = {
 0x01:'a',0x03:'b',0x09:'c',0x19:'d',0x11:'e',0x0b:'f',0x1b:'g',0x13:'h',
 0x0a:'i',0x1a:'j',0x05:'k',0x07:'l',0x0d:'m',0x1d:'n',0x15:'o',0x0f:'p',
 0x1f:'q',0x17:'r',0x0e:'s',0x1e:'t',0x25:'u',0x27:'v',0x3a:'w',0x2d:'x',
 0x3d:'y',0x35:'z',
}
def decode_braille(text):
    return ''.join(LETTERS.get(ord(ch) - 0x2800, '?') for ch in text)

print(decode_braille('⠁⠃⠉'))    # -> abc
```

Проверим на первых трёх: `⠁` = U+2801 → маска 0x01 → `a`; `⠃` = U+2803 → 0x03 → `b`; `⠉` = U+2809 → 0x09 → `c`. Декодер готов, и он не зависит от «шрифта» — только от кода символа. Если встретился `?`, значит либо это не латиница (например, цифра или знак препинания с отдельной таблицей), либо использован 8-точечный «компьютерный Брайль», где задействованы точки 7 и 8.

## Таблица: латинский Брайль (точки → буква)

| Буква | Точки | Маска | Буква | Точки | Маска |
|---|---|---|---|---|---|
| a | 1 | 0x01 | n | 1,3,4,5 | 0x1d |
| b | 1,2 | 0x03 | o | 1,3,5 | 0x15 |
| c | 1,4 | 0x09 | p | 1,2,3,4 | 0x0f |
| d | 1,4,5 | 0x19 | q | 1,2,3,4,5 | 0x1f |
| e | 1,5 | 0x11 | r | 1,2,3,5 | 0x17 |
| f | 1,2,4 | 0x0b | s | 2,3,4 | 0x0e |
| g | 1,2,4,5 | 0x1b | t | 2,3,4,5 | 0x1e |
| h | 1,2,5 | 0x13 | u | 1,3,6 | 0x25 |
| i | 2,4 | 0x0a | v | 1,2,3,6 | 0x27 |
| j | 2,4,5 | 0x1a | w | 2,4,5,6 | 0x3a |
| k | 1,3 | 0x05 | x | 1,3,4,6 | 0x2d |
| l | 1,2,3 | 0x07 | y | 1,3,4,5,6 | 0x3d |
| m | 1,3,4 | 0x0d | z | 1,3,5,6 | 0x35 |

Обрати внимание на структуру: буквы `a`–`j` используют только верхние четыре точки, `k`–`t` добавляют точку 3 (сдвиг на «десяток»), `u`–`z` добавляют точку 6. Эта регулярность позволяет не зубрить таблицу, а вывести её.

## Семафор: как устроена таблица

Флажный семафор кодирует букву положением двух флажков. Позиций восемь (по кругу), и буква — это **пара** позиций. Стандартная нумерация: позиция 1 — вверх, дальше по часовой стрелке до 8. Тогда таблица начинается так:

```
A = 1-2   B = 1-3   C = 1-4   D = 1-5   E = 1-6   F = 1-7   G = 1-8
H = 2-3   I = 2-4   J = 2-5*  K = 2-6   L = 2-7   M = 2-8
N = 3-4   O = 3-5   P = 3-6   Q = 3-7   R = 3-8   S = 4-5
T = 4-6   U = 4-7   V = 4-8   W = 5-6   X = 5-7   Y = 5-8   Z = 6-7
```

(`J` иногда совпадает с `I` — в «буквенной» раскладке; цифры и пробел используют оставшиеся комбинации, например 7-8.)

В CTF семафор чаще дают не картинкой, а списком пар чисел `(1,2) (1,3) ...` — тогда задача сводится к подстановке по таблице. Если пары выглядят как `(1,2) (1,4) (2,4)` — это уже Полибий или Брайль, смотри на диапазон чисел: 1–5 → Полибий, 1–8 → семафор.

## Если не сработало

- **Получаются `?` на всех символах.** Скорее всего, это не Брайль, а другой алфавит (например, «шрифт» из подстановки). Проверь диапазон кодов символов: Брайль — ровно U+2800–U+28FF.
- **Половина букв неверна.** Возможно, использован 8-точечный компьютерный Брайль с точками 7–8; дополни таблицу старшими битами.
- **Пары чисел не сходятся с таблицей.** Уточни нумерацию позиций: разные источники нумеруют флажки с разной начальной точки. Попробуй сдвинуть нумерацию и перебрать 8 вариантов — один совпадёт.
- **Строка читается, но смысла нет.** Попробуй инвертировать биты точек (чёрное/белое поменяны) или прочитать строку в обратном порядке.

## Ограничения

Головоломки с нестандартными алфавитами — это в первую очередь тренировка навыка «классифицируй до того, как декодируешь». В реальной работе тот же приём применяется к base64/base32/hex и к экзотическим кодировкам из утечек: сначала определить систему, потом искать её декодер. Ограничение простое: таблицы неоднозначны (Брайль 6 vs 8 точек, семафор с разной нумерацией), поэтому результат всегда проверяют по осмысленности текста, а не по формальному совпадению.

## Итоговый чек-лист опознания алфавита

- Один-два разных символа → Бэкон или бинарное кодирование.
- Точки и тире → азбука Морзе.
- Пары чисел 1–5 → квадрат Полибия.
- Пары чисел 1–8 → флажный семафор.
- Символы диапазона U+2800–U+28FF → шрифт Брайля.
- Сетка из точек → пиксельный код / QR.
- Брайль декодируется вычитанием `0x2800` и таблицей масок.
- Проверяй результат по осмысленности текста, а не по формальному совпадению.

## Кратко: что запомнить

Брайль в Unicode — это битовая маска точек: вычти `0x2800` и сопоставь с таблицей. Семафор — пара позиций флажков из восьми. Общий навык — опознать систему кодирования по форме символов прежде, чем декодировать: диапазон кодов, вид символов и размер групп сразу сужают круг кандидатов.

## Что мы теперь знаем

- Нестандартные алфавиты начинаются с опознания системы кодирования.
- Брайль в Unicode = 0x2800 + битовая маска 8 точек.
- Семафор кодирует буквы парами позиций 1–8.
- Морзе/Бэкон/Полибий различаются по алфавиту примитивов.
- «Сначала классифицируй» — универсальный приём.
