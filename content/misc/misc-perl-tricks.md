## Введение

Когда данных много, а времени мало, Perl-однострочники выручают лучше тяжёлых скриптов. `awk` и `sed` — стандартные инструменты на любом Linux. В CTF они незаменимы для извлечения флагов, преобразования кодировок, подсчёта частот и разбора «грязных» дампов. Этот урок — набор проверенных однострочников и приёмов, а также методология выбора инструмента под задачу.

## Perl: базовые флаги

```bash
perl -ne 'print' file        # -n: цикл по строкам, -e: код
perl -pe 's/foo/bar/g' file  # -p: как -n, но печатает $_ после кода
perl -a -ne 'print $F[0]'    # -a: авторазбиение на поля @F
perl -F: -a -ne 'print $F[0]' # -F: разделитель полей
perl -l -ne 'print'          # -l: chomp при вводе, \n при выводе
```

Специальные переменные: `$_` (текущая строка), `$.` (номер строки), `@F` (поля при `-a`), `$/` (разделитель записей), `$1..$9` (группы захвата).

## Извлечение флага и полезного

```bash
perl -ne 'print "$1\n" if /(flag\{[^}]+\})/i' file
grep -aE 'flag\{' file
awk '{print $1}' file | sort -u
perl -ne 'while(/(\d{1,3}(?:\.\d{1,3}){3})/g){print "$1\n"}' file
```

`-a` на бинарном файле бессмысленно; для «грязных» дампов используйте `grep -a` и `perl -0` (читать целиком).

## Подстановки с eval: s///e

Флаг `e` выполняет Perl-код в правой части подстановки — regex превращается в вычислитель:

```bash
perl -pe 's/%([0-9A-Fa-f]{2})/chr(hex($1))/ge' file
perl -pe 's/(\d+)\+(\d+)/$1+$2/ge'
perl -pe 'tr/A-Za-z/N-ZA-Mn-za-m/' file
```

`e` также позволяет вызывать функции (`pack`, `unpack`) прямо в подстановке — удобно для hex→bin→текст.

## awk: поля, условия, суммы

```bash
awk '{sum+=$1} END{print sum}' nums.txt
awk '$3 > 100 {print $0}' data.txt
awk -F, '{print $2}' data.csv | sort | uniq -c | sort -rn
awk 'NR%2==0' file
awk '{a[$1]++} END{for(k in a) print a[k],k}' file
```

`awk` умеет regex (`~`, `!~`), функции (`substr`, `split`, `gsub`, `tolower`, `length`) и математику — часто заменяет полноценный скрипт.

## sed: потоковые преобразования

```bash
sed -n '10,20p' file               # строки 10..20
sed 's/foo/bar/g' file             # замена
sed -E 's/(\w+)@(\w+)/\2:\1/' file # группы
sed '/^#/d' file                   # удалить комментарии
sed -n '/BEGIN/,/END/p' file       # диапазон между маркерами
```

Осторожно: `sed` не умеет жадные группы и backreferences во всех реализациях; для сложного берите Perl.

## Типовые CTF-сценарии

- **Частотный анализ:** `perl -ne 'for(split//){$c{$_}++} END{print "$_ $c{$_}\n" for sort keys %c}'`.
- **XOR с ключом:** `perl -pe '$_ = join "", map { chr(ord($_)^0x42) } split //'`.
- **Base64-декод:** `perl -MMIME::Base64 -ne 'print decode_base64($_)'`.
- **Гекс-дамп:** `xxd -r -p`.
- **Разделение по NUL:** `perl -0 -ne '...'`.
- **Многострочная замена:** `perl -0777 -pe 's/A.*B/X/s'`.

## Методология

1. **Поймите формат данных:** строки, поля, кодировка.
2. **Выберите инструмент:** `grep` для фильтра, `awk` для полей, `sed` для замен, Perl для сложной логики и eval.
3. **Проверьте на маленьком фрагменте** (`head -5`), затем применяйте ко всему.
4. **Комбинируйте** через пайпы: `... | awk ... | sort | uniq -c`.

## Разобранный пример

Дано: лог с тысячами строк, где флаг спрятан в base64-строках. Решение:

```bash
grep -aoE '[A-Za-z0-9+/]{16,}={0,2}' dump.log \
  | while read -r b; do echo "$b" | base64 -d 2>/dev/null; done \
  | grep -aoE 'flag\{[^}]+\}'
```

Так за один конвейер извлекаются и декодируются все кандидаты.

## Частые ошибки и подводные камни

- Забыть `-a` при использовании `@F` — поля пусты.
- Путать `-n` и `-p`: `-n` требует явного `print`.
- Использовать жадные квантификаторы там, где нужны ленивые (`.*?`).
- Забыть `-l` и получить лишние переводы строк.
- `sed -i` без бэкапа затирает файл — делайте копию.
- Игнорировать бинарные данные — `grep` без `-a` может молчать.

## Продвинутые Perl-приёмы

```bash
# читать файл целиком (multi-line режим)
perl -0777 -ne 'print if /BEGIN.*END/s' file
# заменять с вычислением (eval)
perl -pe 's/(\d+)/$1*2/ge' file
# работать с hex-байтами
perl -ne 'print pack("H*", $1), "\n" if /([0-9a-fA-F]+)/' file
# перекодировать UTF-8 <-> latin1
perl -MEncode -ne 'print decode("UTF-8", $_)' file
```

`-M` подключает модули: `MIME::Base64`, `Digest::MD5`, `Encode` — без внешних зависимостей.

## awk: скрипты и функции

```bash
awk 'BEGIN{FS=","} NR>1 {gsub(/"/,"",$2); a[$2]+=$3} END{for(k in a) print k, a[k]}' data.csv
awk '{printf "%s|", $1} END{print ""}' file
awk 'length($0) > 80' file
```

`awk` с `BEGIN`/`END` и ассоциативными массивами часто заменяет целый скрипт агрегации.

## sed: многострочное и адресация

```bash
sed -n '/start/,/end/{/start/d;/end/d;p}' file   # между маркерами
sed 'N;s/\n/ /' file                              # склейка пар строк
sed -E 's/[[:space:]]+$//' file                   # trim
sed -i.bak 's/old/new/g' file                     # с бэкапом
```

## Извлечение и модификация данных в однострочниках

```bash
# извлечь все email из текста
grep -aoE '[[:alnum:]._%+-]+@[[:alnum:].-]+\.[a-z]{2,}' file | sort -u
# распарсить key=value в TSV
perl -ne 'print "$1\t$2\n" if /^(\w+)=(.+)$/' file
# вырезать N-й столбец (по табу)
cut -f3 file | sort | uniq -c | sort -rn
# заменить в нескольких файлах
perl -pi -e 's/old/new/g' *.txt
```

`perl -pi -e` — «sed -i» на стероидах с полноценным regex и логикой. Всегда делайте бэкап (`-i.bak`).

## Шпаргалка по частым задачам

| Задача | Команда |
|--------|---------|
| Найти все флаги | `grep -aoE 'flag\{[^}]+\}' f` |
| Уникальные строки | `sort -u f` |
| Топ значений | `sort f | uniq -c | sort -rn | head` |
| Сумма чисел | `awk '{s+=$1}END{print s}' f` |
| Base64 всех строк | `perl -MMIME::Base64 -ne 'print decode_base64($_)' f` |
| Замена по regex | `perl -pi -e 's/old/new/g' f` |
| Между маркерами | `sed -n '/A/,/B/p' f` |
| Поля по разделителю | `awk -F, '{print $2}' f` |

Держите эту таблицу под рукой — большинство текстовых CTF-задач решаются комбинацией этих однострочников.
