## Введение

Динамическое программирование (DP) — это способ решать задачи, разбивая их на перекрывающиеся подзадачи и запоминая результаты. В CTF DP встречается там, где нужен оптимум: минимальная стоимость, максимальная выгода, число способов. Умение **распознать** DP важнее знания конкретной задачи: большинство задач сводится к нескольким базовым шаблонам.

## Когда это DP

Признаки:

- задача про **оптимум** (минимум/максимум) или **число способов**;
- решение строится из решений меньших подзадач;
- подзадачи **перекрываются** (одни и те же считаются многократно);
- «жадный» выбор не гарантирует оптимум.

Если подзадачи не перекрываются — хватит «разделяй и властвуй». Если жадность работает — она проще и быстрее.

## Мемоизация: сверху вниз

```python
from functools import lru_cache

@lru_cache(maxsize=None)
def fib(n):
    if n < 2:
        return n
    return fib(n-1) + fib(n-2)

print(fib(200))
```

`lru_cache` превращает экспоненту в линейное время. Самый быстрый способ прототипа.

## Табуляция: снизу вверх

```python
def fib(n):
    a, b = 0, 1
    for _ in range(n):
        a, b = b, a + b
    return a
```

Табуляция экономит стек и часто память (храните только последние состояния).

## Задача о рюкзаке (0/1 knapsack)

```python
def knapsack(items, W):
    dp = [0] * (W + 1)
    for w, v in items:
        for cap in range(W, w - 1, -1):
            dp[cap] = max(dp[cap], dp[cap - w] + v)
    return dp[W]
```

Обратный проход по `cap` не даёт взять предмет дважды. Для неограниченного рюкзака проход прямой.

## LCS и редакционное расстояние

```python
def lcs(a, b):
    dp = [[0]*(len(b)+1) for _ in range(len(a)+1)]
    for i in range(1, len(a)+1):
        for j in range(1, len(b)+1):
            if a[i-1] == b[j-1]:
                dp[i][j] = dp[i-1][j-1] + 1
            else:
                dp[i][j] = max(dp[i-1][j], dp[i][j-1])
    return dp[-1][-1]
```

Редакционное расстояние (Левенштейн) — то же с операциями замены/вставки/удаления; встречается в задачах на «похожесть» и подсказках про опечатки.

## Размен монет и число способов

```python
def ways(coins, amount):
    dp = [0]*(amount+1)
    dp[0] = 1
    for c in coins:
        for x in range(c, amount+1):
            dp[x] += dp[x-c]
    return dp[amount]
```

Порядок циклов важен: внешний по монетам — сочетания, внешний по сумме — перестановки.

## DP по подмножествам (малый n)

```python
n = 5
dp = [[float('inf')]*n for _ in range(1<<n)]
dp[1][0] = 0
for mask in range(1<<n):
    for u in range(n):
        if not (mask >> u) & 1 or dp[mask][u] == float('inf'):
            continue
        for v in range(n):
            if not (mask >> v) & 1:
                nm = mask | (1 << v)
                dp[nm][v] = min(dp[nm][v], dp[mask][u] + cost[u][v])
```

Сложность `O(2^n * n^2)` — приемлемо только для малых `n`.

## Распознавание и стратегия

1. **Определите состояние:** что описывает подзадачу (индекс, остаток, маска).
2. **Определите переход:** как из меньших состояний получить большее.
3. **Задайте базу:** начальные состояния.
4. **Выберите порядок:** мемоизация или табуляция.
5. **Оптимизируйте память:** храните только нужный слой.

## Разобранный пример

Дано: набор чисел, нужно набрать сумму минимальным количеством монет.

```python
def min_coins(coins, amount):
    INF = float('inf')
    dp = [0] + [INF]*amount
    for x in range(1, amount+1):
        for c in coins:
            if c <= x and dp[x-c]+1 < dp[x]:
                dp[x] = dp[x-c]+1
    return dp[amount] if dp[amount] != INF else -1
print(min_coins([1,3,4], 6))   # 2  (3+3)
```

## Частые ошибки и подводные камни

- Неправильный порядок циклов в рюкзаке (взять предмет дважды).
- Забыть базу → неверный ответ на краях.
- Индексация вне диапазона при переходе.
- Слишком большой массив для табуляции → память.
- Путать «число способов» и «минимум» — разные переходы.
- Рекурсия без `lru_cache` → экспонента.

## Классические DP-задачи в CTF

Помимо рюкзака и LCS, часто встречаются:

- **Наибольшая возрастающая подпоследовательность (LIS):** `O(n log n)` через бинарный поиск.
- **Разбиение строки на слова:** словарь + DP по префиксам.
- **Подсчёт путей в сетке:** `dp[i][j] = dp[i-1][j] + dp[i][j-1]`.
- **Минимальная стоимость подъёма по лестнице.**
- **Интервальное DP:** порядок умножения матриц, разбор выражений.
- **Битовая маска:** назначения, коммивояжёр, покрытие.

```python
# LIS за O(n log n)
import bisect
def lis(a):
    tails = []
    for x in a:
        i = bisect.bisect_left(tails, x)
        if i == len(tails): tails.append(x)
        else: tails[i] = x
    return len(tails)
```

## Оптимизация памяти

Для задач, где переход зависит только от предыдущего слоя, храните один-два ряда:

```python
# редакционное расстояние в O(min(n,m)) памяти
def edit(a, b):
    if len(a) < len(b): a, b = b, a
    prev = list(range(len(b)+1))
    for i, ca in enumerate(a, 1):
        cur = [i]
        for j, cb in enumerate(b, 1):
            cur.append(min(prev[j]+1, cur[j-1]+1, prev[j-1]+(ca != cb)))
        prev = cur
    return prev[-1]
```

## DP с восстановлением ответа

Часто нужен не только оптимум, но и сам путь. Храните «родителя» состояния или восстанавливайте обратным проходом по таблице.

## DP на строках и последовательностях

Помимо LCS и редакционного расстояния, частые сюжеты:

- **Палиндромные подстроки/подпоследовательности:** `dp[i][j]` — булево/длина для подстроки `s[i..j]`.
- **Разбиение на слова:** `dp[i]` = можно ли разбить префикс длиной `i`.
- **Наибольшая общая подстрока (не подпоследовательность):** DP с обнулением при несовпадении.
- **Умножение матриц / разбор выражений:** интервальное DP.

```python
# разбиение строки на слова из словаря
def word_break(s, words):
    n = len(s)
    dp = [False]*(n+1); dp[0] = True
    for i in range(1, n+1):
        for w in words:
            if i >= len(w) and dp[i-len(w)] and s[i-len(w):i] == w:
                dp[i] = True; break
    return dp[n]
print(word_break("leetcode", {"leet","code"}))   # True
```

## Битовая маска: назначения и покрытие

Задачи «распределить N задач между M исполнителями» или «покрыть множество» решаются DP по маске:

```python
# назначение: dp[mask] = минимальная стоимость покрытия mask
INF = float('inf')
n = 4
cost = [[1,3,3,2],[2,1,3,2],[3,2,1,2],[2,3,2,1]]
dp = [INF]*(1<<n); dp[0] = 0
for mask in range(1<<n):
    worker = bin(mask).count('1')
    if worker >= n: continue
    for task in range(n):
        if not (mask>>task)&1:
            nm = mask | (1<<task)
            dp[nm] = min(dp[nm], dp[mask] + cost[worker][task])
print(dp[(1<<n)-1])
```

## Жадность vs DP: как выбрать

- Жадность работает, если можно доказать «обменный аргумент» (например, дробный рюкзак, выбор интервалов по раннему окончанию).
- DP нужен, когда локально оптимальный выбор ломает глобальный оптимум (0/1 рюкзак, размен монет с произвольными номиналами).
- Проверка: попробуйте найти контрпример к жадному алгоритму на маленьких данных.
