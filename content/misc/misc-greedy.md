## Что такое жадные алгоритмы

Жадный алгоритм строит решение пошагово, на каждом шаге выбирая **локально лучший** вариант и больше к нему не возвращаясь. Это самый быстрый класс алгоритмов: обычно `O(n log n)` из-за предварительной сортировки, а логика — один проход. В CTF жадность встречается в задачах «уложи максимум», «покрой минимумом», «собери строку дешевле всего».

## Свойства: жадный выбор и оптимальная подструктура

Жадность корректна, когда выполнены два условия:

1. **Свойство жадного выбора** — существует оптимальное решение, начинающееся с локально лучшего выбора.
2. **Оптимальная подструктура** — задача распадается на подзадачи того же вида.

Если хотя бы одно нарушено, жадный алгоритм даёт неоптимальный ответ. Поэтому в задачах оптимизации всегда полезно сначала спросить: «а точно ли жадность проходит?» — и проверить на контрпримере.

## Интервальное планирование

Классика: даны интервалы `[start, end)`, выбрать максимальное число непересекающихся. Жадная стратегия — **сортировать по времени окончания** и брать всё, что начинается не раньше конца последнего выбранного:

```python
def max_non_overlapping(intervals):
    intervals.sort(key=lambda iv: iv[1])   # по концу
    count, last_end = 0, float("-inf")
    chosen = []
    for s, e in intervals:
        if s >= last_end:
            chosen.append((s, e))
            last_end = e
            count += 1
    return count, chosen

print(max_non_overlapping([(1,3),(2,4),(3,5),(0,6),(5,7)]))
```

```
(3, [(1, 3), (3, 5), (5, 7)])
```

Обратите внимание: сортировка именно **по концу**, а не по началу. Сортировка по началу даёт неоптимальный результат.

## Сортировки: ключ и стабильность

В жадных задачах критичен порядок обработки. В Python сортировка стабильна, а `key` позволяет сортировать по нескольким полям через кортеж:

```python
items = [("a", 2), ("b", 1), ("c", 2)]
print(sorted(items, key=lambda x: (x[1], x[0])))
# [('b', 1), ('a', 2), ('c', 2)]
```

Для «сортировки по одному полю по убыванию, другому по возрастанию» используют отрицание или несколько проходов (сортировка стабильна, поэтому проходы «с конца к началу» дают нужный порядок).

## Хаффман и куча

Сжатие Хаффмана — жадный алгоритм на куче: многократно объединяем два самых редких символа. Сложность `O(n log n)`.

```python
import heapq
from collections import Counter

def huffman_lengths(data):
    heap = [[freq, [ch, ""]] for ch, freq in Counter(data).items()]
    heapq.heapify(heap)
    while len(heap) > 1:
        lo = heapq.heappop(heap)
        hi = heapq.heappop(heap)
        for pair in lo[1:]:
            pair[1] = "0" + pair[1]
        for pair in hi[1:]:
            pair[1] = "1" + pair[1]
        heapq.heappush(heap, [lo[0] + hi[0]] + lo[1:] + hi[1:])
    return heap[0][1:]

print(huffman_lengths("abracadabra"))
```

Код Хаффмана даёт минимальную средневзвешенную длину префиксного кода — это доказанно оптимально, поэтому жадность здесь корректна.

## Задачи покрытия и обмена

- **Покрытие отрезками.** Минимум отрезков, покрывающих `[0, L]`: сортируем по началу, жадно расширяем текущее покрытие самым дальним концом.
- **Дробный рюкзак.** Предметы делимы: берём в порядке убывания `value/weight` — жадность оптимальна.
- **Заправки/обмен.** Классическая задача «минимум остановок на заправках»: жадно едем до самой дальней достижимой заправки.

## Инструменты и код

- **heapq** — приоритетная очередь для Хаффмана и Dijkstra.
- **sorted / list.sort** — сортировка по ключу, основа почти всех жадных решений.
- **functools.cmp_to_key** — когда нужен нестандартный компаратор (например, «составить наибольшее число из цифр»).
- **Проверка гипотезы** — брутфорс на маленьких входах и сравнение с жадным ответом: это лучший способ убедиться, что жадность верна.

## Разобранный пример: минимум остановок

Дан маршрут и заправки с координатами; бак вмещает `F` км. Нужно минимум заправок.

```python
def min_stops(stations, target, F):
    stations = [0] + sorted(stations) + [target]
    stops, cur, fuel = 0, 0, F
    import heapq
    heap = []
    i = 0
    while cur < target:
        # все заправки в пределах бака
        while i < len(stations) and stations[i] <= cur + fuel:
            heapq.heappush(heap, -stations[i])
            i += 1
        if not heap:
            return -1
        cur = -heapq.heappop(heap)   # едем до самой дальней достижимой
        stops += 1
    return stops - 1

print(min_stops([100, 200, 300, 400], 500, 150))
```

```
2
```

Жадность здесь работает потому, что «достичь самой дальней заправки» всегда безопасно: любой другой план не даст больше возможностей впереди.

## Когда жадность не работает

| Задача | Жадность | Правильно |
|--------|----------|-----------|
| 0/1-рюкзак | неверно | динамическое программирование |
| Монеты (неканонические номиналы) | неверно | ДП по сумме |
| Кратчайший путь с отриц. рёбрами | неверно | Беллман-Форд |
| Интервальное планирование | верно | — |
| Хаффман | верно | — |
| Дробный рюкзак | верно | — |

## Частые ошибки и подводные камни

- **Сортировка не по тому ключу.** В интервалах — по концу, а не по началу.
- **Применение жадности к 0/1-рюкзаку.** Делимые и неделимые предметы — разные задачи.
- **Забытая проверка на достижимость.** Жадный выбор может завести в тупик — нужен `-1`.
- **Нестабильная гипотеза.** Не проверив жадность на малых входах, легко получить WA на скрытых тестах.
- **Переполнение при отрицаниях.** Для max-кучи на `heapq` берут `-x`; следите за типами.

| Задача | Жадный критерий | Сложность |
|--------|-----------------|-----------|
| Макс. непересек. интервалы | сортировка по концу | O(n log n) |

## Что дальше / решение

1. Поймите, что оптимизируется: число, стоимость, длина.
2. Проверьте, делимы ли объекты и есть ли свойство жадного выбора.
3. Подберите правильный ключ сортировки (для интервалов — по концу).
4. Реализуйте один проход; при необходимости — кучу.
5. Обязательно сверьтесь с брутфорсом на маленьких входах.

## Размен монет и египетские дроби

Размен монет — показательный пример: для «канонических» номиналов (как 1, 5, 10, 25) жадность оптимальна, но для произвольных — нет. Контрпример: номиналы `{1, 3, 4}`, сумма 6. Жадность берёт 4, затем 1, 1 → три монеты; оптимум — 3 + 3 → две.

```python
def greedy_coins(coins, amount):
    coins.sort(reverse=True)
    used = []
    for c in coins:
        while amount >= c:
            amount -= c
            used.append(c)
    return used if amount == 0 else None

print(greedy_coins([1,3,4], 6))   # [4, 1, 1] — НЕ оптимум
```

Египетские дроби (представить дробь как сумму долей `1/n`) решаются жадным алгоритмом Фибоначчи: на каждом шаге берём наибольшую долю, не превосходящую остаток. Здесь жадность доказуемо завершается.

```python
from fractions import Fraction
def egyptian(fr):
    out = []
    while fr > 0:
        n = -(-fr.denominator // fr.numerator)   # ceil(1/fr)
        out.append(n)
        fr -= Fraction(1, n)
    return out

print(egyptian(Fraction(5, 6)))   # [2, 3]  (1/2 + 1/3)
```

## Сортировка по компаратору

Иногда «правильный порядок» не выражается одним ключом. Классика — «составить наибольшее число из фрагментов»: сравнивать нужно конкатенации `a+b` и `b+a`.

```python
from functools import cmp_to_key
def largest_number(parts):
    parts = list(map(str, parts))
    parts.sort(key=cmp_to_key(lambda a, b: -1 if a+b > b+a else (1 if a+b < b+a else 0)))
    return "".join(parts)

print(largest_number([3, 30, 34, 5, 9]))   # 9534330
```

Если бы мы сортировали просто по значению или по первой цифре, получилось бы неверно. Компаратор — способ задать нестандартный жадный критерий.

## Матроиды и почему жадность работает

Теоретическое объяснение корректности жадности — **матроиды**. Если система «независимых множеств» образует матроид, то жадный алгоритм (сортировка по весу и добавление, если множество остаётся независимым) даёт максимум. Минимальное остовное дерево (Краскал) — пример жадности на матроиде: сортируем рёбра по весу и добавляем, если не образуется цикл.

```python
def kruskal(n, edges):
    parent = list(range(n))
    def find(x):
        while parent[x] != x:
            parent[x] = parent[parent[x]]; x = parent[x]
        return x
    total = 0
    for w, u, v in sorted(edges):
        ru, rv = find(u), find(v)
        if ru != rv:
            parent[ru] = rv; total += w
    return total
```

## Частые вопросы по жадным алгоритмам

- **Как быстро проверить гипотезу жадности?** Напишите брутфорс на малых входах и сравните ответы.
- **Что если критериев несколько?** Сортируйте по кортежу или используйте компаратор.
- **Жадность и ДП — что выбрать?** Если жадность верна, она быстрее; если сомневаетесь — ДП надёжнее.
- **Нужна ли куча?** Да, когда на каждом шаге нужен текущий минимум/максимум (Хаффман, Dijkstra).

## Мини-шпаргалка по жадным алгоритмам

Опорные правила: интервалы — сортировка по концу; дробный рюкзак — по `value/weight`; Хаффман — два минимума через кучу; покрытие — самый дальний конец; размен монет — только для канонических номиналов; наибольшее число — компаратор конкатенации. Перед применением жадности проверьте контрпример брутфорсом. Если жадность не проходит — переходите к динамическому программированию. И помните: минимальное остовное дерево (Краскал) — это тоже жадность, но уже на матроиде, поэтому она доказуемо оптимальна.
