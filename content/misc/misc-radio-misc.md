## Вопрос, с которого всё начинается

В CTF тебе дали файл `challenge.iq` — это **запись радиосигнала**. Если открыть его как текст, там мусор. Но внутри — сообщение, которое надо достать: перехваченная передача пульта, датчика или самодельного передатчика. Как из сырых отсчётов сигнала получить байты и найти флаг? Это и есть radio misc — навык, который прямо нужен в hardware-ветке (RF, суб-GHz, BLE) и в анализе IoT.

## Наш пример: файл challenge.iq

Смотрим на файл:

```bash
$ file challenge.iq
challenge.iq: data
$ ls -l challenge.iq
-rw-r--r-- 1 user user 2097152 challenge.iq
```

`file` говорит «data» — значит, это не текст, а сырые байты. Размер 2 МБ при записи `int16` — это примерно 1 миллион отсчётов. Первый вопрос: как вообще радиосигнал превращается в файл?

## Что такое IQ-данные

Радиосигнал — это колебание, у которого есть амплитуда и фаза. Чтобы хранить его в цифре, сигнал записывают как **комплексное число** — пару из двух компонент:

```
sample = I + jQ
```

- **I** (in-phase) — синфазная компонента;
- **Q** (quadrature) — квадратурная, сдвинутая по фазе на 90°.

В файле эти пары лежат подряд: `I0 Q0 I1 Q1 ...`, обычно как `int8`, `int16` или `float32`. Чтобы запись была осмысленной, нужны ещё два числа: **частота дискретизации** (sample rate, сколько отсчётов в секунду) и **центральная частота** (какую полосу мы слушали). Без них запись неоднозначна, и при демодуляции их приходится подбирать.

## Читаем запись в Python: спектрограмма

Загружаем файл как `int16`, разбиваем на I и Q, собираем комплексные отсчёты:

```python
import numpy as np
raw = np.fromfile('challenge.iq', dtype=np.int16).astype(np.float32)
s = raw[0::2] + 1j*raw[1::2]   # I + jQ
s /= 32768.0                   # нормируем к диапазону [-1, 1]
```

`raw[0::2]` берёт каждый второй элемент — это I, `raw[1::2]` — Q. Дальше смотрим **спектрограмму** (водопад) — картинку, где по горизонтали время, по вертикали частота, а яркость = мощность:

```python
import matplotlib.pyplot as plt
plt.specgram(s, NFFT=1024, Fs=2_000_000)
plt.show()
```

На спектрограмме видно: ровные горизонтальные линии — несущая (сигнал есть постоянно), короткие вспышки — посылки `OOK/ASK` (сигнал включается и выключается). Для нашего примера видны отдельные «пакеты» — типичная картина передачи пульта.

## Демодуляция OOK: огибающая → биты

`OOK` (On-Off Keying) — простейшая манипуляция: сигнал есть = 1, нет = 0. Извлекаем **огибающую** (модуль комплексного отсчёта — общую амплитуду) и берём порог:

```python
mag = np.abs(s)
thr = (mag.max() + mag.min()) / 2
bits = (mag > thr).astype(int)
print(''.join(map(str, bits[:64])))
# 1010101011001010...
```

Получаем поток нулей и единиц. Дальше группируем по длительности (**run-length**): короткий импульс — один бит, длинный — разделитель или другой бит. Многие суб-GHz пульты используют OOK + PWM (ширина импульса кодирует 0 и 1).

## FSK: сигнал с двумя частотами

Если спектрограмма показывает **два** устойчивых уровня частоты — это `FSK` (Frequency Shift Keying): 0 и 1 передаются на разных частотах. Демодулируем через мгновенную частоту (производную фазы):

```python
phase = np.unwrap(np.angle(s))
inst = np.diff(phase) / (2*np.pi) * 2_000_000
bits = (inst > inst.mean()).astype(int)
```

Смысл: знак отклонения частоты от средней говорит, какая из двух частот сейчас передаётся. В интерактивном инструменте `inspectrum` то же делается мышкой: выбираешь модуляцию, задаёшь символьную скорость — получаешь биты.

## Собираем байты и получаем флаг

Теперь биты надо превратить в байты, найдя **преамбулу** (синхронизирующую последовательность) и выровняв кадр:

```python
bitstr = ''.join(str(b) for b in bits)
for off in range(8):
    chunk = bitstr[off:off+len(bitstr)//8*8]
    data = bytes(int(chunk[i:i+8], 2) for i in range(0, len(chunk), 8))
    if b'flag' in data:
        print(data)
        break
# b'...flag{radio}...'
```

Перебор `off` от 0 до 7 нужен, потому что мы не знаем, где начинается первый бит — сдвиг на один бит ломает всю группировку по 8.

## Если в записи шум

Иногда файл выглядит как белый шум — сигнал слабый или смещён по частоте. Тогда сначала ищем **всплеск в спектре**: усредняем мощность по времени и смотрим, где пик:

```python
from scipy import signal
f, Pxx = signal.welch(s, fs=2_000_000, nperseg=4096)
peak = f[np.argmax(Pxx)]
print(f'peak at {peak/1000:.1f} kHz offset')
```

Пик указывает на несущую — вокруг неё ставим узкополосный фильтр и демодулируем. И помни про **DC-спайк**: в центре спектра почти всегда торчит артефакт приёмника (постоянная составляющая), его нельзя принимать за сигнал. Если видишь симметричные пики — возможно, зеркальное отражение; попробуй поменять знак Q. Ещё одна причина «шума» — неверный тип отсчётов: `int16`, `uint8` и `float32` дают разные картинки, так что сначала убедись в формате, а уже потом ищи пики.

## Приём сигнала своими руками

Если задача не даёт запись, а просит поймать сигнал, нужен **SDR** (Software Defined Radio — приёмник, который оцифровывает эфир и отдаёт IQ в компьютер). Самый доступный — RTL-SDR-донгл; пишем с него 10 секунд на частоте 433.92 МГц (типовой суб-GHz диапазон для пультов и датчиков):

```bash
$ rtl_sdr -f 433920000 -s 2048000 -n 20480000 capture.iq
```

`-f` — центральная частота, `-s` — частота дискретизации (2.048 МГц), `-n` — число отсчётов (20.48 млн при `-s 2048000` это ~10 секунд). Формат вывода — `uint8` со смещением (DC в значении 127), поэтому перед анализом его надо привести к нужному типу: неверный тип искажает спектр. Популярные форматы: `.cu8` (uint8), `.cs16` (int16), `.cf32` (float32). Конвертируют их через `csdr` конвейерами, например `csdr convert_u8_f` или `csdr convert_s16_f`. Для интерактивного просмотра используют `gqrx` (водопад в реальном времени) и `inspectrum` (разбор записанного файла), для суб-GHz протоколов — `rtl_433 -f 433.92M` (готовый декодер многих датчиков) и `URH`.

## Что мы теперь знаем

- Радиозапись — это **комплексные IQ-отсчёты** `I0 Q0 I1 Q1 …` (int8/int16/float32).
- Без **sample rate** и **центральной частоты** запись неоднозначна.
- Смотрим спектрограмму: линии = несущая, вспышки = OOK/ASK, два уровня = FSK.
- OOK демодулируется через огибающую `np.abs`, FSK — через производную фазы.
- Биты → байты через группировку по 8 с перебором сдвига; ищи преамбулу.
- DC-спайк в центре спектра — артефакт, а не сигнал.
