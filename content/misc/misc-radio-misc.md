Radio misc — это задачи, где вам дают **запись радиосигнала** (или просят принять его), и нужно найти в ней сообщение. Формат — IQ-данные: квадратурные отсчёты, комплексные числа. Этот навык прямо нужен в hardware-ветке (RF, суб-GHz, BLE) и в анализе IoT.

## Что такое IQ-данные

Радиосигнал — это вещественное колебание, но при оцифровке его удобно представить как комплексное число:

```
sample = I + jQ
```

- **I** (in-phase) — синфазная компонента;
- **Q** (quadrature) — квадратурная, сдвинутая на 90°.

Хранят обычно как чередующиеся пары `int8`/`int16`/`float32`: `I0 Q0 I1 Q1 ...`. Метаданные: **частота дискретизации** (sample rate), **центральная частота**, тип отсчётов. Без них запись неоднозначна.

```bash
# определить тип записи
file signal.iq
# data
ls -l signal.iq
# -rw-r--r-- 1 user user 2097152 signal.iq  (2 МБ = 1M сэмплов по int16 I/Q)
```

## Приём сигнала

```bash
# записать 10 МГц-полосу на частоте 433.92 МГц
rtl_sdr -f 433920000 -s 2048000 -n 20480000 capture.iq
# -f частота, -s sample rate, -n число сэмплов
```

`-n 20480000` при `-s 2048000` даёт ~10 секунд. Центральная частота 433.92 МГц — типичный суб-GHz диапазон для пультов и датчиков.

## Визуализация в Python

```python
import numpy as np
import matplotlib.pyplot as plt

raw = np.fromfile('capture.iq', dtype=np.int16).astype(np.float32)
i = raw[0::2]
q = raw[1::2]
s = i + 1j*q
s /= 32768.0

# спектр
plt.psd(s, NFFT=1024, Fs=2048000)
plt.show()

# спектрограмма (водопад)
plt.specgram(s, NFFT=1024, Fs=2048000)
plt.show()
```

На спектрограмме видно «всплески» — это посылки сигнала. Ровные горизонтальные линии = несущая; короткие вспышки = OOK/ASK.

## Декодирование OOK/ASK

OOK (On-Off Keying) — простейший: есть сигнал = 1, нет = 0. Извлекаем огибающую:

```python
mag = np.abs(s)
thr = (mag.max() + mag.min()) / 2
bits = (mag > thr).astype(int)
print(''.join(map(str, bits[:64])))
# 1010101011001010...
```

Затем группируем по длительности (run-length) в биты. Суб-GHz пульты часто используют OOK с фиксированным кодом.

## Декодирование FSK

FSK (Frequency Shift Keying): 0 и 1 — разные частоты. Смотрим спектр: два пика = две частоты.

```python
# сдвиг частоты через дифференцирование фазы
phase = np.unwrap(np.angle(s))
freq = np.diff(phase) / (2*np.pi) * Fs
bits = (freq > 0).astype(int)
```

В `inspectrum` это делается мышкой: выбираешь модуляцию, задаёшь символьную скорость, получаешь биты.

## Поиск сигнала в шуме

Если файл выглядит как шум — ищите всплеск в спектре. Приём:

```python
# усреднённый спектр — пик укажет несущую
from scipy import signal
f, Pxx = signal.welch(s, Fs=2048000, nperseg=4096)
peak = f[np.argmax(Pxx)]
print(f'peak at {peak/1000:.1f} kHz offset')
```

Затем узкополосный фильтр вокруг пика и демодуляция.

## Полный разобранный пример

Дан файл `challenge.iq` (int16, 2 МГц). Спектрограмма показывает OOK-пакет. Скрипт:

```python
import numpy as np
raw = np.fromfile('challenge.iq', dtype=np.int16).astype(np.float32)
s = raw[0::2] + 1j*raw[1::2]
mag = np.abs(s)
bits = (mag > (mag.max()*0.5)).astype(int)

# run-length → символы
out, cur, run = [], bits[0], 1
for b in bits[1:]:
    if b == cur: run += 1
    else:
        out.append((cur, run)); cur, run = b, 1
# короткий run = бит, длинный = разделитель
print(out[:20])
```

Далее сопоставляем длительности и собираем ASCII:

```python
# грубо: 2 коротких run = 1 бит
bitstr = ''.join('1' if v==1 else '0' for v,_ in out if r < 20)
print(bytes(int(bitstr[i:i+8],2) for i in range(0,len(bitstr)-7,8)))
# b'flag{radio}'
```

## Частые ошибки и подводные камни

- Неверный тип отсчётов: `int16` vs `uint8` vs `float32` — спектр «плывёт».
- Путать sample rate и центральную частоту.
- Забывать про **DC-спайк** в центре спектра (артефакт приёмника) — не путать с сигналом.
- Игнорировать инверсию спектра (зеркальный приём) — частота может быть отрицательной.
- Демодулировать не тот сигнал: в записи может быть несколько передатчиков.

## Дополнительная теория: модуляции, символьная скорость и кодирование

Радиосигнал несёт данные через **модуляцию**: амплитудную (ASK/OOK), частотную (FSK/GFSK/MSK), фазовую (PSK/QPSK), амплитудно-фазовую (QAM). Суб-GHz-устройства (пульты, датчики) чаще всего используют OOK и FSK. Чтобы демодулировать, нужно знать **символьную скорость** (baud rate) и **кодирование линии**: NRZ, Manchester (переход в середине бита), PWM (ширина импульса). Например, многие пульты используют OOK + PWM, где «0» и «1» — импульсы разной длительности. Определив длительности, вы восстанавливаете биты.

Далее идёт **кадрирование**: преамбула (синхронизация), заголовок, данные, CRC. Часто данные повторяются несколько раз для надёжности. Понимание этих слоёв (модуляция → кодирование линии → кадр → полезная нагрузка) — то же, что разбор сетевого протокола, только по радио. Инструменты вроде URH автоматизируют распознавание, но при нестандартном сигнале нужен ручной анализ.

## Форматы IQ и преобразования

IQ-записи хранятся в разных форматах: `.cu8` (uint8), `.cs16` (int16), `.cs8`, `.cf32` (float32), а также в формате `rtl_sdr` (uint8 с DC на 127). Важно знать формат **до** анализа: неверный тип искажает спектр. Файлы `gqrx`/`SDR#` используют разные форматы. Для преобразования: `sox`, `csdr`, или numpy. Частота дискретизации (`-s`) и центральная частота (`-f`) хранятся в имени файла или в отдельном метафайле (`SDR#` `.wav` с `iq`). Без них запись неоднозначна — при демодуляции придётся подбирать.

Полезные преобразования: децимация (уменьшение частоты), фильтрация (убрать соседние сигналы), сдвиг частоты (перенести сигнал в ноль). В `csdr` это конвейеры: `csdr convert_s16_f | csdr fir_decimate_cc 4`.

## Разбор ошибок и отладка

Если спектр «пустой» — проверьте тип отсчётов и частоту дискретизации; возможно, сигнал за пределами полосы. Если видите симметричные пики — вероятно, зеркальное отражение (комплексное сопряжение); поменяйте знак Q. Если демодуляция даёт случайные биты — неверна символьная скорость или кодирование линии; попробуйте Manchester. Если данные «почти читаемы», но с ошибками — ищите преамбулу и выравнивайте кадр. Сохраняйте промежуточные результаты (спектр, огибающая, биты) — это помогает изолировать слой, где ломается декодирование. И проверяйте DC-спайк: он не сигнал.

## Практический разбор: FSK-сигнал от записи до флага

Дано: `challenge.iq` (int16, 2 МГц), задача — извлечь сообщение.

```python
import numpy as np
raw = np.fromfile('challenge.iq', dtype=np.int16).astype(np.float32)
s = raw[0::2] + 1j*raw[1::2]

# 1. спектр — ищем пики
from scipy import signal
f, Pxx = signal.welch(s, fs=2_000_000, nperseg=4096)
peaks = f[np.argsort(Pxx)[-4:]]
print('peaks', peaks)          # две частоты → FSK
```

Найдя две частоты FSK, демодулируем через мгновенную частоту:

```python
phase = np.unwrap(np.angle(s))
inst = np.diff(phase)/(2*np.pi)*2_000_000
bits = (inst > inst.mean()).astype(int)
# группируем по символьной скорости (например, 1000 бод → 2000 сэмплов/бит)
```

Собираем байты, ищем преамбулу, выравниваем кадр. Если данные «почти читаемы» — подберите символьную скорость и кодирование линии (Manchester). В URH то же самое делается интерактивно: выбираете сигнал, задаёте модуляцию/скорость, получаете биты и текст. Для OOK используйте огибающую (`np.abs`) с порогом. Сохраняйте промежуточные результаты — это помогает изолировать слой, где ломается декодирование.
