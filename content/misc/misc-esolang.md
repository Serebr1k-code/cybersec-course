## Вопрос, с которого всё начинается

Тебе дали файл `prog` без расширения. Открываешь — а там строка из символов `+`, `-`, `<`, `>`, `[`, `]`, `.`, `,`. На код это не похоже, на шифр тоже. Что это?

Это **эзотерический язык программирования** (esolang) — язык, созданный ради эксперимента или шутки. В CTF они встречаются как задачи «исполни этот мусор»: непонятная строка оказывается программой, которая печатает флаг. Весь урок — на одном файле `prog`, а в конце мы научимся узнавать и другие такие языки по алфавиту.

## Наш пример: файл prog

Сначала — как всегда, определяем тип:

```
$ file prog
prog: ASCII text, with no line terminators
```

Обычный текст. Смотрим содержимое:

```
$ cat prog
++++++++[>++++[>++>+++>+++>+<<<<-]>+>+>->>+[<]<-]>>.>---.+++++++..+++.>>.<-.<.+++.------.--------.>>+.>++.
```

Алфавит ровно из восьми символов: `+ - < > [ ] . ,`. Ничего лишнего. Это сигнатура **Brainfuck** — самого известного esolang.

## Шаг 1: как устроен Brainfuck

Brainfuck работает с **лентой** — массивом ячеек (обычно байтов), и **указателем** на текущую ячейку. Восемь команд:

| Команда | Действие |
|---------|----------|
| `>` | сдвинуть указатель вправо |
| `<` | сдвинуть указатель влево |
| `+` | увеличить текущую ячейку на 1 |
| `-` | уменьшить текущую ячейку на 1 |
| `.` | вывести текущую ячейку как символ |
| `,` | прочитать символ в текущую ячейку |
| `[` | если ячейка = 0, прыгнуть за парную `]` |
| `]` | если ячейка ≠ 0, прыгнуть назад к парной `[` |

Всё остальное в файле — комментарии, их можно выбрасывать. Программа «Hello World!» на Brainfuck выглядит ровно как наш `prog` — набор плюсов и циклов `[...]`.

## Шаг 2: запускаем интерпретатор

Есть готовые интерпретаторы (`bf`, `beef`), но проще написать свой — это 20 строк на Python. Вот полный код:

```python
import sys
code = [c for c in open('prog').read() if c in '><+-.,[]']
tape = [0] * 30000
p = 0
stack = []
i = 0
while i < len(code):
    c = code[i]
    if c == '>': p += 1
    elif c == '<': p -= 1
    elif c == '+': tape[p] = (tape[p] + 1) % 256
    elif c == '-': tape[p] = (tape[p] - 1) % 256
    elif c == '.': sys.stdout.write(chr(tape[p]))
    elif c == ',': tape[p] = ord(sys.stdin.read(1) or '\0')
    elif c == '[' and tape[p] == 0:
        d = 1
        while d:
            i += 1
            d += (code[i] == '[') - (code[i] == ']')
    elif c == ']' and tape[p] != 0:
        d = 1
        while d:
            i -= 1
            d += (code[i] == ']') - (code[i] == '[')
    i += 1
```

Запускаем:

```
$ python3 bf.py
Hello World!
```

Мы получили `Hello World!` — значит, интерпретатор верный. В реальной задаче тот же `prog` печатает флаг. Секрет в том, что все эти плюсы и циклы — просто способ собирать числа и выводить символы; читать их глазами не нужно, нужен исполнитель.

## Шаг 3: как отличить один esolang от другого

Ключ — **алфавит символов**. Разные языки используют разные наборы:

| Язык | Признак (алфавит) | Чем запускать |
|------|-------------------|---------------|
| Brainfuck | `+ - < > [ ] . ,` | `bf`, свой интерпретатор |
| JSFuck | только `[ ] ( ) ! +` | `node prog.js` |
| Ook! | слова `Ook. Ook? Ook!` | конвертировать в Brainfuck |
| Whitespace | пробелы, табы, переводы строк | ws-интерпретатор |
| Piet | картинка (`.png`) | `npiet prog.png` |
| Malbolge | «случайные» символы | malbolge-интерпретатор |

Например, если файл состоит только из `[]()!+` — это **JSFuck**, JavaScript, записанный шестью символами. Он исполняется обычным движком:

```
$ node prog.js
```

А если файл выглядит пустым, но `xxd` показывает пробелы и табы — это **Whitespace**, у которого весь код «невидим»:

```
$ xxd prog | head -2
00000000: 2020 0909 2020 2009 0a20 2009 2009 2009   ..   .. . . .
```

Видим байты `20` (пробел), `09` (таб), `0a` (перевод строки) — три символа, из которых состоит Whitespace.

## Шаг 4: визуальные и «невозможные» языки

Два особых случая:

- **Piet** — программа это картинка; команды кодируются переходами между цветными блоками. Запускается интерпретатором `npiet prog.png`.
- **Malbolge** — язык, специально созданный, чтобы на нём было почти невозможно писать. Задачи на него решают готовым интерпретатором, а не написанием кода.

Для Ook! есть простое правило: это Brainfuck словами. Пары токенов заменяются на команды (`Ook. Ook.` = `>`, `Ook? Ook.` = `+` и т.д.), после чего исполняется как обычный Brainfuck.

## Шаг 5: что делать, если язык неизвестен

Общий алгоритм:

1. **Соберите алфавит** символов в файле (`xxd`, `python3 -c 'print(set(open("prog").read()))'`).
2. **Сопоставьте** с таблицей выше.
3. **Возьмите интерпретатор** (готовый или свой).
4. **Запустите** и прочитайте вывод.
5. Если не запускается — **прочитайте условие**: язык и ссылка на интерпретатор часто указаны прямо там.

Если вывод оказался байтами, а не текстом, — сохраните его в файл и проверьте `file`: возможно, это картинка или архив.

## Если не сработало

Эзотерические языки специально сделаны неудобными. Разберём.

**Brainfuck-программа не даёт вывод.** Проверь баланс скобок `[` и `]` — частая ошибка. Убедись, что интерпретатор читает ввод там, где ожидается (`,`), — иначе он ждёт данные. Ограничь время: некоторые программы зациклены.

**Язык не определяется.** Сигнатуры: Brainfuck — только `+-<>[].,`; Whitespace — пробелы, табы, переносы; Ook — пары `Ook.`; JSFuck — `[]()!+`. Если символы смешанные — возможно, это **полиглот** или кастомный язык. Ищи интерпретатор по характерным токенам.

**Интерпретатор не найден.** Многие esolang имеют публичные реализации (esolangs.org, GitHub). Если язык кастомный — придётся разобрать его семантику по условию задачи или по коду интерпретатора (часто приложен).

**Визуальный язык (Piet) не читается.** Piet — программа-картинка, где цвет задаёт команду, а переходы между цветами — движение. Нужен Piet-интерпретатор. Если картинка выглядит как шум, проверь палитру и размер блока (codel size).

**Программа требует нестандартных расширений.** Некоторые диалекты Brainfuck добавляют команды (например, `#` для отладки) или меняют размер ячейки (8 vs 16 бит). Пробуй разные интерпретаторы — результат может отличаться.

**Обфускация поверх esolang.** Код может быть дополнительно закодирован (Whitespace внутри текста, Brainfuck через символы). Сначала сними внешний слой, потом запускай.

## Частые вопросы

**Зачем существуют эзотерические языки?** Как упражнение, шутка или головоломка. В CTF их используют, потому что они ломают привычные инструменты анализа.

**Brainfuck — это Turing-полный язык?** Да. На нём можно написать любую программу, хотя это крайне неудобно.

**Как быстро прочитать Brainfuck?** Автоматически: интерпретатор плюс трассировка. Руками — только короткие фрагменты. Часто проще дать программе выполниться и посмотреть вывод.

**Что делать с незнакомым языком?** Найди его спецификацию (esolangs.org), определи алфавит и семантику, напиши или найди интерпретатор. Если приложен код интерпретатора — читай его, там вся семантика.

## Порядок разбора esolang

Сначала определи язык по алфавиту: только `+-<>[].,` — Brainfuck; пробелы/табы/переносы — Whitespace; пары `Ook.` — Ook!; `[]()!+` — JSFuck. Затем найди интерпретатор (esolangs.org, GitHub) или используй онлайн-эмулятор. Прогони программу с ограничением времени и памяти — эзотерические языки легко зацикливаются.

Если язык кастомный и интерпретатор не найден, разбирай семантику по коду интерпретатора, приложенному к задаче, — там вся правда. Проверь, не обфусцирован ли код поверх esolang (закодирован, разбит на части), и сними внешний слой. И помни: часто цель — просто получить вывод программы (флаг), а не понять её логику целиком; не углубляйся без нужды.

## Что мы теперь знаем

По-простому:

1. Esolang — это программа, замаскированная под «мусор».
2. Язык определяется по **алфавиту символов**, а не по смыслу.
3. Brainfuck (8 команд) — самый частый; для него легко написать интерпретатор.
4. JSFuck, Ook!, Whitespace, Piet, Malbolge узнаются по своим наборам символов.
5. Вручную писать на esolang не нужно — нужен правильный исполнитель.

## На что смотреть дальше

- **Не теряйте символы при копировании** — Brainfuck чувствителен к каждому знаку.
- **Смотрите условие задачи** — там почти всегда подсказка про язык.
- **«Невидимые» языки проверяйте через `xxd`** — пробелы и табы видны только в байтах.
- **Программа «висит»** — значит ждёт ввод (`,`); подайте данные.
- **Вывод — байты** — сохраните в файл и определите тип через `file`.
