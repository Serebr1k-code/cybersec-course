## Что такое эзотерические языки

Эзотерические языки программирования (esolang) — это языки, созданные ради эксперимента или шутки: brainfuck, JSFuck, Ook!, Whitespace, Malbolge, Piet, Befunge. В CTF они появляются как задачи «исполни этот мусор». Строка из плюсов и минусов, последовательность эмодзи или картинка оказываются программой, которая печатает флаг. Цель модуля — научиться распознавать и исполнять esolang-код, а при необходимости — писать на нём.

## Brainfuck

Самый известный esolang. Восемь команд: `>` (вправо), `<` (влево), `+` (инкремент), `-` (декремент), `.` (вывод), `,` (ввод), `[` (начало цикла), `]` (конец цикла). Всё остальное — комментарии.

```brainfuck
++++++++[>++++[>++>+++>+++>+<<<<-]>+>+>->>+[<]<-]>>.>---.+++++++..+++.>>.<-.<.+++.------.--------.>>+.>++.
```

Это «Hello World!». Исполнить можно любым интерпретатором:

```bash
python3 -c "print('команды')"   # или использовать готовый bf-интерпретатор
```

Быстрый интерпретатор на Python:

```python
import sys
code = open('prog.bf').read()
code = [c for c in code if c in '><+-.,[]']
tape = [0]*30000; p = 0
stack = []; i = 0
while i < len(code):
    c = code[i]
    if c == '>': p += 1
    elif c == '<': p -= 1
    elif c == '+': tape[p] = (tape[p]+1) % 256
    elif c == '-': tape[p] = (tape[p]-1) % 256
    elif c == '.': sys.stdout.write(chr(tape[p]))
    elif c == ',': tape[p] = ord(sys.stdin.read(1) or '\0')
    elif c == '[' and tape[p] == 0:
        depth = 1
        while depth:
            i += 1
            if code[i] == '[': depth += 1
            elif code[i] == ']': depth -= 1
    elif c == ']' and tape[p] != 0:
        depth = 1
        while depth:
            i -= 1
            if code[i] == ']': depth += 1
            elif code[i] == '[': depth -= 1
    i += 1
```

## JSFuck

JSFuck — это JavaScript, записанный всего шестью символами: `[]()!+`. Он исполняется обычным движком JS:

```javascript
[][(![]+[])[+[]]+([![]]+[][[]])[+!+[]+[+[]]]+(![]+[])[!+[]+!+[]]+...]()
```

Исполнить можно прямо в Node.js:

```bash
node prog.js
```

Если код в файле — просто запустите его движком. Для декодирования в читаемый вид есть онлайн-декодеры, но обычно достаточно выполнить.

## Ook!

Ook! — brainfuck, записанный словами `Ook.`, `Ook?`, `Ook!`. Три токена соответствуют парам команд bf:

- `Ook. Ook.` = `>`
- `Ook. Ook?` = `<`
- `Ook? Ook.` = `+`
- `Ook? Ook?` = `-`
- `Ook! Ook!` = `.`
- `Ook! Ook.` = `,`
- `Ook! Ook?` = `[`
- `Ook? Ook!` = `]`

Конвертируйте в brainfuck и исполняйте.

## Whitespace

Whitespace использует только пробелы, табуляции и переводы строк — весь остальной текст игнорируется. Программа выглядит пустой. Сложность — в том, что код «невидим». Используйте интерпретатор Whitespace (есть реализации на многих языках) или онлайн-инструменты.

## Piet

Piet — язык, где программа — это изображение, а «команды» кодируются цветами соседних блоков. Задача часто даёт картинку и просит исполнить её как Piet. Нужен Piet-интерпретатор (например `npiet`).

```bash
npiet prog.png
```

## Malbolge и другие

Malbolge — язык, специально созданный, чтобы на нём было почти невозможно программировать. Задачи на него обычно решаются готовыми интерпретаторами, а не написанием кода. Аналогично — Befunge (двумерный стековый язык), INTERCAL, Shakespeare. Для каждого есть готовый интерпретатор.

## Как определять язык

- **Только `+-<>[].,`** → brainfuck.
- **Только `[]()!+`** → JSFuck.
- **Слова `Ook`** → Ook!.
- **Только пробелы/табы/переводы строк** → Whitespace.
- **Картинка** → Piet.
- **Странные символы/эмодзи** → возможно, свой мини-язык из условия.

Всегда читайте условие: часто там указан язык или дана ссылка на интерпретатор.

## Типичные ошибки и подводные камни

- **Считать «мусор» неисполнимым** — это программа.
- **Терять символы при копировании** — brainfuck чувствителен к каждому символу.
- **Неверная версия интерпретатора** — поведение может отличаться.
- **Забыть про ввод** — некоторые программы ждут данные (`,`).
- **Игнорировать условие** — там подсказка про язык.
- **Пытаться писать на Malbolge вручную** — используйте интерпретатор.
- **Whitespace «невидим»** — используйте `xxd`, чтобы увидеть пробелы/табы.

## Справочная таблица

| Язык | Признак | Запуск |
|------|---------|--------|
| Brainfuck | `+-<>[].,` | bf-интерпретатор |

| Ook! | `Ook. Ook?` | конвертировать в bf |

## Что дальше / решение

План: определите язык по набору символов, возьмите готовый интерпретатор и запустите программу. Для brainfuck при необходимости напишите свой интерпретатор (шаблон выше) или используйте конвертеры. Для «невидимых» языков смотрите байты через `xxd`. Не пытайтесь писать на esolang вручную — это редко нужно. Всегда читайте условие: язык и подсказки часто указаны прямо. Навык здесь — не программирование на экзотике, а быстрое распознавание и правильный инструмент запуска.

## Практический пример: распознаём язык по символам

Разберём задачу. Дана строка `+++++[>++++[>++>+++>+++>+<<<<-]>+>+>->>+[<]<-]>>.>---.` — набор из плюсов, минусов и скобок. Однозначно brainfuck. Берём интерпретатор, исполняем — получаем «Hello World!». Но задача даёт не текст, а последовательность, которая после исполнения печатает флаг. Запускаем bf-интерпретатор (свой или готовый) — получаем флаг.

Другой пример: файл содержит `[]()!+` и ничего больше — это JSFuck. Запускаем `node prog.js`, флаг печатается. Третий: файл выглядит пустым, но `xxd` показывает пробелы и табы — это Whitespace. Четвёртый: дана картинка — это Piet, запускаем `npiet`.

Общий алгоритм: определите язык по алфавиту символов, возьмите интерпретатор, запустите. Если интерпретатора нет — напишите минимальный (для brainfuck это 30 строк, см. основной текст).

## Где брать интерпретаторы

Онлайн-интерпретаторы удобны для быстрой проверки, но в CTF лучше иметь локальные: `bf`/`beef` для brainfuck, `node` для JSFuck, `ws` для Whitespace, `npiet` для Piet, `malbolge` для Malbolge. Для Ook! сначала конвертируйте в brainfuck (правило замены простое). Для Befunge — `bef` или `cfunge`.

## Частые вопросы

«Что если язык неизвестен?» — читайте условие, там почти всегда подсказка. «Как отличить JSFuck от обычного JS?» — по алфавиту: только шесть символов. «Почему программа «висит»?» — brainfuck с вводом ждёт данные; подайте их. «Что если вывод — байты?» — сохраните в файл и проверьте `file`.

## Что дальше / решение

Итог: распознайте язык по набору символов, возьмите готовый интерпретатор и запустите программу. Для brainfuck держите под рукой собственный интерпретатор или конвертер. Не пишите на esolang вручную — это редко требуется. Навык здесь — быстрое распознавание и правильный инструмент, а не владение экзотическим синтаксисом.
