## Вопрос, с которого всё начинается

В misc почти всегда упираешься в одно: нужно что-то преобразовать — декодировать, посчитать, распарсить, отправить по сети. Делать это руками больно, а инструмента под конкретную задачу нет. Что тогда?

Ответ — написать короткий скрипт на Python. Это главный инструмент misc-решателя: 90% задач решаются несколькими строками. В этом уроке мы соберём набор шаблонов, которые переиспользуются снова и снова.

## Наш пример: задача с данными

Допустим, в задаче дан файл `data.txt`, внутри которого строка в неизвестной кодировке, а рядом лежит URL, куда надо отправить результат. Мы решим её целиком скриптом.

## Шаг 1: читаем файл

Первое — прочитать данные:

```python
with open("data.txt") as f:
    data = f.read().strip()
print(data)
```

```
ZmxhZ3tweXRob25fMXNfMXNzMXN0YW50fQ==
```

`strip()` убирает переводы строки в конце. Мы получили строку, похожую на Base64. Дальше — декодировать.

## Шаг 2: кодировки

```python
import base64
decoded = base64.b64decode(data).decode()
print(decoded)
```

```
flag{python_1s_1ss1stant}
```

Модуль `base64` умеет `b64decode`, `b64encode`, а также `b32`, `b16`. Если данных несколько слоёв, оборачивайте декодирование в цикл, пока результат не перестанет меняться.

Полезно уметь быстро распознавать кодировки:

| Кодировка | Модуль Python |
|-----------|---------------|
| Base64 | `base64.b64decode` |
| Base32 | `base64.b32decode` |
| Hex | `bytes.fromhex` |
| URL | `urllib.parse.unquote` |

## Шаг 3: HTTP через requests

Если флаг надо отправить на сервер, используют `requests`:

```python
import requests
r = requests.post("http://target/check", data={"flag": decoded})
print(r.status_code, r.text)
```

```
200 Correct!
```

`requests` избавляет от ручной сборки HTTP: сессии, cookies, заголовки, JSON — всё одной строкой. Для перебора параметров удобно оборачивать вызов в цикл.

## Шаг 4: сокеты

Иногда сервис не HTTP, а «сырой» TCP. Тогда — модуль `socket`:

```python
import socket
s = socket.create_connection(("target", 1337))
print(s.recv(1024).decode())      # читаем приглашение
s.sendall(b"hello\n")             # отправляем строку
print(s.recv(1024).decode())      # читаем ответ
```

Так общаются с pwn-подобными и misc-сервисами, которые ждут данные на порту. Для удобства часто пишут обёртку с `recvuntil`.

## Шаг 5: работа с байтами и struct

Когда данные бинарные, поля читают модулем `struct`:

```python
import struct
raw = open("data.bin", "rb").read()
magic, size = struct.unpack("<4sI", raw[:8])
print(magic, size)
```

`<4sI` означает: little-endian, 4 байта как строка, затем 4-байтовое целое. Так разбирают бинарные форматы, когда под рукой нет готового парсера.

## Шаблоны, которые переиспользуются

Держите этот набор под рукой:

- **Чтение/запись файлов:** `open(..., "rb"/"wb")`.
- **Кодировки:** `base64`, `bytes.fromhex`, `urllib.parse`.
- **HTTP:** `requests.get/post`.
- **TCP:** `socket.create_connection`.
- **Бинарные данные:** `struct.unpack`.
- **Регулярки:** `re.findall(r"...", text)`.
- **Перебор:** `itertools`, `for` + `tqdm` для прогресса.

## Полный разбор от начала до конца

Собираем всё вместе. Есть `data.txt` → читаем → Base64 → флаг → отправляем POST → сервер отвечает «Correct». Три шага, десять строк кода.

Если бы кодировок было несколько (например, Base64 от hex), добавили бы цикл: декодируем, пока результат остаётся «закодированным». Именно так и решается большинство misc-задач.

## Почему именно Python

Python удобен для misc по трём причинам. Во-первых, он читается как псевдокод — писать быстро. Во-вторых, в стандартной библиотеке уже есть всё для кодировок, сокетов, структур и регулярных выражений. В-третьих, готовые модули (`requests`, `pycryptodome`, `pwntools`) закрывают типовые задачи. Наконец, скрипт легко менять на ходу, а в CTF условия меняются постоянно.

## Как запускать скрипты

Скрипт — обычный файл `.py`. Запуск: `python3 solve.py`. Для интерактивной работы есть REPL (`python3` без аргументов) — удобно проверять гипотезы по одной строке. Виртуальное окружение изолирует зависимости:

```bash
$ python3 -m venv venv && source venv/bin/activate
$ pip install requests pwntools
$ python3 solve.py
```

## Частые ошибки новичков

- **Забыть про режим файла.** `open()` по умолчанию текстовый; для бинарных данных нужен `"rb"`.
- **Смешать `str` и `bytes`.** В Python 3 это разные типы: `b"abc"` и `"abc"` не складываются.
- **Игнорировать исключения.** Оберните рискованный код в `try/except`, чтобы скрипт не падал на середине.
- **Писать монолит.** Разбейте на функции — легче менять.

## Полный скрипт целиком

Соберём всё в один файл `solve.py`:

```python
import base64, requests

data = open("data.txt").read().strip()
flag = base64.b64decode(data).decode()
r = requests.post("http://target/check", data={"flag": flag})
print(r.status_code, r.text)
```

Запуск: `python3 solve.py` → `200 Correct!`. Это шаблон, из которого меняют только способ декодирования и адрес.

## Работа с регулярками на практике

Регулярные выражения (`re`) — ещё один обязательный инструмент. Ими вытаскивают флаги и поля из текста:

```python
import re
text = "user=admin token=abc123 status=ok"
m = re.search(r"token=(\w+)", text)
print(m.group(1))
```

```
abc123
```

`\w+` означает «одна или несколько букв/цифр». `re.findall` возвращает все совпадения сразу — удобно для парсинга логов и дампов.

## Автоматизация перебора

Когда задача требует перебрать варианты, помогает `itertools`:

```python
import itertools
for combo in itertools.product("abc", repeat=3):
    print("".join(combo))
```

Это выдаст все комбинации из трёх символов. Так решают задачи с короткими паролями и перестановками.

## Что делать, когда скрипт «зависает»

Частая проблема — сетевой вызов без таймаута ждёт вечно. Всегда указывайте `timeout`:

```python
requests.get(url, timeout=5)
```

Для сокетов задавайте `s.settimeout(5)`. Если сервис отвечает медленно — увеличивайте, но не бесконечно.

## Как читать чужие скрипты

В CTF часто дают чужой скрипт (`chall.py`) и просят найти слабое место или предсказать выход. Читайте его сверху вниз, отмечая: откуда берутся данные, как преобразуются, что сравнивается с флагом. Часто уязвимость в предсказуемом генераторе случайных чисел или в сравнении строк.

Умение читать код так же важно, как писать. Оно пригодится не только в misc, но и в reversing и crypto.

## Полезные готовые модули

За пределами стандартной библиотеки:

- **`requests`** — HTTP-запросы.
- **`pwntools`** — сетевые сервисы, упаковка чисел, hexdump.
- **`pycryptodome`** — криптография (AES, RSA).
- **`z3-solver`** — решение логических уравнений.
- **`pillow`** — работа с изображениями.

Ставятся через `pip install`. Эти пять модулей покрывают почти всё.

## Где брать шаблоны

Не пишите с нуля. Сохраняйте удачные скрипты в личную папку и копируйте заготовки: чтение и декодирование файла, отправку HTTP, общение с TCP-сервисом, разбор бинарного формата. Через месяц такой «карман» станет вашей главной скоростью на CTF.

## Что мы теперь знаем

По-простому:

1. Python — главный инструмент misc.
2. Кодировки — через `base64`, `bytes.fromhex`, `urllib`.
3. HTTP — через `requests`, сырой TCP — через `socket`.
4. Бинарные данные — через `struct`.
5. Один короткий скрипт закрывает почти любую задачу.

## На что смотреть дальше

- **Начинайте с чтения данных.** Сначала поймите, что на входе.
- **Оборачивайте декодирование в цикл.** Слоёв может быть несколько.
- **Не изобретайте HTTP.** `requests` уже всё умеет.
- **Сохраняйте шаблоны.** Личная библиотека скриптов экономит часы.
