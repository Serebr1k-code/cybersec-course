## Вопрос, с которого всё начинается

В CTF всё чаще дают задачу: «вот вектор состояния квантовой схемы — найди флаг». Ты открываешь файл, видишь набор комплексных чисел и не понимаешь, при чём тут безопасность. На самом деле всё просто: квантовые вычисления — это линейная алгебра над вероятностями, и именно из-за неё рушится часть современной криптографии.

## Наш пример: состояние из двух кубитов

Пусть у нас есть файл `state.txt` с амплитудами четырёх базисных состояний:

```
$ cat state.txt
00 0.70710678+0.00000000j
01 0.00000000+0.00000000j
10 0.00000000+0.00000000j
11 0.70710678+0.00000000j
```

Читаем: с вероятностью 50% измерение даст `00` и с вероятностью 50% — `11`. Это знакомое состояние Белла — максимально запутанная пара.

## Шаг 1: кубит, амплитуда, вероятность

Классический бит — это 0 или 1. Кубит до измерения описывается парой комплексных чисел (a, b) — **амплитуд**. Квадрат модуля амплитуды даёт вероятность:

```
P(0) = |a|^2,   P(1) = |b|^2,   |a|^2 + |b|^2 = 1
```

Важно: нельзя «увидеть» a и b, пока не измеришь. Измерение **коллапсирует** состояние — после него кубит становится обычным битом. Именно поэтому квантовые вычисления нельзя просто «прочитать»: любое чтение портит ответ, и алгоритмы строят так, чтобы нужный результат получался с высокой вероятностью.

Для двух кубитов базис — `00, 01, 10, 11`, а состояние — вектор из четырёх амплитуд. Правило вероятности то же: складываем квадраты модулей всех амплитуд, получаем 1.

## Шаг 2: гейты — это матрицы

Квантовый **гейт** — это унитарная матрица, которая линейно преобразует вектор амплитуд. Разберём три, которых хватает для большинства CTF-задач.

Гейт X (квантовое NOT) переставляет амплитуды:

```
X = [[0,1],[1,0]]      X|0> = |1>,  X|1> = |0>
```

Гейт Адамара H создаёт равную суперпозицию:

```
H = 1/sqrt(2) * [[1,1],[1,-1]]     H|0> = (|0>+|1>)/sqrt(2)
```

Гейт CNOT запутывает два кубита: он меняет второй, если первый равен 1. Из `H` на первом кубите и `CNOT` получается ровно наше состояние Белла `(|00>+|11>)/sqrt(2)` — то, что лежит в `state.txt`.

Полезно запомнить: последовательность гейтов = произведение матриц, а измерение — вытягивание одного индекса по вероятностям.

## Шаг 3: чем это опасно для криптографии

Два алгоритма определяют всю повестку:

**Алгоритм Shor** решает задачу факторизации и дискретного логарифма за полиномиальное время. RSA ломается, потому что стойкость RSA = сложность факторизации. ECC ломается, потому что стойкость ECC = сложность дискретного логарифма в группе точек.

**Алгоритм Grover** даёт квадратичное ускорение поиска: перебор ключа длиной n бит требует не 2^n, а примерно 2^(n/2) операций. AES-128 становится как AES-64 по стойкости, поэтому рекомендуют удвоить длину ключа.

Отсюда термин **store now, decrypt later**: перехваченный сегодня трафик можно расшифровать через 10–20 лет, когда появится достаточно большой квантовый компьютер. Поэтому PQC внедряют заранее, не дожидаясь угрозы.

## Шаг 4: пост-квантовые семейства

Пост-квантовая криптография (PQC) — схемы, для которых не известен эффективный квантовый алгоритм. Основные семейства:

| Семейство | Идея | Пример |
|---|---|---|
| Решётки | задача LWE/SVP | Kyber (ML-KEM), Dilithium (ML-DSA) |
| Коды | декодирование случайного кода | Classic McEliece |
| Хеш-подписи | стойкость хеша | SPHINCS+ (SLH-DSA) |
| Многомерные | системы квадратичных уравнений | Rainbow (сломан) |
| Изогении | изогении эллиптических кривых | SIKE (сломан) |

Обратите внимание: два последних семейства уже пали. Это хороший урок — «пост-квантовая» не значит «непробиваемая».

## Полный прогон: считаем вероятности измерения

Вернёмся к `state.txt`. Считаем квадраты модулей:

```
$ python3 - <<'PY'
for line in open('state.txt'):
    basis, amp = line.split()
    a = complex(amp)
    print(basis, round(abs(a)**2, 4))
PY
00 0.5
01 0.0
10 0.0
11 0.5
```

Вероятности `00` и `11` равны 0.5, остальные — нулю. Значит, измерение даст либо `00`, либо `11` с равным шансом, и никогда `01`/`10`. Это сигнатура запутанности: кубиты коррелированы.

## Инструменты: Qiskit и Cirq

В реальных задачах схемы не пишут руками — их собирают в симуляторе:

```
$ python3 -c "from qiskit import QuantumCircuit; qc=QuantumCircuit(2); qc.h(0); qc.cx(0,1); print(qc)"
     ┌───┐
q_0: ┤ H ├──■──
     └───┘┌─┴─┐
q_1: ─────┤ X ├
          └───┘
```

`qc.h(0)` — Адамар на первом кубите, `qc.cx(0,1)` — CNOT. Запуск `qiskit_aer` с 1000 выстрелами вернёт примерно `{'00': 500, '11': 500}`. Так проверяют, что схема делает задуманное, до всякой криптографии.

## Что мы теперь знаем

- Кубит описывается амплитудами; вероятность измерения — квадрат модуля.
- Гейты — это унитарные матрицы; CNOT+H дают запутанность.
- Shor ломает RSA/ECC, Grover ускоряет перебор вдвое по битам.
- PQC заменяет уязвимые схемы; часть кандидатов уже сломана.

## Шаг 5: интерференция — откуда берётся верный ответ

Если бы квантовый компьютер просто «пробовал все варианты параллельно», он был бы бесполезен: при измерении мы получили бы случайный вариант из миллиарда. Польза появляется из **интерференции**. Амплитуды — комплексные числа, и они умеют складываться с разными знаками. Отрицательная амплитуда «гасит» положительную, и вероятность такого исхода падает до нуля.

Квантовые алгоритмы строят так, чтобы амплитуды неверных ответов взаимно уничтожились, а амплитуда верного — сложилась. Это и есть «фокус»: не перебор, а вычитание неверного. Гейт Адамара — главный инструмент интерференции: два его применения возвращают исходное состояние (`H·H = I`), потому что знаки аккуратно сокращаются.

## Кратко про запутанность и телепортацию

**Запутанность** — корреляция сильнее любой классической. В состоянии `(|00>+|11>)/sqrt(2)` кубиты не имеют индивидуальных значений: измерение одного мгновенно определяет другой. Это не «сигнал быстрее света» — передать информацию так нельзя, потому что результат измерения одного случаен.

**Квантовая телепортация** переносит состояние кубита, используя запутанную пару и два классических бита. Обратите внимание: классический канал обязателен. Телепортация не нарушает теорию относительности, но показывает, насколько запутанность — реальный ресурс.

## Чем квантовые вычисления НЕ являются

Полезно развеять мифы, потому что в CTF на них ловят:

- Это **не** «мгновенный перебор всех паролей». Grover даёт лишь квадратичное ускорение.
- Это **не** замена классических компьютеров. Квантовый компьютер хорош для узкого класса задач (факторизация, поиск периода, симуляция молекул).
- Это **не** «магия с нулевыми ошибками». Кубиты декогерируют, нужна коррекция ошибок, и это главный инженерный барьер.

Понимание этих границ помогает отличать реальную угрозу (RSA) от шумихи (взлом AES-256 за секунды).

## Шпаргалка по обозначениям

| Символ | Значение |
|---|---|
| `|0>`, `|1>` | базисные состояния |
| `a`, `b` | комплексные амплитуды |
| `|a|^2` | вероятность исхода |
| `H` | Адамар: создаёт суперпозицию |
| `X` | квантовое NOT |
| `CNOT` | управляемое отрицание |
| `s·x mod 2` | скалярное произведение по GF(2) |

## Разбираем ещё одну схему: состояние GHZ

Трёхкубитное состояние `(|000>+|111>)/sqrt(2)` называется **GHZ**. Оно строится так же, как пара Белла, только CNOT применяют к двум кубитам сразу:

```
$ python3 - <<'PY'
from qiskit import QuantumCircuit
from qiskit.quantum_info import Statevector
qc = QuantumCircuit(3)
qc.h(0); qc.cx(0,1); qc.cx(0,2)
print(Statevector(qc).probabilities_dict())
PY
{'000': 0.5, '111': 0.5}
```

Вероятности `001`, `010`, `100` и их соседей равны нулю. Если вы видите такой результат, перед вами GHZ: все три кубита «согласованы». Именно по такому признаку в CTF опознают запутанность.

## Как читать CTF-условие про кванты

В условии почти всегда есть один из четырёх маркеров, и от него зависит план:

- **Дан вектор состояния** (набор амплитуд) — считайте квадраты модулей и берите индекс по подсказке.
- **Даны матрицы гейтов** — перемножьте их справа налево, начиная с вектора `|0...0>`.
- **Дана схема словами** («H на первом, CNOT на второй») — соберите её в Qiskit и получите counts.
- **Даны только counts** — восстановите схему: какие исходы невозможны, какая у них частота.

Полезно сразу спросить себя: «какие исходы запрещены?» Запрещённые исходы — самый быстрый путь к структуре схемы.

## Частые ошибки при подсчёте вероятностей

Четыре ловушки, на которых теряют время:

- Забыть про нормировку. Сумма `|a|^2` обязана быть 1; если нет — вы потеряли слагаемое.
- Складывать **амплитуды** там, где нужно складывать вероятности. Интерференция работает только до измерения; после — это обычная классическая статистика.
- Перепутать базисы. Состояние `|+>` в Z-базисе даёт 50/50, но в X-базисе — детерминированный исход.
- Игнорировать фазу. Глобальная фаза невидима, но относительная фаза между слагаемыми определяет интерференцию.

## Полный прогон: от файла к флагу

Итоговый маршрут по такой задаче выглядит так: открыть `state.txt`, убедиться, что амплитуд ровно `2^n`, посчитать вероятности, найти ненулевые индексы, сопоставить их с метками и записать результат в `found.txt`. Каждый шаг проверяем глазами: сумма вероятностей равна единице, число ненулевых исходов согласуется со степенью запутанности.
