## Что такое misc и почему это «сборная солянка»

Misc (от англ. *miscellaneous* — «разное») — это категория CTF-задач, которые не относятся ни к web, ни к pwn, ни к crypto, ни к forensics в чистом виде. Сюда попадает всё, что проверяет не владение конкретным инструментом, а **смекалку, общую техническую эрудицию и умение быстро писать скрипты**. Именно поэтому misc одновременно самая простая и самая непредсказуемая категория: иногда флаг лежит в открытом виде в метаданных, а иногда нужно написать солвер для нестандартной логики на 200 строк.

Ключевая особенность: в misc **нет универсального эксплойта**. Есть набор паттернов и отработанный процесс разведки. Ваша задача — за первые 2–3 минуты понять, *к какому классу* относится задача, и применить соответствующий инструмент.

## Классификация задачи за 3 минуты

Первое, что нужно сделать, — определить «жанр». Работает простое дерево решений:

- дана **строка из незнакомых символов** → кодировка, эзотерический язык, шифр;
- дан **файл** → смотри `file`, метаданные, энтропию, `strings`;
- дана **программа с чёрным списком** (Python/bash jail) → песочница;
- дан **сервис/бот** → логика, инъекция, rate-limit;
- даны **большие данные** → пиши скрипт (programming);
- дан **`.git`/архив истории** → git-форензика.

Заведите привычку проговаривать вслух: «что я вижу на входе и что требуется на выходе». Формат флага (например `FLAG{...}`, `KubSTU{...}`) часто прямо подсказывает, какой длины и из чего состоит ответ.

## Из чего состоит misc-категория

Типовые подкатегории, которые вы встретите:

- **Кодировки и представления данных** — base64/base32/hex, QR-коды, штрихкоды, ROT, морзянка, «странные» Unicode-символы.
- **Эзотерические языки** — brainfuck, JSFuck, Ook!, Whitespace, Malbolge, Piet. Программа выглядит как мусор, но исполняется.
- **Песочницы и джейлы (jails)** — вам дают интерпретатор Python или bash с чёрным списком, нужно выйти и прочитать флаг.
- **Скриптинг и алгоритмы** — «обработайте 10 ГБ данных и найдите ответ», programming-задачи с автопроверкой.
- **Git-форензика** — история коммитов, удалённые ветки, dangling objects, следы в `.git`.
- **LLM / prompt injection** — чат-бот с секретом в системном промпте, нужно вытащить его через инъекцию.
- **Misc-web и логические задачи** — капчи, обход rate-limit, игры, «найди закономерность».

## Универсальный чек-лист разбора артефакта

Когда задача даёт вам файл или строку и вы не понимаете, что это, идите по списку **сверху вниз** — не пропуская шаги:

1. **Прочитайте условие целиком.** Часто формат флага, подсказка или способ взаимодействия уже описаны. Не игнорируйте текст.
2. **Определите тип файла** — `file <файл>`, `xxd <файл> | head`, `strings -n 6 <файл> | head`.
3. **Проверьте метаданные** — `exiftool <файл>`, `mediainfo`, `binwalk`. Часто флаг лежит прямо в EXIF.
4. **Посмотрите на размер и энтропию** — `ls -l`, `binwalk -E`. Высокая энтропия → сжатие/шифр; низкая → текст/код.
5. **Попробуйте автодекодеры** — CyberChef «Magic», `python -c` с base64/hex, `zsteg`, `steghide`.
6. **Поищите флаг по шаблону** — `grep -a -o 'FLAG{[^}]*}'` или `KubSTU{[^}]*}` по всем распакованным слоям.
7. **Запишите, что уже проверили.** Это важно: misc-задачи любят «слоёный» формат, и без заметок вы забудете, какой слой уже разобрали.

> Совет: держите под рукой **CyberChef** (офлайн-версию) — это швейцарский нож для кодировок. Recipe из операций можно сохранять и переиспользовать.

## Инструментарий первой необходимости

Минимальный набор, который стоит иметь в контейнере:

```bash
# Разбор файлов
file, binwalk, exiftool, strings, xxd, hexdump, mediainfo

# Кодировки и стего
python3, zsteg, steghide, stegseek, foremost, pngcheck

# Сеть и сервисы
nc, socat, curl, httpie, jq, pwntools

# Git-форензика
git, git-filter-repo, trufflehog, gitleaks

# Общее
CyberChef (offline), ripgrep (rg), jq, imagemagick, ffmpeg
```

Проверить, что всё на месте, можно одной командой:

```bash
for t in file binwalk exiftool strings zsteg steghide pngcheck jq rg ffmpeg; do
  command -v "$t" >/dev/null && echo "ok  $t" || echo "MISS $t"
done
```

Вывод:

```
ok  file
ok  binwalk
ok  exiftool
MISS zsteg
ok  steghide
...
```

Отсутствие `zsteg` не критично — LSB-стего можно вытащить и вручную через PIL.

## Рабочий пример: разбор неизвестного файла

Пусть задача дала файл `challenge` без расширения.

```bash
$ file challenge
challenge: Zip archive data, at least v2.0 to extract

$ unzip -l challenge
Archive:  challenge
  Length      Date    Time    Name
---------  ---------- -----   ----
       24  2024-01-01 00:00   flag.png

$ unzip challenge -d out && file out/flag.png
out/flag.png: PNG image data, 200 x 200, 8-bit/color RGB, non-interlaced

$ exiftool out/flag.png | grep -i comment
Comment                         : FLAG{z1p_1n_png_ftw}
```

Здесь сработал принцип «слои»: архив → картинка → метаданные. Не пропускайте промежуточные шаги.

## Как быстро писать скрипты-солверы

Для «данных» задач пригодится каркас на Python:

```python
import sys, re
data = sys.stdin.read()
# 1) извлечь все числа
nums = list(map(int, re.findall(r'-?\d+', data)))
print("count:", len(nums), "sum:", sum(nums), "min/max:", min(nums), max(nums))
# 2) найти аномалии
from statistics import mean, pstdev
m, s = mean(nums), pstdev(nums)
print([n for n in nums if abs(n-m) > 3*s])
```

Такой «статистический фильтр» спасает в задачах «найди подозрительное значение среди миллиона нормальных». Пишите коротко и переиспользуйте.

## Логические и интерактивные задачи

Если задача даёт сервис (`nc host port`), не пытайтесь угадывать вручную — автоматизируйте взаимодействие через `pwntools`:

```python
from pwn import *
io = remote('host', 1337)
for _ in range(50):
    q = io.recvline()
    # простой парсер вопроса
    if b'+' in q:
        a, b = map(int, re.findall(rb'\d+', q)[:2])
        io.sendline(str(a+b).encode())
io.interactive()
```

Главный навык — научиться парсить формат сервиса и отвечать быстрее таймаута.

## Типичные ошибки и подводные камни

- **Игнорирование условия.** Половина «сложных» задач решается чтением текста.
- **Попытка угадать вручную** там, где нужен цикл/скрипт.
- **Забытые слои.** После распаковки архива внутри часто лежит ещё один архив/картинка/бинарь.
- **Работа с бинарём как с текстом.** Используйте `xxd`/`hexdump`, а не `cat`.
- **Потеря гипотез.** Ведите короткий блокнот: что проверили, что осталось.
- **Неверная кодировка при чтении.** Явно указывайте `encoding='utf-8', errors='replace'`.

## Тактика распределения времени на CTF

Классическая ошибка новичка — залипнуть в одну misc-задачу на час. Правило «20 минут»: если нет прогресса — запишите гипотезы, переключитесь на другую задачу, вернитесь со свежим взглядом. На соревновании очки важнее гордости. Также держите параллельно 2–3 задачи из разных категорий: пока одна «варится» в голове, вы продвигаетесь по другой.

## Что дальше / решение

Резюмируем методику:

1. Прочитайте условие → определите жанр задачи по дереву решений.
2. Примените чек-лист разбора артефакта сверху вниз.
3. Держите готовый тулкит и короткие скрипты-каркасы.
4. Автоматизируйте интерактивные сервисы через pwntools.
5. Ведите заметки и соблюдайте правило «20 минут».

Дальше переходите к специализированным модулям: кодировки, эзотерические языки, джейлы, git-форензика, программирование, prompt-injection. Каждый из них — это отдельный «паттерн», который после практики распознаётся за секунды.

## Где пригодится

- **CTF любой сложности** — misc-задачи есть на каждом турнире, часто как «разминочные» за лёгкие очки.
- **Реальный пентест** — навык «разобрать неизвестный артефакт» напрямую применим к анализу дампов, логов, вложений фишинга.
- **Реверс и форензика** — половина их работы начинается с того же чек-листа разбора файла.
- **Автоматизация** — умение быстро написать скрипт на Python экономит часы в любой категории.
