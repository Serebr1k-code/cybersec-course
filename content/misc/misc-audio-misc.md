## Audio-задачи: общий подход

Аудио-задачи выглядят загадочно, но почти всегда сводятся к визуализации или к декодированию известного сигнала. Первый шаг — понять, что это за файл: `file audio.wav`, `ffprobe audio.wav`, `soxi audio.wav`. Дальше — посмотреть на волновую форму и спектрограмму. В спектрограмме текст или картинки часто «нарисованы» — это классический приём CTF: в аудио прячут изображение, которое видно только на спектрограмме. Цель модуля — освоить спектрограммы, DTMF и SSTV.

## Спектрограмма: главный инструмент

Спектрограмма показывает частоты во времени. Инструменты: `sonic-visualiser`, `Audacity` (Analyze → Plot Spectrum / Spectrogram), `sox`, или Python:

```python
import numpy as np
from scipy.io import wavfile
import matplotlib.pyplot as plt
fs, data = wavfile.read('audio.wav')
if data.ndim > 1:
    data = data[:, 0]
plt.specgram(data, Fs=fs, NFFT=1024, noverlap=512)
plt.savefig('spec.png')
```

Откройте `spec.png` — часто там виден текст или флаг.

## DTMF: телефонные тона

DTMF (Dual-Tone Multi-Frequency) — набор двух тонов на каждую цифру телефонной клавиатуры. Задачи «расшифруй набор номера» решаются детектором тонов:

```python
# для каждой цифры — пара частот из таблицы DTMF
# низкие: 697, 770, 852, 941
# высокие: 1209, 1336, 1477, 1633
```

Готовые инструменты: `multimon-ng -a DTMF -t wav audio.wav`. Он выдаёт последовательность цифр. Часто это и есть ответ или часть флага.

## SSTV: картинки по радио

SSTV (Slow-Scan Television) — передача изображений узкополосным сигналом (используется радиолюбителями). В CTF задача даёт запись звука, которую надо декодировать в картинку. Инструмент: `qsstv` (GUI) или `sstv`-декодер. Признак — характерные «пищащие» тона в начале.

## Морзе и другие кодировки

Морзе в аудио декодируется по длительностям тонов: короткий = точка, длинный = тире, паузы разделяют символы и слова. Инструменты: `multimon-ng -a MORSE`, `fldigi`. Для «тонов» можно написать простой детектор по амплитуде.

## Стеганография в аудио

- **LSB в сэмплах** — как в картинках, только по семплам WAV.
- **Спрятанные данные в метаданных** — `exiftool audio.wav`, ID3-теги в MP3.
- **Эхо-стего** — данные в задержках эха.
- **Вложенные файлы** — `binwalk audio.wav`, `foremost`.

## Работа с частотами и фильтрацией

Если сигнал «зашумлён», применяйте фильтры: полосовой фильтр вокруг полезной частоты, подавление шума. В `scipy.signal` есть `butter`, `filtfilt`. Иногда данные закодированы сменой частоты (FSK) — тогда нужен детектор частотных переходов.

## Типичные ошибки и подводные камни

- **Не посмотреть спектрограмму** — половина задач решается ей.
- **Игнорировать метаданные** — там бывает флаг.
- **Не проверить вложенные файлы** — `binwalk`.
- **Неверная частота дискретизации** — читайте её из файла.
- **Моно vs стерео** — данные могут быть во втором канале.
- **Слишком маленький NFFT** — спектрограмма нечитаема; увеличьте.
- **Путать DTMF с морзе** — DTMF это пары тонов, морзе — одиночные.

## Что дальше / решение

План: определите формат, посмотрите спектрограмму (это главное), затем проверьте DTMF/SSTV/морзе, затем LSB и метаданные, затем `binwalk` на вложения. Держите под рукой `multimon-ng`, `sox` и скрипт на matplotlib для спектрограмм. Большинство аудио-задач решаются визуализацией сигнала — если «слышно непонятное», почти наверняка это видно на спектрограмме.

## Практический пример: флаг на спектрограмме

Разберём задачу с аудио. Дают WAV-файл с «писком». Строим спектрограмму:

```python
import numpy as np
from scipy.io import wavfile
import matplotlib.pyplot as plt
fs, data = wavfile.read('audio.wav')
if data.ndim > 1:
    data = data[:, 0]
plt.specgram(data, Fs=fs, NFFT=1024, noverlap=768)
plt.savefig('spec.png')
```

Открываем `spec.png` — и видим нарисованный текст «FLAG{...}». Это классический приём: текст «нарисован» изменением частоты во времени. Если NFFT маленький и картинка нечитаема — увеличиваем NFFT и перекрытие. Если текст тонкий — уменьшаем.

## Практический пример: DTMF

Другой сценарий: запись набора номера. Прогоняем через `multimon-ng -a DTMF -t wav audio.wav` — получаем последовательность цифр, которая и есть ответ или ключ. Если DTMF «шумный» — сначала отфильтруйте полосовым фильтром.

## Что делать, если сигнал странный

Если ни спектрограмма, ни DTMF не дают результата, проверьте: SSTV (`qsstv`), морзе (`multimon-ng -a MORSE`), вложенные файлы (`binwalk`), метаданные (`exiftool`), LSB в сэмплах. Иногда данные закодированы сменой частоты (FSK) или амплитуды — тогда нужен детектор переходов.

## Частые вопросы

«Спектрограмма пустая?» — неверный формат канала или частота; читайте параметры из файла. «Стерео?» — проверьте оба канала, данные могут быть во втором. «Что если это не аудио?» — `file` покажет реальный тип. «Как ускорить?» — используйте `sox` для конвертации и фильтрации.

## Что дальше / решение

Итог: аудио-задачи решаются каскадом — спектрограмма → DTMF/SSTV/морзе → LSB/метаданные → вложенные файлы. Главный инструмент — спектрограмма, поэтому начинайте с неё. Держите под рукой `multimon-ng`, `sox`, `qsstv` и скрипт на matplotlib. Если «слышно непонятное» — почти наверняка это видно на спектрограмме.

## Расширенный чек-лист по аудио-задачам

Пройдите по списку последовательно, пока не найдёте флаг. Первое: `file`, `ffprobe`, `soxi` — определите формат, частоту, каналы. Второе: `exiftool` — метаданные и теги. Третье: спектрограмма (`sox`/`matplotlib`) — визуализируйте сигнал, часто там нарисован текст. Четвёртое: если видите ритмичные тона — проверьте морзе (`multimon-ng -a MORSE`) и DTMF (`multimon-ng -a DTMF`). Пятое: если сигнал похож на «картиночный» — SSTV (`qsstv`). Шестое: LSB в сэмплах и метаданные. Седьмое: `binwalk` — возможно, внутри другой файл. Восьмое: если сигнал зашумлён, примените полосовой фильтр и повторите.

Особое внимание уделяйте каналам: в стереофайле данные часто лежат только в одном канале, а второй — «приманка». Разделите каналы и обработайте каждый отдельно. Также проверяйте скорость воспроизведения: иногда сигнал замедлен или ускорен, и спектрограмма читается только при правильной скорости. Если задача даёт «звук» без файла (поток, радио) — записывайте его и анализируйте офлайн.

## Полезные команды одной строкой

```bash
sox in.wav -n spectrogram -o spec.png
sox in.wav out.wav channels 1
multimon-ng -a DTMF -t wav in.wav
zbarimg qr.png
binwalk -e in.wav
```

Эти пять команд закрывают большинство аудио-задач. Держите их под рукой.

## Что дальше / решение

Итог: аудио-задачи решаются методичным каскадом, где главный шаг — спектрограмма. Работайте с каналами раздельно, проверяйте метаданные и вложения, не забывайте про DTMF/SSTV/морзе. Натренировавшись, вы будете определять нужный шаг по первым секундам прослушивания и решать такие задачи за минуты.
