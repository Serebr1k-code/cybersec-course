Befunge — язык, где программа — **двумерная сетка**, а указатель инструкций (IP) движется по ней вверх, вниз, влево, вправо. В отличие от Brainfuck (одномерная лента), здесь код «разворачивается» в плоскости. В CTF такие задачи выглядят как странная ASCII-картинка из символов. Этот урок — про распознавание и исполнение двумерных языков.

## Идея Befunge

Программа — сетка символов. Есть **IP** (instruction pointer) с направлением (изначально вправо) и **стек**. Каждый символ — команда. Ключевые команды Befunge-93:

| Символ | Действие |
|--------|----------|
| `0`–`9` | положить число на стек |
| `+` `-` `*` `/` `%` | арифметика |
| `!` | логическое НЕ |
| `` ` `` | больше |
| `>` `<` `^` `v` | задать направление |
| `?` | случайное направление |
| `_` | влево/вправо по условию |
| `\|` | вверх/вниз по условию |
| `"` | режим строки (до следующей `"`) |
| `:` | дублировать вершину |
| `\` | поменять два верхних |
| `$` | убрать вершину |
| `.` | вывести число |
| `,` | вывести символ |
| `&` | ввести число |
| `~` | ввести символ |
| `#` | «мост» (пропустить след. символ) |
| `@` | завершить |
| `p` `g` | запись/чтение в «поле» (самокод) |
| `&` `~` | ввод |

`p` и `g` делают Befunge самоизменяющимся — можно писать в собственный код.

## Как читать программу

1. Найти стартовую позицию — левый верхний угол.
2. Идти по направлению IP, выполняя команды.
3. Отслеживать стек.
4. Учитывать переходы строк: в Befunge-93 выход за границу «заворачивает» на противоположную сторону (тор).

```text
"!dlroW ,olleH">:#,_@
```

Это классический «Hello World»: `"` включает строковый режим, символы кладутся на стек в обратном порядке, затем `>:#,_@` выводит их по одному. Разберём:

- `"!dlroW ,olleH"` кладёт строку (в обратном порядке, т.к. читается слева направо, а выводится с конца);
- `>` задаёт движение вправо;
- `:` дублирует вершину;
- `#` пропускает следующую команду (`,`), чтобы проверить `_`;
- `_` идёт вправо, если 0, иначе влево;
- `,` выводит символ;
- `@` завершает.

## Befunge-98

Расширение добавляет:

- `k` — повторить команду k раз;
- `w`/`x` — расширенные переходы;
- `'` и `s` — работа со стеком строк;
- fingerprint'ы — расширения.

## INTERCAL и другие

**INTERCAL** — язык-пародия с `PLEASE DO ...`, `COME FROM`, оператором `IGNORE`, и требованиями к «вежливости» (слишком много `PLEASE` — ошибка компиляции). В CTF встречается редко, но узнаётся по ключевым словам.

Другие двумерные/странные:

| Язык | Признак |
|------|---------|
| Befunge | `< > ^ v` + цифры + `"` |
| INTERCAL | `PLEASE DO`, `COME FROM` |
| FALSE | стек, `$`, `;` |
| Brainfuck | `+-<>[],.` |
| Whitespace | только пробелы/табы |
| Chef | рецепт с ингредиентами |
| Shakespeare | «пьеса» с персонажами |

## Разобранный пример

Дано: файл с символами `><^v0123456789+:,.@`.

```bash
cfunge challenge.bf
# flag{befunge_is_2d}
```

Если вывод нечитаем — возможно, программа просит ввод:

```bash
echo "answer" | cfunge challenge.bf
```

Если `cfunge` не установлен — можно написать интерпретатор на Python (100 строк) или использовать онлайн, но с секретами осторожно.

## Ручная интерпретация

Для маленьких программ:

1. Нарисовать сетку.
2. Отметить старт и направление.
3. Пройти по символам, ведя стек.
4. Учесть «мост» `#` и заворачивание краёв.
5. Проследить вывод `.`/`,`.

Ошибка на одном символе меняет всё — будьте внимательны с `?` (случайность) и `p` (самомодификация).

## Частые ошибки и подводные камни

- Забывать про заворачивание краёв (тор) — IP «перескакивает».
- Путать `_`/`|` (условные переходы) с `>`/`<`.
- Игнорировать `#` (мост) — пропуск команды.
- Не учитывать `"` строковый режим — символы кладутся как есть.
- Считать, что `p`/`g` не используются — они меняют код на лету.
- Использовать интерпретатор не той версии (93 vs 98).

## Дополнительная теория: самокод, тор и многопоточность

Befunge уникален тем, что программа может **читать и изменять собственный код** через `g` (get) и `p` (put). `g` берёт координаты (x, y) и кладёт на стек ASCII-код символа в этой позиции; `p` берёт (x, y, v) и записывает символ с кодом v в позицию. Это делает Befunge самоизменяющимся: программа может «печатать» себе новые инструкции во время выполнения. В CTF это используется для обфускации: код, который выглядит безобидно, переписывает себя в опасный. При анализе обращайте внимание на `p` — он может менять поток непредсказуемо.

Пространство — **тор**: выход за левый край приводит к правому, за верхний — к нижнему. Это позволяет писать циклы без явных переходов. Befunge-98 добавляет `k` (повторить команду), fingerprint'ы (расширения вроде `REFC` для ссылок), и `;` (комментарий до следующей `;`). Некоторые реализации поддерживают многопоточность (`t`), что делает поведение ещё сложнее. Понимание этих расширений нужно, чтобы не запутаться.

## Сравнение с другими двумерными языками

Befunge — не единственный двумерный язык. **FALSE** использует стек и одномерный код, но с хитрыми операторами. **Befunge-93** — базовый, **Befunge-98** — расширенный. **Wumpus**, **PATH**, **ADJUST** — другие 2D-языки, где IP движется по сетке. **Piet** — визуальный (см. отдельный урок). Распознавание: если видите сетку символов с `<>^v` и цифрами — это Befunge; если цветные блоки — Piet; если рецепт — Chef. В CTF важно быстро классифицировать язык по алфавиту и структуре.

## Разбор ошибок и отладка

Если `cfunge` выдаёт ошибку — читайте её: часто это «stack underflow» (не хватило аргументов) или недопустимая команда. Запустите с трассировкой (`cfunge -t`), чтобы увидеть поток. Если программа «зацикливается» — возможно, IP бегает по тору без выхода; проверьте условия `_`/`|`. Если результат нечитаем — возможно, нужен ввод (`&`/`~`); подайте его. Если вы пишете интерпретатор и он расходится с эталоном — проверьте обработку краёв (тор) и `#` (мост). Мелкая ошибка в направлении меняет всё — ведите стек вручную для маленьких программ.

## Практический разбор: от сетки символов до вывода

Дано: файл `challenge.bf` со странной ASCII-сеткой. Шаги:

```bash
head -c 200 challenge.bf
# "!dlroW ,olleH">:#,_@
cfunge challenge.bf
# Hello World
```

Классический «Hello World» понятен. Теперь посложнее: программа с `p`/`g` (самомодификация). Запускаем с трассировкой:

```bash
cfunge -t challenge.bf 2>&1 | head -40
# 0000: '>' dp=(1,0)
# 0001: ':' push
# ...
```

Если программа просит ввод:

```bash
echo "myinput" | cfunge challenge.bf
```

Если вывод — числа, преобразуем:

```bash
cfunge challenge.bf | python3 -c "import sys;print(bytes(int(x) for x in sys.stdin.read().split()))"
```

Если `cfunge` нет — напишите интерпретатор на Python (или используйте `bef`/онлайн). Для маленьких программ интерпретируйте вручную: ведите стек, отмечайте направление, помните про тор и `#`. Ошибка в одном символе меняет результат — сверяйтесь с трассировкой эталонного интерпретатора.
