## Что такое парольные головоломки

Задачи, где дан хеш, архив или документ с паролем, а нужно восстановить пароль. Это классика CTF: файл `hash.txt` с строкой вида `5f4dcc3b5aa765d61d8327deb882cf99`, архив `secret.zip` или PDF с защитой. Ключ к успеху — не «тупой перебор», а **методика**: определить тип, выбрать инструмент, применить правило/маску.

## Идентификация хешей

Первый шаг — понять, что за хеш. Ориентиры:

| Длина (hex) | Вероятный тип |
|-------------|---------------|
| 32 | MD5, NTLM |
| 40 | SHA-1 |
| 56 | SHA-224 |
| 64 | SHA-256 |
| 96 | SHA-384 |
| 128 | SHA-512 |
| 60, `$2...` | bcrypt |
| `$1$` | md5crypt |
| `$6$` | sha512crypt |
| `sha1$...` | Django |

Инструменты: `hashid`, `hash-identifier`, `haiti`. Для NTLM характерны 32 hex-символа без соли.

```bash
hashid 5f4dcc3b5aa765d61d8327deb882cf99
# MD5, MD4, NTLM ...
```

## Словарные и гибридные атаки

- **Словарная атака** — перебор паролей из списка (`rockyou.txt`).
- **Гибридная** — словарь + правила мутации (`password` → `P@ssw0rd!`).
- **Правила (rules)** — встроенные наборы (`best64.rule`, `OneRuleToRuleThemAll.rule`), превращающие базовые слова в типичные пароли.
- **Маска** — когда известен шаблон (`?u?l?l?l?d?d`).

```bash
hashcat -m 0 hash.txt rockyou.txt
hashcat -m 0 hash.txt rockyou.txt -r best64.rule
hashcat -m 0 hash.txt -a 3 '?u?l?l?l?l?d?d'
```

Здесь `-m 0` — режим MD5, `-a 0` — словарь, `-a 3` — маска.

## Правила hashcat

Правила — это файлы, описывающие трансформации. Пример правила `c $1$2$3` (капитализация + суффикс `123`). Проверить, какие пароли даст правило:

```bash
hashcat --stdout -r best64.rule <<< "password" | head
```

Ключевой практический приём: `--stdout` позволяет «увидеть» мутации, не запуская полный перебор.

## Маски и брутфорс

Символы маски: `?l` (a-z), `?u` (A-Z), `?d` (0-9), `?s` (спецсимволы), `?a` (все), `?b` (байты). Маска `?u?l?l?l?l?d?d?s` — 7–8 символьные пароли с заглавной буквой и спецсимволом.

```bash
hashcat -m 0 hash.txt -a 3 '?d?d?d?d' --increment
```

`--increment` увеличивает длину по шагам — удобно, когда точная длина неизвестна.

## John the Ripper

John умеет автоматически определять тип хеша и конвертировать форматы:

```bash
john hash.txt --wordlist=rockyou.txt
john --show hash.txt
# архивы и документы через *2john
zip2john secret.zip > zip.hash
john zip.hash --wordlist=rockyou.txt
```

Есть аналоги: `rar2john`, `pdf2john`, `office2john`, `ssh2john`, `keepass2john`.

## Взлом архивов и документов

```bash
# ZIP
zip2john secret.zip > z.hash && john z.hash -w=rockyou.txt
# RAR
rar2john secret.rar > r.hash && john r.hash -w=rockyou.txt
# PDF
pdf2john protected.pdf > p.hash && john p.hash -w=rockyou.txt
# 7z
7z2hashcat secret.7z > s.hash && hashcat -m 11600 s.hash rockyou.txt
```

Для 7z/Office режимы hashcat указывают вручную (`-m 11600` для 7z).

## Разобранный пример: MD5 + правила

```bash
echo -n 'password' | md5sum
# 5f4dcc3b5aa765d61d8327deb882cf99
hashcat -m 0 -a 0 hash.txt rockyou.txt -r best64.rule --force
```

Вывод:

```
5f4dcc3b5aa765d61d8327deb882cf99:password
```

Восстановленный пароль — `password`. Для CTF этого часто достаточно, но если пароль не в словаре — переходите к маске по известному шаблону.

## Частые ошибки и подводные камни

- **Неверный режим hashcat.** NTLM и MD5 имеют одинаковую длину; разница в режиме (`-m 1000` vs `-m 0`).
- **Соль игнорируется.** Для bcrypt/md5crypt нужен полный хеш с солью, а не только digest.
- **Слишком большой словарь сразу.** Начните с rockyou + правил, потом маски.
- **Архив с шифрованием имён.** Тогда `zip2john` может не сработать без `-p` опций; используйте `bkcrack` для известного plaintext.
- **GPU против CPU.** bcrypt на GPU медленный; учитывайте режим.

## Справочная таблица

| Тип | Инструмент | Режим hashcat |
|-----|------------|---------------|
| MD5 | hashcat | `-m 0` |
| NTLM | hashcat | `-m 1000` |
| SHA-256 | hashcat | `-m 1400` |
| bcrypt | hashcat | `-m 3200` |
| ZIP | zip2john + john | `-m 17200` |
| PDF | pdf2john + john | `-m 10500` |
| 7z | 7z2hashcat | `-m 11600` |

## Что дальше / решение

1. Идентифицируйте хеш (`hashid`).
2. Попробуйте словарь + правила (`rockyou` + `best64`).
3. Если не вышло — уточните шаблон и переходите к маске.
4. Для архивов/документов используйте `*2john`.
5. Ведите заметки: какой словарь и правило уже пробовали, чтобы не повторяться.

## Режимы hashcat: как выбрать `-m`

Правильный режим — половина успеха. Ниже расширенная таблица частых типов:

| Хеш | `-m` | Пример |
|-----|------|--------|
| MD5 | 0 | `5f4dcc3b...` |
| SHA-1 | 100 | 40 hex |
| SHA-256 | 1400 | 64 hex |
| NTLM | 1000 | 32 hex |
| bcrypt | 3200 | `$2a$...` |
| md5crypt | 500 | `$1$...` |
| sha512crypt | 1800 | `$6$...` |
| WPA-PMKID | 22000 | `22000` |
| ZIP (WinZip AES) | 13600 | `$zip2$` |
| 7-Zip | 11600 | `$7z$` |

Если сомневаетесь, `hashcat --example-hashes | grep -i <тип>` покажет формат и номер режима.

## Атака по известному открытому тексту на архивы

Иногда пароль архива неизвестен, но внутри есть файл, содержимое которого предсказуемо (известный plaintext). Тогда применяют **bkcrack** (для ZipCrypto):

```bash
bkcrack -C secret.zip -c known.txt -p known_plaintext.txt
```

Если угадать хотя бы 12 байт plaintext (например, заголовок PNG), bkcrack восстановит ключи и расшифрует архив **без пароля**. Это частый CTF-приём: «архив с паролем, но внутри лежит известная картинка».

## Синтаксис правил hashcat

Правило — это набор функций над словом. Примеры функций:

| Функция | Действие |
|---------|----------|
| `:` | ничего |
| `l` | в нижний регистр |
| `u` | в верхний регистр |
| `c` | капитализация |
| `$X` | добавить символ X в конец |
| `^X` | добавить символ X в начало |
| `sXY` | заменить X на Y |
| `d` | дублировать слово |

Строка `c $1 $2 $3` превращает `password` → `Password123`. Проверка:

```bash
hashcat --stdout -r best64.rule <<< "password"
```

## Бенчмарк и выбор железа

```bash
hashcat -b -m 0
```

Покажет скорость хешей в секунду для режима. Быстрые хеши (MD5, NTLM) перебираются на GPU миллиардами в секунду; медленные (bcrypt) — тысячами, поэтому для них важен точный словарь, а не брутфорс.

## Частые вопросы по паролям

- **Словарь не помог — что дальше?** Уточните шаблон (длина, регистр) и перейдите к маске `-a 3`.
- **Хеш с солью?** Передавайте полную строку (`$1$salt$hash`), а не только digest.
- **Архив с шифрованием имён?** `zip2john` не справится — пробуйте bkcrack с известным plaintext.
- **Много хешей?** Пакетный режим `hashcat hashes.txt` и `--username`.
