## Что такое OSINT в misc

OSINT (Open Source Intelligence) — сбор информации из открытых источников. В misc-задачах это чаще всего «по файлу найти информацию»: где сделано фото, кто автор документа, что за устройство. Отличие от полноценной OSINT-разведки — узкий фокус на артефактах задачи.

## Метаданные как разведданные

Метаданные — самый быстрый источник сведений.

```bash
exiftool photo.jpg
# Camera Model Name, Create Date, GPS Position, Software, Artist
```

Что искать:

- **GPS** — координаты съёмки;
- **Artist/Author** — имя автора;
- **Software** — чем редактировали;
- **Create/Modify Date** — время;
- **Serial Number** — серийник камеры (уникален).

## Изображения и геолокация

Если GPS нет, геолокацию определяют по содержимому: вывески, архитектура, тени, язык. Полезные инструменты:

- **Google/Bing/Yandex reverse image** — поиск похожих изображений;
- **Google Maps / OpenStreetMap** — сопоставление с местностью;
- **suncalc** — определение времени по длине и направлению тени;
- **GeoGuessr-методики** — распознавание стран по деталям.

## Документы и авторы

PDF/Office хранят автора, компанию, историю правок.

```bash
exiftool document.pdf
pdfinfo document.pdf
```

В DOCX можно посмотреть `docProps/core.xml` и `docProps/app.xml`:

```bash
unzip -p document.docx docProps/core.xml
```

Там бывают `dc:creator`, `cp:lastModifiedBy`, название организации.

## Поиск по хешам и именам

- **Хеш файла** — поиск в VirusTotal/базах (`sha256sum file`);
- **Имя пользователя** — `sherlock`, `whatsmyname`;
- **Email** — HIBP (утечки), Gravatar;
- **Домен** — WHOIS, DNS-история.

## Инструменты

- **exiftool** — метаданные.
- **sherlock / maigret** — поиск по username.
- **Google/Yandex reverse image** — по картинке.
- **suncalc** — время по тени.
- **theHarvester / Maltego** — сбор по домену/почте.
- **Wayback Machine** — история страниц.

## Разобранный пример

Дано изображение, нужно найти место съёмки.

```bash
exiftool -GPSPosition photo.jpg
# если пусто — идём по содержимому
```

Если GPS есть — координаты сразу дают ответ. Если нет — используем reverse image search и сопоставляем вывески/архитектуру. Часто флаг — это название места или координаты в определённом формате.

## Частые ошибки и подводные камни

- **Удалённые метаданные.** Редакторы «чистят» EXIF — тогда работайте по содержимому.
- **Неверный часовой пояс.** Время съёмки может быть в локальном поясе.
- **Ложные совпадения при reverse image.** Проверяйте несколько признаков.
- **Этические и правовые границы.** Работайте только в рамках задачи/легальной программы.
- **Игнорирование текста.** OCR (`tesseract`) вытаскивает надписи с картинки.

## Что дальше / решение

1. Снимите метаданные (`exiftool`).
2. Если GPS есть — используйте координаты.
3. Если нет — reverse image + анализ содержимого.
4. Для документов — автор и история правок.
5. Проверьте OCR и текстовые надписи.

## Верификация изображений

Кроме поиска места, OSINT включает проверку подлинности изображений. Признаки редактирования:

- **ELA (Error Level Analysis)** — показывает области разного «сжатия»; вставки выделяются;
- **несоответствие теней** — направление тени не совпадает с освещением;
- **метаданные после редактирования** — `Software: Photoshop`, а EXIF неполный;
- **клонирование** — повторяющиеся фрагменты (детектится `Forensically`, `FotoForensics`).

```bash
# базовые метаданные и несоответствия
exiftool -a -u -g1 suspect.jpg
```

## OSINT по доменам и людям

В misc-задачах OSINT не ограничен картинками. Полезные приёмы:

- **WHOIS/RDAP** — владелец домена, даты регистрации;
- **DNS-история** — куда указывал домен раньше (`SecurityTrails`, `crt.sh`);
- **reverse WHOIS** — другие домены того же владельца;
- **username enumeration** — `sherlock`, `maigret` по нику;
- **email** — HIBP (утечки), Gravatar, поиск по формату;
- **архивы** — Wayback Machine для удалённых страниц.

```bash
whois example.com | grep -i 'registrant\|creation'
curl -s "https://crt.sh/?q=%25.example.com&output=json" | jq '.[].name_value' | sort -u
```

## Метаданные как «отпечаток»

Серийный номер камеры в EXIF уникален — по нему можно связать несколько фотографий с одним устройством. Аналогично `Document ID` в PDF и `Template`/`Author` в Office связывают документы. В CTF это ключ к задачам «найди, что ещё сделал этот автор/устройство».

## Частые вопросы по OSINT

- **Где искать обратное изображение?** Google, Yandex, Bing, TinEye.
- **Как определить время по тени?** `suncalc` — по координатам и длине тени.
- **Что если метаданных нет?** OCR (`tesseract`), reverse image, анализ деталей.
- **Этика?** Работайте строго в рамках задачи и легальной программы.

## OSINT и приватность

Собирая открытые данные, помните о границах: работайте только в рамках задачи или легальной программы, не переходите к преследованию людей и не публикуйте персональные данные. В CTF «цель» — синтетическая, но навык переносится в реальность, где этика критична.

Инструменты для проверки приватности (своей):

- **Have I Been Pwned** — утечки email;
- **Google Activity / эксгибиционизм метаданных** — что видно на ваших фото;
- **sherlock** по своему нику — какие аккаунты находятся.

## Практический конвейер OSINT

Для задачи «по файлу найти максимум информации»:

1. `exiftool` — метаданные (GPS, автор, ПО).
2. `strings` — текстовые артефакты.
3. reverse image — источник картинки.
4. OCR (`tesseract`) — надписи.
5. WHOIS/DNS — если есть домен.
6. Архивы — если есть URL.

Каждый шаг сужает неизвестность; записывайте результаты.

## Частые вопросы по OSINT в misc

- **Где хранятся серийники камеры?** EXIF `SerialNumber`.
- **Как связать фото с местом без GPS?** Reverse image + анализ деталей.
- **Что даёт `strings`?** URL, пути, имена, иногда флаг.
- **Как не ошибиться?** Проверяйте гипотезу несколькими независимыми источниками.

## Кейс: геолокация без GPS

Дано: фото без EXIF. Порядок:

1. `tesseract photo.jpg out` — вытащить надписи.
2. Reverse image search — найти похожие кадры.
3. Сопоставить архитектуру, язык вывесок, номерные знаки.
4. `suncalc` по теням — оценить время и широту.

Часто достаточно одной вывески, чтобы определить город; флаг — название места.

## Кейс: связь нескольких файлов

Дано: несколько фото одного автора. Сравниваем метаданные:

```bash
for f in *.jpg; do echo "== $f"; exiftool -SerialNumber -Model -Artist "$f"; done
```

Одинаковый серийник камеры связывает снимки с одним устройством. Аналогично `Document ID` в PDF и `Author` в Office связывают документы. Это ключ к задачам «найди, что ещё сделал автор».

## Итог по OSINT в misc

OSINT в misc — это извлечение максимума из артефактов: метаданные, содержимое, контекст. Начните с `exiftool`, добавьте reverse image и OCR, свяжите несколько файлов по «отпечаткам» (серийник, автор, стиль). Работайте этично и только в рамках задачи. Часто ответ лежит на поверхности — в EXIF или в надписи на картинке.
