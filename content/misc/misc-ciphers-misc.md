## Что такое классические шифры

Классическая криптография — это шифры до компьютерной эпохи: подстановки, перестановки, полиалфавитные шифры. В CTF они встречаются постоянно, потому что распознаются по внешнему виду и вскрываются инструментами за минуты. Понимание их устройства — фундамент криптоанализа.

## Цезарь и ROT

Шифр Цезаря сдвигает алфавит на фиксированное число позиций. ROT13 — сдвиг на 13 (сам себе обратный). Перебрать все 25 сдвигов — тривиально.

```python
def caesar(text, shift):
    out = []
    for c in text:
        if c.isalpha():
            base = ord('A') if c.isupper() else ord('a')
            out.append(chr((ord(c)-base+shift) % 26 + base))
        else:
            out.append(c)
    return "".join(out)

for s in range(26):
    print(s, caesar("KHOOR", s))
```

Вывод покажет `HELLO` при `s = 3`. Варианты: ROT47 (по печатному ASCII), ROT5/ROT18/ROT13 (для цифр/букв).

## Виженер

Полиалфавитный шифр: сдвиг каждой буквы задаётся ключевым словом. Он устойчивее Цезаря, потому что одна и та же буква шифруется по-разному. Взлом: определить длину ключа (индекс совпадений, Касиски), затем решить каждый «Цезарь-столбец» частотным анализом.

```python
def vigenere(text, key, decrypt=False):
    out = []
    ki = 0
    for c in text:
        if c.isalpha():
            base = ord('A') if c.isupper() else ord('a')
            k = ord(key[ki % len(key)].lower()) - ord('a')
            if decrypt: k = -k
            out.append(chr((ord(c)-base+k) % 26 + base))
            ki += 1
        else:
            out.append(c)
    return "".join(out)

print(vigenere("LXFOPVEFRNHR", "LEMON", decrypt=True))   # ATTACKATDAWN
```

## Моноалфавитные подстановки

Каждая буква заменяется другой по фиксированной таблице. Пространство ключей огромно (26!), но взламывается **частотным анализом**: в естественном языке буквы встречаются неравномерно (`e`, `t`, `a` — частые). Инструмент — `quipqiup` (онлайн), который подбирает подстановку по частотам и словарю.

## Аффинный и мультипликативный шифры

Аффинный шифр: `c = (a·p + b) mod 26`, где `a` взаимно просто с 26. Обратное преобразование требует `a⁻¹ mod 26`. Перебираются 12 допустимых `a` и 26 значений `b` — всего 312 вариантов.

```python
def affine_decrypt(c, a, b):
    a_inv = pow(a, -1, 26)
    return chr((a_inv * ((ord(c)-ord('A')) - b)) % 26 + ord('A'))
```

## Анализ частот

Основной метод для подстановок:

1. Посчитать частоты букв в шифртексте.
2. Сопоставить с частотами языка (`e`→самая частая, и т. д.).
3. Учесть частые биграммы (`th`, `he`, `in`) и триграммы (`the`).
4. Итеративно исправлять гипотезы.

```python
from collections import Counter
def freq(text):
    return Counter(c for c in text.upper() if c.isalpha()).most_common(10)
print(freq("LXFOPVEFRNHR..."))
```

## Разобранный пример: подстановка

Дано: текст, где частые буквы `X`, `Q`, `J`. Гипотеза: `X`→`e`. Смотрим слова с `X` на конце — вероятно `the`. Постепенно строим таблицу замены. Инструмент `quipqiup` делает это автоматически: вставляем шифртекст, получаем кандидатов на открытый текст.

## Частые ошибки и подводные камни

- **Неверный алфавит.** Латинский vs русский, регистр, цифры — учитывайте всё.
- **Путаница шифр/кодировка.** Base64 и hex — не шифры; их «взлом» — декодирование.
- **Игнорирование пробелов.** Некоторые шифры их удаляют перед шифрованием.
- **Слепой перебор вместо анализа.** Для подстановок частотный анализ быстрее.
- **Потеря ключа.** Сохраняйте промежуточные гипотезы, чтобы не начинать заново.

## Перестановочные шифры

В перестановочных шифрах буквы не заменяются, а **переставляются**. Простые варианты:

- **Rail Fence (забор)** — текст пишется зигзагом по `n` строкам и читается построчно.
- **Columnar transposition (столбцовая)** — текст пишется в таблицу, столбцы переставляются по ключу.

```python
def rail_fence_decrypt(cipher, rails):
    pattern = list(range(rails)) + list(range(rails-2, 0, -1))
    cycle = pattern
    n = len(cipher)
    rows = [[] for _ in range(rails)]
    idx = [0]*rails
    # распределяем символы шифртекста по строкам в порядке зигзага
    counts = [cycle[:n].count(r) for r in range(rails)]
    pos = 0
    for r in range(rails):
        rows[r] = list(cipher[pos:pos+counts[r]])
        pos += counts[r]
    out, r = [], 0
    for i in range(n):
        out.append(rows[cycle[i % len(cycle)]].pop(0))
    return "".join(out)

print(rail_fence_decrypt("WECRLTEERDSOEEFEAOCAIVDEN", 3))
```

Взлом Rail Fence — перебор числа строк (обычно 2–10).

## Плейфейр и биграммные шифры

Плейфейр шифрует **парами** букв по квадрату 5×5. Он устойчивее моноалфавитных, но вскрывается частотным анализом биграмм (диграмм). Ключевые правила: буквы одной строки сдвигаются вправо, одного столбца — вниз, иначе — по прямоугольнику.

```python
# упрощённая иллюстрация правила прямоугольника
def playfair_rect(a, b, square):
    ra, ca = divmod(square.index(a), 5)
    rb, cb = divmod(square.index(b), 5)
    return square[ra*5+cb] + square[rb*5+ca]
```

## Роторные машины (Энигма) — кратко

Энигма — полиалфавитный шифр с роторами: каждый символ проходит через несколько вращающихся подстановок, поэтому сдвиг меняется от буквы к букве. В CTF «полная» Энигма встречается редко, но её **принцип** (композиция подстановок с ротацией) полезен для понимания. Инструмент — `py-enigma` или онлайн-эмуляторы.

## Частые вопросы по классическим шифрам

- **Как отличить шифр от кодировки?** Кодировка (base64/hex/URL) обратима без ключа; шифр — нет.
- **Ключ неизвестен — с чего начать?** С определения класса (сдвиг, полиалфавит, подстановка, перестановка).
- **Что если текст короткий?** Частотный анализ ненадёжен; нужен контекст или словарь.
- **Помогает ли CyberChef?** Да, для быстрой идентификации и массового перебора вариантов.
