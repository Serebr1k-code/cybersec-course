## Вопрос, с которого всё начинается

В прошлом уроке данные прятались в строке. Но спрятать можно и в **картинке**: в пикселях, отдельных цветовых каналах, метаданных или вообще в том, что «картинка на самом деле не картинка». Задача даёт файл `challenge.png` и молчит про метод — надо найти, где лежит флаг.

Здесь нет единственной команды. Есть **каскад**: последовательность проверок от простого к сложному. Разберём его на одном файле.

## Наш пример: challenge.png

Открываем файл глазами — обычная картинка, ничего не видно. Значит, данные спрятаны программно. Первый шаг — понять, что это вообще за файл.

```bash
$ file challenge.png
challenge.png: PNG image data, 800 x 600, 8-bit/color RGB, non-interlaced
```

`file` смотрит на **сигнатуру** файла (первые байты) и говорит: это PNG, 800×600, RGB. Важный факт: картинка цветная, 8 бит на канал.

## Шаг 1: метаданные — самое дешёвое

Прежде чем лезть в пиксели, проверяем **метаданные** — служебные поля внутри файла. Инструмент `exiftool`:

```bash
$ exiftool challenge.png
ExifTool Version Number : 12.40
File Name               : challenge.png
Image Width             : 800
Image Height            : 600
...
```

Ничего лишнего. Метаданные — пусто. Идём дальше.

## Шаг 2: не вложен ли другой файл

Иногда картинка — это контейнер: после «картинки» дописан архив или другой файл. Проверяем `binwalk` (ищет вложенные сигнатуры):

```bash
$ binwalk challenge.png
DECIMAL       HEXADECIMAL     DESCRIPTION
--------------------------------------------------------------------------------
0             0x0             PNG image, 800 x 600, 8-bit/color RGB
```

Только сама картинка. Вложений нет.

## Шаг 3: LSB — младшие биты

Ключевая идея стеганографии: **младший бит** каждого цветового канала почти не влияет на вид пикселя. Если изменить красный с 200 на 201, глаз не заметит — а в этих «последних битах» можно спрятать целый текст, бит за битом.

Для PNG/BMP есть готовый инструмент `zsteg`, который перебирает все комбинации каналов и порядков битов:

```bash
$ zsteg -a challenge.png
b1,rgb,lsb,xy       .. text: "flag{lsb_hidden}"
b1,r,lsb,xy         .. text: "flag{lsb_hidden}"
```

Есть! Флаг лежит в младшем бите (LSB) каналов. `b1` — один бит на пиксель, `rgb` — все три канала, `lsb` — порядок от младшего, `xy` — построчно. Если `zsteg` ничего не находит — не тупик, переходим к следующему шагу.

## Шаг 4: разложение на битовые плоскости

Если `zsteg` молчит, данные могут быть не в LSB, а в другой **битовой плоскости**. Плоскость — это картинка, собранная из одного и того же бита каждого пикселя: например, только 3-й бит. Собираем все восемь через numpy:

```python
import numpy as np
from PIL import Image
arr = np.array(Image.open('challenge.png').convert('RGB'))
for k in range(8):
    plane = ((arr >> k) & 1) * 255     # сдвигаем на k, оставляем младший бит, растягиваем в 0/255
    Image.fromarray(plane.astype('uint8')).save(f'plane{k}.png')
```

Операция `arr >> k` сдвигает биты вправо (бит номер `k` становится младшим), `& 1` оставляет только его, `* 255` делает чёрное/белое. Открываем восемь получившихся файлов — на одной из плоскостей может быть текст или QR.

## Шаг 5: каналы и «обрезанная» картинка

Иногда данные лежат в одном канале. Разделяем их:

```python
r, g, b = arr[:,:,0], arr[:,:,1], arr[:,:,2]
Image.fromarray(r).save('r.png')     # смотрим только красный
```

Ещё один трюк — картинка «выше», чем показывает заголовок: данные дописаны ниже видимой области. Сравните реальный размер файла с ожидаемым: если файл заметно больше — в хвосте что-то есть, и `binwalk` его найдёт.

## Шаг 6: текст на картинке — OCR

Если на изображении текст (пусть повёрнутый или зашумлённый), его распознаёт **OCR** — оптическое распознавание символов. Утилита `tesseract`:

```bash
$ tesseract clean.png stdout
flag{ocr_text}
```

Перед распознаванием картинку полезно подготовить: перевести в оттенки серого, увеличить контраст:

```python
from PIL import Image, ImageOps
im = Image.open('cap.png').convert('L')   # L = grayscale
im = ImageOps.autocontrast(im)
im.save('clean.png')
```

## Шаг 7: разность двух картинок

Иногда дают **две** почти одинаковые картинки, и данные спрятаны в их отличиях. Вычитаем одну из другой — и на разности проступает текст:

```python
from PIL import Image, ImageChops
a = Image.open('a.png').convert('RGB')
b = Image.open('b.png').convert('RGB')
diff = ImageChops.difference(a, b)      # попиксельная разность
diff.save('diff.png')
```

`ImageChops.difference` берёт модуль разности каждого канала. Есть и `ImageChops.logical_xor` для бинарных (1-битных) картинок. Тот же приём работает, когда вторая картинка — «приманка», а данные только в разнице.

## Шаг 8: палитра и альфа-канал

Две ловушки, которые легко пропустить. Первая — **палитровые** картинки (`mode='P'`): цвет пикселя хранится как индекс в таблице палитры, и флаг может быть закодирован именно индексами, а не цветами. `im.convert('RGB')` покажет реальные цвета. Вторая — **альфа-канал** (прозрачность): если картинка RGBA, данные могут лежать в четвёртом канале, которого нет в RGB. Всегда проверяйте `im.mode` перед разбором.

## Порядок действий

Каскад целиком, чтобы не метаться:

1. `file` / `binwalk` — не архив ли и что за формат.
2. `exiftool` — метаданные (иногда флаг прямо в Comment).
3. `pngcheck -v` — чанки PNG.
4. `zsteg -a` — LSB по всем комбинациям.
5. битовые плоскости и раздельные каналы — скрипт на numpy.
6. размер файла против ожидаемого — данные в хвосте.
7. OCR (`tesseract`) и QR (`zbarimg`).
8. палитра (`mode='P'`) и альфа-канал.

Если ничего не нашлось — проверьте, не контейнер ли это и не спрятан ли флаг в индексах палитры.

## Что мы теперь знаем

- Каскад для картинок: `file` → метаданные (`exiftool`) → `binwalk` → LSB (`zsteg -a`) → битовые плоскости и каналы → размер/хвост файла → OCR/QR.
- LSB — младший бит канала, почти незаметный глазу; извлекается `zsteg` или numpy-скриптом.
- Битовые плоскости — восемь отдельных картинок по одному биту.
- Пиксельные операции делаем через numpy, а не циклами Python (иначе медленно).
- Текст распознаёт `tesseract`, QR — `zbarimg`.

## На что смотреть дальше

- **Игнорировать метаданные** — `exiftool` первым делом; флаг бывает в поле Comment.
- **Считать, что «картинка — это картинка»** — `file`/`binwalk` покажут обратное.
- **Забыть про альфа-канал** — бывает RGBA, а не RGB.
- **Путать порядок битов** — MSB-first против LSB-first; `zsteg -a` перебирает оба.
- **Пиксельные циклы в Python** — используйте numpy, разница в скорости на порядки.
- **Палитровые картинки** (`mode='P'`) — флаг может быть в индексах палитры; `im.convert('RGB')` покажет реальные цвета.
