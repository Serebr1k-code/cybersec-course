## Image/pixel-задачи: с чего начать

Задачи с изображениями — один из самых частых типов misc. На входе картинка, на выходе — флаг, спрятанный в пикселях, каналах, метаданных или в самом факте «картинка на самом деле не картинка». Главный инструмент — библиотека PIL/Pillow и `numpy` для векторной обработки. Первый шаг всегда одинаков: посмотреть метаданные и базовую информацию. `exiftool image.png`, `identify -verbose image.png` (ImageMagick), `pngcheck -v image.png`. Часто флаг лежит в поле Comment или в нестандартном чанке.

## Базовые операции с PIL

```python
from PIL import Image
im = Image.open('challenge.png')
print(im.size, im.mode)          # (800, 600) RGB
px = im.load()
print(px[0, 0])                  # кортеж RGB
# пройтись по всем пикселям
for y in range(im.height):
    for x in range(im.width):
        r, g, b = px[x, y]
```

Для скорости конвертируйте в массив:

```python
import numpy as np
arr = np.array(im)               # shape (H, W, 3)
```

## LSB-стеганография

Младший бит каждого канала может нести скрытые данные — изменение на 1 незаметно глазу. Извлечение:

```python
import numpy as np
from PIL import Image
arr = np.array(Image.open('lsb.png'))
bits = (arr & 1).flatten()
# собрать биты в байты (обычно по 8, MSB-first)
data = bytes(int(''.join(map(str, bits[i:i+8])), 2)
             for i in range(0, len(bits)//8*8, 8))
print(data[:100])
```

Готовый инструмент — `zsteg` для PNG/BMP: `zsteg -a challenge.png` перебирает все комбинации каналов и битов. Для «сырых» задач пишите свой извлекатель.

## Каналы и палитры

Иногда данные лежат в одном канале (только R, только G) или в альфа-канале. Разделяйте каналы и смотрите их отдельно:

```python
r, g, b = arr[:,:,0], arr[:,:,1], arr[:,:,2]
Image.fromarray(r).save('r.png')
```

Для палитровых изображений (`mode='P'`) важен индекс палитры — иногда флаг кодируется индексами. `im.convert('RGB')` покажет реальные цвета.

## Каналы как битовые плоскости

Bit-plane slicing — разложение на 8 плоскостей (по одному биту на пиксель). Скрытые данные часто лежат в младшей или старшей плоскости:

```python
for k in range(8):
    plane = ((arr >> k) & 1) * 255
    Image.fromarray(plane.astype('uint8')).save(f'plane{k}.png')
```

Просмотрите получившиеся картинки — на одной из них может быть текст.

## Аномалии: размеры, высота, «обрезанная» картинка

Частый трюк — картинка выше, чем показывает заголовок: данные дописаны ниже «видимой» области. Проверьте реальный размер файла против ожидаемого (`ls -l`, `pngcheck`). Если файл больше, чем нужно для заявленных размеров, — в хвосте что-то есть. Также проверяйте `binwalk` — возможно, картинка — это контейнер с вложенным архивом.

## OCR и текст на картинке

Если на изображении текст — используйте OCR: `tesseract image.png stdout` или `pytesseract`. Иногда текст повёрнут, зашумлён или разделён на части — предобработайте: увеличить контраст, инвертировать, бинаризовать.

```python
from PIL import Image, ImageOps
im = Image.open('cap.png').convert('L')
im = ImageOps.autocontrast(im)
im.save('clean.png')
```

## QR-коды и штрихкоды

```bash
zbarimg qr.png
```

Или `pyzbar` в Python. Если QR повреждён — попробуйте восстановить через `qrazybox` или вручную по трём маркерам.

## Типичные ошибки и подводные камни

- **Игнорировать метаданные** — проверьте EXIF первым делом.
- **Полагать, что «картинка — это картинка»** — `file`/`binwalk` покажут обратное.
- **Не проверить размер файла** — данные бывают в хвосте.
- **Забыть про альфа-канал** — RGBA, а не RGB.
- **Путать порядок битов** — MSB-first vs LSB-first.
- **Работать пиксельно в Python** — медленно, используйте numpy.
- **Не попробовать `zsteg -a`** — он перебирает все варианты.

## Что дальше / решение

План: сначала метаданные и `file`/`binwalk`, затем LSB (`zsteg -a`), затем bit-planes и раздельные каналы, затем размеры/хвост файла. Для текста — OCR, для кодов — `zbarimg`. Работайте через numpy, а не пиксельными циклами. Большинство задач с картинками решаются одним-двумя из этих шагов; если ничего не выходит — проверьте, не спрятан ли внутри другой файл.

## Практический пример: флаг в bit-plane

Разберём задачу с картинкой. `exiftool` и `pngcheck` ничего не дают, `zsteg -a` тоже молчит. Значит, данные спрятаны не в LSB напрямую, а, например, в старшем бите или в конкретной плоскости. Разложим изображение на битовые плоскости:

```python
import numpy as np
from PIL import Image
arr = np.array(Image.open('challenge.png').convert('RGB'))
for k in range(8):
    plane = ((arr >> k) & 1) * 255
    Image.fromarray(plane.astype('uint8')).save(f'plane{k}.png')
```

Открываем получившиеся восемь картинок — на одной из них может быть текст или QR-код. Часто данные лежат в младшем бите (k=0), но в задачах похитрее — в 1-м или 2-м. Если текст «шумный», попробуйте взять только один канал (R, G или B).

Ещё один путь — проверить, не «обрезана» ли картинка. Сравните реальный размер файла с ожидаемым для заявленных ширины/высоты. Если файл больше — данные дописаны в хвосте, и `binwalk` их найдёт.

## Комбинирование с OCR

Если на картинке текст, но он повреждён — предобработайте и прогоните OCR. Увеличьте контраст, инвертируйте, масштабируйте, затем `tesseract`. Иногда текст разбит на части, и его надо собрать из нескольких картинок — тогда склеивайте в правильном порядке.

## Частые вопросы

«zsteg ничего не нашёл — тупик?» — нет, проверьте bit-planes, каналы, размер файла. «Как понять, где данные?» — сравните энтропию регионов. «Что если картинка — это архив?» — `binwalk`/`foremost`. «Как быстро?» — используйте numpy, не пиксельные циклы.

## Что дальше / решение

Итог: при работе с картинками идите по каскаду — метаданные → LSB (`zsteg`) → bit-planes и каналы → размер/хвост файла → вложенные форматы → OCR/QR. Работайте через numpy и держите под рукой скрипт для bit-plane. Большинство задач решается одним-двумя шагами этого каскада.

## Расширенный чек-лист по image-задачам

Порядок действий: `file`/`binwalk` (не архив ли?), `exiftool` (метаданные), `pngcheck -v` (чанки), `zsteg -a` (LSB), bit-planes (сдвиг + `Image.fromarray`), раздельные каналы, сравнение размера файла с ожидаемым (данные в хвосте), OCR (`tesseract`), QR (`zbarimg`), вложенные форматы (`foremost`). Для пиксельных операций используйте numpy. Если ничего не найдено — проверьте, не является ли картинка контейнером или не спрятан ли флаг в палитре (`mode='P'`). Держите скрипт bit-plane под рукой — он решает много задач, где `zsteg` молчит.

## Итог по image-задачам

Помните каскад: метаданные → `zsteg -a` → bit-planes и каналы → размер/хвост файла → вложенные форматы → OCR/QR. Используйте numpy, а не пиксельные циклы. Держите скрипт bit-plane и `zbarimg` под рукой. Если «картинка ничего не даёт» — проверьте, не архив ли это и не спрятан ли флаг в палитре.
