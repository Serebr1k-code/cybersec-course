## Что такое математические головоломки

Задачи, где флаг получается из чисел: найти следующий член последовательности, восстановить модуль, решить систему сравнений, посчитать число комбинаций. В CTF это часто «порог» перед крипто-задачей: RSA, дискретный логарифм и хеши строятся на модульной арифметике и теории чисел.

## Последовательности и их распознавание

Первый инструмент — **OEIS** (Online Encyclopedia of Integer Sequences). Дана последовательность `1, 1, 2, 3, 5, 8, ...` — ищем первые члены в OEIS и читаем описание. Часто флаг — это номер последовательности или её название.

Типовые последовательности: Фибоначчи, факториалы, треугольные числа, числа Каталана, простые. Если задача даёт «следующий элемент», проверьте разности, отношения и известные семейства.

```python
def fib(n):
    a, b = 0, 1
    for _ in range(n):
        a, b = b, a + b
    return a
print([fib(i) for i in range(10)])
```

## Модульная арифметика

Основа крипто-задач. Операция `a mod m` даёт остаток; важны обратный элемент и малая теорема Ферма.

- **Обратный элемент:** `a⁻¹ mod m` существует, если `gcd(a, m) = 1`; считается расширенным Евклидом.
- **Ферма:** `a^(p-1) ≡ 1 (mod p)` для простого `p` — отсюда `a⁻¹ = a^(p-2) mod p`.
- **Быстрое возведение:** `pow(a, e, m)` в Python делает это за `O(log e)`.

```python
from math import gcd
p = 10**9 + 7
print(pow(3, p-2, p))      # обратный к 3 по модулю p
print(pow(2, 1000, p))     # быстрая степень
```

## Простые числа и факторизация

- **Проверка простоты:** `sympy.isprime`, тест Миллера-Рабина.
- **Факторизация:** `sympy.factorint`, `yafu`, `msieve`, `ecm`. Для больших чисел — методы Полларда (rho, p-1), квадратичное решето.
- **RSA-разложение:** если модуль `n` факторизуется — восстанавливаем `d = e⁻¹ mod φ(n)`.

```python
from sympy import factorint, isprime
print(isprime(2**31 - 1))
print(factorint(1234567890))
```

## Китайская теорема об остатках (CRT)

Система сравнений `x ≡ a1 (mod m1)`, `x ≡ a2 (mod m2)`, … при взаимно простых модулях имеет единственное решение по модулю произведения. Это частая CTF-задача («собери секрет из остатков»).

```python
from sympy.ntheory.modular import crt
m = [3, 5, 7]
a = [2, 3, 2]
x, mod = crt(m, a)
print(x, mod)   # 23 mod 105
```

## Комбинаторика

- **Перестановки/сочетания:** `math.perm`, `math.comb`.
- **Числа Каталана:** количество правильных скобочных последовательностей.
- **Модульные сочетания:** `C(n, k) mod p` через факториалы и обратные элементы.

```python
from math import comb, perm
print(comb(10, 3), perm(10, 3))
```

## Инструменты

- **sympy** — символьная математика, факторизация, CRT, простые.
- **gmpy2** — быстрые большие числа и `iroot`/`is_prime`.
- **sage** — мощная среда для теории чисел и алгебры (часто есть в CTF-докерах).
- **OEIS** — распознавание последовательностей.
- **factordb.com** — онлайн-факторизация известных чисел.

## Разобранный пример: восстановление модуля

Даны пары `(x, x mod m)`? Нет — чаще даны `a mod m` для нескольких `m`. Решим систему CRT:

```python
from sympy.ntheory.modular import crt
residues = [2, 3, 2]
moduli = [3, 5, 7]
x, mod = crt(moduli, residues)
print(x, mod)
```

```
23 105
```

Если модули не взаимно просты, CRT обобщается через `lcm` и проверку согласованности остатков.

## Разобранный пример: следующий член

Дано `2, 12, 36, 80, 150, ...`. Разности: `10, 24, 44, 70`; вторые разности: `14, 20, 26` — растут на 6. Значит, третья разность постоянна (6), и следующий член можно вычислить, продолжив разности.

```python
seq = [2, 12, 36, 80, 150]
d1 = [b-a for a, b in zip(seq, seq[1:])]
d2 = [b-a for a, b in zip(d1, d1[1:])]
d3 = [b-a for a, b in zip(d2, d2[1:])]
print(d1, d2, d3)   # [10,24,44,70] [14,20,26] [6,6]
```

## Частые ошибки и подводные камни

- **Обычный `/` вместо модульного деления.** В крипто деление — это умножение на обратный элемент.
- **Переполнение.** Python даёт большие целые бесплатно, но при переносе в C учитывайте размер.
- **Забыть про `pow(a, -1, m)`.** В Python 3.8+ есть встроенный обратный элемент.
- **Не проверять взаимную простоту.** Обратный элемент существует не всегда.
- **Игнорировать OEIS.** Иногда ответ находится за одну минуту поиском последовательности.

## Линейная алгебра по модулю

Многие крипто-задачи сводятся к решению системы линейных уравнений над конечным полем. Матрицы по модулю `p` обращают через `sympy.Matrix.inv_mod` или вручную через определитель и обратный элемент.

```python
from sympy import Matrix
M = Matrix([[2, 3], [1, 4]])
print(M.inv_mod(11))          # обратная матрица по модулю 11
```

Это используется в атаках на линейные шифры (Hill cipher) и в схемах с линейными проверками.

## Решето Эратосфена и генерация простых

Для задач, где нужны все простые до `N`:

```python
def sieve(n):
    is_p = [True]*(n+1); is_p[0]=is_p[1]=False
    for i in range(2, int(n**0.5)+1):
        if is_p[i]:
            for j in range(i*i, n+1, i):
                is_p[j] = False
    return [i for i, v in enumerate(is_p) if v]

print(sieve(30))
```

Для генерации больших простых берут случайное число и проверяют `sympy.nextprime` / тест Миллера-Рабина.

## Дискретный логарифм

Задача «найти `x` из `g^x ≡ h (mod p)`» — основа Diffie-Hellman и Эль-Гамаля. Для маленьких групп — перебор/ baby-step giant-step; для гладких `p-1` — алгоритм Полига-Хеллмана; для эллиптических кривых — свои методы. В CTF часто достаточно `sympy.discrete_log`:

```python
from sympy.ntheory.residue_ntheory import discrete_log
print(discrete_log(101, 3, 2))   # 2^x ≡ 3 mod 101
```

## Быстрое возведение: почему оно логарифмично

`pow(a, e, m)` работает за `O(log e)`, потому что использует двоичное разложение показателя: возводит в квадрат и умножает только на установленных битах. Понимание этого помогает писать свои реализации и объяснять, почему RSA-операции быстры.

## Частые вопросы по математике

- **Числа слишком большие?** Python и `gmpy2` справятся; следите за временем факторизации.
- **Факторизация не идёт?** Проверьте число на factordb.com; возможно, оно уже разложено.
- **Нужны сочетания по модулю?** Считайте через факториалы и обратные элементы.
- **Гладкое `p-1`?** Тогда дискретный логарифм решается Полигом-Хеллманом, а не перебором.
