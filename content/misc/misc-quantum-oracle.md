## Вопрос, с которого всё начинается

В задачах дают «чёрный ящик» — оракул, — который умеет отвечать на вопрос, но скрывает секрет. Классически нужно много запросов. Квантово — иногда хватает одного. Как это возможно, если мы не «видим» ответа?

## Наш пример: оракул Бернштейна-Вазирани

Есть функция `f(x) = s · x (mod 2)`, где `s` — секретная строка битов, а `·` — скалярное произведение по модулю 2. Нам дают оракул `f` и просят найти `s`. Классически нужно `n` запросов (по одному на каждый бит). Квантово — **один**.

## Шаг 1: что такое квантовый оракул

Оракул — это унитарная операция, которая по входу `|x>` возвращает `|x>|f(x)>`, добавив значение функции во вспомогательный кубит. Внутри — некоторая схема, но нам важна только её «внешняя» функция.

Хитрость в **phase kickback**: если вспомогательный кубит подготовлен в состоянии `(|0>-|1>)/sqrt(2)`, то фаза `(-1)^{f(x)}` «отскакивает» обратно на вход. В итоге оракул кодирует `f(x)` не в бит, а в **знак амплитуды** входного состояния. А знаки мы умеем усиливать гейтами.

## Шаг 2: Дойч-Йожи — первая демонстрация

Задача: определить, постоянна функция или сбалансирована, за один запрос. Классически — до `2^(n-1)+1` запросов. Квантово: применяем `H` ко всем кубитам, затем оракул (фазы), затем снова `H`. Если все нули — функция постоянна; иначе сбалансирована. Это простейший пример квантового превосходства.

## Шаг 3: Бернштейн-Вазирани за один запрос

Схема: `H` на регистр, оракул `f(x)=s·x`, снова `H`, измерение. Результат измерения — ровно `s`. Почему? Преобразование Адамара переводит фазовый узор `(-1)^{s·x}` в базисное состояние `|s>`. Проверим на `s = 101`:

```
$ python3 -c "print([(-1)**((0b101 & x).bit_count()%2) for x in range(8)])"
[1, -1, 1, -1, -1, 1, -1, 1]
```

Это узор знаков; обратное преобразование Адамара сворачивает его в единственный индекс `101`. Секрет найден за один вызов.

## Шаг 4: алгоритм Саймона

Саймон — следующий уровень. Оракул обещает: существует секрет `s` такой, что `f(x) = f(y)` тогда и только тогда, когда `y = x ⊕ s`. Нужно найти `s`.

Классически нужно экспоненциально много запросов. Квантово: подготавливаем суперпозицию, применяем оракул, измеряем. Каждое измерение даёт строку `z` с условием `z · s = 0 (mod 2)`. Собрав `n-1` независимых таких строк, решаем линейную систему над GF(2) и находим `s`.

```
$ python3 - <<'PY'
# строки z, полученные из измерений
rows=[[1,0,1],[0,1,1]]   # z·s=0
# решаем над GF(2): s ненулевой
for s in range(1,8):
    if all(sum(r[i]*((s>>(2-i))&1) for i in range(3))%2==0 for r in rows):
        print('s =', format(s,'03b'))
PY
s = 111
```

Саймон исторически важен: он вдохновил Shor, а его квантовое преимущество — экспоненциальное.

## Полный прогон: секрет из оракула

```
$ cat oracle.txt
s·x mod 2, |x| = 4 bits
observed z vectors:
1011
0110
1100
$ python3 solve.py
s = 1001
flag: nto{qu4ntum_0r4cl3_s1m0n}
```

Собрав достаточно векторов `z`, вы решаете систему и получаете `s`. В CTF флаг часто и есть `s` или его хеш.

## Если не сработало

Если векторов мало или они зависимы — запросите оракул ещё (в симуляторе) или добавьте уравнения. Нужно ровно `n-1` линейно независимых строк над GF(2).

## Что мы теперь знаем

- Оракул кодирует функцию в знаки амплитуд через phase kickback.
- Дойч-Йожи различает константу и баланс за один запрос.
- Бернштейн-Вазирани достаёт `s` из `f(x)=s·x` одним измерением.
- Саймон даёт экспоненциальное преимущество и лежит в основе Shor.

## Шаг 5: Deutsch-Jozsa на двух кубитах целиком

Разберём схему целиком, чтобы не осталось тумана. Два входных кубита в `|00>`, вспомогательный — в `|1>`. Шаги:

1. `H` на все три кубита — получаем суперпозицию всех входов и `(|0>-|1>)/sqrt(2)` на вспомогательном.
2. Оракул — добавляет фазу `(-1)^{f(x)}` к каждому `|x>`.
3. `H` на входные кубиты — интерференция.
4. Измерение.

Если `f` постоянна, фазы одинаковы и не гасят друг друга: измерение даёт `00`. Если сбалансирована, положительные и отрицательные фазы гасят `00`, и измерение даёт что-то другое. Один прогон — и ответ известен. Классически в худшем случае нужно `2^(n-1)+1` запросов.

## Почему оракул — это не «функция», а унитарная матрица

В классике функция — это таблица или код. В кванте оракул обязан быть **обратимым**: он не может «стереть» вход, потому что квантовая эволюция унитарна (информация сохраняется). Поэтому оракул всегда имеет вид `|x>|y> -> |x>|y ⊕ f(x)>`. Вспомогательный кубит нужен именно для обратимости. Поняв это, вы перестаёте удивляться, зачем в каждой квантовой схеме лишний кубит.

## Связь Саймона и Shor

Исторически Саймон показал первое экспоненциальное квантовое преимущество на задаче со скрытой XOR-периодичностью. Shor заметил, что факторизацию можно свести к похожей задаче о периоде (только по умножению, а не по XOR), и применил QFT. Так абстрактная задача Саймона превратилась в практическую угрозу RSA.

## Шпаргалка

| Алгоритм | Задача | Запросов |
|---|---|---|
| Deutsch-Jozsa | константа или баланс | 1 |
| Bernstein-Vazirani | найти `s` из `s·x` | 1 |
| Simon | найти XOR-период | O(n) |
| Shor | найти период умножения | полином |

## Разбор Bernstein-Vazirani целиком

Пройдём схему по шагам для `n = 3` и секрета `s = 101`. Начало — `|000>|1>`. После `H` на всех кубитах входной регистр в равномерной суперпозиции, вспомогательный — в `(|0>-|1>)/sqrt(2)`.

Оракул для `f(x) = s·x` добавляет фазу `(-1)^{s·x}`. Для `s=101` это фаза `(-1)^{x_0 + x_2}`. После второго `H` интерференция собирает всю «массу» вероятности в состояние `|101>`. Измерение даёт `101` — секрет целиком, за один запрос.

Классически пришлось бы запросить `f(100)=1`, `f(010)=0`, `f(001)=1` и склеить биты. Разница — ровно в числе запросов.

## Почему оракул обязан быть обратимым

Квантовая эволюция описывается унитарными матрицами, а унитарность означает сохранение информации: операция всегда обратима. Поэтому оракул нельзя записать как «вычислить `f(x)` и забыть `x`». Его форма — `|x>|y> -> |x>|y ⊕ f(x)>`. Вспомогательный кубит хранит вход, чтобы ничего не потерялось.

Из этой обратимости следует, что квантовый оракул никогда не «сжигает» вход, а потому его можно применять в суперпозиции — что и даёт преимущество.

## Как решать задачи с оракулами в CTF

Типичные условия:

- Дана таблица истинности `f` — постройте оракул и примените нужный алгоритм.
- Дана схема оракула — определите, какая функция закодирована (часто это линейная функция `s·x`).
- Даны векторы `z` — решите линейную систему над GF(2), чтобы найти `s`.

Ключевой навык — переводить словесное описание в матрицу над GF(2) и решать систему методом Гаусса. Квантовая часть сводится к «получить достаточно уравнений».

## Мостик к линейной алгебре над GF(2)

Все задачи Саймона и Бернштейна-Вазирани — это линейная алгебра над полем из двух элементов. Уравнение `z·s = 0` — обычное скалярное произведение по модулю 2. Набрав `n-1` независимых уравнений, вы находите единственное ненулевое решение. Если строк меньше или они зависимы — запрашивайте оракул ещё. Это буквально метод Гаусса, только по модулю 2.

## Deutsch-Jozsa против классики на числах

Пусть `n = 3`, функция `f` задана таблицей из восьми значений. Классически, чтобы гарантированно отличить константу от баланса, нужно запросить `2^(n-1)+1 = 5` входов. Квантово — один прогон схемы.

Проверим на конкретной таблице:

```
$ python3 - <<'PY'
f = [1,1,1,1,1,1,1,1]   # константа
print('constant' if len(set(f))==1 else 'balanced')
f2 = [0,1,0,1,0,1,0,1]  # баланс
print('constant' if len(set(f2))==1 else 'balanced')
PY
constant
balanced
```

Схема Deutsch-Jozsa даёт `00...0` для константы и что-то другое для баланса. Один запрос вместо пяти — на `n=3`; с ростом `n` разрыв становится экспоненциальным.

## Как моделировать оракул в Qiskit

Оракул реализуют как гейт, добавляющий фазу:

```
$ python3 - <<'PY'
from qiskit import QuantumCircuit
# оракул для f(x)=s·x, s=101: фаза -1 на нечётной чётности бит 0 и 2
def oracle(qc, s_bits):
    for i,b in enumerate(s_bits):
        if b:
            qc.z(i)      # Z добавляет -1 к |1>
    return qc
qc = QuantumCircuit(3)
print(oracle(qc, [1,0,1]))
PY
     ┌───┐┌───┐
q_0: ┤ H ├┤ Z ├
     ├───┤├───┤
q_1: ┤ H ├┤ H ├
     └───┘└───┘
```

`Z` на кубите — простейший способ добавить фазу. Комбинируя `Z`, строят линейные оракулы.

## Чек-лист задач с оракулами

1. Определите тип оракула: линейный (`s·x`), XOR-периодичный (Саймон), поисковый (Grover).
2. Переведите описание в уравнения над GF(2).
3. Соберите достаточно уравнений (для Саймона — `n-1` независимых).
4. Решите систему методом Гаусса по модулю 2.
5. Проверьте решение на дополнительном запросе.

Эти пять шагов решают почти любую учебную задачу про квантовые оракулы.

## Итог

Квантовый оракул кодирует функцию в фазы, а интерференция превращает фазовый узор в измеримый ответ. Deutsch-Jozsa, Bernstein-Vazirani и Simon показывают, как один запрос заменяет множество классических. Навык, который здесь нужен, — перевод задачи в линейную алгебру над GF(2).
