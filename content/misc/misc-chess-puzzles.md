## Что такое шахматные задачи в CTF

Иногда задача даёт позицию на доске и просит сделать ход, найти мат в N, или расшифровать флаг, закодированный последовательностью ходов. Формат задачи всегда опирается на **стандартные нотации** — FEN (позиция) и PGN (партия). Понимание этих нотаций и умение работать с библиотекой `python-chess` решает такие задачи за минуты.

## Нотация FEN

FEN (Forsyth–Edwards Notation) — строка, полностью описывающая позицию. Пример начальной позиции:

```
rnbqkbnr/pppppppp/8/8/8/8/PPPPPPPP/RNBQKBNR w KQkq - 0 1
```

Поля:

| Поле | Значение |
|------|----------|
| `rnbqkbnr/...` | 8 рядов сверху вниз; заглавные — белые, строчные — чёрные, цифра — пустые клетки |
| `w` | чей ход (w/b) |
| `KQkq` | права рокировки |
| `-` | поле взятия на проходе (или `e3`) |
| `0` | счётчик полуходов для правила 50 ходов |
| `1` | номер хода |

```python
import chess
b = chess.Board("rnbqkbnr/pppppppp/8/8/8/8/PPPPPPPP/RNBQKBNR w KQkq - 0 1")
print(b)
print(b.legal_moves.count())   # 20
```

## Нотация PGN и ходы

PGN — запись партии: `1. e4 e5 2. Nf3 Nc6 3. Bb5 a6 ...`. Ход в **SAN** (Standard Algebraic Notation): фигура + поле, `Nf3`, `O-O` (рокировка), `e8=Q` (превращение), `+`/`#` (шах/мат).

```python
import chess
b = chess.Board()
b.push_san("e4")
b.push_san("e5")
b.push_san("Nf3")
print(b.fen())
```

Перебор ходов из партии:

```python
import chess.pgn
game = chess.pgn.read_game(open("game.pgn"))
node = game
while node.variations:
    node = node.variations[0]
    print(node.move.uci())   # e2e4, e7e5, ...
```

## Инструменты

- **python-chess** — доски, ходы, FEN/PGN, легальность (`pip install chess`).
- **Stockfish** — движок для поиска лучшего хода; с python-chess интегрируется через `chess.engine`.
- **polyglot** — работа с книгой дебютов, если задача про неё.

```python
import chess, chess.engine
engine = chess.engine.SimpleEngine.popen_uci("stockfish")
info = engine.analyse(chess.Board(), chess.engine.Limit(time=0.5))
print(info["pv"][0])   # лучший ход
engine.quit()
```

## Логические сетки

Помимо шахмат, в misc часто встречаются constraint-головоломки:

- **Судоку** — 9×9, решается перебором с возвратом или Z3 (`Distinct` по строкам/столбцам/блокам).
- **Nonogram** — числа по краям задают длины закрашенных блоков; решается построчно с распространением ограничений.
- **Kakuro** — суммы по строкам/столбцам; сводится к системе ограничений.
- **Логические сетки** («кто в каком доме живёт») — таблицы с ограничениями; Z3 или `itertools.permutations`.

## Задачи на переливания и взвешивания

- **Переливания** (jug problem) — поиск в ширину по состояниям `(a, b)`.
- **Взвешивания** — информация из результатов (больше/меньше/равно) кодируется как троичные исходы; часто ответ — `ceil(log3(n))`.

```python
from collections import deque
def pour(cap_a, cap_b, target):
    start = (0, 0)
    q = deque([(start, [])])
    seen = {start}
    while q:
        (a, b), path = q.popleft()
        if a == target or b == target:
            return path
        moves = [(cap_a, b), (a, cap_b),
                 (max(0, a-(cap_b-b)), min(cap_b, b+a)),
                 (min(cap_a, a+b), max(0, b-(cap_a-a)))]
        for m in moves:
            if m not in seen:
                seen.add(m); q.append((m, path+[m]))
    return None

print(pour(3, 5, 4))
```

## Разобранный пример: лучший ход по FEN

Дана позиция, нужно найти мат в 1.

```python
import chess, chess.engine
b = chess.Board("6k1/5ppp/8/8/8/8/5PPP/4R1K1 w - - 0 1")
engine = chess.engine.SimpleEngine.popen_uci("stockfish")
info = engine.analyse(b, chess.engine.Limit(depth=10))
print("best:", info["pv"][0])
engine.quit()
```

Для «мата в N» можно перебрать все ходы и проверить `b.is_checkmate()` после хода — для N=1 этого достаточно.

## Частые ошибки и подводные камни

- **Путать ряды FEN.** Первый ряд — восьмой (чёрные сверху).
- **Не учитывать чей ход.** Поле `w`/`b` меняет легальные ходы.
- **Игнорировать рокировку/en passant.** FEN кодирует их в отдельном поле.
- **Не проверять легальность.** `push_san` бросит исключение на нелегальном ходе — используйте `parse_san`.
- **Слишком глубокий поиск.** `depth`/`time` ограничивайте, иначе движок «висит».

## Перебор вариантов и minimax

Для задач «обыграй противника» и «найди мат в N» пишут перебор с оценкой позиции. Для шахмат используют negamax с альфа-бета-отсечением; на глубине 3–4 он находит форсированные маты.

```python
import chess
def mate_in(board, depth):
    if depth == 0:
        return None
    for move in board.legal_moves:
        board.push(move)
        if board.is_checkmate():
            board.pop()
            return move
        board.pop()
    # (для N>1 нужен более полный перебор с защитами соперника)
    return None

b = chess.Board("6k1/5ppp/8/8/8/8/5PPP/4R1K1 w - - 0 1")
print(mate_in(b, 1))
```

Для полноценного «мата в N» чередуют ходы атакующего (максимум) и соперника (минимум), проверяя, что **все** ответы соперника ведут к мату.

## Эндшпильные базы (tablebase)

Сиракузские таблицы (Syzygy) содержат точные оценки позиций до 7 фигур. Если задача — эндшпиль, ответ часто берётся из базы мгновенно. `python-chess` умеет открывать Syzygy:

```python
import chess, chess.syzygy
tb = chess.syzygy.open_tablebase("syzygy/3-4-5")
board = chess.Board("8/8/8/8/8/8/6k1/R6K w - - 0 1")
print(tb.probe_dtz(board))
```

## Nonogram: алгоритм решения

Nonogram (японский кроссворд) решается распространением ограничений: для каждой строки/столбца перебираем возможные расстановки блоков, пересекаем множества и фиксируем общие клетки. Повторяем, пока есть прогресс.

```python
def line_placements(clue, length):
    # все способы уложить блоки clue в строку length
    res = []
    def rec(i, pos, cur):
        if i == len(clue):
            res.append(cur + [0]*(length-len(cur))); return
        block = clue[i]
        max_start = length - sum(clue[i:]) - (len(clue)-i-1)
        for s in range(pos, max_start+1):
            rec(i+1, s+block+1, cur + [0]*(s-pos) + [1]*block)
    rec(0, 0, [])
    return res
```

Пересечение всех расстановок строки даёт гарантированно закрашенные/пустые клетки — их и фиксируем.

## Частые вопросы по логическим задачам

- **Шахматы или перебор?** Для «лучшего хода» — движок, для «мата в N» — перебор.
- **Что если позиция нестандартная?** Загружайте FEN, проверяйте легальность.
- **Судоку/кен-кен?** Z3 с `Distinct` решает почти мгновенно.
- **Переливания?** Поиск в ширину по состояниям — надёжнее формул.

## Взвешивания и переливания: детали

В задаче на взвешивания каждый результат (легче/тяжелее/равно) — троичный, поэтому `k` взвешиваний различают до `3^k` исходов. Для 12 монет с одной фальшивой (неизвестно, легче или тяжелее) нужно `ceil(log3(24)) = 3` взвешивания. Решение ищется как дерево решений: на каждом шаге делим множество гипотез на три равные части.

Задача о переливании решается BFS по состояниям `(a, b)` с четырьмя типами ходов: наполнить `a`, наполнить `b`, опустошить, перелить. Если целевой объём достижим, BFS даст кратчайшую последовательность.

## Итог по логическим задачам

Ключ к успеху — выбрать правильную модель: для шахмат это доска и перебор/движок, для сеток — система ограничений (Z3), для переливаний — поиск в графе состояний, для взвешиваний — дерево решений с троичными исходами. Почти всегда задача сводится к одному из этих четырёх шаблонов, и распознавание шаблона экономит больше времени, чем любой ручной разбор.
