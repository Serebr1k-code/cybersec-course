## Misc-крипто: что это за класс

Misc-крипто — это «лёгкая» криптография: классические шифры, кодировки, XOR, простые замены, нестандартные реализации. В отличие от полноценной crypto-категории, здесь редко нужны сложные математические атаки; чаще достаточно распознать схему и применить правильный однострочник. Цель модуля — собрать набор рецептов, покрывающих 90% misc-крипто задач, и научиться быстро определять шифр по признакам.

## Классические шифры и их признаки

- **ROT-N / Caesar** — сдвиг алфавита; признак: текст из букв, но нечитаемый; перебор 25 сдвигов.
- **Атбаш** — отражение алфавита (a↔z).
- **Виженер** — сдвиг по ключу; признак: частотный анализ не даёт чистого результата; нужен ключ или атака Касиски.
- **Подстановка** — перестановка букв; решается частотным анализом.
- **Rail fence / перестановки** — буквы перемешаны; пробуйте разные числа «рельс».

```python
import codecs
codecs.decode('uryyb', 'rot_13')      # 'hello'
# перебор ROT
for n in range(26):
    print(n, ''.join(chr((ord(c)-65-n)%26+65) if c.isupper() else c for c in s))
```

## XOR и его варианты

XOR — самый частый «крипто»-примитив в misc. Признаки: бинарный вывод, повторяющийся паттерн, известный префикс (`FLAG{`). Приёмы:

- **Односимвольный XOR** — перебор всех 256 ключей, ищите читаемый текст.
- **XOR с известным префиксом** — `key = ciphertext XOR known_plaintext`.
- **Повторяющийся ключ** — определите длину ключа (расстояние Хэмминга), затем частотный анализ по столбцам.

```python
def xor(data, key):
    return bytes(b ^ key[i % len(key)] for i, b in enumerate(data))
# односимвольный перебор
for k in range(256):
    out = xor(ct, bytes([k]))
    if b'FLAG' in out or all(32 <= c < 127 for c in out):
        print(k, out)
```

## Base-кодировки

Признаки: base64 — `[A-Za-z0-9+/]` с `=`; base32 — `[A-Z2-7]`; base58 — без `0OIl`; base85/ascii85. Часто данные «закодированы несколько раз» — декодируйте в цикле.

```python
import base64
base64.b64decode('RkxBR3t4fQ==')
base64.b32decode('...')
# base58
import base58; base58.b58decode('...')
```

Иногда встречаются нестандартные алфавиты — тогда декодируйте вручную через `int(s, base)` и свой алфавит.

## Одноразовые и потоковые шифры

Простая реализация XOR-потока с PRNG часто ломается из-за слабого seed. Смотрите, как генерируется ключевой поток: если `random.seed(time)` — воспроизведите. Если поток короткий и повторяется — это фактически повторяющийся XOR.

## Хеши и «найди прообраз»

Задачи «дан хеш, найди строку» — это либо словарь (`rockyou`, `hashcat`), либо подсказка в условии. Быстрая проверка:

```bash
hashcat -m 0 hash.txt /usr/share/wordlists/rockyou.txt    # MD5
```

Для нестандартных хешей (с солью, кастомных) читайте исходник и повторяйте логику.

## Роторные и исторические машины

Энигма, Bifid, Playfair, ADFGX. Для Энигмы — `py-enigma` с настройками роторов. Для Playfair/Bifid — готовые реализации. Признак: буквы сгруппированы парами/пятёрками, алфавит без пробелов.

## Типичные ошибки и подводные камни

- **Не распознать двойное кодирование** — декодируйте итеративно.
- **Игнорировать регистр** — ROT сохраняет регистр, base64 — нет.
- **Неверный алфавит** — base58/base85 различаются.
- **Забыть про префикс флага** — он часто даёт ключ XOR.
- **Считать, что «сложно»** — в misc крипто почти всегда просто.
- **Не проверить частотный анализ** — для подстановки это основа.
- **Путать хеш и шифр** — хеш необратим, нужен словарь/брут.

## Что дальше / решение

План: определите тип по признакам, примените соответствующий рецепт, при XOR — сначала односимвольный перебор и известный префикс, затем длина ключа и частотный анализ. Держите под рукой набор однострочников на Python (ROT, XOR, base-декодеры) и CyberChef. Помните: misc-крипто — это про распознавание и правильный инструмент, а не про сложную математику.

## Практический пример: ломаем повторяющийся XOR

Разберём задачу. Дан файл, зашифрованный XOR с повторяющимся ключом, и подсказка, что флаг начинается с `FLAG{`. Первый шаг — определить длину ключа методом Хэмминга: для каждой предполагаемой длины считаем среднее расстояние Хэмминга между соседними блоками; минимальное значение указывает на истинную длину.

```python
def hamming(a, b):
    return sum(bin(x ^ y).count('1') for x, y in zip(a, b))
best = min(range(1, 41),
           key=lambda k: sum(hamming(ct[i*k:(i+1)*k], ct[(i+1)*k:(i+2)*k])
                             for i in range(4)) / k)
```

Зная длину, восстанавливаем ключ по известному префиксу: `key[i] = ct[i] ^ ord('FLAG{'[i])`. Остальные байты ключа добираем частотным анализом по каждому столбцу. Наконец, расшифровываем целиком и ищем флаг.

## Практический пример: односимвольный XOR

Если ключ один байт, просто перебираем 256 вариантов и ищем читаемый текст или флаг:

```python
for k in range(256):
    out = bytes(b ^ k for b in ct)
    if b'FLAG' in out:
        print(k, out)
```

## Распознавание схемы по признакам

Прежде чем писать код, определите схему: бинарный вывод + повторяющиеся паттерны → XOR; текст из букв, нечитаемый → ROT/подстановка; строка из base64-символов → base64; сгруппированные пары → Playfair. Правильное распознавание экономит время: не пытайтесь ломать base64 как XOR.

## Частые вопросы

«Не знаю префикс?» — попробуйте частотный анализ или поищите известное слово. «Ключ длиннее текста?» — это одноразовый блокнот, нужна утечка ключа. «А если двойное кодирование?» — декодируйте в цикле. «Как быстро?» — начните с перебора и известного префикса.

## Что дальше / решение

Итог: для XOR — сначала односимвольный перебор и известный префикс, затем длина ключа через Хэмминг и частотный анализ. Для классических шифров — перебор ROT и частотный анализ. Распознавайте схему по признакам и держите набор однострочников. misc-крипто — это про правильный инструмент, а не про сложную математику.

## Расширенный чек-лист по misc-крипто

Идите по признакам. Строка из `[A-Za-z0-9+/]=` — base64; из `[A-Z2-7]` — base32; бинарный вывод с повторами — XOR; буквы без пробелов, нечитаемые — ROT/подстановка; пары букв — Playfair; группы по пять — ADFGX/Энигма; строка фиксированной длины из hex — возможно, хеш (тогда словарь/hashcat). Начните с самого простого: перебор ROT (26 вариантов) и односимвольный XOR (256). Затем — известный префикс флага для восстановления ключа XOR. Для base-кодировок декодируйте в цикле, пока не получите читаемый текст. Держите под рукой CyberChef и набор однострочников: они покрывают 90% задач. Не усложняйте — misc-крипто почти всегда решается правильным распознаванием схемы.

## Итог по misc-крипто

Запомните порядок: распознать схему по признакам, начать с самого простого (перебор ROT/XOR), использовать известный префикс флага, при повторяющемся XOR — определить длину ключа и применить частотный анализ, при base-кодировках — декодировать в цикле. Держите CyberChef и однострочники под рукой. Не усложняйте: в misc-крипто решение почти всегда проще, чем кажется.
