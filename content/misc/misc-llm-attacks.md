Модель — это тоже программа, и у неё своя поверхность атаки: вход (изображения, текст), интерфейс (API запросов) и формат хранения (веса). Этот модуль — про четыре класса атак, каждый из которых целится в свой слой.

## Что покрывает модуль

1. **Мультимодальные LLM** — атаки через изображения: типографические подсказки, скрытый текст, патчи.
2. **Извлечение модели** — восстановление поведения (и весов) чужой модели по запросам к API.
3. **Adversarial-примеры** — малые возмущения входа, ломающие предсказание.
4. **Pickle-модели** — небезопасная десериализация весов как путь к RCE.

## Почему такой порядок

Начинаем со входа (изображения) — самого «видимого» вектора. Затем — интерфейс API (извлечение). Потом — природа модели (adversarial). И в конце — формат хранения (pickle), где модель становится кодом. Порядок идёт от внешнего слоя к внутреннему.

## Чему вы научитесь

- Объяснять, почему изображение может нести инструкцию для модели.
- Строить запросы для извлечения поведения модели.
- Создавать adversarial-примеры и понимать их переносимость.
- Находить небезопасную десериализацию в файлах моделей.
