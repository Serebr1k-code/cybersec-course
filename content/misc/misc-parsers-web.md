Когда вы пишете «пользовательский ввод санитизирован», вы на самом деле доверяете одному конкретному парсеру. Проблема в том, что парсеров обычно несколько: браузер, санитайзер, серверный рендер, почтовый клиент. Если они понимают вход по-разному, появляется **парсер-дифф** — вход, который один считает безобидным, а другой превращает в код. Этот модуль про такие расхождения.

## Что покрывает модуль

Четыре темы, объединённые идеей «два парсера — одна строка»:

1. **Markdown-рендер** — как разметка превращается в HTML и где санитайзер отстаёт.
2. **Диффы HTML-парсеров** — mXSS и mutation XSS при повторной сериализации.
3. **HTML-письма** — парсинг почты и CSS-эксфильтрация данных.
4. **Парсер-диффы валидации** — обход WAF/валидатора через разное декодирование.

## Почему такой порядок

Начинаем с Markdown — самого частого источника mXSS на форумах и в CMS. Затем — чистый HTML и браузерная сериализация. Потом — письма, где нет JavaScript, но есть CSS. И в конце — общий случай: валидатор и бэкенд парсят один вход по-разному.

## Чему вы научитесь

- Проследить цепочку Markdown → HTML → DOM и найти, где ломается санитизация.
- Объяснять mXSS как результат «санитизировали, потом браузер переразобрал».
- Строить CSS-эксфильтрацию в письме без JavaScript.
- Находить парсер-диффы между WAF и приложением.

## Квиз

Проверь себя.

```quiz
- question: Что такое парсер-дифф?
  options:
    - Ошибка в парсере
    - Разное понимание одного входа двумя парсерами
    - Быстрый парсинг
    - Отладка
  answer: 1
  explanation: Основа обхода валидации.
- question: Что такое mXSS?
  options:
    - Обычный XSS
    - XSS, появляющийся при повторной сериализации DOM
    - SQL-инъекция
    - CSRF
  answer: 1
  explanation: Mutation XSS.
- question: Почему CSS опасен в письмах?
  options:
    - Он тормозит
    - Может делать запросы и утекать данные без JS
    - Он не работает
    - Он удаляется
  answer: 1
  explanation: background-image и @font-face.
```

## Куда дальше

Дальше — медиа-форматы: EBML, MIDI, PCAP, SRT. А пока запомни: если вход парсят два разных компонента, ищи расхождение.
