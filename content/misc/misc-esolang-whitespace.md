## Что такое Whitespace

Whitespace — эзотерический язык программирования, созданный Эдвином Брэди (Edwin Brady) и Крисом Моррисом (Chris Morris) в 2003 году. Его идея: **значимы только три символа** — пробел (Space, `0x20`), табуляция (Tab, `0x09`) и перевод строки (Line feed, `0x0A`). Все остальные символы (буквы, цифры, знаки) полностью игнорируются интерпретатором и могут нести любой текст.

Отсюда два практических следствия:

- Программа Whitespace может быть спрятана внутрь обычного исходника на C, Python или JavaScript: для глаза это обычный файл, для интерпретатора Whitespace — программа, закодированная в пробелах и переводах строк.
- При копировании через мессенджер или веб-форму программа легко «убивается»: редактор заменяет табы пробелами или обрезает пробелы в конце строк.

## Алфавит: три символа

Whitespace кодирует инструкции не отдельными символами, а их **последовательностями**. Для записи удобно ввести мнемонику:

- `S` = пробел,
- `T` = таб,
- `L` = перевод строки.

Тогда, например, `SS` — это «положить число на стек», а `TLSS` — «вывести символ». Именно эта мнемоника используется в дизассемблерах и в разборах задач.

## Стек-машина и модель памяти

Whitespace — стековая машина. У неё:

- **стек** — основной рабочий регион (числа кладутся и снимаются сверху);
- **куча (heap)** — ассоциативный массив «адрес → значение» для долговременного хранения;
- **счётчик инструкций** — неявный, плюс метки для переходов.

Числа в Whitespace — знаковые целые произвольной длины. При выводе числа (`TLST`) интерпретатор печатает его в десятичном виде; при выводе символа (`TLSS`) — как один байт (ASCII/Unicode-код).

## Полный набор инструкций

Ниже — вся система команд. Префикс задаёт группу, дальше идёт конкретная операция.

| Мнемоника | Инструкция | Действие |
|-----------|------------|----------|
| `SS` | push | положить число на стек |
| `SLS` | dup | продублировать вершину |
| `SLT` | swap | поменять две верхние ячейки |
| `SLL` | discard | снять и выбросить вершину |
| `STS` | copy n | скопировать n-й элемент наверх |
| `TSSS` | add | сложение двух верхних |
| `TSST` | sub | вычитание |
| `TSSL` | mul | умножение |
| `TSTS` | div | целочисленное деление |
| `TSTT` | mod | остаток |
| `TTS` | store | heap[addr] = value |
| `TTT` | retrieve | положить heap[addr] |
| `LSS` | label | метка |
| `LST` | call | вызов подпрограммы |
| `LSL` | jump | безусловный переход |
| `LTS` | jz | переход, если 0 |
| `LTT` | jn | переход, если < 0 |
| `LTL` | ret | возврат |
| `LLL` | end | конец программы |
| `TLSS` | out char | вывести символ |
| `TLST` | out num | вывести число |
| `TLTS` | read char | прочитать символ |
| `TLTT` | read num | прочитать число |

Число после `SS` кодируется так: знак (`S` = «+», `T` = «−»), затем двоичные цифры (`S` = 0, `T` = 1) и завершающий `L`.

## Инструменты и интерпретаторы

- **Онлайн:** `https://vii5ard.github.io/whitespace/` — интерпретатор в браузере, визуализирует стек; удобно для быстрой проверки.
- **wspace** — интерпретатор на Ruby (`gem install wspace`), запуск `wspace prog.ws`.
- **Эталонный интерпретатор** — Haskell-версия от авторов языка; собирается GHC.
- **Дизассемблеры/IDE:** существует ряд инструментов, показывающих программу в мнемонике `S/T/L`.
- **Собственный однострочник** для превращения невидимого в видимое:

```bash
sed 's/ /S/g; s/\t/T/g' prog.ws | cat -A
```

## Разобранный пример: печатаем «H»

Соберём минимальную программу, которая выводит символ `H` (код 72) и завершается.

1. Код `H` = 72. В двоичном виде 72 = `1001000`.
2. `push 72` = `SS` + знак `S` + биты `T S S T S S S` + `L` = `SSSTSSTSSSL`.
3. `out char` = `TLSS`.
4. `end` = `LLL`.

Склеиваем: `SSSTSSTSSSLTLSSLLL` (18 символов). Запишем байтами (`S=0x20`, `T=0x09`, `L=0x0A`):

```bash
printf '\x20\x20\x20\x09\x20\x20\x09\x20\x20\x20\x0a\x09\x0a\x20\x20\x0a\x0a\x0a' > h.ws
wspace h.ws
```

Вывод:

```
H
```

Проверим, что внутри действительно только три вида байтов:

```bash
xxd -g1 h.ws
```

```
00000000: 2020 2009 2020 0920 2020 0a09 0a20 200a   ...   .    ...  .
00000010: 0a0a                                     ..
```

Видим ровно `20`, `09`, `0a` — пробел, таб и перевод строки.

## Как сделать программу видимой

В CTF файл часто приходит как «пустой» или как обычный текст. Чтобы найти Whitespace:

```bash
# показать все непечатаемые символы
cat -A prog.txt
# заменить пробелы/табы/переводы строк на буквы
tr ' \t\n' 'STL' < prog.txt | head -c 200; echo
# проверить, есть ли вообще табы
grep -c $'\t' prog.txt
```

Если в файле десятки табов и переводов строк вперемешку с осмысленным текстом — это почти наверняка Whitespace внутри «приманки».

## Частые ошибки и подводные камни

- **Копирование через браузер.** Многие редакторы и формы заменяют табы на пробелы — программа ломается. Скачивайте файл, а не копируйте текст.
- **Обрезка пробелов в конце строк.** Trailing whitespace значим; многие редакторы его удаляют.
- **Путаница S/T/L.** Пробел — `S`, таб — `T`, перевод строки — `L`. Не путайте с обратной мнемоникой из чужого разбора.
- **Знак числа.** Число начинается со знака (`S`/`T`) — если пропустить его, значение уедет.
- **`out num` против `out char`.** Для вывода флага нужен `out char` (`TLSS`), а не `out num`.

## Справочная таблица

| Что | Как |
|-----|-----|
| Значимые символы | пробел, таб, LF |

| Вывод символа | `TLSS` |
| Вывод числа | `TLST` |
| Конец | `LLL` |

## Что дальше / решение

1. Увидели «пустой» или подозрительный файл — проверьте наличие табов и переводов строк (`grep -c $'\t'`, `cat -A`).
2. Переведите символы в мнемонику `S/T/L` и сравните с таблицей команд.
3. Запустите готовым интерпретатором (`wspace`, онлайн) — в большинстве задач это сразу даёт флаг.
4. Если интерпретатора нет — напишите свой: парсер разбивает поток на группы по префиксам и исполняет стек-машину; объём кода — порядка 150–250 строк.

## Пример с циклом и вводом

Разберём чуть более содержательную программу: она читает один символ, кладёт его в кучу и печатает обратно. Здесь видно, зачем нужны метки и переходы.

1. `read char` (`TLTS`) — прочитать символ со входа; он оказывается на стеке.
2. `dup` (`SLS`) — продублировать, чтобы значение осталось для вывода.
3. `push 0` + `store` (`TTS`) — сохранить в ячейку кучи с адресом 0.
4. `out char` (`TLSS`) — напечатать символ.
5. `end` (`LLL`) — завершить.

В мнемонике это выглядит так:

```text
TLTS        read char
SLS         dup
SS S L      push 0
TTS         store
TLSS        out char
LLL         end
```

Ключевая идея: метки (`LSS`) и условные переходы (`LTS` — «если 0», `LTT` — «если меньше нуля») позволяют строить циклы. Типичный цикл чтения-печати выглядит как метка, проверка условия, переход назад по метке и выход при нулевом символе (признак конца ввода).

## Whitespace как стеганография в реальном коде

Самое практичное применение Whitespace — сокрытие программы внутри обычного исходника. Представьте файл `main.c`, который нормально компилируется, но между строк спрятаны пробелы и табы, образующие вторую, невидимую программу. Для человека это рабочий код; для интерпретатора Whitespace — команда напечатать флаг.

Как это обнаружить:

```bash
# сколько табов и переводов строк в файле
grep -c $'\t' main.c
# показать непечатаемые как S/T/L
tr ' \t\n' 'STL' < main.c | grep -o 'S\{2,\}\|T\{2,\}' | head
```

Если в «обычном» текстовом файле аномально много табов и переводов строк в неожиданных местах — проверьте его интерпретатором Whitespace. Обратная ситуация тоже частая: задача даёт «пустой» файл, а внутри — сотни пробелов, которые как раз и являются программой.

## Частые вопросы по Whitespace

- **Можно ли скомпилировать Whitespace в обычный код?** Прямого компилятора почти нет; на практике пишут интерпретатор или используют онлайн-песочницу.
- **Что делать, если программа ничего не печатает?** Проверьте, что файл не был испорчен: табы не превратились в пробелы, а переводы строк не обрезаны. Это самая частая причина «мёртвой» программы.
- **Как быстро понять, что делает программа?** Замените пробелы на `S`, табы на `T`, переводы строк на `L` и прочитайте мнемонику: `SS` — push, `TLSS` — вывод символа, `LLL` — конец.
- **Где взять длинную программу для тренировки?** Возьмите готовый «Hello World» на Whitespace и разберите его по мнемонике вручную — это лучшая практика чтения стек-машины.
