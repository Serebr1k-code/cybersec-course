Часть misc-задач — это не «разбор формата», а **головоломка**: программа, которая печатает себя; код минимальной длины; картинка с искажённым текстом. Общее у них одно — их решают инструментом или хитрым приёмом, а не перебором. Этот модуль — про такие задачи.

## Что покрывает модуль

1. **Квины и саморепликация** (`misc-quine`) — программы, печатающие собственный код.
2. **Code golf** (`misc-code-golf`) — минимальный код под задачу, приёмы сжатия.
3. **Решение CAPTCHA** (`misc-captcha-solve`) — предобработка и распознавание.
4. **OCR: Tesseract** (`misc-ocr-deep`) — распознавание текста из изображений.
5. **Повреждённые QR** (`misc-qr-damaged`) — восстановление и декодирование QR/штрихкодов.

## Почему такой порядок

Начинаем с квинов — самоссылающихся программ, где важна идея. Затем code golf — минимализм как навык. После — распознавание: CAPTCHA, OCR, QR — три уровня «картинка → текст», от искажённого к структурированному.

## Чему вы научитесь

- Писать и понимать квины.
- Сжимать код, не теряя корректности.
- Предобрабатывать изображение для распознавания.
- Распознавать текст через OCR и чинить повреждённые коды.

## Квиз

Проверь себя.

```quiz
- question: Что печатает квин?
  options:
    - Свой собственный исходный код
    - Число Пи
    - Случайный текст
    - Ничего
  answer: 0
  explanation: Самореплицирующаяся программа.
- question: Зачем нужен code golf в CTF?
  options:
    - Решить задачу минимальным кодом (часто есть лимит длины)
    - Ускорить программу
    - Уменьшить память
    - Обфусцировать
  answer: 0
  explanation: Иногда ввод ограничен по длине.
- question: Что делают с CAPTCHA перед распознаванием?
  options:
    - Предобрабатывают (шум, порог, сегментация)
    - Шифруют
    - Сжимают
    - Удаляют
  answer: 0
  explanation: Чистка изображения повышает точность.
```

## Куда дальше

Первый урок — квины. Запомни главное: у головоломки есть приём, и его лучше знать заранее.

- CTF misc: головоломки и автоматизация.
- Обработка изображений: OCR и коды.
- Программирование: саморепликация и минимализм.
