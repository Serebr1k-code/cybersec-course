## Вопрос, с которого всё начинается

Задача: «выведи число от 1 до 100 минимальным кодом». Или: «введи строку, но она не должна содержать букв». Code golf — соревнование в краткости, но в CTF он превращается в реальное ограничение: иногда вход **не должен содержать** определённых символов. Разберём приёмы.

## Наш пример

В Python `print("hello")` — 14 символов. Можно короче: `print("hello")` уже минимально для строки, но если нужно вывести результат вычисления, помогает `print(sum(...))`. Разберём конкретный приём — замену строк на числа.

## Шаг 1: зачем это нужно

Code golf полезен, когда:
- Есть **лимит длины** ввода (WAF, поле формы).
- Запрещены определённые символы (фильтр).
- Нужно уместиться в минимальный payload.

Тогда «красивый код» не работает — нужен короткий и/или без запрещённых символов.

## Шаг 2: приёмы сжатия

- Убирай пробелы и переводы строк (где синтаксис позволяет).
- Используй короткие имена (`x` вместо `result`).
- Заменяй строки на числа/коды символов (`chr(104)` → `'h'`).
- Используй тернарники и генераторы.
- Применяй `lambda` вместо `def`.
- В Python — `*a,` для распаковки, `~` для `-x-1`.

## Шаг 3: обход фильтров

Если запрещены буквы, строку можно собрать из кодов: `chr(104)+chr(105)`. Если запрещены кавычки — взять строку из `__doc__`, имени функции, или через `bytes([...]).decode()`. Так строят payload'ы без ключевых слов.

## Шаг 4: полиглоты и квины

Code golf пересекается с полиглотами (код, валидный сразу на нескольких языках) и квинами. Полиглот — частый CTF-приём: одна строка работает и как bash, и как Python, и как Perl.

## Шаг 5: связь с обфускацией

Минимальный код часто непонятен — а это уже обфускация. Приёмы golf'а (короткие имена, коды символов, отсутствие пробелов) применяют, чтобы скрыть смысл кода. Обратная задача: **деобфусцировать** такой код.

## Шаг 6: как подходить к задаче

1. Пойми ограничение: длина? запрещённые символы? язык?
2. Реши «в лоб», потом сокращай.
3. Ищи эквиваленты короче (число вместо строки).
4. Проверяй, что результат тот же.
5. Для фильтров — строй строку из кодов.

## Шаг 7: инструменты

- `golf.shinh.org` — рейтинги golf'а.
- Онлайн-минификаторы.
- Python `exec`/`eval` для динамики.
- Для полиглотов — тесты в нескольких интерпретаторах.

## Шаг 8: практический пример

Задача: вывести `Hi` без букв `H` и `i` в коде. Решение: `print(chr(72)+chr(105))` — букв нет, результат есть. Так фильтры, запрещающие символы, обходятся через коды.

## Частые ошибки

- Жертвовать корректностью ради краткости.
- Забывать про ограничение длины ввода, а не кода.
- Полагать, что golf — только для соревнований.

## Разбор кейса: payload без букв

Задача: выполнить `print("Hi")`, но код не должен содержать ни одной буквы. Наивно невозможно — `print` состоит из букв. Обходят это через имена, собранные из символов:

```python
# нет ни одной буквы в коде:
print(chr(72)+chr(105))
```

`chr(72)` = `'H'`, `chr(105)` = `'i'`. Буквы исчезли из исходника, результат остался. Если запрещены и цифры, числа берут из других мест — длины строк, индексы, арифметику:

```python
# 'A' через арифметику без цифр и букв
c = chr(len('!!')+len('!')+True+True+True+True+True+True+True)   # 7+1+... -> 65
```

Более общий приём — собрать имя функции из кусков: `globals()['pr'+'int']('Hi')`. Строки `'pr'` и `'int'` можно получить из `__doc__`, `__name__` или `dir()` существующих объектов, тогда в коде вообще не будет нужных букв.

## Таблица: приёмы сокращения и обхода

| Цель | Приём | Пример |
|---|---|---|
| Убрать пробелы | сжать в одну строку | `a=1;b=2;print(a+b)` |
| Короткие имена | односимвольные | `x` вместо `result` |
| Строка без кавычек | код символа | `chr(104)` |
| Строка из другого объекта | `__doc__`, `__name__` | `().__class__.__name__` |
| Число без цифр | длины, `True`, арифметика | `len('!!')+True` |
| Ветвление | тернарник | `a if c else b` |
| Функция | `lambda` | `f=lambda x:x*x` |
| Распаковка | `*a,` | `a,*b=x` |
| Инверсия знака | `~x` = `-x-1` | `~5 == -6` |
| Двойное отрицание | `--x` | `--5 == 5` |

Помни, что экономия символов в коде и обход фильтра входа — разные задачи. Первая про длину исходника, вторая про множество допустимых символов в payload.

## Ограничение длины кода против ограничения ввода

Это частая путаница. В классическом golf ограничен размер **программы**. В CTF чаще ограничен размер **ввода** — поля формы, URL, аргумента. Тогда «сокращать» надо не свою программу, а именно отправляемое значение. Например, WAF режет запросы длиннее 100 байт: тогда длинный `UNION SELECT` не пройдёт, а короткий эквивалент (`||` вместо `CONCAT`, `0x616263` вместо `'abc'`) — пройдёт. Сначала выясни, что именно ограничено, и только потом сокращай.

## Если не сработало

- **Фильтр режет кавычки.** Возьми строку из существующего объекта: `open.__doc__`, имя класса, ключ в `os.environ`. Кавычки в коде не нужны.
- **Фильтр режет буквы вообще.** Собери строку из `chr()`/`bytes([...]).decode()`; `bytes` тоже имя — получи его через `''.__class__.__mro__` и индексы.
- **Фильтр режет скобки.** В Python вызов можно сделать через декораторы или через `exec` в формате, но проще искать другой путь; иногда помогает `@`-декоратор.
- **Получилось длиннее лимита.** Реши сначала в лоб, потом сокращай по таблице — не наоборот.

## Ограничения

Code golf — это головоломка, но в реальной эксплуатации он даёт конкретный выигрыш: обход наивных фильтров, влезание в лимит поля. У него есть цена: минимальный код трудночитаем, и его легко сломать одной правкой. Обратная сторона навыка — деобфускация: умение читать такой код нужно в reverse-задачах и при разборе чужого payload'а. Не путай golf с настоящей минификацией: минификатор сохраняет читаемость по смыслу, golf жертвует всем ради длины.

## Практика: строка-полиглот

Полиглот — код, валидный сразу на нескольких языках и делающий полезное в каждом. Простейший пример, работающий и как sh, и как Python:

```
echo hi
```

В shell это команда `echo`, в Python — вызов функции `echo` с аргументом `hi`. Общий приём — использовать синтаксис, который в одном языке является строкой-комментарием, а в другом — кодом. Например, `#` — комментарий в Python, но не в Perl; `;` завершает инструкцию в C и разделяет в Python.

Практическая ценность полиглота в CTF: иногда вход исполняется двумя интерпретаторами (например, файл отдают и bash, и python), и нужно, чтобы каждый получил то, что ожидает. Строят такие конструкции постепенно: пишут код для первого языка, проверяют его вторым, и подбирают общий синтаксис.

```python
# проверка полиглота: один и тот же файл двумя интерпретаторами
# sh polyglot.sh ; python3 polyglot.py
```

Ключ — не пытаться угадать «универсальный» синтаксис, а строить и тестировать итеративно, пока оба интерпретатора не дадут нужный результат.

## Отладка golf-кода

Минимальный код трудно отлаживать, потому что в нём нет ни пробелов, ни понятных имён. Практический приём: сначала напиши читаемую версию, убедись, что она работает на тестовых данных, а уже потом сжимай шаг за шагом, проверяя результат после каждого шага. Если после сжатия поведение изменилось — виноват последний шаг, и его легко откатить.

Для payload'ов без запрещённых символов это особенно важно: собирай строку из `chr()`/`bytes()` и печатай промежуточный результат, чтобы видеть, что реально получается на выходе. Частая ошибка — получить корректную по смыслу, но не ту строку из-за лишнего экранирования.

## Итоговая шпаргалка

- Ограничение бывает на **код** (классический golf) и на **ввод** (CTF-фильтры) — сначала выясни, что именно.
- Запрещённые символы обходят через `chr()`, `bytes([...]).decode()`, `__doc__`, `__name__`.
- Пробелы убирают, имена сокращают, ветвления делают тернарниками.
- Минимальный код трудночитаем — это уже обфускация; обратный навык — деобфускация.
- Полиглот — код для нескольких интерпретаторов сразу; строй его итеративно.
- Сначала пиши читаемую версию, сжимай по шагам, проверяй после каждого.
- `--x`, `~x`, `x if c else y` — базовые микро-приёмы экономии.

## Ещё один приём: экономия на импортах

Импорт — дорогая строка. Вместо `import os` берут модуль из уже загруженного пространства имён: `__import__('os')` длиннее, зато `os` часто уже есть в `globals()`. Ещё короче — `exec(open('f').read())`, если код лежит рядом. А для вывода без `print` годится `sys.stdout.write`, полученный из `__import__('sys')`. Помни: каждый такой приём экономит символы, но делает код хрупким — проверяй на целевой версии интерпретатора.

## Что мы теперь знаем

- Code golf — решение задачи минимальным кодом.
- В CTF это лимиты длины и запреты символов.
- Приёмы: короткие имена, коды символов, генераторы, lambda.
- Минимальный код часто обфусцирован.
- Обратная задача — деобфускация.
