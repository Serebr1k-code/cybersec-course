## Что такое SMT и Z3

SMT (Satisfiability Modulo Theories) — это задача поиска значений переменных, при которых выполняются логические и арифметические ограничения. Z3 — самый популярный SMT-солвер (от Microsoft Research). В CTF его применяют всюду, где есть «неизвестные + ограничения»: обратная разработка check-функций, криптографические задачи, судоку, криптарифмы, планирование. Вместо ручного перебора вы описываете условие, а Z3 находит решение.

## Установка и базовый API

```bash
pip install z3-solver
```

Минимальный пример: решить систему `x + y = 10`, `x - y = 2`.

```python
from z3 import *
x, y = Int('x'), Int('y')
s = Solver()
s.add(x + y == 10, x - y == 2)
print(s.check())     # sat
print(s.model())     # [y = 4, x = 6]
```

`check()` возвращает `sat` (есть решение), `unsat` (нет) или `unknown` (солвер не смог). После `sat` модель достают через `s.model()`.

## Булевы переменные и ограничения

```python
p, q = Bools('p q')
s = Solver()
s.add(Or(p, q), Not(And(p, q)))
print(s.check(), s.model())   # sat [q = True, p = False]
```

Логические головоломки («ровно один из трёх лжёт») удобно выражать через `And/Or/Not/Implies` и `PbEq` (ровно K истинных).

## Целочисленная арифметика

```python
a, b, c = Ints('a b c')
s = Solver()
s.add(a > 0, b > 0, c > 0, a + b + c == 12, a*a + b*b == c*c)
print(s.check(), s.model())   # пифагорова тройка
```

Для ограничений диапазона используйте `And(x >= 1, x <= 100)`. Для «ровно одно из» — `PbEq([(v,1) for v in vars], 1)`.

## Битовые векторы

Крипто-задачи и реверс почти всегда работают с машинными словами — здесь нужен `BitVec`, а не `Int`, потому что только `BitVec` воспроизводит переполнение и беззнаковую арифметику.

```python
from z3 import *
x = BitVec('x', 32)
s = Solver()
s.add((x * 0x1234 + 0x5678) & 0xffffffff == 0xdeadbeef)
print(s.check(), hex(s.model()[x].as_long()))
```

Операции: `+ - * & | ^ ~ << >>`, сравнения `ULT/ULE/UGT/UGE` (беззнаковые) и `ULT`/`SLT` (знаковые).

## Массивы и функции

```python
arr = Array('arr', BitVecSort(32), BitVecSort(8))
i = BitVec('i', 32)
s = Solver()
s.add(Select(arr, i) == 0x41, i == 3)
print(s.check(), s.model())   # arr[3] = 0x41
```

`Array` моделирует память (в том числе память программы при символическом исполнении). `Select(arr, idx)` — чтение, `Store(arr, idx, val)` — запись.

## Разобранный пример: решение check-функции

Пусть реверс показал: для флага из 4 байт нужно `f[0] + f[1] == 0x8f` и `f[2] ^ f[3] == 0x10`, все байты печатные.

```python
from z3 import *
f = [BitVec(f'f{i}', 8) for i in range(4)]
s = Solver()
s.add(f[0] + f[1] == 0x8f)
s.add(f[2] ^ f[3] == 0x10)
for c in f:
    s.add(c >= 0x20, c <= 0x7e)
print(s.check())
m = s.model()
print(bytes([m[c].as_long() for c in f]))
```

```
sat
b'...'
```

Если флаг длиннее, генерируйте переменные циклом и добавляйте ограничения по мере разбора check-функции.

## Разобранный пример: крипто-задача

Дано: `y = (x * A + B) mod 2^32`, известно `y`, `A`, `B`, найти `x`.

```python
from z3 import *
x = BitVec('x', 32)
A, B, Y = 0x1234567, 0x89abcdef, 0x0badf00d
s = Solver()
s.add(x * A + B == Y)
print(s.check(), hex(s.model()[x].as_long()))
```

Ключ к успеху — использовать `BitVec(…, 32)`, чтобы умножение и сложение переполнялись по модулю `2^32` ровно так, как в бинарнике.

## Оптимизация и модель

Если нужно не любое решение, а лучшее (минимум/максимум), берут `Optimize`:

```python
from z3 import *
o = Optimize()
x, y = Ints('x y')
o.add(x + y == 10, x >= 0, y >= 0)
o.maximize(x)
o.check()
print(o.model())   # x = 10, y = 0
```

Полезно и для «минимизировать число отличий от известного текста» в задачах на восстановление.

## Частые ошибки и подводные камни

- **`Int` вместо `BitVec`.** Классическая ошибка: `Int` не переполняется по модулю, поэтому реверс-условие не сойдётся. Для машинных слов — только `BitVec`.
- **Нет ограничений на печатность.** Без `c >= 0x20, c <= 0x7e` солвер вернёт «случайные» байты.
- **Молчаливый `unsat`.** Если система нерешаема — ищите ошибку в ограничениях: `s.unsat_core()` покажет противоречивое подмножество (нужны `s.set(unsat_core=True)` и именованные утверждения).
- **`unknown` из-за таймаута.** Ставьте `s.set("timeout", 10000)` и упрощайте нелинейность.
- **Медленная нелинейность.** Умножение переменных друг на друга дорого; фиксируйте известные константы.
- **Забыт импорт.** `from z3 import *` покрывает почти всё; отдельные сортировки — `BitVecSort` и т. п.

## Что дальше / решение

1. Определите неизвестные (байты флага, регистры) и их типы (`BitVec(8)` для байт).
2. Соберите ограничения из условия задачи: арифметика, сравнения, диапазоны.
3. Добавьте ограничения печатности для флага.
4. Запустите `check()`; при `sat` извлеките модель.
5. При `unsat` проверьте типы (`Int` vs `BitVec`) и ограничения; при `unknown` — таймаут и упрощение.

## Разбор судоку

Z3 элегантно решает судоку: каждая клетка — `Int` от 1 до 9, строки/столбцы/блоки содержат все цифры по разу.

```python
from z3 import *
cells = [[Int(f'c{i}{j}') for j in range(9)] for i in range(9)]
s = Solver()
for i in range(9):
    for j in range(9):
        s.add(cells[i][j] >= 1, cells[i][j] <= 9)
for i in range(9):
    s.add(Distinct(cells[i]))                      # строки
    s.add(Distinct([cells[j][i] for j in range(9)]))  # столбцы
for bi in range(3):
    for bj in range(3):
        block = [cells[3*bi+r][3*bj+c] for r in range(3) for c in range(3)]
        s.add(Distinct(block))                     # блоки 3x3
# начальные подсказки
s.add(cells[0][0] == 5)
print(s.check())
m = s.model()
print([[m[cells[i][j]].as_long() for j in range(9)] for i in range(9)])
```

`Distinct` — ключевой предикат «все значения разные». Тот же приём годится для латинских квадратов, кен-кен и планирования.

## Символическое исполнение и angr

Z3 — движок под капотом символического исполнения. В angr вы не пишете ограничения вручную: инструмент сам строит формулы из инструкций бинарника и просит Z3 найти вход, ведущий к «успеху».

```python
import angr
p = angr.Project("./crackme")
st = p.factory.entry_state()
sm = p.factory.simulation_manager(st)
sm.explore(find=0x401234, avoid=0x401300)   # адреса success/fail
print(sm.found[0].posix.dumps(0))           # искомый ввод
```

Понимание Z3 (BitVec, переполнение, `check()/model()`) делает angr предсказуемым: вы знаете, какую формулу он решает и почему она может оказаться `unsat` из-за неверной модели памяти.

## Ограничения и трюки Z3

- **`Distinct`** — «все значения разные» одной строкой.
- **`Sum`, `PbEq`, `PbLe`** — суммы и ограничения «ровно K истинных».
- **`If(cond, a, b)`** — ветвление внутри формулы.
- **`s.to_smt2()`** — выгрузить систему в SMT-LIB (для отладки во внешнем солвере).
- **`s.assertions()`** — посмотреть добавленные ограничения.
- **Множественные модели.** После `sat` добавьте `s.add(x != old_value)` и вызовите `check()` снова — получите следующее решение (перечисление всех флагов).

```python
from z3 import *
x = BitVec('x', 8)
s = Solver()
s.add(x > 0x40, x < 0x45)
while s.check() == sat:
    v = s.model()[x].as_long()
    print(chr(v), end="")
    s.add(x != v)
# ABCD
```

## Частые вопросы по Z3

- **Почему `unsat`?** Проверьте типы: `Int` не переполняется, а в бинарнике переполнение есть — берите `BitVec`.
- **Почему солвер «висит»?** Нелинейная арифметика (`x*y` с переменными) тяжёлая; фиксируйте известные константы и ставьте таймаут.
- **Как ускорить?** Сузьте диапазоны (`0x20..0x7e` для байт), уберите лишние переменные.
- **Что если решений много?** Добавьте критерий (`Optimize`) или перебирайте модели по одной.

## Мини-шпаргалка по Z3

Порядок работы: определите неизвестные (`BitVec` для машинных слов, `Int` для математики), добавьте ограничения из условия, ограничьте печатные байты (`0x20..0x7e`), вызовите `check()`, извлеките `model()`. Для «все разные» — `Distinct`, для «ровно K» — `PbEq`, для оптимума — `Optimize`. При `unsat` проверяйте типы и используйте `unsat_core()`; при `unknown` — таймаут и упрощение нелинейности. Для перечисления всех решений добавляйте `x != old` после каждой модели. Этого каркаса хватает и для реверса check-функций, и для судоку, и для крипто-задач.

## Итог по Z3

Z3 превращает «сложную головоломку» в «опиши условия». Ключ к успеху — правильный тип переменных (`BitVec` для машинной арифметики) и полный набор ограничений (включая печатность байт). Научившись один раз формулировать задачу как систему ограничений, вы получаете универсальный инструмент для реверса, крипто и логических задач, который экономит часы ручного перебора.
