Даже без cookie и логина браузер выдаёт о вас десятки параметров: разрешение экрана, набор шрифтов, особенности отрисовки графики, часовой пояс, язык, поведение GPU. В совокупности это **отпечаток**, который с высокой вероятностью уникален. Для OSINT это палка о двух концах: вы можете использовать фингерпринтинг против цели, но и сами рискуете быть отслеженным и связанным между сессиями, если не управляете отпечатком.

## Что такое browser fingerprinting

Фингерпринтинг — это пассивная идентификация браузера по набору характеристик, без хранения состояния (stateless tracking). В отличие от cookie, отпечаток не «сбрасывается» очисткой кэша и работает между сайтами (в рамках одного движка). Он строится из десятков энтропийных признаков, и чем больше признаков комбинируется, тем выше вероятность уникальности.

## Компоненты отпечатка

| Признак | Что выдаёт |
|---|---|
| User-Agent | Версия ОС/браузера |
| Screen/Window | Разрешение, DPR |
| Timezone/Locale | Регион |
| Fonts | Установленные шрифты |
| Canvas | Отрисовка текста/графики |
| WebGL | Параметры GPU |
| AudioContext | Обработка звука |
| Plugins | Список плагинов |
| Hardware | Ядра CPU, память, батарея |
| Do Not Track | Настройка |
| HTTP-заголовки | Accept-Language, порядок |

Особенно «дороги» в энтропии Canvas (различия в рендеринге зависят от драйверов/шрифтов), WebGL (модель GPU) и список шрифтов.

## Библиотеки и сервисы проверки

- **FingerprintJS** — коммерческая библиотека (open-source версия `fingerprintjs2`).
- **CreepJS** — продвинутый тест, выявляет несоответствия (для детекта антидетект-браузеров).
- **AmIUnique** — исследовательский сервис с базой отпечатков.
- **Cover Your Tracks (EFF, ex-Panopticlick)** — наглядный отчёт об уникальности.
- **BrowserLeaks** — отдельные тесты (Canvas, WebGL, WebRTC, DNS).
- **deviceandbrowserinfo / whoami** — сводный отпечаток.

```bash
# Проверка через CreepJS (открыть в браузере):
# https://abrahamjuliot.github.io/creepjs/
# AmIUnique:
# https://amiunique.org/
```

Эти сервисы показывают ваш отпечаток и его «уникальность» в процентах.

## Как связывают сессии

Аналитик/платформа может:

1. Считать отпечаток на каждом визите и группировать по нему.
2. Сопоставлять отпечаток с поведением (тайминги, движения мыши, скорость набора).
3. Связывать отпечаток с IP (даже при смене VPN остаются признаки).
4. Использовать **cookie + отпечаток** вместе (суперcookie-подобные техники).
5. Применять **TLS-фингерпринтинг (JA3)** на сетевом уровне.

Именно поэтому «просто включить VPN» недостаточно: отпечаток остаётся стабильным и выдаёт вас между сессиями.

## Защита и антидетект-браузеры

| Подход | Эффект |
|---|---|
| Tor Browser | Унифицированный отпечаток (все «одинаковы») |
| Mullvad Browser | Антифингерпринт по умолчанию |
| Brave | Рандомизация отпечатка |
| Firefox + resistFingerprinting | Снижение энтропии |
| Антидетект (Multilogin/AdsPower) | Разные отпечатки для профилей |
| Изолированные VM | Разделение окружений |

Ключевая идея Tor Browser: **сделать всех похожими** (общий отпечаток), а не уникальными. Антидетект-браузеры делают обратное — дают каждому профилю правдоподобный, но разный отпечаток. Для OSINT-легенды чаще подходит антидетект (чтобы профиль выглядел как реальный пользователь), для анонимности — Tor.

## Разобранный пример: сравнение отпечатков

1. Откройте `creepjs` в обычном браузере — сохраните отпечаток.
2. Откройте в Tor Browser — увидите унифицированный, «как у многих».
3. Откройте в антидетект-профиле — увидите уникальный, но согласованный отпечаток.
4. Сравните Canvas/WebGL/шрифты между профилями.
5. Проверьте утечки: WebRTC (реальный IP), DNS (провайдер), timezone.
6. Сделайте вывод: какой профиль подходит для вашей легенды.

## OPSEC-чеклист

- Отдельный браузерный профиль на каждую легенду.
- VPN/прокси в регионе легенды; проверка на DNS/WebRTC-утечки.
- Отключение WebRTC, синхронизации, автозаполнения.
- Часовой пояс и язык = регион легенды.
- Не смешивать cookie/сессии с личными.
- Проверять отпечаток до и после настроек.
- Осторожно с расширениями (они тоже фингерпринтятся).

## Подводные камни

- **VPN без антифингерпринта.** IP сменился, отпечаток — нет.
- **Расширения.** Блокировщики и менеджеры паролей добавляют энтропию.
- **Разрешение экрана.** Уникальное разрешение выделяет вас.
- **Локальные шрифты.** Редкие шрифты (например, из специфичного ПО) уникальны.
- **Смена user-agent без согласования.** Несоответствия ловит CreepJS.
- **Tor для легенды.** Tor-выход часто помечен как «аноним», что подозрительно для соцсети.

## Что дальше / решение

Фингерпринтинг — фундамент OPSEC. Свяжите с `osint-sock-puppets`, `osint-opsec`, `osint-legal-ethics`. Дальше — изоляция на уровне ОС (Whonix/Tails), управление TLS-отпечатком. Для тренировки проверьте свой отпечаток на CreepJS и AmIUnique и попробуйте сделать его «как у всех» или «правдоподобно уникальным».

## TLS/JA3 и сетевой фингерпринтинг

Отпечаток есть не только в браузере, но и на сетевом уровне. **JA3/JA3S** — хэш параметров TLS ClientHello/ServerHello (версии, набор шифров, расширения, эллиптические кривые). Разные клиенты (Chrome, Firefox, curl, python-requests, malware) дают разные JA3. Это позволяет:

- детектировать инструменты (например, `python-requests` в логах);
- связывать сессии, использующие один и тот же стек;
- выявлять malware по уникальному JA3.

```bash
# JA3 в Zeek (ssl.log) или через tshark
tshark -r cap.pcap -Y "tls.handshake.type==1" \
  -T fields -e ip.src -e tls.handshake.ja3
```

Для OSINT это важно: если вы ходите под легендой через `curl`/скрипты, ваш JA3 отличается от браузерного и выдаёт автоматизацию. Правило: **инструменты должны имитировать браузерный TLS-стек** (или использовать реальный браузер), иначе вы «светитесь».

## Фингерпринтинг против цели (для OSINT)

Фингерпринтинг работает в обе стороны. Как OSINT-инструмент он помогает:

- **Различать устройства** за одним IP (NAT): по отпечатку видно, сколько разных браузеров.
- **Подтверждать принадлежность** аккаунтов (одинаковый отпечаток на разных площадках).
- **Выявлять ботов/фермы** в соцсетях (шаблонные отпечатки).
- **Определять технологии** сайта по JS-фингерпринтам и библиотекам.
- **Связывать** посещения с профилем через canvas-отпечаток в аналитике.

Инструменты: `FingerprintJS` (сайт), `Wappalyzer`/`BuiltWith` (технологии), `CreepJS` (анализ чужого отпечатка при встраивании).

## Лаборатория

1. Проверьте свой отпечаток на CreepJS и AmIUnique — запишите уникальность.
2. Откройте тот же сайт в Tor Browser — сравните.
3. Запустите `curl` и посмотрите свой JA3 (через Wireshark/Zeek) — сравните с браузером.
4. Включите VPN и перепроверьте отпечаток — убедитесь, что он не изменился.
5. Настройте антидетект-профиль и добейтесь «правдоподобно уникального» отпечатка.
6. Проверьте утечки WebRTC/DNS.
