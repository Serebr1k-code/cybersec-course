VK (ВКонтакте) — крупнейшая русскоязычная соцсеть и один из richest-источников для OSINT по России/СНГ. Профили часто содержат полное имя, город, вуз, работу, фото и — главное — **список друзей и подписок**, что позволяет строить граф связей. Google почти не индексирует VK-контент, поэтому нужен локальный поиск и API. Для OSINT это ключевой инструмент, если цель из русскоязычного региона.

## VK как источник

В отличие от анонимного Reddit, VK обычно **деанонимизирован по умолчанию**: реальные имена, фото, город. Люди используют VK как «паспорт» соцсетей: там же музыка, видео, сообщества по интересам, комментарии. Для аналитика ценны: сам профиль, список друзей (кто с кем), сообщества (интересы, работа, учёба), фотографии (геолокация, события), «стена» (посты и репосты).

## Поиск людей и сообществ

- **Расширенный поиск людей** (`vk.com/search`): фильтры по имени, городу, вузу, возрасту, работе.
- **Поиск сообществ** (`vk.com/search?c[section]=communities`): по названию, тематике.
- **Поиск по стене/постам** — через сам VK или сторонние сервисы.
- **`site:vk.com`** в Яндексе (Google индексирует хуже).

```
# Яндекс-дork по VK
site:vk.com "Иван Иванов" "Москва"
site:vk.com "компания Ромашка"
```

## Профиль: что видно

В зависимости от настроек приватности видны: имя, аватар, город, день рождения, вуз, школы, работа, статус, «о себе», музыка, видео, подписки, друзья, фотоальбомы, стена. Даже при закрытом профиле часто доступны: аватар, имя, число друзей, некоторые общие сообщества. Настройки приватности — «дырявые»: одна открытая секция может выдать контекст.

## Друзья, подписки, интересы

Три ключевых вектора:

1. **Друзья** — социальный граф: круг общения, коллеги, семья. Общие друзья связывают людей.
2. **Подписки/сообщества** — интересы, работа, учёба, политика; иногда сообщества-«инсайдеры».
3. **Музыка/видео/репосты** — вкусы и ценности, иногда с геопривязкой.

Анализ графа выявляет «мосты» — людей, связывающих группы, и общие сообщества, указывающие на принадлежность.

## VK API и инструменты

VK имеет официальный **API** (`api.vk.com`), методы `users.get`, `friends.get`, `groups.getMembers`, `wall.get`. Требуется access token (свой). Также:

- **VK API в Python** через `vk`-библиотеку или `requests`.
- **`vk-osint`**, **`vkparse`**, **`VK-Scrapper`** — сторонние обёртки.
- **Экспорт друзей** и построение графа (Gephi/networkx).
- **Поиск по фото** (VK-поиск по изображению) и обратный поиск.

```python
import requests
TOKEN = "..."  # свой токен
r = requests.get("https://api.vk.com/method/users.get",
    params={"user_ids": "durov", "fields": "city,bdate,universities",
            "access_token": TOKEN, "v": "5.131"})
print(r.json())
```

## Разобранный пример

1. Находим профиль по имени+городу через расширенный поиск.
2. Фиксируем: имя, город, вуз, работа, дата рождения.
3. Открываем друзей — выгружаем список (вручную/через API).
4. Смотрим подписки: сообщества работы/учёбы/интересов.
5. Ищем упоминания в сообществах: `site:vk.com "<имя>"`.
6. Проверяем фото на геометки (обратный поиск, `osint-image-reverse`).
7. Строим граф: профиль — друзья — общие сообщества; ищем связи с компанией.

## Анализ связей

Граф VK особенно ценен для выявления **скрытых связей**: если два человека не «друзья», но оба подписаны на малое сообщество или оба в друзьях у третьего — это указывает на знакомство. Также полезны **общие фото** (события), **одновременные посты** (совместные проекты). Инструменты: экспорт в Gephi, `networkx` для метрик (betweenness, кластеры). Для крупных сообществ анализируют администраторов и активных участников — там часто «ядро».

## Этика и защита

- Публичный профиль — можно смотреть; массовый сбор (scraping) может нарушать ToS.
- Не публикуйте личные данные без необходимости.
- Не используйте VK для преследования.
- Для защиты: закрыть профиль, ограничить друзей, скрыть подписки, не публиковать геолокацию.

## Подводные камни

- **Приватность «частичная».** Закрытый профиль всё равно отдаёт часть данных.
- **Устаревшие данные.** Люди меняют работу/город, старые посты остаются.
- **Фейковые профили.** Проверяйте активность и связи.
- **Google-индекс слабый.** Используйте Яндекс и API.
- **Лимиты API.** VK ограничивает частоту; планируйте запросы.
- **Юридические рамки.** Массовый скрейпинг — риск.

## Что дальше / решение

VK — центральный узел русского социального OSINT; свяжите с `osint-people-search`, `osint-username-enum`, `osint-image-reverse`, `osint-verification`, `osint-search-regional`. Дальше — Telegram (`osint-telegram`) и графовый анализ. Для CTF потренируйтесь восстанавливать связи по друзьям и сообществам.

## VK для CTF и расследований

В CTF VK-задачи строятся вокруг восстановления связи: дан профиль, нужно найти человека/флаг по друзьям, сообществам или фото. Алгоритм: найти профиль → выгрузить друзей → найти «необычного» друга (админ сообщества, коллега) → перейти к нему → найти флаг в его статусе/посте. Иногда флаг спрятан в геолокации фото или в названии закрытого сообщества. В расследованиях (журналистика, HR) VK помогает проверить кандидата: реальные ли данные, нет ли компромата в старых постах, кто в окружении.

## Анализ сообществ в деталях

Сообщества VK — это мини-графы. Что анализируют:

- **Администраторы** — «ядро»; часто связаны между собой и с владельцем.
- **Активные участники** — по комментариям/лайкам; повторяющиеся лица выдают связи.
- **Тематика** — работа, учёба, хобби, политика; формируют профиль.
- **География** — локальные сообщества указывают на район/город.
- **Даты** — время основания/активности коррелирует с событиями.

Связка «человек → общее малое сообщество → другой человек» — сильный индикатор знакомства, даже если они не в друзьях. Для автоматизации выгружают участников через `groups.getMembers` (с лимитами) и считают пересечения в Python (pandas/networkx).

## Лаборатория

1. Найдите публичный профиль по имени+городу.
2. Зафиксируйте базовые поля (город, вуз, работа, ДР).
3. Выгрузите друзей (вручную или API) — постройте список.
4. Соберите подписки/сообщества.
5. Найдите пересечения: общие сообщества с другим человеком.
6. Экспортируйте граф в Gephi, посчитайте метрики.
7. Проверьте фото на геометки.

## Геолокация по VK-фото

VK-фото — богатый геолокационный источник. Что проверять:

- **EXIF** (если фото не пережато): GPS, модель камеры (`osint-exif-deep`).
- **Геометки на карте** (VK показывает места съёмки для некоторых фото).
- **Привязка к сообществам/событиям** (встречи, концерты, вуз).
- **Фон** (вывески, архитектура, номера) — обратный поиск и `osint-geolocation`.
- **Альбомы** («Мой город», «Отдых 2023») дают регион.

Для точной локации комбинируют обратный поиск (`osint-image-reverse-deep`) и анализ теней (`osint-shadow-analysis`). Помните: VK часто пережимает фото, поэтому EXIF может быть удалён — тогда работают только визуальные признаки.

## Инструменты и обёртки VK

Помимо официального API, есть готовые обёртки и сервисы:

- **`vk` (Python-библиотека)** — удобный доступ к методам API.
- **`vk-api` / `vk_api`** — синхронный/асинхронный клиент.
- **`VK-Scrapper` / `vkparse`** — скрейпинг профилей (осторожно с ToS).
- **`target-my-friends`** — экспорт друзей/подписчиков.
- **Gephi / networkx** — построение и анализ графа.
- **Сервисы «шерлок»** — проверка ника на других площадках.

```python
import vk_api
vk = vk_api.VkApi(token="...")
api = vk.get_api()
print(api.users.get(user_ids="durov", fields="city,bdate")[0])
print(api.friends.get(user_id=1)["items"][:10])
```

Токен получают через standalone-приложение VK. Учитывайте лимиты (обычно ~3–5 запросов/сек) и не запускайте массовый сбор без авторизации.
