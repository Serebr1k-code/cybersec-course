## Вопрос, с которого всё начинается

Тебе прислали одно фото: обычная улица, ни подписи, ни геометки. Нужно понять, где оно сделано. Новичок начинает угадывать город — и почти всегда ошибается.

Геолокация по фото — это не угадывание, а **дедукция**: мы собираем десятки мелких подсказок и сужаем область от континента до конкретной улицы. Разберём это на одном снимке — и ты увидишь, что каждая деталь на фото отвечает ровно на один вопрос.

## Наш пример: файл street.jpg

У нас один объект — `street.jpg`. Первый вопрос самый дешёвый: может, место уже спрятано внутри самого файла?

Фотографии хранят **EXIF** — служебные метаданные камеры: модель, дату, иногда GPS-координаты. Проверим:

```bash
exiftool -a -G1 -gps:all -n street.jpg
```

```
(пусто)
```

Координат нет — соцсеть, через которую шло фото, вырезала геометку. Значит, работаем глазами. Выстраиваем **воронку**: сначала континент, потом страна, город, улица. На каждом уровне фиксируем уверенность и не двигаемся дальше, пока не набрали подтверждений.

## Шаг 1: письменность сужает до страны

Первое, что бросается в глаза, — вывеска кириллицей. Кириллица сразу очерчивает круг: Россия, Беларусь, Украина, Болгария, Сербия, Казахстан, Монголия.

Чтобы сузить, смотрим не на алфавит в целом, а на конкретные буквы. Украинский выдаёт `і`, `ї`, `є`; белорусский — `ў`; болгарский — `ъ` в конце слова. На нашей вывеске этих маркеров нет, а написание и шрифт типичны для России. Гипотеза уровня «страна»: Россия. Пока это только гипотеза — одной письменности мало.

## Шаг 2: инфраструктура сужает до города

Теперь ищем признаки, которые различаются между городами. На снимке над улицей видны **троллейбусные провода** — две пары натянутых линий с характерными подвесами.

Троллейбус есть не везде: это признак крупного города с троллейбусной сетью. Добавляем второй признак — материал домов: красный кирпич, этажность 4–5, характерные арочные окна первого этажа. Третий признак — форма столба у тротуара.

Правило трёх деталей: гипотеза считается рабочей, когда совпали минимум три **независимых** признака (не три вида одной вывески, а, например, язык + транспорт + тип застройки). У нас они набрались: кириллица + троллейбус + кирпичная застройка. Сузились до списка городов России с троллейбусом.

## Шаг 3: OCR вывески даёт поисковый запрос

На вывеске читается `АПТЕКА № 12`. Распознаем текст программно — **OCR** (optical character recognition, распознавание текста с картинки):

```bash
tesseract street.jpg - -l rus+eng 2>/dev/null
```

```
АПТЕКА № 12
Тел. +7 (XXX) XXX-XX-XX
```

Теперь у нас есть точная строка для поиска. `+7` подтверждает Россию или Казахстан, а номер аптеки «№ 12» — это уже привязка к конкретной сети. Ищем `"Аптека № 12"` плюс город-кандидат в обычном поиске. Такие вывески часто попадают в отзывы, объявления, местные справочники — и выдают адрес.

## Шаг 4: проверяем свет и тень

Прежде чем искать перекрёсток, проверим ещё одну подсказку — направление теней. Тень всегда падает **от** солнца, поэтому по ней можно понять сторону света, а по длине — примерное время суток.

Инструмент **SunCalc** (или библиотека `pysolar`) считает положение солнца для любой точки и времени:

```bash
pip install pysolar
python3 -c "import datetime;from pysolar.solar import get_altitude,get_azimuth;print(round(get_altitude(55.75,37.62,datetime.datetime(2024,6,21,10,tzinfo=datetime.timezone.utc)),1))"
```

```
48.3
```

Высота солнца ~48° в 10 утра — тени короткие, солнце высоко. Сопоставив направление тени на фото с азимутом для городов-кандидатов, мы отсеиваем те, где в это время тень падала бы иначе. Это связывает фото с конкретным временем (об этом подробнее — в уроке про хронолокацию).

## Шаг 5: верификация по панорамам

Гипотеза — это ещё не ответ. Финальный шаг — сопоставление с уличными панорамами.

1. Открываем **Google Street View** и **Яндекс.Панорамы** на кандидатном адресе (для России Яндекс часто детальнее).
2. Ищем **два-три неподвижных объекта** — аптеку, столб, дерево — и сравниваем ракурс.
3. Проверяем **исторические снимки**: вывеска могла переехать, дом — перестроиться.
4. Убеждаемся, что совпадение неслучайно: типовая застройка даёт ложные срабатывания.

Дополнительно можно проверить объекты вокруг через **Overpass Turbo** — поиск по базе OpenStreetMap по тегам. Например, все аптеки в радиусе 500 метров:

```
[out:json][timeout:25];
node["amenity"="pharmacy"](around:500,55.7558,37.6173);
out body;
```

Обратное геокодирование найденных координат — через Nominatim:

```bash
curl -s "https://nominatim.openstreetmap.org/reverse?lat=55.7558&lon=37.6173&format=json" \
  -H "User-Agent: osint-research" | jq -r '.display_name'
```

```
улица Тверская, 12, Тверской район, Москва, Россия
```

## Если внешних ориентиров почти нет

Бывает, что улицы на фото нет вовсе — снят интерьер, еда или документ на столе. Тогда работают мелочи:

- **Розетки и выключатели.** Форма вилки выдаёт страну: Type A/B — США, Type C/F — Европа, Type G — Великобритания, Type I — Австралия и Китай.
- **Еда и упаковка.** Язык этикетки, единицы измерения и **штрих-код**: префикс EAN (первые цифры) кодирует страну регистрации бренда.
- **Документы на фоне.** Формат даты выдаёт привычку страны: `ДД.ММ.ГГГГ` — Европа и СНГ, `ММ/ДД/ГГГГ` — США.
- **Форма и знаки различия.** Военная и полицейская расцветка, шевроны.

Комбинируя такие мелочи, можно дойти от континента до страны даже без единой вывески.

## Что мы теперь знаем

- Место не было в EXIF — пришлось определять по картинке.
- Кириллица + троллейбус + кирпичная застройка дали страну и тип города.
- OCR вывески дал точный поисковый запрос, а `+7` подтвердил страну.
- Направление тени связало фото с временем суток.
- Панорамы подтвердили перекрёсток по трём неподвижным объектам.

## На что смотреть дальше

Обрати внимание на **столбы и провода** (форма деревянных опор уникальна для регионов), **люки и тротуарную плитку**, **bollards** (столбики с светоотражателями) и **розетки в интерьерах** (Type G — Британия, Type C/F — Европа). Это «подписи» местности, которые новичок не замечает, а опытный геолокатор читает как текст.

## Куда дальше

Мы определили место по снимку. В следующем уроке — **хронолокация**: возьмём то же фото и по теням, погоде и положению солнца восстановим не только место, но и время съёмки. А пока главное запомни: геолокация — это воронка «континент → страна → город → улица» плюс проверка по панорамам, а не догадка.

## Где пригодится

- **CTF (OSINT):** задачи «найди место по фото».
- **Журналистика:** верификация снимков из зон конфликтов.
- **Антифрод и правоохранительные органы:** установление места по фото (в рамках закона).
- **GeoGuessr и тренировки:** прокачка наблюдательности.
