Стриминговые платформы (Twitch, YouTube Live, Kick, Trovo, VK Play) — это не только видео, но и большой объём метаданных: расписания, панели с контактами, чаты, донаты, VOD-архивы. Стримеры часто выкладывают больше, чем планируют: реальное имя в донатах, ссылки на соцсети в панелях, геолокацию в фоне, распорядок дня. Для OSINT это отдельный, богатый пласт.

## Теория: что раскрывает стример

Структура публичных данных стримера:

| Данные | Где |
|--------|-----|
| Ник, отображаемое имя | канал |
| Био и «панели» | под плеером |
| Расписание | панель/календарь |
| Соцсети | панели, команды чата |
| VOD (архив) | вкладка Videos |
| Чат | live-чат, логи |
| Донаты/сабы | оверлей, чат-боты |
| Игровые аккаунты | стрим, оверлеи |
| Голос/лицо | веб-камера, микрофон |

Ключ: **панели канала** — это, по сути, визитка. Там часто GitHub, Discord, Telegram, личный сайт, бизнес-email.

## Публичный API Twitch

Twitch имеет публичный Helix API (нужен `Client-ID` и токен), но многое читается без входа. Базовый просмотр канала:

```bash
curl -s "https://decapi.me/twitch/avatar/target"            # аватар
curl -s "https://decapi.me/twitch/uptime/target"           # аптайм
curl -s "https://decapi.me/twitch/followage/target"        # подписка
curl -s "https://decapi.me/twitch/title/target"            # заголовок
```

`decapi.me` — удобный публичный прокси к данным Twitch. Через Helix API:

```bash
curl -s -H "Client-ID: $CID" -H "Authorization: Bearer $TOKEN" \
  "https://api.twitch.tv/helix/users?login=target" | python3 -m json.tool
```

Вывод содержит `id`, `display_name`, `created_at` (дата регистрации), `description` (био с ссылками).

## Панели и расписание

Панели канала доступны через неофициальные эндпоинты или парсинг страницы. Часто содержат ссылки:

```bash
curl -s "https://www.twitch.tv/target" | grep -oiE 'https?://[^"'\'' ]+' | grep -viE 'twitch|jtvnw|cloudfront' | sort -u
```

Из этого списка — Discord, Telegram, GitHub, личный сайт. Каждая ссылка — pivot.

## VOD и чат: архив активности

**VOD** (Video On Demand) — записи стримов. Они содержат:
- **голос и лицо** (биометрия, акцент);
- **фон** (геолокация по комнате/виду из окна);
- **оверлеи** (игровые ники, счёт);
- **уведомления** (имена донатеров).

Скачивание VOD:

```bash
yt-dlp "https://www.twitch.tv/videos/123456789"
```

**Чат** — история сообщений. Twitch-чаты логируются сторонними сервисами (`twitchchat`-архивы, `rechat`). Через `rechat` можно скачать чат VOD и найти: упоминания, паттерны, ответы стримера на вопросы.

```bash
# rechat: https://rechat.twitch.tv/rechat-messages?start=...&video_id=...
```

## Разобранный пример: от канала к личности

Дано: канал `target`.

Шаг 1 — аватар и дата регистрации:

```bash
curl -s "https://decapi.me/twitch/avatar/target"
# https://static-cdn.jtvnw.net/jtv_user_pictures/abc123-profile_image-300x300.png
```

Скачиваем аватар и прогоняем через обратный поиск (см. `osint-image-reverse`) — часто находят Instagram/Telegram с тем же фото.

Шаг 2 — ссылки на странице:

```bash
curl -s "https://www.twitch.tv/target" | grep -oiE 'https?://[^"'\'' ]+' | grep -iE 'discord|telegram|github|twitter|youtube' | sort -u
# https://discord.gg/abcd
# https://t.me/targetchat
# https://github.com/target
```

Шаг 3 — Discord-инвайт даёт сервер (см. `osint-discord`), Telegram — канал (см. `osint-telegram`).

Шаг 4 — VOD: скачиваем и смотрим фон/голос для геолокации.

Итог: Twitch → Discord/Telegram/GitHub → личность и сообщество.

## Другие платформы

| Платформа | Особенность OSINT |
|-----------|-------------------|
| YouTube Live | история, подписки, комментарии |
| Kick | новая, слабая модерация |
| Trovo | регионы, меньше данных |
| VK Play | рунет, связь с VK-профилем |

| Rumble | альтернативная, политический контент |

DLive и подобные блокчейн-платформы интересны тем, что донаты видны в цепочке (см. `osint-blockchain`).

## Расписание и активность

Расписание стримера раскрывает **часовой пояс** и **распорядок**:

```bash
curl -s "https://decapi.me/twitch/schedule/target"
# Mon 18:00-22:00, Wed 19:00-23:00 ...
```

Регулярные стримы в 18:00 по местному времени + сравнение с UTC дают часовой пояс → регион.

## Ошибки и подводные камни

- **Забывать про VOD-архивы.** Даже после удаления стрима VOD может остаться.
- **Игнорировать чат.** В чате люди пишут реальные имена, города, места работы.
- **Не проверять аватар.** Стримеры переиспользуют фото из других соцсетей.
- **Считать голос ненадёжным.** Акцент и лексика — сильные сигналы, но не доказательство.
- **Нарушать приватность в донатах.** Донат-сообщения могут содержать PII третьих лиц.
- **Путать канал и владельца.** Канал может вести команда модераторов.

## Что дальше / решение

Стриминг даёт мультимедиа-следы и социальные связи. Дальше: **подкасты** (`osint-social-podcast`) для аудио, **Discord** (`osint-discord`) и **Telegram** (`osint-telegram`) по найденным инвайтам, **обратный поиск изображений** по аватару. Итог: Twitch — точка входа в сообщество стримера; через панели, VOD и чат вы выходите на его личность и круг общения.

## Анализ VOD: кадры и метаданные

Скачанный VOD — это источник кадров и метаданных. Разбиваем на кадры и проверяем фон:

```bash
yt-dlp -o "vod.%(ext)s" "https://www.twitch.tv/videos/123456789"
ffmpeg -i vod.mp4 -vf fps=1/30 frames/%04d.jpg    # кадр раз в 30 секунд
```

Из кадров извлекаем:
- **фон комнаты** — вид из окна, вывески за окном, географические ориентиры;
- **оверлеи** — игровые ники, счёт, донаты;
- **уведомления** — имена и суммы донатеров (иногда с комментариями).

Метаданные файла:

```bash
ffprobe -v quiet -print_format json -show_format vod.mp4 | python3 -m json.tool | grep -i tag
```

## Чаты: извлечение и анализ

Историю чата VOD можно скачать через сторонние сервисы. Чат содержит: ники модераторов, ответы стримера, упоминания. Ищем паттерны:

```bash
# пример: выгрузка чата через rechat API
curl -s "https://rechat.twitch.tv/rechat-messages?start=1700000000&video_id=123456789" \
  | python3 -m json.tool | grep -iE 'display_name|message' | head -40
```

Что искать в чате: вопросы «откуда ты?», «какой город?», ответы стримера; упоминания работы, вуза, игр; никнеймы, совпадающие с другими платформами.

## Донаты и финансовая активность

Донаты и подписки — источник имён и мотивации. На стриме видны: имя донатера, сумма, сообщение. На блокчейн-платформах (DLive) транзакции прозрачны и трассируются (см. `osint-blockchain`). На Twitch фиатные донаты через сторонние сервисы оставляют публичные «лидерборды».

## Связь с игровыми аккаунтами

Стримеры показывают игровые профили (Steam, Riot, Faceit). Steam-профиль раскрывает друзей, историю игр, иногда реальное имя. Проверяем:

```bash
curl -s "https://api.steampowered.com/ISteamUser/ResolveVanityURL/v1/?key=$KEY&vanityurl=target" \
  | python3 -m json.tool | grep steamid
```

Связка «Twitch → Steam → друзья → соцсети» — типичная цепочка атрибуции.

## Модерация и приватность

Стримеры используют моды для сокрытия PII, но часто ошибаются: всплывающие уведомления, ALT-TAB, экран Discord. При анализе ищите моменты «утечек экрана» — это классические находки в OSINT по стримерам.

## Оверлеи, виджеты и утечки экрана

Стримеры используют оверлеи (Streamlabs, StreamElements), которые иногда раскрывают:
- **донат-топы** с реальными именами;
- **цели/прогресс** с датами;
- **уведомления** с сообщениями.

Классические утечки — моменты ALT-TAB на рабочий стол, Discord, личную почту. Ищите их в VOD по кадрам с аномалиями. Инструмент автоматического поиска утечек:

```bash
# кадры + OCR (tesseract) для поиска текста на экране
ffmpeg -i vod.mp4 -vf fps=1/10 frames/%04d.jpg
for f in frames/*.jpg; do
  txt=$(tesseract "$f" - 2>/dev/null)
  echo "$txt" | grep -qiE '@|email|discord|token' && echo "LEAK? $f: $txt"
done
```

## Связь с игровыми и рабочими аккаунтами

Стримеры показывают игровые ники (Steam, Riot, Faceit, Battle.net). Через публичные API:

```bash
# Steam: vanity URL → SteamID → друзья → имена
curl -s "https://api.steampowered.com/ISteamUser/GetFriendList/v1/?key=$KEY&steamid=$SID"
```

Список друзей → новые профили → соцсети. Это стандартная цепочка расширения.

## Анализ расписания и часового пояса

Собираем историю стримов и вычисляем часовой пояс:

```bash
# decapi отдаёт расписание и последний стрим
curl -s "https://decapi.me/twitch/schedule/target"
curl -s "https://decapi.me/twitch/laststream/target"
```

Регулярные стримы в одно и то же локальное время + сравнение с UTC → часовой пояс → регион. Дополняет геолокацию по фону.

## Клипы и нарезки

Клипы (`clips.twitch.tv`) — короткие фрагменты, которые часто содержат самые «говорящие» моменты (утечки, эмоции, ответы на вопросы). Их удобно искать по названию/дате и анализировать отдельно, не качая весь VOD. Метаданные клипа включают автора, дату и привязку к стриму — ещё один временной маркер для таймлайна.

## Спонсорство и бренды

Стримеры рекламируют бренды (панели, заставки, «спонсор стрима»). Список спонсоров раскрывает деловые связи и партнёров. Бренд-безопасность работает и в обратную сторону: ищите каналы, выдающие себя за компанию (impersonation) — по имени, логотипу, ссылкам. Такие каналы часто ведут фишинг на зрителей, и их выявление — часть мониторинга бренда.

## Где пригодится

- **CTF (OSINT):** в панелях/био канала спрятана ссылка или код.
- **Расследования:** установить личность стримера и его окружение.
- **Мониторинг контента:** отслеживать активность и расписание.
- **Threat intelligence:** выявить связанные Discord/Telegram-сообщества.
- **Бренд-безопасность:** найти impersonation-каналы, выдающие себя за компанию.
