Автомобиль — сильный идентификатор: на фото видны марка, модель, цвет, а иногда VIN и номерной знак. По ним можно установить регион, связать человека с местом и событиями. Здесь особенно важна правовая осторожность: персональные данные владельца защищены. В этом уроке — что технически возможно и где границы.

## Теория: что можно извлечь

- **Марка/модель/год:** по дизайну, фарам, решётке, шильдикам.
- **VIN (17 символов):** завод, модель, год, серийный номер; на лобовом стекле/дверях.
- **Номерной знак:** формат кодирует страну/регион; серия/код — ведомство.
- **Регион:** по формату и коду.
- **История:** объявления о продаже, фото на автофорумах, госномер в базах.
- **Особенности:** наклейки, вмятины, аксессуары — уникальные маркеры.

Ключ: VIN и номер — «отпечатки» авто; их поиск в открытых базах и объявлениях связывает машину с человеком.

## Инструменты и команды

Декодирование VIN:

```bash
# онлайн: vpic.nhtsa.dot.gov (US), vindecoderz, carvertical
curl -s "https://vpic.nhtsa.dot.gov/api/vehicles/decodevin/1HGCM82633A004352?format=json" \
  | jq -r '.Results[] | select(.Value!="") | "\(.Variable): \(.Value)"' | head -20
```

Извлечение EXIF и деталей из фото:

```bash
exiftool car.jpg | grep -iE "gps|date|model"
# увеличение участка с VIN/номером
ffmpeg -i car.jpg -vf "crop=400:200:200:600,scale=800:400" plate.jpg
```

Поиск по номеру/модели в открытых базах:

```text
"А123БВ" "Example City"
"Toyota Camry" "Example City" site:auto.ru
site:drive2.ru "VIN 1HGCM82633A004352"
```

## Чтение VIN по частям

VIN — 17 символов, каждый блок несёт информацию (стандарт ISO 3779):

- **Символы 1–3 (WMI)** — производитель и страна: `1HG` = Honda, США.
- **Символы 4–8 (VDS)** — модель, кузов, двигатель, тип.
- **Символ 9** — контрольная цифра (проверка корректности VIN).
- **Символ 10** — год выпуска (кодируется буквой/цифрой).
- **Символ 11** — завод сборки.
- **Символы 12–17** — серийный номер.

```bash
# проверить контрольную цифру (для рынка США)
curl -s "https://vpic.nhtsa.dot.gov/api/vehicles/decodevinvalues/1HGCM82633A004352?format=json" \
  | jq -r '.Results[0] | {Make,Model,ModelYear,PlantCity,ErrorCode,ErrorText}'
```

Если контрольная цифра не сходится, VIN прочитан с ошибкой — не строьте на нём вывод.

## Разобранный пример: от фото к региону и владельцу (в рамках закона)

Дано: фото автомобиля с видимым номером.

Шаг 1 — определяем марку/модель/год по дизайну (сравнение с каталогами).

Шаг 2 — читаем номер: формат `А123БВ` + код региона → страна и регион регистрации.

Шаг 3 — декодируем VIN (если виден) через NHTSA API → завод, модель, год.

Шаг 4 — ищем авто в объявлениях (auto.ru, drive2): совпадение VIN/номера → профиль продавца.

Шаг 5 — проверяем фото на форумах/соцсетях: тот же номер → другие фото владельца.

Шаг 6 — фиксируем только публичные данные. **Данные о владельце из закрытых реестров не получаем** — это нарушение закона.

## Определение модели по фото

Когда VIN/номер не читаются, модель определяется визуально:

- **Каталоги и базы**: сравните фары, решётку, бампер с фото в каталогах (auto.ru, Drive2, Wikipedia).
- **Годы выпуска**: рестайлинги меняют детали; определите поколение и диапазон лет.
- **Логотипы и шильдики**: бренд, серия, комплектация.
- **Рынок**: некоторые модели продаются только в отдельных странах (сильный гео-сигнал).
- **Особенности**: правый/левый руль (левостороннее движение), цвет, тюнинг.

```bash
# увеличить участок с шильдиком/фарой для детального сравнения
ffmpeg -i car.jpg -vf "crop=300:150:400:500,scale=900:450" detail.jpg
```

## Номерные знаки по странам

Формат и цвет номера — надёжный гео-индикатор:

| Регион | Особенности |
|---|---|
| РФ | белый, буквы кириллицей, код региона + флаг |
| ЕС | белый с синей полосой слева (страна + флаг) |
| UK | жёлтый задний, белый передний |
| США | разнообразие по штатам; надпись штата |
| Япония | белый/жёлтый, иероглифы + цифры |
| ОАЭ | белый, эмират на арабском |

Формат сужает страну, код — регион/ведомство. Это связывает авто с местом, даже без VIN.

## Открытые сервис-истории и объявления

- **Сервис-история**: Carfax/AutoCheck (US), аналоги в других странах — ДТП, пробег, владельцы.
- **Объявления о продаже**: фото, VIN, город, контакт продавца — связка авто↔человек.
- **Форумы (Drive2)**: бортовые журналы с фото и модификациями — устойчивые маркеры.
- **Госуслуги/штрафы**: в некоторых странах публичная проверка по номеру (в рамках закона).

## Продвинутые приёмы

- **Уникальные маркеры:** вмятина, наклейка, тюнинг — устойчивый идентификатор в разных фото.
- **Хронология:** объявления о продаже дают даты и города.
- **Кросс-постинг:** фото авто в соцсетях связывают аккаунты.
- **VIN в сервис-истории:** открытые отчёты о ДТП/пробеге (Carfax и аналоги).
- **Модель-регион:** редкие модели сужают географию.
- **Номер-регион:** код региона → ведомство и город.

## Правовые рамки и этика

Автомобиль связан с **персональными данными владельца**, и это самая чувствительная часть:

- Публичные данные (объявления, форумы, соцсети) — можно.
- Закрытые реестры владельцев (ГИБДД/ДМВ) — нельзя без законного основания.
- Не используйте данные для слежки, преследования или «пробива».
- Фиксируйте источник и дату каждого факта.
- В отчётах маскируйте номера и VIN, если они не нужны для вывода.

## Частые ошибки

- **Пытаться получить ПДн владельца.** Незаконно; ограничьтесь публичными данными.
- **Путать похожие номера.** Одна буква меняет владельца; читайте внимательно.
- **Игнорировать качество фото.** Низкое разрешение даёт ошибки в VIN/номере.
- **Верить объявлениям.** Данные могут быть устаревшими/фейковыми.
- **Забыть про EXIF.** GPS в фото авто может дать точную локацию.
- **Отсутствие правовых рамок.** Фиксируйте законность источника.

## Что делать дальше / решение

- **Нужен VIN** → кроп фото → NHTSA/vindecoderz → проверка контрольной цифры.
- **Нужен регион** → формат номера → код региона.
- **Нужны связи с человеком** → объявления/форумы/соцсети по номеру и VIN.
- **Нужна локация** → EXIF фото + уникальные маркеры + фон (см. `osint-geolocation`).

## Работа с EXIF и метаданными фото

Фото автомобиля — это ещё и файл с метаданными, которые часто выдают больше, чем сам кадр. `exiftool car.jpg` показывает модель камеры/телефона, дату и время съёмки, а иногда **GPS-координаты** (если геотеги не вырезаны при загрузке). Порядок работы: (1) прочитать EXIF; (2) если GPS есть — отметить точку; (3) если GPS вырезан — восстановить локацию по фону (вывески, номера домов, растительность, тени — см. `osint-geolocation` и `osint-chronolocation`); (4) сверить время съёмки с погодой/солнцем для подтверждения. Для скриншотов из соцсетей EXIF обычно пуст, но имя файла и миниатюры иногда сохраняют оригинальные данные.

## Мошенничество с пробегом и VIN

В объявлениях авто часто фигурирует «скрученный» пробег или перебитый VIN — это класс, где OSINT помогает и в защите покупателя:

- **Несоответствие пробега**: сравните показания с сервис-историей (Carfax/AutoCheck) и датами объявлений.
- **Перебитый VIN**: контрольная цифра (символ 9) не сходится; сверьте WMI/год с реальным дизайном модели.
- **Двойные объявления**: один VIN в разных городах — признак «перекупа» или подлога.
- **Смена цвета/деталей**: расхождение с комплектацией по VIN.

Так vehicle OSINT работает в обе стороны: и для атрибуции в расследовании, и для верификации сделки.
