Deepfake и синтетические медиа — изображения, видео и аудио, созданные или изменённые нейросетями. Они угрожают доверию к визуальным доказательствам: поддельное видео политика, фейковое фото события, клонированный голос для мошенничества. Для OSINT это и вызов (нужно уметь распознавать), и инструмент (атрибуция генерации). Урок о признаках, инструментах и — главное — методологии: **детекторы ошибаются, поэтому вердикт строится на совокупности доказательств**.

## Теория: виды синтетических медиа

| Тип | Что это |
|-----|---------|
| Face-swap | замена лица в видео/фото |
| Face reenactment | перенос мимики |
| Voice clone | клон голоса по образцу |
| Text-to-image | генерация изображения (diffusion) |
| Text-to-video | генерация видео |
| Full-body deepfake | синтез тела/движений |
| Lip-sync | синхронизация губ с чужим аудио |

Технологии: GAN, diffusion-модели, neural rendering. Качество растёт, поэтому «на глаз» определить всё труднее — нужны инструменты и контекст.

## Визуальные признаки генерации (изображения)

У diffusion/GAN-изображений остаются артефакты:
- **Руки и пальцы** — лишние/искажённые (классика).
- **Зубы** — сливаются, неровное число.
- **Волосы/украшения** — «плавают», не имеют физики.
- **Фон** — нелогичные объекты, размытые детали.
- **Текст/вывески** — нечитаемые символы.
- **Отражения и тени** — не соответствуют свету.
- **Симметрия** — гипертрофированная или нарушенная.
- **Уши/серьги** — асимметрия, артефакты.
- **Кожа** — «пластиковая», без пор.

Одиночный признак — не приговор; совокупность — сигнал.

## Признаки видео-дипфейка

- **Мерцание границ лица** (temporal flicker).
- **Неестественные моргания** (слишком редкие/частые).
- **Рассинхрон губ и звука.**
- **Границы вставки** — «шов» по линии челюсти/шеи.
- **Освещение** лица не совпадает с фоном.
- **Неестественные микродвижения** головы.
- **Артефакты по краям** при быстром движении.

## Признаки голосового клона

- **Отсутствие дыхания/пауз.**
- **Слишком ровная интонация.**
- **Артефакты на шипящих/взрывных.**
- **Неестественный фон** (студийная тишина).
- **Металлический оттенок** в спектре.
- **Повторы фраз** (модель «зацикливается»).

Спектрограмма помогает:

```bash
sox voice.wav -n spectrogram -o spec.png
```

## Инструменты детекции

| Инструмент | Что делает |
|-----------|-----------|
| `FotoForensics` / ELA | артефакты сжатия |
| `InVID` / `WeVerify` | верификация видео, keyframes |
| `Deepware Scanner` | детект deepfake-видео |
| `Hive` / `Illuminarty` | детект AI-изображений |
| `AI or Not` | классификатор |
| `Reality Defender` | мультимодальный детект |
| `Hugging Face` детекторы | open-source модели |

Caveat: **детекторы дают вероятность, не приговор**. Они ошибаются на сжатых/пересохранённых файлах.

## Метаданные и provenance

- **C2PA / Content Credentials** — стандарт «подписи» происхождения контента. Проверяется через `c2patool`:

```bash
c2patool image.jpg
# выводит манифест: кто, чем, когда создал
```

- **EXIF** — генераторы (Midjourney, DALL·E) иногда оставляют маркеры.
- **Несоответствие метаданных и содержания** — сигнал.
- **Reverse search** — найти оригинал/источник.

## Разобранный пример: «видео политика»

Дано: короткое видео с заявлением.

Шаг 1 — InVID: разбить на keyframes, обратный поиск по кадрам:

```bash
# InVID/WeVerify: извлечь кадры, поиск по Google/Yandex
ffmpeg -i video.mp4 -vf fps=1 frames/%03d.jpg
```

Кадры не находятся нигде, кроме этого видео → подозрительно (реальные события имеют множество ракурсов).

Шаг 2 — визуальные признаки: мерцание границ лица, неестественные моргания, шов на шее.

Шаг 3 — аудио: спектрограмма показывает отсутствие дыхания.

Шаг 4 — детектор (Deepware) даёт «вероятно, синтетика».

Шаг 5 — C2PA отсутствует, метаданные вычищены.

Итог: совокупность (нет источника + артефакты + аудио + детектор) → вердикт «вероятный deepfake», сформулированный с оговоркой.

## Методология верификации

1. **Provenance** — откуда файл? Кто первый опубликовал?
2. **Контекст** — есть ли другие ракурсы/источники?
3. **Технический анализ** — артефакты, ELA, шум, спектр.
4. **Детекторы** — как дополнительный сигнал.
5. **Согласованность** — совпадает ли с известными фактами?
6. **Формулировка** — «вероятно/подтверждено» с оговорками.

|-----|-----------|

## Ошибки и подводные камни

- **Верить детектору на 100%.** Ложные срабатывания часты.
- **Судить по одному признаку.** Нужна совокупность.
- **Игнорировать пересохранение.** Соцсети «ломают» артефакты.
- **Забывать про реальные видео с эффектами.** Не всё «странное» — deepfake.
- **Не проверять источник.** Provenance важнее пикселей.
- **Давать категоричный вердикт.** Формулируйте с вероятностью.

## Что дальше / решение

Детекция deepfake — часть верификации медиа. ## Практический анализ изображения: пошаговый чек-лист

Дано подозрительное AI-изображение. Шаги:

1. **Метаданные и C2PA:**

```bash
exiftool -a -u -g1 suspect.jpg | grep -iE 'software|tool|generator|create'
c2patool suspect.jpg 2>/dev/null || echo "нет C2PA-манифеста"
```

2. **Размер и аспект.** Diffusion-модели часто генерируют «квадрат» 1024×1024 или 512×512 — нетипично для камер.

3. **ELA и шум** (см. `osint-photo-forensics`) — вставки и «пластиковая» кожа.

4. **Детектор** (Hive, Illuminarty) — как дополнительный сигнал, с фиксацией вероятности.

5. **Обратный поиск** — найти первоисточник.

6. **Контекст** — есть ли другие кадры/ракурсы, подтверждает ли событие кто-то ещё.

## Голосовой deepfake: разбор спектра

Спектрограмма выявляет «машинные» признаки:

```bash
sox voice.wav -n spectrogram -o spec.png
```

Ищем:
- **ровную полосу** без естественных вариаций;
- **отсутствие дыхания** между фразами;
- **обрывы** на шипящих (модель «срезает» высокие частоты);
- **повторы** одинаковых фраз (зацикливание).

Инструмент `Praat` даёт детальный анализ формант. Для сравнения двух записей одного человека полезны эмбеддинги динамиков (`resemblyzer`):

```python
from resemblyzer import VoiceEncoder, preprocess_wav
enc = VoiceEncoder()
e1 = enc.embed_utterance(preprocess_wav("a.wav"))
e2 = enc.embed_utterance(preprocess_wav("b.wav"))
print("similarity:", enc.similarity(e1, e2))
```

Высокая близость → вероятно, один голос; но клон может имитировать и это.

## Юридические и этические аспекты

- **Deepfake-порнография и диффамация** — прямое нарушение законов во многих странах.
- **Доказательства в суде** требуют экспертизы, а не «мнения детектора».
- **Публикация обвинений** в подделке без доказательств опасна.
- **Синтетические медиа как оружие** — дис-инфо-кампании; атрибуция требует осторожности.
- **Не создавайте deepfake** людей без согласия, даже для демонстрации.

## Детекторы: практика и ограничения

Категории детекторов:
- **Частотный анализ** — ищет артефакты GAN в спектре (FFT).
- **Артефактные** — классификаторы на остаточных шумах.
- **Биологические** — анализ пульса, морганий (для видео).
- **Мультимодальные** — Reality Defender, Hive.

Практика:

```bash
# Reality Defender / Hive API (пример)
curl -s -X POST "https://api.realitydefender.com/v1/detect" \
  -H "Authorization: Bearer $KEY" \
  -F "file=@suspect.mp4" | python3 -m json.tool
```

Ограничения: детекторы обучены на старых генераторах и часто «ломаются» на новых моделях; пересохранение снижает точность. Отсюда правило: детектор — один из сигналов, не вердикт.

## Форензика видео: InVID/WeVerify

Рабочий процесс верификации видео:
1. **Keyframes** — разбить на кадры (`ffmpeg -vf fps=1`).
2. **Reverse image** по кадрам — найти оригинал/другие ракурсы.
3. **Metadata** — проверить EXIF/кодеки.
4. **Magnification** — увеличить область лица для поиска швов.
5. **Forensic** — ELA/шум по кадрам.

```bash
ffmpeg -i video.mp4 -vf fps=1/5 frames/%04d.jpg
# затем загрузить кадры в Google/Yandex/TinEye
```

Отсутствие кадров в поиске + артефакты → вероятная синтетика.

## Частотный анализ (FFT)

GAN/diffusion-изображения оставляют характерные следы в частотной области. Быстрый визуальный тест:

```python
import numpy as np
from PIL import Image
import matplotlib.pyplot as plt
g = np.asarray(Image.open("suspect.jpg").convert("L"), dtype=float)
f = np.fft.fftshift(np.fft.fft2(g))
plt.imshow(np.log1p(np.abs(f)), cmap="gray"); plt.savefig("fft.png")
```

У синтетики часто видны регулярные «решётки» или аномальный высокочастотный фон. Это ещё один сигнал, который рассматривается в совокупности с метаданными, артефактами и контекстом публикации, но сам по себе не является доказательством.

## Аудио-дипфейк в мошенничестве

Самое практичное применение deepfake — **voice phishing (vishing)**: клон голоса руководителя звонит сотруднику и просит перевод. Признаки реального инцидента: срочность, давление, необычный канал, нестандартная просьба. Для защиты: верификация по второму каналу, кодовые слова, регламент платежей. Для OSINT: анализ записи голоса на артефакты клона (спектр, дыхание) и проверка контекста звонка.

## Где пригодится
