## Вопрос, с которого всё начинается

В чат скинули «фото с вечеринки»: генеральный директор крупной компании за столом с сомнительными людьми. Пост быстро удалили, но скриншот пошёл гулять по сети. Ты должен ответить: это реальное фото или его сгенерировала нейросеть?

**Deepfake и синтетические медиа** — изображения, видео и аудио, созданные или изменённые нейросетями. Они ломают доверие к визуальным доказательствам. В прошлом уроке мы разбирали правки в настоящем фото; теперь разберём случай, когда камеры не было вообще.

## Наш пример: файл suspect.jpg

У нас один объект — `suspect.jpg` из того самого поста. Начинаем с того же, с чего начинали фотофорензику: что файл говорит о себе сам?

## Шаг 1: метаданные — ищем «пустоту»

```bash
$ exiftool -a -u -g1 suspect.jpg
---- ExifTool ----
Image Width                     : 1024
Image Height                    : 1024
```

Обрати внимание на два факта:

- **Нет ни `Make`, ни `Camera Model Name`.** Настоящая камера всегда их пишет. Их отсутствие — сигнал, но не приговор: соцсети часто вычищают метаданные.
- **Размер ровно 1024×1024.** Диффузионные модели (Midjourney, DALL·E, Stable Diffusion) по умолчанию генерируют квадрат 1024×1024 или 512×512. Камеры почти никогда не снимают ровно в квадрат.

Два намёка есть. Теперь смотрим на само изображение.

## Шаг 2: визуальные артефакты генерации

У сгенерированных изображений остаются характерные ошибки:

- **Руки и пальцы** — лишние, слипшиеся или искажённые (классика жанра).
- **Текст и вывески** — символы «нечитаемые», буквы плывут.
- **Волосы и украшения** — не имеют физики, «плавают».
- **Отражения и тени** — не соответствуют источнику света.
- **Кожа** — «пластиковая», без пор; фон — с нелогичными объектами.

Одиночный признак ничего не значит: у реальных фото тоже бывают искажения. Сигнал появляется, когда признаков **совокупность**.

## Шаг 3: частотный анализ (FFT)

Нейросети оставляют следы не в пикселях, а в **частотах**. Быстрый тест — посмотреть спектр изображения через преобразование Фурье (FFT):

```python
import numpy as np
from PIL import Image
import matplotlib.pyplot as plt

g = np.asarray(Image.open("suspect.jpg").convert("L"), dtype=float)
f = np.fft.fftshift(np.fft.fft2(g))
print("fft shape:", f.shape, "log magnitude mean:", round(float(np.log1p(np.abs(f)).mean()), 2))
# fft shape: (1024, 1024) log magnitude mean: 6.75
plt.imshow(np.log1p(np.abs(f)), cmap="gray")
plt.savefig("fft.png")
```

На `fft.png` у синтетики часто видны регулярные «решётки» или аномальный высокочастотный фон. Это ещё один сигнал, который смотрят только **вместе** с метаданными и артефактами — сам по себе он не доказательство.

## Шаг 4: детекторы — как дополнительный сигнал

Существуют сервисы, обученные отличать AI-изображения: Hive, Illuminarty, AI or Not, Deepware (для видео). Обычно это API:

```bash
$ curl -s -X POST "https://api.example-detector.com/v1/detect" \
    -H "Authorization: Bearer $KEY" \
    -F "file=@suspect.jpg" | python3 -m json.tool
{
  "verdict": "likely_synthetic",
  "confidence": 0.87
}
```

Важно понимать: детектор выдаёт **вероятность, а не приговор**. Он обучен на старых генераторах и часто «ломается» на новых моделях и на пересохранённых файлах. Детектор — один из сигналов.

## Шаг 5: provenance — откуда файл

Самый весомый вопрос — не «как выглядит», а «откуда взялось». Здесь помогает стандарт **C2PA (Content Credentials)** — подпись происхождения контента, которую проверяет `c2patool`:

```bash
$ c2patool suspect.jpg
# нет C2PA-манифеста
```

Отсутствие манифеста — обычное дело для соцсетей, но его наличие сразу сказало бы, чем и когда создан файл. Дальше — обратный поиск: если фото не встречается **нигде**, кроме этого поста, и нет других ракурсов события — это подозрительно. Реальные события обрастают множеством снимков с разных сторон.

## Видео и голос: соседние задачи

Deepfake бывает не только картинкой. Для видео методика та же, но добавляется движение:

- **Мерцание границ лица** (temporal flicker) — «шов» дёргается между кадрами.
- **Неестественные моргания** — слишком редкие или частые.
- **Рассинхрон губ и звука.**
- **Освещение лица** не совпадает с фоном.

Кадры удобно вытащить через `ffmpeg` и прогнать обратный поиск:

```bash
$ ffmpeg -i video.mp4 -vf fps=1 frames/%03d.jpg
```

Если кадры не находятся нигде, кроме этого видео, — тревожный сигнал: у реальных событий обычно много ракурсов.

Голосовой клон — отдельная разновидность. Его признаки: отсутствие дыхания и пауз, слишком ровная интонация, артефакты на шипящих, повторы фраз. Смотрят на **спектрограмму**:

```bash
$ sox voice.wav -n spectrogram -o spec.png
```

Ровная полоса без естественных вариаций и отсутствие дыхания — характерная картина клона. Такие записи часто используют в мошенничестве: клон голоса руководителя звонит сотруднику с просьбой о переводе. Признаки инцидента — срочность, давление, нестандартная просьба.

## Методология верификации

Порядок действий при подозрительном файле:

1. **Provenance** — откуда файл, кто первым опубликовал?
2. **Контекст** — есть ли другие ракурсы и подтверждения?
3. **Технический анализ** — метаданные, артефакты, FFT.
4. **Детекторы** — как дополнительный сигнал с фиксацией вероятности.
5. **Согласованность** — совпадает ли с известными фактами?
6. **Формулировка** — «вероятно/подтверждено» с оговорками.

Такой порядок не даёт увлечься пикселями и забыть про источник — а источник, как правило, важнее.

## Юридические и этические границы

Deepfake-порнография и диффамация — прямое нарушение закона во многих странах. Доказательства в суде требуют экспертизы, а не «мнения детектора». Публиковать обвинения в подделке без доказательств опасно. И главное правило: **не создавай deepfake реальных людей без согласия**, даже для демонстрации.

## Инструменты детекции

| Тип медиа | Инструмент |
|-----------|-----------|
| AI-изображение | Hive, Illuminarty, AI or Not |
| Deepfake-видео | Deepware, InVID |
| Голос | спектрограмма, Reality Defender |
| Provenance | `c2patool` (C2PA) |

Ни один из них не даёт приговора в одиночку — они лишь добавляют вес к остальным сигналам.

## Что мы теперь знаем

По-простому:

1. Метаданные пусты, а размер ровно 1024×1024 — типично для генерации.
2. Визуальные артефакты (руки/текст/кожа) — совокупность, а не один признак.
3. FFT показал регулярный фон — дополнительный сигнал.
4. Детектор дал «вероятно, синтетика», но это лишь вероятность.
5. Файл не находится в других источниках, C2PA отсутствует.

Вердикт формулируем осторожно: «вероятный синтез» — с оговоркой, потому что стопроцентного доказательства у нас нет.

## На что смотреть дальше

- **Не верь детектору на 100%.** Ложные срабатывания часты, особенно на сжатых файлах.
- **Суди по совокупности.** Один артефакт — не вывод; метаданные + визуал + FFT + provenance вместе — вывод.
- **Provenance важнее пикселей.** Источник и другие ракурсы говорят больше, чем анализ одного файла.
- **Помни про реальные эффекты.** Не всё «странное» — deepfake: фильтры и ретушь дают похожие артефакты.
- **Формулируй с вероятностью.** «Вероятно/подтверждено», а не категоричное «подделка».

## Где пригодится

- **CTF (OSINT):** задача «это подделка?» — применить анализ и найти нестыковку/флаг.
- **Фактчекинг:** проверять вирусные видео и фото.
- **Threat intelligence:** выявлять deepfake-кампании (дезинформация).
- **Корпоративная безопасность:** защита от CEO-fraud с клоном голоса.
- **Журналистика:** верификация пользовательского контента перед публикацией.
