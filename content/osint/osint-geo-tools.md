## Вопрос, с которого всё начинается

У тебя есть `street.jpg` — фотография улицы. Ни координат, ни подписи, только вывеска «Café», дорожный знак и трамвайные пути в кадре. Задача: определить **точное место** съёмки.

Геолокация по фото — это не «посмотреть на Google Maps», а методичная работа: собрать признаки на снимке и превратить их в координаты с помощью карт. В этом уроке мы возьмём один снимок и доведём его до подтверждённых координат.

## Наш пример: признаки на street.jpg

Смотрим на фото и выписываем всё, что можно: язык вывески (французский), форма дорожного знака «STOP» (европейская), трамвайные пути, тип зданий, растительность. Пока это только **признаки**, а не место. Дальше — инструменты.

## Шаг 1: гипотеза страны

Язык и тип знаков сужают регион: французский + европейский знак + трамвай → скорее всего Франция. Это гипотеза, а не ответ. Теперь нужно найти **уникальный объект** на снимке, который ищется в базе.

Ключевая идея: карта — это база объектов с тегами. Если объект на фото (кафе, вокзал, трамвайная остановка) есть в базе, мы получим координаты.

## Шаг 2: OpenStreetMap и Overpass API

**OpenStreetMap (OSM)** — открытая карта с огромной базой объектов (POI — points of interest, «точки интереса»). К ней обращаются языком запросов **Overpass API**: можно искать объекты по тегам, например «все кафе в радиусе 200 метров от точки».

Пример запроса — найти кафе рядом с заданной точкой:

```bash
$ curl -s "https://overpass-api.de/api/interpreter" \
    --data-urlencode 'data=[out:json];node(around:200,48.8584,2.2945)[amenity=cafe];out;' \
  | python3 -m json.tool | grep -iE 'name|lat|lon'
```

Поиск объекта по имени в регионе выглядит так:

```
[out:json];
area["name"="Lyon"]->.a;
node(area.a)["name"~"Café",i];
out;
```

Здесь `area` выбирает город, `node(...)["name"~"Café"]` ищет узлы с именем, похожим на «Café», а `i` означает «без учёта регистра». Ключевые теги для геолокации: `amenity` (кафе, банкоматы), `shop`, `tourism`, `highway`, `railway`, `man_made`.

## Шаг 3: Nominatim — адрес в координаты

Если известен адрес или название, проще спросить у **Nominatim** — поисковика по данным OSM. Например, проверим ориентир:

```bash
$ curl -s -A "osint-lesson/1.0" \
    "https://nominatim.openstreetmap.org/search?q=Eiffel+Tower&format=json&limit=1"
[{"osm_type":"way","osm_id":5013364,
  "lat":"48.8582599","lon":"2.2945006",
  "name":"Tour Eiffel",
  "display_name":"Tour Eiffel, 5, Avenue Anatole France, Quartier du Gros-Caillou, Paris 7e Arrondissement"}]
```

Мы получили точные координаты `48.8582599, 2.2945006` и адрес. Так же можно «привязать» найденное на фото кафе, если знаем его название.

## Шаг 4: панорамы — подтверждаем фасад

Координаты из базы — ещё не доказательство. Нужно **увидеть** это место. Здесь помогают краудсорсинговые панорамы **Mapillary** и **KartaView**: пользователи загружают уличные фото с геотегами. Google Street View — эталон, но покрывает не всё; Mapillary часто закрывает пробелы.

```bash
$ curl -s "https://graph.mapillary.com/images?access_token=$TOKEN&fields=id,captured_at,compass_angle&bbox=37.61,55.75,37.62,55.76"
```

Сравниваем панораму с нашим фото: совпадает ли вывеска, форма фасада, номер дома, направление трамвайных путей. Совпадение панорамы и карты — это **двойное подтверждение**.

## Шаг 5: время по теням (SunCalc)

Иногда нужно не только место, но и время. По длине и направлению тени можно оценить, когда сделан снимок, а через это — уточнить широту. Библиотека `pysolar` считает положение солнца:

```python
from pysolar.solar import get_altitude, get_azimuth
import datetime

lat, lon = 48.858, 2.294
dt = datetime.datetime(2026, 7, 1, 12, 0, tzinfo=datetime.timezone.utc)
print("altitude:", get_altitude(lat, lon, dt))
print("azimuth:", get_azimuth(lat, lon, dt))
```

Сопоставляя угол тени на фото с расчётом, сужаем время съёмки. Подробнее — в уроках `osint-chronolocation` и `osint-shadow-analysis`.

## Шаг 6: точные координаты и сетки

Для очень точного указания места используют **What3Words** (мир разбит на квадраты 3×3 м, у каждого — три слова) и **Plus Codes** (Open Location Code). Адрес вида `слово.слово.слово` в ссылке `https://w3w.co/...` превращается в координаты. Это удобно для CTF, где ответ часто и есть три слова.

## Пошаговый алгоритм геолокации

1. **Инвентаризация признаков:** язык, знаки, номера, архитектура, растительность, инфраструктура.
2. **Гипотеза страны/региона** по языку и знакам.
3. **Поиск уникального объекта** в OSM (Overpass) по названию или типу.
4. **Подтверждение панорамой** (Mapillary/Street View).
5. **Уточнение координат** (What3Words, спутник).
6. **Проверка времени** (SunCalc по теням).
7. **Двойная верификация** двумя независимыми источниками.

Записывай каждый шаг и источник — это доказательная база. Не переходи к выводу, пока не подтвердил хотя бы двумя источниками.

## Полезные источники

| Источник | Что даёт |
|----------|----------|
| OpenStreetMap | карта и объекты |
| Overpass API | поиск POI по тегам |
| Nominatim | адрес → координаты |
| Mapillary / KartaView | уличные панорамы |
| Google Street View | эталонные панорамы |
| What3Words / Plus Codes | точные координаты |
| SunCalc / pysolar | время по теням |
| PeakVisor | идентификация гор |
| Sentinel Hub / Landsat | спутниковые снимки |

Используй несколько источников: спутник подтверждает расположение объектов, панорама — детали фасада, а карта даёт точные координаты.

## Полный прогон от начала до конца

Соберём историю: `street.jpg` → вывеска на французском и европейский знак → гипотеза «Франция» → ищем кафе в OSM через Overpass → находим объект с координатами → подтверждаем фасад по панораме Mapillary → сверяем тень с `pysolar` по дате из EXIF → получаем координаты улицы. Место подтверждено **двумя независимыми источниками** (карта + панорама), как и положено.

## Работа с панорамами: практические приёмы

- **Дата съёмки.** Mapillary и Street View показывают дату панорамы — сравните с фото: ремонт, новые вывески датируют снимок.
- **Ракурс.** Совпадение ракурса и объектов подтверждает место; разные ракурсы одной улицы помогают.
- **Сезон.** Листва или снег на панораме против фото сужают дату.
- **Детали.** Номера домов, названия магазинов, рекламные щиты — уникальные маркеры.

```bash
$ curl -s "https://graph.mapillary.com/images?access_token=$TOKEN&fields=id,captured_at,compass_angle&bbox=37.61,55.75,37.62,55.76"
```

Сравнение панорамы с фото — финальный шаг подтверждения геолокации.

## Что мы теперь знаем

По-простому:

1. Геолокация идёт от признаков (язык, знаки, объекты) к координатам.
2. OSM + Overpass — база объектов и язык запросов к ней.
3. Nominatim превращает название/адрес в координаты.
4. Mapillary/Street View подтверждают место визуально.
5. SunCalc сужает время по теням; What3Words даёт точную сетку.

## На что смотреть дальше

- **Учитывай дату фото.** Карта сегодня ≠ карта на момент съёмки: вывески меняются.
- **Не доверяй одной панораме.** Она могла устареть; сверяйся со спутником.
- **Ищи уникальный маркер.** Похожие улицы есть везде — нужен объект, который встречается один раз.
- **Проверяй часовой пояс.** SunCalc требует правильного UTC, иначе время «уедет».
- **Подтверждай двумя источниками.** Один источник — гипотеза, два — вывод.
