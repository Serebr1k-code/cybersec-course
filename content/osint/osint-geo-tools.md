Геолокация по фото — определить место съёмки — опирается на инструменты карт и уличных панорам. В отличие от простого «посмотреть на Google Maps», профессиональная геолокация использует **запросы к базам объектов** (Overpass), **краудсорсинговые панорамы** (Mapillary, KartaView), **солнечные вычисления** (SunCalc) и **специализированные сервисы** (What3Words). Этот урок — практический арсенал для определения места по деталям на снимке.

## Теория: на чём стоит геолокация

Место определяется по совокупности признаков:

| Признак | Что даёт |
|---------|----------|
| Вывески/надписи | язык, бренды, адрес |
| Дорожные знаки | страна, регион |
| Номера автомобилей | страна/регион |
| Архитектура | регион, эпоха |
| Растительность | климат, широта |
| Тени | время + широта |
| Ландшафт | рельеф, горы |
| Инфраструктура | ЛЭП, столбы, разметка |

Инструменты превращают признаки в координаты: карты находят объекты, панорамы подтверждают, SunCalc сужает по времени.

## OpenStreetMap и Overpass API

OpenStreetMap (OSM) — открытая карта с богатой базой объектов (POI). **Overpass API** — язык запросов к ней. Это мощнейший инструмент геолокации: можно искать объекты по тегам.

Пример: найти все аптеки в радиусе 200 м от точки:

```bash
curl -s "https://overpass-api.de/api/interpreter" \
  --data-urlencode 'data=[out:json];node(around:200,55.7558,37.6173)[amenity=pharmacy];out;' \
  | python3 -m json.tool | grep -iE 'name|lat|lon'
```

Поиск объекта по имени в регионе:

```
[out:json];
area["name"="Москва"]->.a;
node(area.a)["name"~"Кофейня",i];
out;
```

Overpass Turbo (веб-UI) позволяет строить запросы визуально. Ключевые теги: `amenity`, `shop`, `tourism`, `highway`, `railway`, `man_made`.

## Mapillary и уличные панорамы

Mapillary — краудсорсинговые уличные фото с геотегами. Позволяет «прогуляться» по улице и сравнить с фото. KartaView (ex-OpenStreetCam) — аналог.

```bash
# Mapillary API: изображения рядом с точкой
curl -s "https://graph.mapillary.com/images?access_token=$TOKEN&fields=id,captured_at,geometry&bbox=37.61,55.75,37.62,55.76"
```

Google Street View — эталон, но не везде; Mapillary покрывает места, где Google нет.

## What3Words и сетки

What3Words делит мир на квадраты 3×3 м и даёт каждому три слова. Полезно для точных координат и для CTF (адрес из трёх слов).

```
https://w3w.co/слово.слово.слово → точные координаты
```

Аналоги: Plus Codes (Open Location Code), MGRS.

## SunCalc: время и широта по теням

По длине и направлению тени можно оценить время и широту. `SunCalc` (веб) и библиотека `pysolar`:

```python
from pysolar.solar import get_altitude, get_azimuth
import datetime
lat, lon = 55.75, 37.62
dt = datetime.datetime(2026, 7, 1, 12, 0, tzinfo=datetime.timezone.utc)
print("altitude:", get_altitude(lat, lon, dt))
print("azimuth:", get_azimuth(lat, lon, dt))
```

Сопоставляя угол тени на фото с расчётом, сужаем время и широту (см. также `osint-chronolocation`, `osint-shadow-analysis`).

## Разобранный пример: найти место по фото улицы

Дано: фото улицы с вывеской «Café», дорожным знаком и трамваем.

Шаг 1 — язык и знаки: надписи на французском, знак «stop» европейского образца → Франция/Бельгия.

Шаг 2 — ищем кафе в OSM:

```
[out:json];
area["name"="Lyon"]->.a;
node(area.a)["amenity"="cafe"]["name"~"Café",i];
out;
```

Шаг 3 — сопоставляем форму улицы и трамвайные пути с OSM-слоем `railway=tram`.

Шаг 4 — проверяем Mapillary-панораму на совпадение вывески и фасада.

Шаг 5 — по тени и дате (если есть EXIF) уточняем время.

Итог: координаты улицы в Лионе подтверждены двумя источниками (OSM + Mapillary).

## Дополнительные приёмы

- **PeakVisor** — определить горы на панораме.
- **GeoNames** — сопоставить топоним с координатами.
- **Wikimapia** — объекты, которых нет в OSM.
- **Flickr map** — фото с геотегами рядом.
- **Bing Maps / Yandex Maps** — другие слои панорам.
- **Sentinel Hub / Landsat** — спутниковые снимки (см. `osint-satellite`).

## Ошибки и подводные камни

- **Игнорировать дату фото.** Карта сегодня ≠ карта на момент съёмки (OSM историчны, но не всегда).
- **Доверять одной панораме.** Панорама могла устареть.
- **Путать похожие улицы.** Нужен уникальный объект-маркер.
- **Забывать про сезонность.** Снег/листва сужают дату.
- **Ошибаться в часовом поясе.** SunCalc требует правильного UTC.
- **Не проверять Overpass-синтаксис.** Ошибка в запросе → пустой ответ.

## Что дальше / решение

Геоинструменты превращают признаки на фото в координаты. Дальше: **спутниковые снимки** (`osint-satellite`) для проверки изменений, **хронолокация** (`osint-chronolocation`) для времени, **верификация** (`osint-verification`) для оформления. Итог: OSM + Overpass + Mapillary + SunCalc дают точную геолокацию; всегда подтверждайте двумя независимыми источниками.

## Overpass Turbo: практические запросы

Overpass Turbo — веб-обёртка над API с визуализацией. Полезные готовые запросы для геолокации.

Все банкоматы в радиусе 300 м:

```
[out:json][timeout:25];
node(around:300,48.8584,2.2945)[amenity=atm];
out body;
```

Все объекты с конкретным именем в городе:

```
[out:json];
area["name"="Берлин"]->.a;
node(area.a)["name"~"Bahnhof",i];
out;
```

Здания определённого типа и этажности (для сопоставления с фото):

```
[out:json];
way(around:200,52.52,13.405)["building"]["building:levels"];
out geom;
```

Результат — JSON с координатами и тегами; сопоставляя их с фото, вы находите уникальный маркер.

## Сопоставление фасадов и панорам

Метод «фасадного матчинга»:
1. На фото выделяем уникальные элементы: вывеска, номер дома, архитектурная деталь, дерево, столб.
2. Ищем объект в OSM по тегам (`addr:housenumber`, `shop`, `amenity`).
3. Проверяем панораму (Mapillary/Street View) на совпадение.
4. Сверяем ракурс, освещение и сезон.

Если фото сделано до появления панорамы, помогут исторические снимки и спутник (см. `osint-satellite`).

## Работа с номерами домов и адресами

Теги OSM для адреса: `addr:street`, `addr:housenumber`, `addr:city`, `addr:postcode`. Запрос всех домов на улице:

```
[out:json];
area["name"="Москва"]->.a;
way(area.a)["addr:street"="Тверская"]["addr:housenumber"];
out center;
```

Совпадение номера дома на фото с OSM-адресом — сильное подтверждение места.

## Инструмент разбора теней и высоты

Помимо SunCalc, полезен `Shadows on the Map` и расчёт по высоте объекта. Если известна высота здания и длина тени, широту можно оценить:

```
tan(угол_солнца) = высота_объекта / длина_тени
```

Сопоставляя с расчётом `pysolar` для даты, сужаем широту и время. Этот приём дополняет хронолокацию (`osint-chronolocation`).

## Практика: скрипт геолокации по теням

Совмещаем SunCalc и данные с фото. Дано: тень человека длиной ≈ высоте (угол 45°), дата из EXIF.

```python
from pysolar.solar import get_altitude
import datetime, pytz

date = datetime.datetime(2026, 7, 15, tzinfo=pytz.UTC)
# ищем широту, где солнце в 45° в это время
for lat in range(30, 61, 5):
    for hour in range(6, 20):
        dt = date.replace(hour=hour)
        alt = get_altitude(lat, 0, dt)
        if 43 < alt < 47:
            print(f"lat~{lat}, UTC~{hour}:00 -> altitude {alt:.1f}")
```

Так сужается широта и время. Комбинируя с языком вывесок и архитектурой, получаете точку.

## Пошаговый алгоритм геолокации

1. **Инвентаризация признаков:** язык, знаки, номера, архитектура, растительность, инфраструктура.
2. **Гипотеза страны/региона** по языку и знакам.
3. **Поиск уникального объекта** в OSM (Overpass) по названию/типу.
4. **Подтверждение панорамой** (Mapillary/Street View).
5. **Уточнение координат** (What3Words, спутник).
6. **Проверка времени** (SunCalc по теням).
7. **Двойная верификация** двумя независимыми источниками.

Записывайте каждый шаг и источник — это доказательная база. Не переходите к выводам, пока не подтвердили хотя бы двумя источниками.

## Работа с панорамами: практические приёмы

- **Даты съёмки.** Mapillary/Street View показывают дату панорамы — сравните с фото: изменения (ремонт, вывески) датируют снимок.
- **Ракурс.** Совпадение ракурса и объектов — подтверждение места; разные ракурсы одной улицы помогают.
- **Сезон.** Листва/снег на панораме vs фото сужают дату.
- **Детали.** Номера домов, названия магазинов, рекламные щиты — уникальные маркеры.

```bash
# поиск панорам в точке (bbox: lon1,lat1,lon2,lat2)
curl -s "https://graph.mapillary.com/images?access_token=$TOKEN&fields=id,captured_at,compass_angle&bbox=37.61,55.75,37.62,55.76"
```

Сравнение панорамы с фото — финальный шаг подтверждения геолокации.
