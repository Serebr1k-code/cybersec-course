## Вопрос, с которого всё начинается

У тебя есть два фото: одно опубликовано с аккаунта A, другое — с аккаунта B. Нужно понять, снял ли их **один и тот же человек**. На глаз — ничего общего.

Но **EXIF** (Exchangeable Image File Format) — стандарт метаданных изображений — хранит технические детали съёмки, включая уникальный номер устройства. Разберём, как это доказывается.

## Наш пример: два фото с разных аккаунтов

У нас два объекта: `a.jpg` и `b.jpg`. Задача — связать их по устройству. В прошлом уроке мы уже вытаскивали базовые поля; теперь смотрим глубже — на те, что переживают даже очистку GPS.

## Шаг 1: сравниваем базовые поля

Начнём с простого вывода и посмотрим на камеру:

```bash
exiftool -s -Make -Model -Software -LensModel a.jpg b.jpg
```

```
======== a.jpg
Make     : Apple
Model    : iPhone 13
Software : 17.4.1
======== b.jpg
Make     : Apple
Model    : iPhone 13
Software : 17.4.1
```

Модель и версия совпадают — но этого мало: таких телефонов миллионы. Нужен признак, уникальный для устройства.

## Шаг 2: серийный номер связывает фото

Ключевое поле — **SerialNumber**. Он уникален для конкретного аппарата:

```bash
exiftool -s -SerialNumber -BodySerialNumber -LensSerialNumber a.jpg b.jpg
```

```
======== a.jpg
SerialNumber : F2LX9A1B2C3D
======== b.jpg
SerialNumber : F2LX9A1B2C3D
```

Один и тот же серийник на обоих снимках. Это сильное доказательство: фото сделаны одним устройством. Так связывают аккаунты и события в расследованиях.

## Шаг 3: уточняем место через высоту и компас

Помимо координат, EXIF хранит **высоту** и **направление съёмки**. Высота помогает отличить похожие точки, а компас — понять, куда смотрела камера:

```bash
exiftool -n -GPSLatitude -GPSLongitude -GPSAltitude -GPSImgDirection a.jpg
```

```
GPSLatitude     : 55.755833
GPSLongitude    : 37.617222
GPSAltitude     : 156
GPSImgDirection : 245
```

Высота 156 метров и азимут 245° (юго-запад) уточняют точку и связываются с хронолокацией: по направлению камеры и теням можно уточнить и место, и время.

## Шаг 4: копаем в MakerNotes

Кроме стандартных полей есть **MakerNotes** — блок, специфичный для производителя. Там лежат настройки, которые не попадают в обычный EXIF, и они тоже уникальны:

```bash
exiftool -MakerNotes:all a.jpg | head
```

```
InternalSerialNumber : 1A2B3C4D
ShutterCount         : 14823
```

Поле `ShutterCount` — счётчик срабатываний затвора — растёт с каждым снимком. Он тоже связывает серию: два фото с близкими счётчиками сделаны почти подряд.

## Шаг 5: пакетная обработка

Когда файлов много, работает **пакетный** режим: `exiftool` умеет рекурсию и вывод в CSV.

```bash
exiftool -r -csv -Make -Model -SerialNumber -GPSPosition ./photos > meta.csv
```

А так строят сводку по устройствам — сразу видно кластеры:

```bash
exiftool -r -T -Model ./photos | sort | uniq -c | sort -rn
```

```
     42 iPhone 13
      7 Pixel 7
```

Сорок два фото с iPhone 13 и семь с Pixel — вероятно, два автора или два устройства. В расследованиях это выделяет кластеры и находит аномалии: фото «не той» камеры среди серии.

## Шаг 6: не забываем про видео и аудио

Метаданные есть и в медиа. Видео (MP4/MOV) хранит **QuickTime-теги**: дату создания, модель устройства и GPS, а аудио — **ID3-теги**:

```bash
exiftool video.mp4 | grep -iE 'gps|create|model'
exiftool audio.mp3 | grep -iE 'artist|comment|encoder'
```

Поле `encoded_by` в MP3 иногда содержит реальное имя пользователя или имя компьютера — это прямая утечка.

## Шаг 7: проверяем непротиворечивость

Важная оговорка: **метаданные редактируемы**. Серийник можно подделать. Поэтому вывод проверяют на непротиворечивость:

- Модель должна соответствовать формату серийников производителя.
- Дата съёмки — не быть раньше даты выпуска модели.
- `Software` не противоречить `DateTimeOriginal`.

Для отчёта фиксируйте не сам серийник, а **факт совпадения** между изображениями — так вы не публикуете лишнего.

## Инструменты

Помимо exiftool, метаданные читают и другие утилиты:

| Инструмент | Назначение |
|---|---|
| exiftool | чтение, запись и удаление метаданных |
| exiv2 | быстрый CLI для EXIF, IPTC, XMP |
| identify | свойства изображения (ImageMagick) |
| mediainfo | медиафайлы (видео и аудио) |
| mat2 | глубокая очистка метаданных |

## Скрытые данные рядом с EXIF

Метаданные — не единственный скрытый слой файла. Рядом могут лежать встроенные архивы и «предпросмотры»:

```bash
binwalk photo.jpg
exiftool -b -ThumbnailImage photo.jpg > thumb.jpg
```

`binwalk` покажет, если к изображению дописан архив (такой файл называют **polyglot** — валидный сразу как два формата), а извлечённый thumbnail иногда содержит версию фото до редактирования.

## Подводные камни

- **Соцсети удаляют EXIF не всегда** и не все поля: MakerNotes часто переживают загрузку.
- **Thumbnail** может содержать исходное изображение до редактирования.
- **SerialNumber** уникален, поэтому это прямая атрибуция — фиксируйте только факт совпадения.
- **Часовой пояс** в дате может быть не указан, и таймлайн «поедет».
- **Метаданные редактируемы**: их легко подделать, поэтому проверяйте непротиворечивость полей.
- **Один инструмент не видит всего** — к exiftool добавляйте exiv2, mediainfo и mat2.

## Что мы теперь знаем

- EXIF хранит не только GPS, но и уникальный SerialNumber устройства.
- Совпадение серийника связывает фото с разных аккаунтов.
- Высота и компас уточняют точку и направление съёмки.
- MakerNotes содержат производительские поля вроде счётчика затвора.
- Пакетный режим `exiftool -r -csv` строит инвентаризацию по устройствам.
- Метаданные подделываемы — проверяйте непротиворечивость.
- Видео и аудио несут свои метаданные: QuickTime-теги и ID3.
- Для отчёта фиксируйте факт совпадения серийников, а не сами номера: так вы не публикуете лишнего.
- Всегда проверяйте, что модель соответствует формату серийных номеров производителя.

## На что смотреть дальше

Разберись с очисткой и её пределами: `exiftool -all=` удаляет теги, но **стеганография** и шум сенсора (**PRNU**) остаются. Изучи, как соцсети частично чистят EXIF — MakerNotes часто переживают такую «очистку». Дальше это ведёт к верификации изображений и анализу документов.

## Разбор кейса: серийный номер как «отпечаток»

EXIF — это метаданные, которые камера пишет в файл: модель, дата, настройки, а иногда GPS. Среди полей есть **Camera Serial Number** — серийный номер корпуса. Он уникален для конкретного фотоаппарата. Это делает его мощным инструментом корреляции: два фото с разных аккаунтов с одинаковым серийником почти наверняка сняты одной камерой.

Разберём, как это использовать. Сначала извлекаем все поля: `exiftool photo.jpg`. Нас интересуют `SerialNumber`, `LensSerialNumber`, `Model`, `DateTimeOriginal`. Затем сравниваем серийники двух подозрительных фото. Совпадение — сильная связь; оно переживает удаление аккаунта и смену ника. Второй приём — **внутренний серийник (InternalSerialNumber)**. У некоторых камер их несколько, и они уникальнее «публичного». Их стоит искать в MakerNotes — скрытом блоке производителя, который `exiftool` показывает по-разному для разных брендов.

Третий приём — **высота и компас**. Если фото снято с GPS, поля `GPSAltitude` и `GPSImgDirection` уточняют не только точку, но и направление съёмки. Это помогает понять, что именно в кадре. Важно: EXIF легко подделать, поэтому метаданные — это гипотеза, которую подтверждают визуальным анализом. И наоборот: отсутствие EXIF не значит «фото не с камеры» — сервисы чистят метаданные при загрузке.

## Если не сработало

**EXIF пустой.** Соцсети и мессенджеры вырезают метаданные. Ищи оригинал: через запрос файла, через архив, через «скачать» в мессенджере.

**Серийник отсутствует.** Многие камеры его не пишут. Тогда работай по комбинации модель + объектив + паттерн шума.

**GPS есть, но неточный.** Уточняй по высоте, компасу и визуальным ориентирам.

**Метаданные противоречат фото.** Возможна подделка. Сравни дату в EXIF с датой публикации.

## Частые вопросы

**Что такое MakerNotes?** Скрытый блок производителя внутри EXIF, куда пишутся фирменные поля. `exiftool -u` показывает и «неизвестные» теги.

**Как очистить свои фото?** `exiftool -all= photo.jpg` удаляет метаданные. Делай это перед публикацией.

**Всегда ли GPS точен?** Нет, он зависит от приёма спутников; в помещении может отсутствовать или быть ошибочным.

## Мини-практика: сравниваем два фото

Возьми два фото одного события, скачанных с разных аккаунтов, и сравни их метаданные. Команда `exiftool -a -G1 photo1.jpg` покажет все поля с указанием группы. Выпиши `Model`, `SerialNumber`, `LensModel`, `DateTimeOriginal`. Повтори для второго фото и сравни. Совпадение серийника — сильная связь: обе фотографии сняты одной камерой. Совпадение модели и объектива — слабая связь: таких камер тысячи. Если серийников нет, сравни паттерн шума и «горячие пиксели» — они тоже индивидуальны. Затем проверь даты: `DateTimeOriginal` и дата публикации должны быть согласованы. Расхождение — повод заподозрить подделку. Этот прогон показывает, что метаданные работают как отпечаток: слабые поля связывают вяло, а серийник и шум — почти однозначно.
