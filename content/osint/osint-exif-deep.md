Почти каждый файл несёт «невидимый» слой информации — **метаданные**. Фотографии содержат модель камеры, настройки съёмки, иногда GPS-координаты; документы — автора, организацию, историю правок; PDF — программу и версию. Для OSINT это источник геолокации, атрибуции и технических деталей; для OPSEC — утечка, которую нужно чистить перед публикацией. Один и тот же инструмент (`exiftool`) работает и на атаку, и на защиту.

## Что такое EXIF

**EXIF** (Exchangeable Image File Format) — стандарт метаданных изображений. Файл JPEG/HEIC хранит блок EXIF рядом с пиксельными данными. Помимо EXIF, есть **IPTC** (описания, авторство), **XMP** (расширяемые метаданные Adobe), **ICC** (профиль цвета) и **MakerNotes** (специфичные для производителя). Все они — потенциальные источники утечек.

## Важные поля

| Поле | Что даёт |
|---|---|
| Make/Model | Модель камеры/телефона |
| DateTimeOriginal | Дата/время съёмки |
| GPSLatitude/Longitude | Координаты |
| GPSAltitude | Высота |
| Software | ПО обработки |
| LensModel | Объектив |
| SerialNumber | Серийник (уникален!) |
| Orientation | Поворот |
| ImageDescription/Artist | Автор/описание |

Особенно ценны **GPS** (точное место) и **SerialNumber** (связывает фото с конкретным устройством — мощный инструмент атрибуции).

## Инструменты

- **exiftool** — универсальный, читает/пишет/удаляет метаданные любых форматов.
- **exiv2** — быстрый CLI для EXIF/IPTC/XMP.
- **identify** (ImageMagick) — свойства изображения.
- **mediainfo** — медиафайлы (видео/аудио).
- **mat2** — очистка метаданных (GUI/CLI).
- **FOCA** — анализ метаданных документов (Windows).

```bash
# Все метаданные
exiftool photo.jpg
# Только GPS
exiftool -gps:all photo.jpg
# Краткий вывод
exiftool -s -Make -Model -DateTimeOriginal -GPSPosition photo.jpg
```

## Разобранный пример

Дано: фото `IMG_1234.jpg`.

```bash
exiftool IMG_1234.jpg
# Make : Apple
# Model : iPhone 13
# DateTimeOriginal : 2024:05:12 17:43:21
# GPS Latitude : 55 deg 45' 21.00" N
# GPS Longitude : 37 deg 37' 4.00" E
# Software : 17.4.1
# SerialNumber : F2LX...
```

1. GPS-координаты → открываем в картах → точное место.
2. Дата/время → строим таймлайн, сверяем с событиями.
3. Модель/Software → версия ОС/устройства.
4. SerialNumber → связываем с другими фото того же устройства.
5. Если GPS нет — ищем косвенные признаки (см. `osint-geolocation`).

## Метаданные в документах

Офисные файлы и PDF особенно «болтливы»:

```bash
exiftool report.docx        # автор, организация, дата, история
exiftool -a -u presentation.pdf  # PDF: создатель, ПО, версия
```

В DOCX/XLSX/PPTX (это ZIP) можно распаковать и посмотреть `docProps/core.xml`, `docProps/app.xml` — там автор, компания, время правок, иногда имена рецензентов. PDF хранит `/Author`, `/Creator`, `/Producer`, а иногда и скрытые слои/аннотации. Для OSINT это даёт имена сотрудников и внутренние данные.

## Скрытые данные и стеганография

Метаданные — не единственный «невидимый» слой. В файлах могут быть: **скрытые потоки** (NTFS ADS), **дописанные архивы** (polyglot), **встроенные превью** (thumbnail может отличаться от основного изображения!), **комментарии**. `exiftool -b -ThumbnailImage` извлечёт превью — иногда там исходная (неотредактированная) картинка. Для стеганографии смотрите stego-ветку.

## Очистка метаданных

Перед публикацией удаляйте метаданные:

```bash
# Удалить все метаданные
exiftool -all= photo.jpg
# Оставить только цветовой профиль
exiftool -all= --icc_profile:all photo.jpg
# Рекурсивно по каталогу
exiftool -all= -r ./photos/
# mat2
mat2 photo.jpg
```

**Важно:** удаление метаданных не удаляет стеганографию и не гарантирует анонимность (см. `osint-browser-fingerprint`).

## Защита и OPSEC

- Всегда чистить метаданные перед публикацией.
- Не публиковать оригиналы с GPS.
- Проверять, что соцсеть действительно удаляет EXIF (некоторые — нет).
- Для документов — обезличивать автора/организацию.
- Помнить: очистка не отменяет другие следы.

## Подводные камни

- **Соцсети удаляют EXIF не всегда** (и не все поля).
- **MakerNotes** остаются после частичной очистки.
- **Превью (thumbnail)** может содержать исходное изображение.
- **SerialNumber** уникален — прямая атрибуция.
- **Часовой пояс** в дате может быть не указан — осторожно с таймлайном.
- **Метаданные редактируемы** — можно подделать (проверяйте непротиворечивость).

## Что дальше / решение

Метаданные — «первый взгляд» на любой файл; свяжите с `osint-metadata`, `osint-document-analysis`, `osint-geolocation`, `osint-image-reverse`, `osint-verification`. Дальше — стеганография (stego-ветка) и очистка. Для CTF всегда начинайте с `exiftool` — там часто лежит флаг.

## EXIF в видео и аудио

Метаданные есть не только в фото. Видео (MP4/MOV) содержит **QuickTime-теги**: дату создания, модель устройства, GPS (для телефонов), а иногда и координаты в `©xyz`. Аудио (MP3/M4A/FLAC) — ID3-теги: исполнитель, альбом, комментарии, иногда имя пользователя/компьютера в поле encoder.

```bash
exiftool video.mp4 | grep -iE "gps|create|model|xyz"
exiftool audio.mp3 | grep -iE "artist|comment|encoder"
mediainfo video.mp4
```

Для OSINT это даёт: место/время съёмки видео, а из ID3 — иногда реальное имя (в поле `comment` или `encoded_by`). Документы, экспортируемые в PDF из Word, несут `/Producer` и `/Creator` — программу и версию, что помогает установить цепочку создания.

## Кейс: атрибуция по серийнику

Серийный номер устройства (`SerialNumber`, `LensSerialNumber`, `BodySerialNumber`) уникален и сохраняется в EXIF, даже когда GPS вычищен. Если у вас есть несколько фото цели с одним серийником — они сделаны одним устройством, что связывает аккаунты/события. Это мощный инструмент атрибуции в расследованиях (например, связать фото с разных аккаунтов). Важно: серийник можно подделать, поэтому проверяйте непротиворечивость (модель ↔ серийник ↔ формат серийников производителя). Для OSINT-отчёта фиксируйте не сам серийник, а факт совпадения между изображениями.

## Пакетная обработка и инвентаризация

Когда файлов много (выгрузка сайта, папка с фото), метаданные обрабатывают пакетно. `exiftool` умеет рекурсию и вывод в CSV/JSON:

```bash
# CSV по всем файлам с ключевыми полями
exiftool -r -csv -Make -Model -DateTimeOriginal -GPSPosition ./data > meta.csv
# Только файлы с GPS
exiftool -r -if '$GPSLatitude' -p '$Directory/$FileName' ./data
# Сводка по моделям камер
exiftool -r -T -Model ./data | sort | uniq -c | sort -rn
```

Так строят инвентаризацию: какие устройства, какие даты, какие места. В расследованиях это позволяет выделить кластеры (одна камера = один автор) и найти аномалии (фото «не той» камеры). Для документов — собрать список авторов/организаций. Пакетный подход превращает разрозненные файлы в структурированные данные для анализа.
