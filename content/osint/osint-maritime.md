Морская разведка опирается на AIS (Automatic Identification System) — транспондеры судов, публично передающие позицию, курс, скорость и идентификаторы. Как ADS-B для авиации, AIS открывает огромный массив данных о мировом судоходстве: от контейнеровозов до частных яхт.

## AIS: идентификаторы

- **MMSI** — 9-значный идентификатор станции (судна).
- **IMO number** — постоянный номер судна (7 цифр, начинается с 9).
- **Callsign** — позывной.
- **Тип судна, флаг, назначение, ETA, осадка**.

Передача идёт по VHF (161.975/162.025 МГц). Приёмники по всему миру питают публичные сети.

```bash
# собственный приём AIS через RTL-SDR
rtl_fm -f 161.975M -M fm -s 48000 | aisdecoder -h 127.0.0.1 -p 10110 -a file -c mono -d
```

```bash
# пример: публичный API VesselFinder (ключ в переменной)

```

## От судна к владельцу

1. Возьмите **IMO** или **MMSI** с карты.
2. Найдите судно в **Equasis** — там владелец, оператор, менеджер, флаг.
3. Сверьте с **реестрами флагов** (Panama, Liberia, Marshall Islands — удобные флаги).
4. Для частных яхт маршрут и порты приписки выдают интересы владельца.
5. Проверьте санкционные списки (OFAC, EU, OpenSanctions) — популярная тема расследований.

## Аномалии и «тёмный» флот

- **AIS off** — судно выключает транспондер (признак незаконной активности, санкционных перевозок).
- **Спуфинг AIS** — подделка позиции (круговые треки, невозможная скорость).
- **Rendezvous** — встреча двух судов в море (перегрузка груза, дозаправка).
- **Gap in track** — разрыв трека у известных «серых» зон (перевалочные районы).
- **Dark fleet** — танкеры, перевозящие санкционную нефть, часто меняют названия и флаги.

Инструменты: Global Fishing Watch (рыболовство), Skylight (незаконный промысел), аналитика по AIS-датасетам.

## Спуфинг AIS: как распознать

Спуфинг — подделка данных транспондера. Признаки:

- **Невозможная скорость** — судно «телепортируется» (скорость выше физической).
- **Круговые треки** — позиции по кругу (следствие подмены MMSI).
- **Дубликаты MMSI** — два судна в разных местах с одним идентификатором.
- **Несоответствие типа** — «рыболов» по документам, но маршрут танкера.
- **Позиция на суше** — ошибка приёмника или намеренная подмена.

```bash
# расчёт «невозможной» скорости между двумя точками трека
python3 -c "
from math import radians,sin,cos,asin,sqrt
def d(a,b): # гаверсинус, км
 p=pi/180
 return 2*6371*asin(sqrt(sin((b[0]-a[0])*p/2)**2+cos(a[0]*p)*cos(b[0]*p)*sin((b[1]-a[1])*p/2)**2))
"
```

Комбинируйте AIS с спутниковыми снимками (SAR) — они ловят суда, выключившие транспондер.

## Практические приёмы

- Сопоставляйте **название судна** с фото (MarineTraffic community).
- История портов = маршрут бизнеса (какие страны, какие поставщики).
- Для яхт — привязка к марине, а марина → к владельцу через реестры.
- Смена названия/флага/MMSI — классический приём «тёмного» флота; отслеживайте по IMO.
- Осадка и груз показывают, идёт ли судно загруженным.

## Практика: идентификация судна по имени/фото

```bash
# поиск судна по названию в публичных реестрах и трекерах
# (MarineTraffic/VesselFinder — веб; пример API VesselFinder)
curl -s "https://api.vesselfinder.com/vessels?userkey=$VF_KEY&name=Example" | jq '.AIS[] | {imo, mmsi, name, flag}'
```

Дополнительно: фото судна на MarineTraffic community, бортовой номер (IMO на корпусе), порт приписки — всё это связывает судно с оператором. Для яхт — название часто содержит имя владельца/семьи.

## Логистика, санкции и «серая» активность

AIS позволяет анализировать цепочки поставок и нарушения:

- **Санкционные перевозки**: судно заходит в порты под санкциями, выключая AIS.
- **Перевалка (STS)**: две встречи в открытом море = перегрузка груза.
- **Смена флага/названия**: «тёмный флот» перерегистрируется, чтобы избежать санкций.
- **Осадка (draught)**: показывает, загружено судно или пустое.
- **Dark activity**: разрывы трека у известных «серых» зон.

Инструменты: **Global Fishing Watch** (промысел), **OpenSanctions** (санкционные суда/владельцы), дашборды AIS-аналитики.

## От судна к компании и людям

```text
IMO → Equasis → владелец/менеджер/оператор
владелец → бизнес-реестр (см. osint-business-registry)
адрес компании → геоконтекст, другие суда
судно → порты захода → деловые связи и поставщики
```

Для частных яхт маршрут (марины, острова, события) часто выдаёт интересы владельца. Связка «судно ↔ компания ↔ люди» — мощный OSINT-путь.

## Этика

- AIS публичен, но слежка за конкретным судном/лицом — чувствительна.
- Не публикуйте персональные данные владельцев без законных оснований.
- Учитывайте, что часть судов отключена или искажена намеренно.

| Инструмент | Назначение |

| MarineTraffic / VesselFinder | карта и история судов |
| FleetMon API | мониторинг и алерты |

## Частые ошибки

- **Путать MMSI и IMO**: MMSI может меняться (станция), IMO — постоянный.
- **Верить позиции AIS без проверки**: спуфинг и разрывы распространены.
- **Игнорировать флаг**: удобный флаг (Panama, Liberia) часто скрывает реального владельца.
- **Считать отсутствие на карте за отсутствие судна**: транспондер мог быть выключен.
- **Не проверять санкции**: пропущенный санкционный владелец обесценивает вывод.

## Что делать дальше / решение

- **Нужен владелец** → IMO → Equasis → бизнес-реестры → люди.
- **Нужны аномалии** → разрывы трека, STS, смена флага → санкционные списки.
- **Нужен «тёмный» флот** → AIS gap + SAR-снимки.
- **Нужен маршрут** → история портов → поставщики и связи.

## SAR-снимки и «тёмный» флот

Когда судно выключает AIS, единственный способ его найти — дистанционное зондирование. **Sentinel-1** (радар SAR) видит суда ночью и сквозь облака: металлический корпус даёт яркий «блик» на снимке. Рабочий процесс: (1) определить «серую» зону по разрывам трека; (2) заказать/скачать SAR-снимок на эту область и время (Copernicus Open Access, Sentinel Hub); (3) сопоставить яркие точки с ожидаемыми судами; (4) сравнить с AIS — суда, которых нет в AIS, но есть на снимке, и есть «тёмный» флот. Дополнительно оптические снимки (Sentinel-2) помогают опознать тип и перегрузку. Это же применяется для незаконного промысла и перевалки санкционного груза.

## Регистры флагов и удобные флаги

Флаг — это юрисдикция регистрации, и он ключевой для атрибуции:

- **Panama, Liberia, Marshall Islands, Malta, Cyprus** — «удобные флаги» (open registries): судно регистрируется там, где дешевле и мягче требования, а реальный владелец — в другой стране.
- **Реестры флага**: у каждой юрисдикции свой реестр, где видны владелец/менеджер (иногда через номинальные компании).
- **Смена флага** — частый приём «тёмного» флота; отслеживайте по постоянному **IMO**.
- **Порт приписки** (home port) на корме — дополнительный гео-сигнал.

Связка «флаг → реестр флага → номинальная компания → реальный владелец» — стандартный путь в расследованиях санкций.

## История и данные AIS

Исторические данные AIS продаются и агрегируются (MarineTraffic, FleetMon, Spire), но есть и открытые датасеты (Global Fishing Watch, NOAA). Что важно при работе с историей:

- **Разрывы трека** фиксируйте как события — они маркируют моменты выключения AIS.
- **Скорость и курс** за длинный период выдают «почерк» судна.
- **Осадка (draught)** меняется при загрузке/разгрузке — видно цикл рейса.
- **Порты захода** строят маршрут бизнеса.

Для больших объёмов стройте локальную базу (SQLite/PostGIS) и запрашивайте «кто был в зоне X в момент Y».
