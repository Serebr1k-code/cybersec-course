Спутниковые снимки — мощный OSINT-инструмент: они позволяют увидеть объект без физического доступа, отследить стройку, движение техники, изменение территории. Ключ к результату — уметь находить снимки **разных дат** и корректно их сравнивать (change detection), а не рассматривать один кадр.

## Как работает спутниковая съёмка

Спутник снимает полосу земли вдоль орбиты; за один проход получается «сцена» (scene) с известной датой/временем и геопривязкой. Различают:

- **Пространственное разрешение** — размер пикселя на местности (10 м → один пиксель = 10×10 м).
- **Спектральные каналы** — видимые (RGB), ближний ИК (NIR), коротковолновый ИК (SWIR), тепловой. Многоканальность даёт индексы.
- **Время ревизии (revisit)** — как часто спутник пролетает над точкой (Sentinel-2 — ~5 дней, Landsat — 16 дней).
- **Облачность** — главный враг оптики; отсюда популярность радара (Sentinel-1 SAR), который «видит» сквозь облака.

## Источники снимков

| Источник | Разрешение | Доступ |
|---|---|---|
| Sentinel-2 (ESA) | 10 м | бесплатно (Copernicus) |
| Sentinel-1 (SAR) | ~20 м | бесплатно (радар, сквозь облака) |
| Landsat 8/9 | 15–30 м | бесплатно (USGS) |
| Planet Labs | 3 м | частично платно, частые ревизии |
| Maxar / Google Earth | 30–50 см | платно / в интерфейсе |
| Sentinel Hub / EO Browser | визуализация | бесплатно |
| Yandex/Google Maps | высокое | интерфейс, таймлайн |

## Таймлайн и сравнение дат

Главный приём — **change detection**: вы берёте снимок «до» и «после» одной и той же области и ищете различия.

- **Google Earth Pro** — исторические снимки (ползунок времени), самый быстрый способ увидеть «как было / как стало».
- **EO Browser** (Sentinel Hub) — Sentinel/Landsat по конкретным датам, сравнение сцен side-by-side.
- **Sentinel Playground** — быстрый просмотр и таймлапсы.
- **USGS EarthExplorer** — глубокие архивы Landsat.
- **Planet Explorer** — частые ревизии (для динамики).

```bash
# Copernicus Data Space OData: найти сцены Sentinel-2 в заданном окне дат
curl -s "https://catalogue.dataspace.copernicus.eu/odata/v1/Products?\$filter=Collection/Name%20eq%20'SENTINEL-2'%20and%20ContentDate/Start%20gt%202024-01-01T00:00:00.000Z&\$top=5" \
  | python3 -c 'import sys,json;[print(p["Name"],p["ContentDate"]["Start"]) for p in json.load(sys.stdin)["value"]]'

# Поиск сцен по координатам и дате (bbox: minlon,minlat,maxlon,maxlat)
curl -s "https://catalogue.dataspace.copernicus.eu/odata/v1/Products?\$filter=OData.CSC.Intersects(area=geography'SRID=4326;POLYGON((37.4%2055.6,37.8%2055.6,37.8%2055.9,37.4%2055.9,37.4%2055.6))')&\$top=5"
```

## Что можно выявить

- **Строительство/расширение** объекта: новые корпуса, парковки, подъездные пути.
- **Движение техники** (для снимков с высокой частотой — Planet): колонны, переброска.
- **Изменение растительности/воды** — через индексы NDVI/NDWI.
- **Разрушения** после событий, пожары (NBR).
- **Инфраструктура**: вышки, склады, ангары, дамбы, вырубки.

## Геопривязка снимка

Задача обратная: по снимку определить точку на карте.

1. Определите **ориентиры**: перекрёстки, берега рек, мосты, характерные здания.
2. Сверьте с картами (Google/Yandex/OSM) — сопоставьте форму дорог, изгибы рек.
3. Используйте **тени** для проверки направления и времени суток (см. урок про хронолокацию).
4. Для высокого разрешения — сопоставьте с панорамами и фото «с земли».
5. Проверьте сезонность: снег/листва меняют вид, но геометрия постоянна.

## Спектральные индексы

Многоканальные снимки дают больше, чем видимый глаз. Индексы считаются из отношений каналов:

- **NDVI** = (NIR − Red)/(NIR + Red) — растительность.
- **NDWI** = (Green − NIR)/(Green + NIR) — вода.
- **NBR** = (NIR − SWIR)/(NIR + SWIR) — выгоревшие территории (пожары).
- **NDBI** — застройка.
- **SWIR** — влажность/тепло, полезно для объектов и техногенных изменений.

```python
# NDVI из Sentinel-2 (B08=NIR, B04=Red) с помощью rasterio/numpy
import rasterio, numpy as np
nir = rasterio.open("B08.tif").read(1).astype(float)
red = rasterio.open("B04.tif").read(1).astype(float)
ndvi = (nir - red) / (nir + red + 1e-9)
print("NDVI min/max/mean:", ndvi.min(), ndvi.max(), ndvi.mean())
```

## Разбор кейса

Задача: подтвердить, что на объекте за последний год велось строительство.

1. В EO Browser открываете область, выбираете Sentinel-2.
2. Берёте две сцены: год назад и свежую, с минимальной облачностью.
3. В режиме сравнения (split/side-by-side) видите новые пятна застройки.
4. Считаете NDVI «до/после» — падение индекса там, где была растительность, указывает на застройку.
5. Фиксируете: даты сцен, координаты, вырезки «до/после», интерпретацию.

## Этика и ограничения

- Снимки публичны, но **наблюдение за частным объектом** и публикация результатов может нарушать приватность.
- Учитывайте «чувствительность» объектов (военные, критическая инфраструктура) — ряд юрисдикций ограничивает публикацию.
- Не делайте выводов по одному снимку: облачность, сезонность, время суток искажают картину.
- Оптика не видит сквозь облака — для регулярного мониторинга используйте SAR (Sentinel-1).

## Частые ошибки

- **Использовать один снимок** — без сравнения дат нельзя доказать изменение.
- **Игнорировать облачность/сезон** — Sentinel часто затянут облаками, картинка «до» и «после» из разных сезонов.
- **Путать разрешение и точность** — 10 м не позволяет разглядеть номер машины или человека.
- **Забывать про дату снимка** — карта в интерфейсе может показывать многолетнюю давность.
- **Не учитывать геопривязку** — сцены имеют собственные координаты; не «натягивайте» их на другую карту без проверки.
- **Переинтерпретировать тени/цвет** — обработка сцен (композит, растяжка контраста) меняет вид, но не реальность.

## Спектральные индексы на практике

```python
# NDVI из Sentinel-2 (B08=NIR, B04=Red)
import rasterio, numpy as np
nir = rasterio.open("B08.tif").read(1).astype(float)
red = rasterio.open("B04.tif").read(1).astype(float)
ndvi = (nir - red) / (nir + red + 1e-9)
print("NDVI", round(float(ndvi.min()), 2), round(float(ndvi.mean()), 2), round(float(ndvi.max()), 2))
```

Индексы: NDVI (растительность), NDWI (вода), NBR (пожары), NDBI (застройка), SWIR (влажность/тепло). Динамика индекса между датами показывает изменения (вырубка, стройка, засуха).

## Верификация и этика

- **Сравнивайте минимум 2 даты** — один снимок ничего не доказывает.
- **Учитывайте облачность** (оптика) — используйте SAR (Sentinel-1) для регулярности.
- **Не публикуйте** координаты частных объектов без законной цели.
- **Фиксируйте** даты сцен, разрешение, источник.

## Практика: Copernicus OData API

```bash
# поиск сцен по коллекции и дате, свежие сверху
curl -s "https://catalogue.dataspace.copernicus.eu/odata/v1/Products?\$filter=Collection/Name%20eq%20'SENTINEL-2'%20and%20ContentDate/Start%20gt%202024-01-01T00:00:00.000Z&\$top=10&\$orderby=ContentDate/Start%20desc" \
  | jq -r '.value[] | [.Name,.ContentDate.Start,.Online]|@tsv'
# фильтр по облачности
curl -s "https://catalogue.dataspace.copernicus.eu/odata/v1/Products?\$filter=Collection/Name%20eq%20'SENTINEL-2'%20and%20Attributes/OData.CSC.DoubleAttribute/any(att:att/Name%20eq%20'cloudCover'%20and%20att/OData.CSC.DoubleAttribute/Value%20lt%2010)&\$top=5" \
  | jq -r '.value[].Name'
# скачивание продукта
curl -s "https://catalogue.dataspace.copernicus.eu/odata/v1/Products(<id>)/\$value" -o scene.zip
```

Пагинация — параметры `$top` (максимум 100) и `$skip`, сортировка — `$orderby`. Поле `Online` показывает, лежит ли сцена в горячем хранилище или её нужно заказывать.

## Практика: индексы и change detection

```python
import rasterio, numpy as np
def ndvi(nir_path, red_path):
    nir = rasterio.open(nir_path).read(1).astype(float)
    red = rasterio.open(red_path).read(1).astype(float)
    return (nir - red) / (nir + red + 1e-9)

a = ndvi("B08_2023.tif", "B04_2023.tif")
b = ndvi("B08_2024.tif", "B04_2024.tif")
diff = b - a
print("mean NDVI change:", float(np.nanmean(diff)))
```

Отрицательная дельта в зоне растительности указывает на застройку или вырубку; положительная — на восстановление. Для воды считайте NDWI, для пожаров — NBR, для застройки — NDBI.

## Практика: Sentinel-1 SAR

Радар «видит» сквозь облака и ночью, поэтому для регулярного мониторинга он незаменим. Изменение обратного рассеяния (backscatter) выявляет затопления, движение техники и стройку:

```bash
# поиск сцен Sentinel-1 GRD
curl -s "https://catalogue.dataspace.copernicus.eu/odata/v1/Products?\$filter=Collection/Name%20eq%20'SENTINEL-1'&\$top=5" | jq -r '.value[].Name'
```

```python
import rasterio, numpy as np
img = rasterio.open("s1_vv.tif").read(1).astype(float)
db = 10*np.log10(img + 1e-9)   # перевод в децибелы
print("backscatter mean dB:", float(np.nanmean(db)))
```

Резкое падение backscatter на водной поверхности — признак разлива или затопления.

## Что дальше / решение

Всегда сравнивайте минимум две даты и фиксируйте облачность обеих сцен — иначе различие «до» и «после» можно приписать изменению, которого не было. Для регулярного мониторинга используйте SAR. В итоговой записи указывайте даты сцен, разрешение, источник и координаты — без этого результат нельзя верифицировать.

## Практика: геопривязка снимка по ориентирам и теням

Обратная задача — по снимку определить точку на карте — решается методично. Начните с поиска устойчивых ориентиров: перекрёстки дорог, изгибы рек, мосты, характерные здания и линии электропередач. Сопоставьте их форму с картами Google, Yandex и OpenStreetMap, обращая внимание не на подписи, а на геометрию: рисунок дорожной сети и береговой линии почти не меняется годами. Тени дают направление и приблизительное время суток: зная дату снимка, можно по длине и азимуту тени вычислить широту и время (см. урок про хронолокацию). Высокое разрешение позволяет сверить снимок с панорамами «с земли» и наземными фотографиями — это финальная проверка. Учитывайте сезонность: снег и листва меняют вид, но геометрия объектов постоянна, поэтому привязывайтесь к геометрии, а не к цвету. Всегда фиксируйте, какой именно снимок и какой даты вы использовали, и проверяйте геопривязку сцены — не натягивайте её на другую карту без перекрёстной проверки по нескольким ориентирам.
