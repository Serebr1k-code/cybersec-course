TikTok — видеоплатформа с огромным охватом и слабыми настройками приватности у многих пользователей. Здесь люди снимают офисы, рабочие места, экраны, бейджи и поездки. Видео сложнее анализировать, чем текст, но кадры дают уникальные детали. В этом уроке — методика сбора и анализа.

## Теория: что доступно в TikTok

- **Профиль:** username, имя, bio, аватар, счётчики, ссылка.
- **Видео:** контент, описание, хэштеги, звук (trending audio), музыка.
- **Комментарии:** обсуждения, контакты, жалобы.
- **Подписки/подписчики:** граф связей (часто ограничен).
- **Локация:** явный геотег редок, но кадры и звуки дают подсказки.
- **Дубликаты:** видео часто кросс-постятся в Instagram/YouTube.

Ключ: видео надо разбирать по кадрам — фон, вывески, экраны, форма.

## Инструменты и команды

Веб-поиск:

```text
site:tiktok.com "Example Corp"
site:tiktok.com/@example
site:tiktok.com "example" (office OR work)
```

Публичная страница профиля:

```bash
curl -s -A "Mozilla/5.0" "https://www.tiktok.com/@example" | grep -oE '"uniqueId":"[^"]+"' | head
```

Скачивание видео для покадрового анализа:

```bash
pip install yt-dlp
yt-dlp "https://www.tiktok.com/@example/video/1234567890"
# извлечь кадры (1 кадр в секунду)
ffmpeg -i video.mp4 -vf fps=1 frames/%04d.jpg
```

Анализ кадров:

```bash
exiftool frames/0001.jpg | grep -iE "gps|date"
# визуальный осмотр: вывески, экраны, логотипы
```

## Разобранный пример: офис и график по видео

Дано: аккаунт `@example_company`.

Шаг 1 — профиль: bio, ссылка на сайт, счётчики.

Шаг 2 — скачиваем несколько видео с «рабочего дня»:

```bash
yt-dlp "https://www.tiktok.com/@example_company"
ffmpeg -i *.mp4 -vf fps=1 frames/%04d.jpg
```

Шаг 3 — покадровый анализ: вывеска офиса, вид из окна (геолокация), экраны с внутренними URL/Jira, бейджи, форма.

Шаг 4 — звук: фоновые объявления на вокзале/в метро дают город и язык.

Шаг 5 — комментарии: вопросы «где вы?» и ответы сотрудников раскрывают адрес.

Шаг 6 — кросс-корреляция: тот же контент в Instagram/YouTube, аватар → другие сети.

## Продвинутые приёмы

- **Trending audio:** звук связывает видео разных пользователей (кампании/компании).
- **Дубликаты:** удалённое в TikTok часто живёт в Instagram Reels.
- **Сторис-аналоги:** TikTok Stories и «Лайки» видны в ограниченном виде.
- **Геоконтекст:** вид из окна + карты (см. osint-geolocation) = точный адрес.
- **Временные метки:** публикации показывают график и периоды отпусков.
- **Хэштеги города:** `#москваофис`, `#example` сужают поиск.

## Частые ошибки

- **Смотреть только текст.** В TikTok всё в кадрах — нужен ffmpeg и внимательный осмотр.
- **Пропускать звук.** Аудио раскрывает локаль и контекст.
- **Забыть про кросс-постинг.** Контент часто дублируется на других платформах.
- **Верить bio.** Ссылки могут вести на партнёров, а не на компанию.
- **Скачивать без нужды.** Берите только релевантные видео (объём, ToS).
- **Игнорировать комментарии.** Там прямые ответы на «где и кто».

## Покадровый анализ: методика «что видно»

Видео TikTok — это десятки кадров, каждый может содержать подсказку. Систематизируйте осмотр:

- **Вывески и логотипы** → OCR (Google Lens) → название → город.
- **Экраны и мониторы** в кадре: внутренние URL, Jira, Slack, тикеты — карта инфраструктуры.
- **Бейджи и форма** сотрудников: название компании, отдел, фото.
- **Вид из окна**: узнаваемые здания, реки, горы → геолокация (см. osint-geolocation).
- **Номера машин и их форматы** → страна/регион.
- **Транспорт**: маршруты, логотипы перевозчика, объявления на остановках.
- **Погода и сезон** → диапазон дат.

```bash
# извлечь 1 кадр в секунду и посмотреть контактный лист
ffmpeg -i video.mp4 -vf "fps=1,scale=320:-1,tile=5x5" contact_sheet.jpg
```

## Звук и метаданные: недооценённые слои

- **Аудио** (речь, объявления, музыка) часто выдаёт язык, акцент и конкретное место. Распознайте речь (`whisper`) и переведите.
- **Фоновые объявления** на вокзалах/в метро содержат названия станций и городов.
- **Оригинальный звук** («original sound») привязывает видео к аккаунту-источнику тренда.
- **Метаданные** скачанного видео через `ffprobe`/`exiftool` иногда сохраняют дату создания и устройство.
- **Описание и хэштеги**: `#<город>`, `#<компания>` сужают поиск; часто там прямые ответы.

```bash
ffprobe -v quiet -print_format json -show_format video.mp4 | jq '.format.tags'
```

## Правовые и этические границы

TikTok-контент публичен, но:

- **Персональные данные** в кадре (лица, документы, номера) — специальная категория; собирайте только в рамках цели и закона.
- **Не выдавайте себя** за сотрудника и не вступайте в контакт под ложной легендой без разрешения.
- **Скачивание** чужого контента регулируется ToS и авторским правом.
- **Фиксируйте** источник (URL, дата, автор) — видео может быть удалено.

## Неофициальные API и эндпоинты TikTok

Официальный Research API ограничен (академические аккаунты), поэтому практики используют публичные web-эндпоинты и инструменты:

```bash
# yt-dlp: скачивание видео и метаданных (JSON)
yt-dlp --write-info-json --skip-download "https://www.tiktok.com/@example_company/video/1234567890"
# содержимое info.json: uploader_id, upload_date, like_count, comment_count,
#                        music.album, music.artist, duration, title, description

# tiktok-scraper (Node): профиль, посты, хэштеги
npx tiktok-scraper user example_company -n 50 --filepath ./out
npx tiktok-scraper hashtag examplecorp -n 100 --filepath ./out
```

Ключевые поля: `author.uniqueId`, `author.id` (внутренний числовой ID, не меняется при смене ника), `createTime` (UNIX), `locationCreated`, `music.id`, `stats.*`. Числовой `id` автора — устойчивый якорь для корреляции.

## Метаданные видео: скрытые слои

| Слой | Что даёт |
|------|----------|
| `createTime` | точное время публикации (таймзона — по локации) |
| `music` | тренды, регион, вкусы |
| `locationCreated` | геотег (часто «популярное место», а не офис) |
| дуэты/stitch | с кем взаимодействует аккаунт |
| комментарии | контакты, конфликты, названия отделов |

```bash
# извлечь всё из info.json
jq '{id:.id, date:.upload_date, author:.uploader_id, loc:.location, music:.music}' \
   "example_company/1234567890.info.json"
```

## Покадровый анализ: расширенная методика

Из видео извлекаем кадры и ищем:

```bash
ffmpeg -i video.mp4 -vf fps=2 frames/%04d.jpg    # 2 кадра/сек
# далее: OCR вывесок, номеров, экранов
for f in frames/*.jpg; do tesseract "$f" - -l rus+eng 2>/dev/null; done | sort -u | grep -iE 'url|login|corp'
```

Что искать в кадрах: вывески и адрес, номера авто, бейджи, логотипы подрядчиков, экраны с внутренними URL/тикетами, схемы на стенах, календари и доски задач. Даже «случайный» кадр даёт адрес офиса или имя системы.

## Звук как источник: что слушают и что слышно

- **Трек (music.id)** — по нему находят другие видео с той же музыкой (тренды, регион).
- **Фоновая речь** — имена, названия отделов, жаргон (ASR: whisper).
- **Фоновые звуки** — сирена, метро, гимн завода: геолокационная зацепка.
- **Язык/акцент** — сужение региона.

```bash
# ASR фоновой речи
ffmpeg -i video.mp4 -ar 16000 -ac 1 audio.wav
whisper audio.wav --language Russian --model small
```

## Кросс-корреляция платформ

TikTok редко изолирован. Один и тот же контент живёт в TikTok, Instagram (Reels), YouTube (Shorts). Метод:

1. Скачать видео → посчитать перцептивный хэш (`imagehash`/`videohash`) — одинаковые кадры связывают аккаунты на разных платформах.
2. Совпадение аватара → reverse image (osint-image-reverse).
3. Совпадение ника → username-enum (osint-username-enum).
4. Совпадение текста подписи → stylometry.

```python
import videohash
h1 = videohash.VideoHash(path="./tt.mp4")
h2 = videohash.VideoHash(path="./yt.mp4")
print(h1 - h2)   # 0 == один и тот же контент
```

## Тренды и геолокация по контенту

Публичные агрегаты (TikTok Creative Center) дают тренды по странам — полезно для контекста: если аккаунт снимает локальные тренды конкретного региона, это уточняет геолокацию. Хэштеги `#<город>`, `#<район>` и локальные челленджи — маркеры места. Сочетайте с хроно- и геолокацией (osint-geolocation, osint-chronolocation).

## Разобранный пример 2: от видео к адресу и графику

Дано: аккаунт `@example_company`.

1. `yt-dlp --write-info-json --skip-download` по последним 30 видео → таблица `createTime`, `music`, `locationCreated`.
2. Извлекаем кадры (fps=2), прогоняем OCR: находим вывеску «Example Corp, корп. 3».
3. По комментариям сотрудников собираем имена → паттерн email.
4. Кросс-корреляция: один сотрудник ведёт тот же ник в Instagram → подтверждение личности.
5. По `createTime` строим график активности → рабочие часы и дни присутствия.
6. Спутниковый снимок корпуса (osint-satellite) → привязка адреса.

## Частые ошибки и ограничения

- **Принимать `locationCreated` за офис** — часто это популярное кафе/город.
- **Игнорировать числовой author.id** — при смене ника он сохраняется, это якорь.
- **Скачивать через основной аккаунт** — бан; используйте изолированную среду/API.
- **Доверять одному видео** — нужна серия и corroboration.
- **Нарушать ToS/приватность** — массовый сбор ПДн регулируется (osint-legal-ethics).
- **Забыть про watermark** — удаление watermark (в т.ч. чужого) этически и юридически спорно; не делайте этого для публикации.
