Радиоэфир — открытая среда. Радиоразведка (radio OSINT) — это сбор и анализ открытых радиопередач: экстренные службы, авиация, железная дорога, пейджинг, APRS. Часто это единственный источник локальной информации в реальном времени, доступный без физического присутствия. В уроке — источники частот, приём и декодирование, идентификация сигналов, оборудование, разобранные примеры и правовые границы.

## Что такое радиоразведка и зачем она

- **Реальное время.** Эфир даёт информацию о событии в момент его развития, а не постфактум.
- **Локальность.** Переговоры привязаны к географии — это контекст, недоступный из интернета.
- **Верификация.** Радиопереговоры подтверждают или опровергают новостные сообщения.
- **Данные, а не только голос.** APRS, AIS, ACARS, ADS-B несут координаты и телеметрию.
- **Blue team.** Понимание того, что организация излучает в эфир, — часть оценки поверхности.

## Источники частот

- **RadioReference** — крупнейшая база частот по странам и регионам (полиция, скорая, пожарные, авиация, железная дорога); есть API и Wiki.
- **Broadcastify** — онлайн-сканеры и архивы записей (слушать можно без оборудования).
- **Sigidwiki** — wiki по идентификации сигналов (как выглядит и звучит сигнал).
- **Local scanner groups** — форумы по регионам с точными частотами и тонами.

```text
# пример структуры записи частот
# 155.7900  FM  CTCSS 100.0  Police Dispatch (пример)
# 462.5625  FM  DCS 023     PMR/FRS канал 1 (пример)
```

## Приём: SDR и сканеры

RTL-SDR (дёшево, ~$30) + `rtl_fm`/`gqrx`/`SDR#` позволяют принимать и декодировать сигналы. Онлайн-сканеры Broadcastify не требуют оборудования, но зависят от добровольцев.

```bash
# приём узкополосной FM на частоте (МГц) в файл
rtl_fm -f 155.790M -M fm -s 22050 -g 40 - | sox -t raw -r 22050 -e signed -b 16 -c 1 - out.wav

# декодирование APRS (144.800 МГц, Европа)
rtl_fm -f 144.800M -M fm -s 22050 | direwolf -t 0 -r 22050 -

# декодирование цифровых тонов и пейджинга
rtl_fm -f 439.9875M -M fm -s 22050 | multimon-ng -t raw -a POCSAG512 -a DTMF -
```

Флаги `rtl_fm`: `-f` (частота), `-M` (модуляция: fm/am/usb/lsb), `-s` (sample rate), `-g` (gain), `-p` (ppm-коррекция), `-l` (squelch).

## Что декодируют

| Сигнал | Частоты/применение |
|---|---|
| APRS | 144.800 (EU) / 144.390 (US) — позиции, телеметрия |
| POCSAG/FLEX | пейджинг — сообщения, иногда медданные |
| DTMF | тональные наборы — управление, телеметрия |
| ACARS | авиация — текстовые сообщения борта |
| ADS-B | 1090 МГц — авиация (см. урок про авиацию) |
| AIS | VHF — суда (см. урок про море) |
| AFSK/FSK | телеметрия, датчики, метеостанции |

## Декодирование цифровых сигналов

Помимо прослушивания, радио даёт **данные**:

```bash
# APRS: позиции и телеметрия
rtl_fm -f 144.800M -M fm -s 22050 | direwolf -t 0 -r 22050 -

# POCSAG/FLEX/DTMF: пейджинг и тоны
rtl_fm -f 439.9875M -M fm -s 22050 | multimon-ng -t raw -a POCSAG512 -a DTMF -

# AIS (суда)
rtl_fm -f 161.975M -M fm -s 48000 | aisdecoder -h 127.0.0.1 -p 10110
```

`direwolf` и `multimon-ng` превращают сырой аудиопоток в читаемый текст и координаты. Вывод `direwolf` содержит позывной, координаты, курс и комментарий.

## Идентификация неизвестного сигнала

Когда сигнал неизвестен, работайте методично: смотрите водопад (waterfall) в `gqrx`/`SDR#`, определяйте ширину полосы, модуляцию (NFM/WFM/AM/USB/LSB), наличие тонов. Затем сверьтесь с Sigidwiki. Записанный IQ-файл можно обрабатывать офлайн в `inspectrum`/`URH`.

```bash
# записать IQ-файл для офлайн-анализа
rtl_sdr -f 433920000 -s 2048000 -n 4096000 capture.iq
```

## Онлайн-сканеры и базы

- **Broadcastify** — живое прослушивание и архивы без оборудования.
- **RadioReference** — точные частоты и тоны по регионам и службам.
- **Sigidwiki** — идентификация незнакомых сигналов по водопаду и звуку.
- **WebSDR** — приёмники по всему миру через браузер.

Связка: определить регион → найти частоты в RadioReference → слушать через Broadcastify → при необходимости принять локально через SDR.

## Оборудование и антенны

- **RTL-SDR** — дешёвый старт (VHF/UHF, ~24–1700 МГц).
- **Airspy/HackRF** — шире полоса, лучшая чувствительность.
- **Антенны**: диполь для VHF, discone для широкого охвата, направленные — для дальних сигналов.
- **Фильтры/LNA** — улучшают слабые сигналы в зашумлённом эфире.
- **Улучшение приёма**: поднимите антенну, уберите источники помех (компьютер, роутер), задайте корректный gain.

## Разобранный пример: от региона до перехвата

1. Определите регион цели.
2. Найдите частоты в RadioReference (по городу/службе).
3. Слушайте через Broadcastify (без оборудования) или SDR (с оборудованием).
4. Декодируйте цифровые сигналы (`direwolf`, `multimon-ng`, `dump1090`).
5. Соотнесите с событиями: время, место, упомянутые объекты, позывные.

## Этика и закон

- **Приём** открытых аналоговых передач обычно легален, но **прослушивание и особенно запись/публикация** шифрованных/частных каналов во многих юрисдикциях **запрещены** (в РФ — ст. 138 УК, в США — ECPA).
- **Передача** (даже на приёмопередатчике) без лицензии — нарушение. SDR только **принимает**.
- Шифрованные каналы (DMR/P25 с шифрованием) взламывать нельзя — это не OSINT, а противоправное действие.
- Не публикуйте персональные данные, услышанные в эфире.

## Частые ошибки

- **Путать частоты стран** — APRS/PMR/FRS различаются по регионам.
- **Игнорировать тоны (CTCSS/DCS)** — без них сканер не откроет шумоподавление.
- **Забыть про модуляцию** — AM vs FM дадут неразборчивый сигнал.
- **Публиковать записи** — юридический риск.
- **Ожидать «хакерских» переговоров** — реальный эфир в основном рутина; ценность в верификации и корреляции.
- **Плохая антенна** — большинство «нет сигнала» объясняется приёмом, а не отсутствием передачи.

## Что дальше / решение

Определив источник сигнала, переходите к корреляции: APRS/AIS/ADS-B дают координаты, которые можно наложить на карту; переговоры — контекст. Решение по каналу: «открытый аналог — можно слушать», «цифровой без шифрования — декодировать», «шифрованный/частный — не трогать». Всегда фиксируйте частоту, модуляцию, время и источник данных.

## Декодирование APRS: практика

APRS — пакетная радиосвязь, несущая позиции, погоду и телеметрию. Станции передают координаты, курс, скорость и короткий комментарий.

```bash
# приём и декодирование APRS в реальном времени
rtl_fm -f 144.800M -M fm -s 22050 | direwolf -c sdr.conf -r 22050 -D 1 -
```

Вывод `direwolf`:

```text
[0.4] R2ABC-9>APRS,WIDE1-1:!5545.12N03737.34E#PHG7000/Test
```

Здесь `5545.12N 03737.34E` — координаты, `R2ABC-9` — позывной. Такие точки можно наносить на карту и отслеживать движение объекта.

## AIS: суда

AIS передаёт позиции, курс, название судна, IMO/MMSI. Приём — на 161.975/162.025 МГц.

```bash
# приём AIS и вывод в формате NMEA
rtl_fm -f 161.975M -M fm -s 48000 | aisdecoder -h 127.0.0.1 -p 10110
```

Онлайн-сервисы (MarineTraffic, VesselFinder) дают те же данные без оборудования (см. урок про море).

## Пейджинг: POCSAG/FLEX

Пейджеры до сих пор используются в больницах и службах. Сообщения часто не шифруются.

```bash
# декодирование POCSAG на нескольких скоростях
rtl_fm -f 439.9875M -M fm -s 22050 | multimon-ng -t raw -a POCSAG512 -a POCSAG1200 -a POCSAG2400 -a FLEX -
```

Вывод — текстовые сообщения и адресаты. Это чувствительная область: содержание может быть медицинским или личным.

## Типичные ошибки приёма

- **Неверный gain** — сигнал перегружен или слишком слаб; подбирайте вручную.
- **PPM-сдвиг** — дешёвые SDR «уводят» частоту; калибруйте (`rtl_test -p`).
- **Нет фильтра** — мощные FM-станции забивают приём; ставьте band-pass.
- **Плохой кабель/разъём** — большая часть потерь здесь.
- **Неверная модуляция** — путаница AM/FM/SSB даёт «шум».

## Правовые нюансы по странам

| Юрисдикция | Приём | Публикация |
|---|---|---|
| РФ | приём открытого — ок | ст. 138 УК при нарушении тайны связи |
| США | приём ок | ECPA ограничивает раскрытие |
| ЕС | зависит от страны | GDPR для персональных данных |
| UK | ок для общего | Wireless Telegraphy Act |

Правило: слушать открытое можно, публиковать содержимое частных переговоров — нет.

## Спектр и планирование наблюдения

- **Диапазоны:** VHF (30–300 МГц) — авиация, морская, полиция; UHF (300–3000 МГц) — PMR, DMR, пейджинг; HF (3–30 МГц) — дальняя связь.
- **Ширина канала:** NFM 12.5 кГц (узкополосная), WFM 200 кГц (вещание), AM 8 кГц (авиация).
- **Сканирование:** `gqrx` умеет сканировать закладки; для массового — `rtl_power` строит карту занятости спектра.

```bash
# карта спектра за 10 минут (найти активные частоты)
rtl_power -f 144M:148M:12.5k -i 10 -e 600m spectrum.csv
```

По `spectrum.csv` видно, где идёт передача — это подсказка, какие каналы декодировать.

## Запись и офлайн-анализ

```bash
# записать IQ для офлайн-разбора
rtl_sdr -f 439987500 -s 2048000 -n 40960000 pager.iq
# разобрать записанный файл
multimon-ng -t wav -a POCSAG512 recording.wav
```

Офлайн-анализ удобен, когда нужно многократно перебирать модуляции и параметры без повторного приёма.

## Где пригодится

- **CTF:** задачи, где ответ звучит в эфире или закодирован тонами.
- **OSINT:** локальный мониторинг событий в реальном времени.
- **SDR/RF:** приём и анализ сигналов, идентификация модуляций.
- **IR/журналистика:** верификация событий по радиопереговорам.
