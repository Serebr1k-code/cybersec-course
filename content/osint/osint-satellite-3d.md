## Вопрос, с которого всё начинается

На снимке — здание, но как узнать его высоту, если у тебя только картинка? Есть несколько путей: фотограмметрия, готовые цифровые модели высот и простой расчёт по тени. Последний доступен каждому и работает удивительно хорошо.

Задача: определить высоту здания по длине его тени и углу Солнца.

## Наш пример: тень и угол Солнца

Держим файл `shadow.json`:

```bash
cat shadow.json
```

```text
{"shadow_length_m":24,"sun_elevation_deg":45,"x_note":"nto{h31ght_by_sh4d0w}"}
```

Первый вопрос: как из этих двух чисел получить высоту?

## Шаг 1: геометрия тени

Здание, его тень и солнечный луч образуют прямоугольный треугольник. Высота здания — вертикальный катет, длина тени — горизонтальный. Угол между лучом и землёй — это **высота Солнца** (sun elevation). Отсюда:

```text
высота = длина_тени × tan(угол_Солнца)
```

## Шаг 2: считаем

```bash
python3 building_height.py
```

```text
Длина тени: 24 м
Угол Солнца: 45°
tan(45°) = 1.00
Высота = 24 * 1.00 = 24.0 м
nto{h31ght_by_sh4d0w}
```

Высота — 24 метра. Это примерно 8 этажей.

## Шаг 3: фотограмметрия

Более точный, но сложный метод — **фотограмметрия**: по нескольким снимкам с разных ракурсов строят 3D-модель. На выходе получают облако точек, из которого извлекают высоты. Для этого нужны перекрывающиеся снимки, что не всегда доступно.

## Шаг 4: готовые модели высот

Есть открытые **DSM** (Digital Surface Model — с высотами объектов) и **DTM** (Digital Terrain Model — только рельеф). Разница между ними даёт высоту зданий. Также существует 3D-слой OpenStreetMap с контурами зданий и высотами. Это быстрый способ, если данные покрывают район.

## Полный прогон

```bash
cat shadow.json            # длина тени и угол
python3 building_height.py # расчёт высоты
```

Непрерывно: снимок → тень → угол Солнца → расчёт → высота.

## Разбор кейса: определение этажности

По снимку нужно понять, сколько этажей у здания. Меряем тень (24 м), берём угол Солнца из альманаха на дату снимка (45°), считаем высоту (24 м). Делим на высоту этажа (около 3 м) — получаем 8 этажей. Так одна фотография превращается в измерительный инструмент.

## Рабочий воркбук: 3D-разведка

1. **Источник.** Выбери снимок с известной датой.
2. **Угол Солнца.** Возьми из астрономического калькулятора.
3. **Тень.** Измерь по снимку с учётом масштаба.
4. **Расчёт.** Примени формулу тангенса.
5. **Кросс-проверка.** Сравни с DSM или 3D OSM.
6. **Отчёт.** Укажи метод и погрешность.

## Если не сработало

**Тени нет.** Снимок сделан в облачность или сверху — используй DSM.
**Искажение.** Косой ракурс искажает длину тени.
**Погрешность.** Высота Солнца меняется — учитывай дату и время.

## Частые ошибки

**Ошибка: не учитывать угол Солнца.** Без него высоту не посчитать.
**Ошибка: мерить тень без масштаба.** Нужен привязанный к местности снимок.
**Ошибка: путать DSM и DTM.** DSM включает объекты, DTM — только рельеф.
**Ошибка: игнорировать время.** Солнце движется, угол меняется.

## Частые вопросы

**Что такое DSM?** Модель поверхности с объектами.
**Что такое DTM?** Модель рельефа без объектов.
**Где взять 3D-модели?** В OSM (3D buildings) и открытых DSM.
**Насколько точен расчёт по тени?** Обычно ±10% при аккуратных измерениях.
**Можно ли определить форму?** Да, по нескольким снимкам (фотограмметрия).

## Термины

**Фотограмметрия** — построение 3D по снимкам.

**DSM** — цифровая модель поверхности.

**DTM** — цифровая модель рельефа.

**Облако точек** — набор 3D-точек.

**Высота Солнца** — угол светила над горизонтом.

## Расширенный разбор: от 2D к 3D

Переход от плоского снимка к трёхмерной модели — ключевой навык георазведки. Существует три подхода, и каждый хорош в своей ситуации.

Первый — тени. Он дешёвый и быстрый: одна фотография, один астрономический расчёт. Его ограничение — нужна ясная погода и различимая тень. Он не даёт формы, только высоту.

Второй — фотограмметрия. Она строит облако точек из множества перекрывающихся снимков. Результат — полноценная 3D-модель, но требуется много исходных изображений и вычислительные ресурсы. Этот метод используют для точных измерений и для реконструкции памятников.

Третий — готовые модели. Государственные и коммерческие DSM, а также 3D-данные OpenStreetMap содержат высоты уже в готовом виде. Это самый быстрый путь, если покрытие есть. Его минус — актуальность: модель может отставать от реальности на месяцы и годы.

Практический совет: начинай с готовых моделей, если они есть. Если нет — используй тени. Фотограмметрию применяй, когда нужна высокая точность и есть достаточно снимков. Комбинируя методы, ты повышаешь надёжность вывода.

## Практикум: измерить высоту

Полный цикл. Возьми снимок с известной датой и временем. Найди в астрономическом калькуляторе высоту Солнца для этой точки и момента. Измерь длину тени на снимке, привязав масштаб по известному объекту (например, ширине дороги). Примени формулу: высота = длина тени × tan(угла). Сравни результат с DSM или 3D OSM. Оцени погрешность и зафиксируй метод.

## Что мы теперь знаем

1. Высоту можно измерить по тени: высота = тень × tan(угла).
2. Фотограмметрия строит 3D из множества снимков.
3. DSM включает объекты, DTM — только рельеф.
4. 3D OSM — быстрый источник высот.
5. Комбинирование методов повышает надёжность.

## Расширенный разбор: точность и погрешности измерений

Любое измерение по снимку имеет погрешность, и профессионал её оценивает и указывает. Разберём источники ошибок.

Первая — угол Солнца. Высота светила зависит от даты, времени и координат. Если взять угол неточно, высота объекта «поплывёт». Ошибка в 5 градусов при угле 45 даёт заметное расхождение. Всегда бери угол из астрономического калькулятора по точным координатам и моменту съёмки.

Вторая — масштаб. Чтобы измерить длину тени в метрах, нужен масштаб. Его берут по известному объекту: ширина дороги, длина футбольного поля, размер контейнера. Чем точнее масштаб, тем точнее измерение.

Третья — ракурс. Снимок, сделанный не строго сверху, искажает пропорции. Орторекорд (исправленный снимок) лишён этого искажения, но не всегда доступен. Если снимок косой, погрешность растёт.

Четвёртая — тень. Тень падает на рельеф, и если земля неровная, её длина искажается. На ровной площадке измерение надёжнее. Также тень может перекрываться другими объектами.

Пятая — модель высоты этажа. Деля высоту на «этаж», ты используешь среднее значение (около 3 метров), но у разных зданий оно разное. Поэтому число этажей — оценка, а не точный факт.

Указывая результат, всегда приводи метод, исходные данные и оценку погрешности. Так вывод становится проверяемым и честным.

## Практикум: сверить два метода

Возьми здание, высоту которого можно определить и по тени, и по DSM. Сначала посчитай по тени: измерь длину, возьми угол Солнца, примени формулу. Затем посмотри высоту в DSM или 3D OSM. Сравни результаты. Если расхождение больше 15%, разберись почему: неточный масштаб, косой ракурс, неровный рельеф или устаревшая модель. Так ты калибруешь свой метод и учишься оценивать погрешность.

## Заметка о данных OpenStreetMap

Проект OpenStreetMap содержит не только контуры зданий, но и, во многих городах, их высоту. Эти данные вносят волонтёры по открытым источникам, поэтому они неполны и могут содержать ошибки, но для быстрой оценки высоты они незаменимы. Проверяй атрибут height у контура здания и сверяй его с другими методами. Если данных нет, используй расчёт по тени. Сочетание OSM, DSM и теневого метода даёт наиболее надёжную оценку, а расхождения между ними указывают на ошибки или устаревшие данные.

## Заметка о практической ценности 3D

Зачем разведке высота зданий и рельеф? Во-первых, для верификации: если заявлено строительство небоскрёба, а на снимке одноэтажное строение, есть противоречие. Во-вторых, для планирования: высота и плотность застройки влияют на оценку обстановки. В-третьих, для геолокации: силуэт зданий и рельеф помогают определить точку съёмки на фотографии. В-четвёртых, для мониторинга изменений: рост этажности указывает на развитие района. Поэтому навык извлекать высоту из снимков — не абстракция, а рабочий инструмент георазведки.

## Заметка об этике измерений

Измеряя объекты по снимкам, помни о границах. Публичные спутниковые данные позволяют оценивать высоту зданий, но не предназначены для слежки за конкретными людьми. Используй метод для законных задач: верификация заявлений, анализ застройки, проверка инфраструктуры. Не публикуй персонально чувствительные выводы без необходимости. И всегда указывай погрешность: «высота около 24 метров» точнее и честнее, чем «высота 24.0 метра», если измерение приблизительное.
