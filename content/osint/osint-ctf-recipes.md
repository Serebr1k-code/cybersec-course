CTF-задачи категории OSINT — это головоломки вида «дан идентификатор — найди флаг». В отличие от реальной разведки, здесь флаг спрятан намеренно, а ввод может быть любым: фото, ник, домен, координата, метаданные, звук. Этот урок — набор **рецептов**: для каждого типа ввода — что делать по шагам и чем. Цель — быстро определить тип задачи и применить нужный чек-лист.

## Теория: анатомия OSINT-задачи

Любая задача содержит: **ввод** (что дано), **ограничения** (подсказки), **цель** (флаг). Флаг обычно в одном из мест:
- в метаданных файла;
- в профиле аккаунта (bio, пост, аватар);
- в координатах места;
- в скрытом контенте страницы;
- в архиве/устаревшей версии;
- в ответе API;
- в утечке/пастбине.

Алгоритм: **классифицировать ввод → выбрать рецепт → pivot по цепочке → извлечь флаг → верифицировать формат**.

## Рецепт 1: дано фото

Чек-лист:

```bash
# 1. Метаданные
exiftool photo.jpg
strings photo.jpg | grep -iE 'flag|ctf|http|@'

# 2. Обратный поиск
# Google Images / Yandex / TinEye / Bing

# 3. Геолокация по объектам
# - вывески, языки, номера авто, архитектура
# - тени → время/широта (suncalc)
# - растительность, климат
# 4. Стеганография (если внутри файла что-то есть)
zsteg photo.png
```

Часто флаг прямо в `Comment`/`XPComment` EXIF или в GPS-координатах.

## Рецепт 2: дан ник/username

```bash
sherlock targetuser
maigret targetuser --html
# проверка вручную: GitHub, Telegram, VK, Reddit, Steam
```

Дальше — по найденным профилям: bio, ссылки, репозитории. Часто флаг в описании одного из аккаунтов или в «о себе».

## Рецепт 3: дан email

```bash
holehe --only-used target@example.com
ghunt email target@gmail.com
# Gravatar по md5(email)
echo -n target@example.com | md5sum
# https://www.gravatar.com/avatar/<md5>
```

Gravatar-профиль по md5(email) — классика CTF: там может быть имя/сайт/флаг.

## Рецепт 4: дан домен/URL

```bash
whois example.com
dig +short example.com TXT      # часто флаг в TXT!
curl -s https://example.com | grep -i flag
curl -s https://example.com/robots.txt
curl -s "http://web.archive.org/cdx/search/cdx?url=example.com*&output=text"
```

Флаг часто в `TXT`-записи, в `robots.txt`, в HTML-комментарии или в архивном снимке.

## Рецепт 5: даны координаты/место

```bash
# координаты → Google Maps / OSM / Bing
# найти ближайший объект, вывеску, адрес
# Overpass API: что рядом?
curl -s "https://overpass-api.de/api/interpreter?data=[out:json];node(around:50,LAT,LON);out;"
```

Флаг — в названии ближайшего заведения, в адресе или в комментарии на карте.

## Рецепт 6: дан аудио/видео

```bash
exiftool file.mp4
ffprobe file.mp3
# транскрипция
whisper file.mp3 --model base
# спектрограмма (скрытый текст в спектре)
sox file.wav -n spectrogram -o spec.png
```

Классика: сообщение в спектрограмме, флаг в субтитрах, в ID3-тегах.

## Рецепт 7: дана строка/хеш/ID

- **md5/sha** → искать в `crackstation`, `hashes.org`.
- **base64** → декодировать.
- **координаты** → карты.
- **номер телефона** → `phoneinfoga`.
- **UUID/ID** → искать в поиске.
- **фотошоп-строка** → определить редактор.

```bash
echo 'aGVsbG8=' | base64 -d
phoneinfoga scan -n "+1234567890"
```

## Разобранный пример: задача «дано фото»

Ввод: `challenge.jpg`.

Шаг 1 — метаданные:

```bash
exiftool challenge.jpg
# GPS Position: 55 deg 45' 21.00" N, 37 deg 37' 4.00" E
# Comment: ctf{...}  ← нет, тут не так
```

Метаданные дали GPS. Шаг 2 — координаты в карты:

```
55.7558, 37.6173 → Москва, Красная площадь
```

Шаг 3 — что рядом? Overpass:

```bash
curl -s "https://overpass-api.de/api/interpreter?data=[out:json];node(around:100,55.7558,37.6173)[name];out;" \
  | python3 -m json.tool | grep -i name
```

Ближайший объект с именем, содержащим часть флага. Или в Google Maps-отзыве. Флаг собран.

## Таблица: ввод → инструмент

| Ввод | Первый инструмент |
|------|-------------------|
| Фото | `exiftool`, reverse image |
| Ник | `sherlock`/`maigret` |
| Email | `holehe`, Gravatar |
| Домен | `dig TXT`, `whois`, Wayback |
| Координаты | Google Maps, Overpass |
| Аудио | `exiftool`, `whisper` |
| Хеш | CrackStation |
| Строка | `base64`, поисковик |

## Стратегия и тайм-менеджмент

- **Читайте подсказки.** Описание задачи часто намекает на инструмент.
- **Проверяйте метаданные первым делом.** Это самый частый источник флага.
- **Не игнорируйте «мелочи».** Дата в EXIF, автор, комментарий, эмодзи.
- **Застряли >10 мин — смените рецепт.** OSINT требует pivot.
- **Проверяйте формат флага.** `ctf{...}`, `flag{...}` — подтверждает находку.
- **Ведите цепочку.** Каждый найденный идентификатор — новый вход.

## Ошибки и подводные камни

- **Не проверить метаданные.** Терять очевидный флаг.
- **Искать только текстом.** OSINT бывает про фото, звук, координаты.
- **Игнорировать архивы.** Удалённое часто есть в Wayback.
- **Забывать про TXT-записи.** Классическое место флага.
- **Не pivot-ить.** Один идентификатор почти всегда ведёт к следующему.
- **Переусложнять.** Простые задачи решаются `exiftool` и `strings`.

## Что дальше / решение

CTF-рецепты — тренировочная площадка OSINT. Дальше: **AI-assisted** (`osint-ai-assisted`) для ускорения разбора, **верификация** (`osint-verification`) для проверки находок, **отчётность** (`osint-reporting`) для оформления writeup. Итог: научившись классифицировать ввод и применять рецепт, вы решаете OSINT-задачи быстро и системно.

## Рецепт 8: дан документ (PDF/Office)

```bash
# метаданные
exiftool document.pdf
pdfinfo document.pdf
# текст и скрытые слои
pdftotext document.pdf -
pdfimages -list document.pdf
# скрытые объекты
binwalk document.pdf
```

Часто флаг: в авторе/продюсере PDF, в скрытом слое, в прикреплённом файле (`pdfdetach -list`).

## Рецепт 9: дана соцсеть/пост

- **Twitter/X:** расширенный поиск (`from:`, `since:`, `until:`), архивы.
- **Instagram:** геотеги, сторис (сторонние viewer'ы).
- **Telegram:** `tgstat`, поиск по каналам.
- **VK:** открытые профили, «стена», фото.

Проверяйте описания профиля и закреплённые посты — там часто прячут флаг.

## Рецепт 10: дан архив/файл

```bash
# определить тип
file challenge.bin
binwalk challenge.bin
# извлечь вложенное
binwalk -e challenge.bin
# скрытые файлы
foremost -i challenge.bin -o out/
# строки
strings -n 8 challenge.bin | grep -iE 'flag|ctf'
```

Матryoshka-архивы (архив в архиве) — распаковывать рекурсивно.

## Стратегия работы в команде

- **Разделяйте вводы.** Каждый берёт свой тип (фото, домен, ник).
- **Ведите общую доску.** Складывайте найденные идентификаторы.
- **Публикуйте прогресс.** «Нашёл профиль X» → кто-то идёт дальше.
- **Держите инструменты готовыми.** `sherlock`, `exiftool`, `holehe` — предустановлены.
- **Тайм-бокс на задачу.** 15 минут на тип, затем pivot или смена задачи.

## Рецепт 11: дан геолокационный пазл

- **Overpass** — поиск объектов (см. `osint-geo-tools`).
- **SunCalc** — время по теням.
- **PeakVisor** — горы.
- **What3Words** — точные координаты.
- **Mapillary** — панорамы.

Алгоритм: язык вывесок → страна → уникальный объект → город → улица → координаты.

## Рецепт 12: дан блокчейн-адрес

```bash
# определить тип и активность
# BTC: blockchain.com/explorer, mempool.space
# ETH: etherscan.io/address/<addr>
curl -s "https://api.etherscan.io/api?module=account&action=txlist&address=$ADDR&apikey=$KEY"
```

Смотрим: транзакции, контрагенты, метки бирж. Иногда в memo/данных транзакции спрятан текст/флаг.

## Рецепт 13: дан исторический артефакт

- **Wayback Machine** — старая версия сайта.
- **archive.today** — снимки.
- **Common Crawl** — индекс страниц.
- **GDELT** — новости за годы.

```bash
curl -s "http://archive.org/wayback/available?url=example.com&timestamp=2015"
curl -s "https://index.commoncrawl.org/CC-MAIN-2024-10-index?url=example.com&output=json"
```

Флаг часто в удалённой странице или старом скриншоте.

## Универсальный чек-лист «что не забыть»

1. `exiftool` и `strings` по любому файлу.
2. `robots.txt`, `sitemap.xml`, `security.txt`.
3. `dig TXT` домена.
4. Reverse image любого фото.
5. Wayback по URL.
6. Gravatar по email.
7. `sherlock` по нику.
8. Проверить формат флага.

## Рецепт 14: дан ник + фото (составная задача)

Составные задачи комбинируют рецепты. Порядок:
1. `exiftool` по фото → геолокация/автор.
2. `sherlock`/`maigret` по нику → аккаунты.
3. Пересечение: аккаунт, привязанный к найденному месту.
4. Углубление в найденный аккаунт → флаг.

Такие задачи решаются «цепочкой»: каждый шаг даёт вход для следующего. Ведите записи, чтобы не потерять нить.

## Инструменты «швейцарский нож»

Держите под рукой набор, покрывающий большинство задач:
- **`exiftool`** — метаданные любого файла.
- **`binwalk`** — поиск вложенных данных.
- **`strings`** — текст в бинарях.
- **`sherlock`/`maigret`** — username.
- **`holehe`** — email.
- **`phoneinfoga`** — телефон.
- **`dig`/`whois`** — домен.
- **`ffmpeg`/`sox`/`whisper`** — медиа.
- **`zsteg`/`stegsolve`** — стеганография.

Установите их заранее (`pipx install`, `apt install`) — в разгар CTF время на установку теряется. Большинство задач решается комбинацией 2-3 инструментов из этого списка.
