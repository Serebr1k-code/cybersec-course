## Вопрос, с которого всё начинается

Ты на CTF, в категории OSINT. Задача короткая: «дано фото, найди флаг». Ты открываешь картинку, смотришь на неё — обычная улица, вывески на непонятном языке. С чего вообще начать? В реальной разведке у тебя были бы часы; здесь — минуты.

Помогает то, что OSINT-задачи типовые. Если научиться классифицировать ввод и применять к нему готовый рецепт, решение ускоряется в разы. Разберём один пример целиком.

## Наш пример: задача «дано фото»

Введём термины. **OSINT-задача** — головоломка вида «дан идентификатор — найди флаг». **Ввод** — то, что дано (фото, ник, домен, координата). **Флаг** — строка-ответ формата `ctf{...}` или `flag{...}`, подтверждающая решение.

Пройдём путь от файла `challenge.jpg` до флага.

## Шаг 1: метаданные — всегда первым делом

Самый частый источник флага — метаданные файла:

```bash
exiftool challenge.jpg
strings challenge.jpg | grep -iE 'flag|ctf|http|@'
```

Вывод `exiftool` (фрагмент):

```
GPS Position    : 55 deg 45' 21.00" N, 37 deg 37' 4.00" E
Comment         : shot on a trip
```

Флага в метаданных нет, но есть **GPS-координаты**. Это уже зацепка: значит, задача про геолокацию.

## Шаг 2: обратный поиск изображения

Прежде чем углубляться в геолокацию, проверим, не находится ли это фото в интернете — там может быть подпись с местом:

```text
Google Images / Yandex / TinEye / Bing reverse image search
```

Если фото нашлось — подпись или метаданные источника часто дают место. Если нет — работаем по объектам на снимке.

## Шаг 3: читаем объекты на фото

Геолокация «вручную» — по признакам:

- **Язык и шрифт вывесок** → страна/регион.
- **Номера автомобилей** → страна.
- **Архитектура, дорожные знаки, разметка.**
- **Тени** → время суток и широта (инструмент SunCalc).
- **Растительность и климат.**

Здесь фото подсказало Россию (кириллица на вывесках), а координаты в EXIF это подтвердили.

## Шаг 4: координаты на карту

Ставим координаты на карту:

```text
55.7558, 37.6173 → Москва, Красная площадь
```

Дальше ищем **уникальный объект** рядом — тот, что виден на фото. Для этого есть Overpass API:

```bash
curl -s "https://overpass-api.de/api/interpreter?data=[out:json];node(around:100,55.7558,37.6173)[name];out;" \
  | python3 -m json.tool | grep -i name
```

Вывод (фрагмент):

```
"name": "Памятник Минину и Пожарскому"
```

## Шаг 5: собираем флаг

Ближайший объект с именем, содержащим часть флага, — типичная развязка. Иногда флаг прямо в названии заведения, иногда в отзыве на Google Maps, иногда в комментарии на карте. Мы собрали `ctf{minin_i_pozharsky}` и проверили формат.

## Шаг 6: другие типы ввода — быстрые рецепты

Фото — лишь один тип. Вот остальные:

**Дан ник/username:**

```bash
sherlock targetuser
maigret targetuser --html
```

Дальше — по найденным профилям: bio, ссылки, репозитории.

**Дан email:**

```bash
holehe --only-used target@example.com
echo -n target@example.com | md5sum   # Gravatar по md5(email)
```

Gravatar-профиль по md5 — классика CTF: там может быть имя, сайт или флаг.

**Дан домен/URL:**

```bash
dig +short example.com TXT      # флаг часто в TXT
curl -s https://example.com/robots.txt
curl -s "http://web.archive.org/cdx/search/cdx?url=example.com*&output=text"
```

**Дан документ (PDF/Office):**

```bash
exiftool document.pdf
pdftotext document.pdf -
pdfdetach -list document.pdf   # прикреплённые файлы
```

**Дан архив/файл:**

```bash
file challenge.bin
binwalk -e challenge.bin       # извлечь вложенное
strings -n 8 challenge.bin | grep -iE 'flag|ctf'
```

**Даны координаты:**

```bash
curl -s "https://overpass-api.de/api/interpreter?data=[out:json];node(around:50,LAT,LON);out;"
```

**Дано аудио/видео:**

```bash
exiftool file.mp4
whisper file.mp3 --model base       # транскрипция
sox file.wav -n spectrogram -o spec.png   # скрытый текст в спектре
```

## Шаг 7: держим стратегию

- **Читай подсказки.** Описание задачи часто намекает на инструмент.
- **Метаданные — первым делом.** Самый частый источник флага.
- **Не игнорируй «мелочи».** Дата, автор, комментарий, эмодзи.
- **Застрял >10 минут — смени рецепт.** OSINT требует pivot.
- **Проверяй формат флага.** `ctf{...}` подтверждает находку.
- **Веди цепочку.** Каждый идентификатор — новый вход.

## Шаг 8: универсальный чек-лист

1. `exiftool` и `strings` по любому файлу.
2. `robots.txt`, `sitemap.xml`, `security.txt`.
3. `dig TXT` домена.
4. Reverse image любого фото.
5. Wayback по URL.
6. Gravatar по email.
7. `sherlock` по нику.
8. Проверить формат флага.

## Шаг 9: работа в команде

На командном CTF помогает разделение:

- **Разделяйте вводы.** Каждый берёт свой тип — фото, домен, ник.
- **Ведите общую доску.** Складывайте найденные идентификаторы.
- **Публикуйте прогресс.** «Нашёл профиль X» — кто-то идёт дальше.
- **Тайм-бокс.** 15 минут на тип, затем pivot или смена задачи.

Составные задачи (ник плюс фото) решаются цепочкой: `exiftool` даёт геолокацию, `sherlock` — аккаунты, пересечение ведёт к флагу.

## Что мы теперь знаем

- OSINT-задача = ввод + ограничения + цель; флаг обычно в метаданных, профиле, координатах или архиве.
- Классифицируй ввод и применяй готовый рецепт.
- `exiftool` — первый инструмент почти для любого файла.
- Каждый найденный идентификатор становится новым входом (pivot).
- Застрял — меняй рецепт, а не копай глубже вслепую.

## Частые ошибки

- **Не проверить метаданные.** Теряешь очевидный флаг.
- **Искать только текстом.** OSINT бывает про фото, звук, координаты.
- **Игнорировать архивы.** Удалённое часто есть в Wayback.
- **Забывать про TXT-записи.** Классическое место флага.
- **Переусложнять.** Простые задачи решаются `exiftool` и `strings`.

## На что смотреть дальше

CTF-рецепты — тренировочная площадка: навыки pivot здесь отрабатываются безопасно и быстро. Дальше разберём **bug bounty workflow** — как та же дисциплина разведки переносится в реальную программу. А пока главное запомни: классифицируй ввод и применяй рецепт — это решает большинство задач.

## Шаг 10: типовые ловушки и как их обойти

CTF-задачи на OSINT специально ломают твой первый рефлекс. Разберём четыре ловушки:

- **EXIF вычищен.** Автор задачи удалил метаданные. Не сдавайся: смотри визуальные зацепки — вывески, номерные знаки, язык, погоду, тень. Они ведут к месту так же надёжно.
- **Зеркальное/перевёрнутое фото.** Обратный поиск по картинке может не находить исходник. Попробуй отзеркалить и искать снова — иногда это разные копии.
- **Поддельные координаты.** GPS в EXIF бывает сдвинут намеренно. Проверяй: если координаты ведут в океан или в пустое поле, а на фото — город, верь картинке.
- **Несколько кандидатов.** Одно фото подходит под десять мест. Сужай по деталям: дом с номером, конкретная вывеска, редкая архитектура.

Принцип: **метаданные — это быстрый путь, но не единственный**. Если он закрыт — переключайся на визуальный анализ.

## Справочник: инструмент под тип ввода

| Ввод | Первый шаг | Инструмент |
|---|---|---|
| Фото | метаданные | `exiftool` |
| Фото без EXIF | обратный поиск | Google Lens, Yandex, TinEye |
| Координаты в тексте | карта | OpenStreetMap, Google Maps |
| Скриншот | найти оригинал | обратный поиск + кроп |
| Документ | метаданные и вложения | `exiftool`, `pdfinfo` |
| Аудио | фон, речь | Shazam, транскрипция |
| Ник | кросс-платформенный поиск | WhatsMyName, Sherlock |

Держи таблицу под рукой: она экономит первые пять минут на каждой задаче.

## Если не сработало

- **Обратный поиск пуст.** Загружай не всё фото, а **вырезанный объект** (здание, вывеску) — поиск по детали часто точнее.
- **Слишком много результатов.** Добавь в запрос город, язык или год. Сужение по контексту важнее, чем по картинке.
- **Фото выглядит «нигде».** Ищи не место, а **время**: по погоде, одежде, рекламе можно датировать снимок и связать с событием.
- **Задача про человека.** Начни с ника и email, а не с имени: они уникальнее.
- **Тупик.** Вернись к условию задачи — в CTF подсказка часто спрятана в тексте, названии файла или хэше.

## Мини-разбор: три задачи подряд

Чтобы рецепты сложились в навык, прогоним три типовые задачи.

**Задача 1 — фото улицы.** Первым делом `exiftool` (вдруг есть GPS). Если метаданных нет — ищем вывески и язык, затем обратный поиск по вырезанному зданию. Ответ — координаты, которые часто и есть флаг.

**Задача 2 — ник.** Один и тот же ник прогоняем через кросс-платформенный поиск (WhatsMyName, Sherlock). Находим профиль с геотегом — он ведёт к городу.

**Задача 3 — скриншот чата.** Ищем не автора, а контекст: часовой пояс в метках времени, язык интерфейса, названия каналов. Часто флаг прячется в деталях интерфейса.

Общий вывод: **начинай с самого дешёвого источника** (метаданные), а дальше двигайся к визуальному анализу и корреляции. И держи тайминг: если задача не поддаётся больше десяти минут, переключайся на следующую и вернись позже со свежим взглядом.

## Куда дальше

Мы прошли типовую OSINT-задачу и собрали набор рецептов под каждый ввод. В следующем уроке — **bug bounty workflow**: как те же навыки работают в реальной программе, с правилами scope и приоритизацией. А пока главное запомни: в CTF выигрывает не тот, кто знает больше инструментов, а тот, кто быстрее классифицирует ввод.

## Где пригодится

- **CTF (OSINT):** прямое применение — решение задач.
- **Обучение:** тренировка навыков разведки в безопасной среде.
- **Пентест:** отработка методологии pivot.
- **Интервью:** OSINT-задачи часто дают на собеседованиях в ИБ.
- **Хакатоны:** быстрый разбор открытых данных под дедлайн.
