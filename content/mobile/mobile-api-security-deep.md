Мобильное приложение — это тонкий клиент к толстому API. Большинство реальных критичных находок живёт не в APK, а на стыке клиента и сервера: как API доверяет полям, которые присылает клиент, как приложения взаимодействуют друг с другом, как устроены push-каналы и где данные утекают из устройства. Этот модуль — про эту границу доверия.

## Что покрывает модуль

- **mobile-mass-assignment** — массовое присваивание и подмена полей: клиент присылает `is_admin`, `role`, `balance` и сервер их принимает.
- **mobile-app2app** — взаимодействие приложений: intent spoofing, Custom Tabs, OAuth-редиректы, доверие к соседнему приложению.
- **mobile-push-security** — безопасность push: FCM/APNs, доверие к payload, подмена уведомлений, утечка токена.
- **mobile-data-leakage** — утечки на устройстве: логи, клавиатурный кэш, буфер обмена, скриншоты, дампы памяти.

## Почему такой порядок

Сначала API-слой: массовое присваивание — самая частая серверная ошибка мобильных бэкендов. Затем app-to-app и push — это тоже «каналы доверия», но на уровне ОС. Завершает модуль утечка данных: даже при корректном API приложение может светить чувствительные данные в логах и кэше.

## Что вы будете уметь

- Искать mass assignment и подмену ролей в API мобильного приложения.
- Моделировать app-to-app атаки и красть OAuth-код через редирект.
- Проверять безопасность push-канала и подделку уведомлений.
- Находить утечки данных в логах, кэше и буфере обмена.
