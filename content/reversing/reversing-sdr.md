## Вопрос, с которого всё начинается

У тебя есть устройство, которое управляется по радио: брелок, датчик, пульт.
Протокол неизвестен, документации нет, а разобрать его надо. Как реверсить
**радиоканал**? Тут помогает **SDR** (Software Defined Radio — программно
определяемое радио): приёмник, который отдаёт не звук, а сырые цифровые отсчёты
сигнала, а всю обработку ты делаешь в коде.

## Наш пример

Возьмём учебный сигнал: сообщение передаётся простейшей модуляцией, а приёмник
записал его в виде **IQ-отсчётов**. IQ — это пара чисел на каждый момент времени
(комплексное число): `I` — синфазная составляющая, `Q` — квадратурная. В коде это
одно комплексное число `I + jQ`.

Посмотрим, что у нас на входе и что получится после обработки:

```
$ python3 sdr.py
IQ samples: 9600  dtype: complex128
recovered: b'FLAG{sdr_rx}'
```

Мы получили сообщение `FLAG{sdr_rx}`. Разберём, как из «сырых» 9600 комплексных
отсчётов получилась строка.

## Шаг 1: как сигнал превращается в отсчёты

Радиочастотный сигнал физически — это колебание. SDR оцифровывает его: на
каждом шаге времени записывает пару `(I, Q)`. Скорость записи — **sample rate**
(в примере 48000 отсчётов в секунду). Комплексная запись удобна тем, что хранит
и амплитуду, и фазу сигнала.

Ключевая мысль для реверса: **байты сообщения «размазаны» по отсчётам**. Чтобы
достать биты, нужно знать три вещи:

1. **Модуляцию** — как биты кодируются в сигнал (амплитудой, частотой, фазой).
2. **Скорость передачи** — сколько отсчётов приходится на один бит (в примере
   `sps = 100` — samples per symbol).
3. **Синхронизацию** — где начинается первый бит.

## Шаг 2: демодуляция — амплитуда и порог

В нашем примере использована **амплитудная манипуляция** (ASK/OOK): «есть
сигнал» — единица, «нет» — ноль. Значит, достаточно взять **амплитуду** каждого
отсчёта (`|IQ|`) и усреднить по периоду символа:

```python
amp = np.abs(iq)                            # амплитуда
sym = amp.reshape(-1, sps).mean(axis=1)     # интегратор на длину символа
thr = (sym.max() + sym.min()) / 2           # порог посередине
rx = (sym > thr).astype(np.uint8)           # выше порога -> 1
```

Приём «усреднить по длине символа» называется **integrate-and-dump**: мы
накапливаем энергию за период бита и принимаем решение один раз. Порог берут
посередине между максимумом и минимумом — так шум меньше влияет.

## Шаг 3: собираем биты в байты

Получили массив нулей и единиц. Собираем их в байты (порядок битов — **MSB
first**, старший бит первый):

```python
out = np.packbits(rx).tobytes()
print("recovered:", out)
```

```
recovered: b'FLAG{sdr_rx}'
```

Если бы порядок битов был неверный, получилась бы «каша» — при реверсе это
первое, что перепроверяют. Также проверяют, нет ли **преамбулы** (последовательности
для синхронизации) и **CRC** в конце кадра.

## Шаг 4: не только амплитуда — частота и фаза

Амплитудная манипуляция — самый простой случай. На практике встречаются:

- **FSK** (частотная): ноль и единица — разные частоты. Демодулируют, отслеживая
  мгновенную частоту (производную фазы).
- **PSK** (фазовая): информация в фазе. Нужна синхронизация несущей.
- **Сложные схемы** (QAM, OFDM) — в Wi-Fi, LTE, цифровом ТВ.

Для реверса протокола часто достаточно понять **структуру кадра**: сколько бит
на команду, есть ли адрес устройства, контрольная сумма. Это делают, сравнивая
несколько записей: нажали кнопку — один бит изменился; нажали другую — другой.

## Шаг 5: рабочий процесс реверса радио

Порядок действий:

1. **Записать сигнал.** SDR-приёмник (RTL-SDR, HackRF, USRP) пишет IQ в файл
   (`gqrx`, `rtl_sdr`, `GNU Radio`).
2. **Найти несущую.** Посмотреть спектр (FFT) — увидеть, на какой частоте
   сигнал и какой ширины.
3. **Определить модуляцию.** По виду сигнала: медленные «включения» — ASK,
   частые колебания — FSK.
4. **Демодулировать.** Своим скриптом или готовым блоком GNU Radio.
5. **Разобрать кадр.** Найти преамбулу, синхронизацию, поля, CRC.
6. **Воспроизвести (replay).** Записать нужный кадр и передать его снова —
   классическая атака на брелоки и датчики.

## Шаг 6: replay и его защита

**Replay** — повтор перехваченного кадра. Работает там, где нет защиты от
повтора. Производители добавляют:

- **счётчик (rolling code)** — каждый кадр новый (как в автосигнализациях);
- **проверку времени/сессии**;
- **шифрование и аутентификацию кадра**.

Для обхода rolling code существует перехват с подавлением (jamming) и
«выкачивание» следующего кода, но это уже на грани атак на конкретные системы.

## Шаг 7: почему это «реверс прошивок»

Часто протокол известен не полностью, и его приходится восстанавливать вместе с
**прошивкой устройства**: находишь в бинарнике таблицы частот, константы
синхронизации, генератор CRC. Поэтому SDR-реверс идёт рука об руку с реверсом
прошивок (предыдущие уроки): код подсказывает формат кадра, а эфир подтверждает.

## Шаг 8: спектр и FFT

Прежде чем демодулировать, сигнал надо **найти** в эфире. Для этого считают
**FFT** (быстрое преобразование Фурье) — оно показывает, какие частоты есть в
сигнале. На спектре видно «горб» вокруг несущей: его центр — частота передачи,
ширина — полоса. По ширине полосы и характеру горба грубо оценивают модуляцию:
узкий мигающий горб — ASK, два «лепестка» — FSK.

Готовые программы (`gqrx`, `SDR#`, `GNU Radio Companion`) рисуют спектр в
реальном времени. В `GNU Radio` из блоков собирают цепочку: источник →
фильтр → демодулятор → декодер → вывод. Это визуальное программирование
обработки сигнала, и те же блоки есть в Python-скриптах.

## Шаг 9: шум и как с ним жить

Реальный эфир всегда с **шумом** (в примере мы добавили гауссов шум к сигналу).
Из-за шума амплитуда «плавает», и порог нельзя брать жёстко. Приёмы:

- **усреднение** по периоду символа (integrate-and-dump) — шум гасится;
- **гистерезис** — разные пороги для перехода 0→1 и 1→0;
- **фильтрация** (полосовой фильтр вокруг несущей) — отсекает лишние частоты;
- **синхронизация по преамбуле** — найти известный паттерн и выровняться.

Если биты «плывут» (сдвиг на один-два отсчёта), ищи преамбулу и подбирай
смещение — это называется **timing recovery**.

## Частые вопросы

**Получилась «каша» вместо текста.** Скорее всего, неверный порядок битов
(MSB/LSB), неверный sps или отсутствует выравнивание по преамбуле.

**Сигнал есть, но биты не читаются.** Проверь модуляцию: возможно, это FSK, а
не ASK, — тогда смотреть надо на частоту, а не амплитуду.

**Как узнать длину кадра?** Сравни несколько записей: неизменные биты — адрес и
преамбула, меняющиеся — данные. CRC обычно в конце.

## Что мы теперь знаем

- SDR отдаёт **IQ-отсчёты** — пары `(I, Q)` комплексных чисел во времени.
- Чтобы достать биты, нужно знать модуляцию, скорость передачи и синхронизацию.
- В нашем примере ASK-сигнал демодулировали через амплитуду, integrate-and-dump
  и порог, а биты собрали `packbits` — получили `FLAG{sdr_rx}`.
- Бывают FSK/PSK/QAM; структуру кадра восстанавливают сравнением записей.
- **Replay** — базовая атака; защита от неё — rolling code, шифрование,
  аутентификация.

## FSK и PSK на практике

Амплитудную манипуляцию мы разобрали; на реальных устройствах чаще встречается **FSK** (частотная) — её и посмотрим. Мгновенную частоту получают из производной фазы: `np.angle(iq)` даёт фазу каждого отсчёта, а её приращение — частоту.

```python
import numpy as np
phase = np.unwrap(np.angle(iq))
freq  = np.diff(phase) / (2*np.pi)          # нормированная мгновенная частота
sym   = freq.reshape(-1, sps).mean(axis=1)  # интегратор на символ
thr   = (sym.max() + sym.min()) / 2
bits  = (sym > thr).astype(np.uint8)        # частота выше порога -> 1
```

Для **PSK** ноль и единица различаются фазой несущей. Здесь нужна синхронизация несущей: без неё фаза «вращается», и порог по амплитуде не работает. Простой приём — считать разность фаз между соседними символами (дифференциальная PSK, DPSK): тогда постоянный сдвиг несущей сокращается.

Полезные проверки, когда биты «плывут»:

- **преамбула** — известная последовательность (часто `1010…` или `0xAA`), по ней выравнивают начало кадра;
- **DC-смещение** — вычесть среднее до демодуляции;
- **передискретизация** — привести `sps` к целому числу отсчётов.

## Как выбрать метод по наблюдению

| Что видно в сигнале | Вероятная модуляция | Как демодулировать |
|---|---|---|
| Медленные «включения/выключения» амплитуды | ASK/OOK | `abs(IQ)` + порог |
| Два устойчивых уровня частоты | 2-FSK | производная фазы + порог |
| Постоянная амплитуда, скачки фазы | PSK | фазовый детектор, DPSK |
| Много уровней амплитуды | ASK (M-ary) | несколько порогов |
| Широкий шумоподобный спектр | DSSS/OFDM | корреляция с кодом / FFT |
| «Прыгающий» горб по частоте | FHSS | следить за несущей во времени |

Начинать всегда стоит с **FFT**: центр горба даёт несущую, ширина — грубую оценку скорости и модуляции. Дальше гипотезу проверяют сравнением нескольких записей — как и с прошивкой: код подсказывает формат, эфир подтверждает.
