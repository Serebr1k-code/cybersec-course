Этот модуль — промежуточный этап ветки «Основы облачной безопасности: модель ответственности и поверхность атаки». Он собирает несколько последовательных уроков в единый учебный шаг и объясняет, зачем и в каком порядке их проходить. Начните с первого подмодуля и двигайтесь по списку.

## Что покрывает модуль

1. **Модуль: AWS глубоко** (`cloud-aws-deep`) — Cognito, SSM, ECS/Fargate и VPC: сервисы, которые чаще всего остаются вне поля зрения.
2. **Модуль: GCP глубоко** (`cloud-gcp-deep`) — metadata-сервис, Cloud Functions/Run, Workload Identity Federation и org policies.
3. **Модуль: Azure глубоко** (`cloud-azure-deep`) — Storage SAS, App Service, Key Vault и ARM-развёртывания.
4. **Модуль: облачная сеть и разведка** (`cloud-network-deep`) — security groups/NACL, API Gateway/WAF и методика разведки.

## Почему такой порядок

Базовый модуль (`cloud-foundations-providers`) дал вам словарь и поверхность атаки. Здесь мы идём вглубь по каждому провайдеру отдельно: сначала AWS (самый частый в пентесте), затем GCP, затем Azure. Сетевой подмодуль стоит последним, потому что он сквозной — применим ко всем трём облакам и опирается на сервисы, разобранные выше.

## Как проходить

- Не пытайтесь пройти все четыре подмодуля за один заход: каждый — это 4 урока по 40–55 минут.
- Держите под рукой CLI провайдера (`aws`, `gcloud`, `az`) и инструменты разведки из последнего подмодуля.
- После каждого подмодуля пробуйте воспроизвести хотя бы одну команду из разобранного примера на тестовом аккаунте или в CTF-стенде.

## Чему вы научитесь

- Находить и эксплуатировать слабые места сервисов AWS/GCP/Azure за пределами «классических» S3 и metadata.
- Читать модели идентичности трёх провайдеров и превращать их в цепочки эскалации.
- Оценивать сетевую изоляцию облака и обходить её.
- Вести методичную разведку облачного аккаунта, не полагаясь на угадывание.

## Где пригодится

- **Пентест:** облачные аккаунты, где нужно выйти за пределы базовых проверок.
- **Bug bounty:** облачные программы с большим scope по сервисам.
- **Red team:** мульти-облачные среды и цепочки между провайдерами.
- **Сертификации:** AWS Security Specialty, GCP Professional Cloud Security Engineer, Azure AZ-500.
