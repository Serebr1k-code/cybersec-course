Этот подмодуль — часть этапа «Модуль: провайдеры глубоко». Он сквозной: применим к AWS, GCP и Azure. Здесь про сетевую изоляцию, публичные API и методику разведки, без которой остальные уроки превращаются в угадывание.

## Что покрывает подмодуль

1. **Облачные сети** (`cloud-network-security`) — security groups, NACL, firewall rules и как читать изоляцию.
2. **API Gateway и WAF** (`cloud-api-gateway`) — публичные эндпоинты, авторизация, обход WAF.
3. **Разведка облака** (`cloud-enum-methodology`) — cloudfox, enumerate-iam, pacu, ScoutSuite.

## Почему такой порядок

Сначала — модель сети: она объясняет, какие сервисы достижимы и почему. Затем — публичные входные точки (API Gateway/WAF), через которые чаще всего начинается атака. Завершает разведка: систематический сбор того, что вам разрешено, — топливо для всех последующих цепочек.

## Как проходить

- Сетевой урок полезно проходить, держа рядом вывод `describe-security-groups` из реального аккаунта.
- В уроке про WAF обращайте внимание на разницу между «заблокировано правилом» и «пропущено, но приложение отклонило».
- В разведке не гоняйтесь за всеми инструментами сразу: выберите один и доведите до результата.

## Чему вы научитесь

- Читать security groups/NACL и находить открытые из интернета сервисы.
- Оценивать авторизацию API Gateway и обходить слабые WAF-правила.
- Вести разведку облака по методике, а не наугад.
