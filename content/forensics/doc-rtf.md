## Вопрос, с которого всё начинается

Пришёл файл `invoice.rtf`. Это текст или что-то опасное? Формат выглядит как обычный
текст, но внутри может быть вложенный объект, который запускает код. Разберёмся.

## Наш пример: invoice.rtf

```
$ file invoice.rtf
invoice.rtf: Rich Text Format data, version 1
```

**RTF (Rich Text Format)** — текстовый формат с **управляющими словами**: командами,
которые начинаются с обратного слэша. Открывается почти везде, поэтому популярен в
фишинге.

## Шаг 1: читаем управляющие слова

Начало файла:

```
$ head -c 200 invoice.rtf
{\rtf1\ansi\deff0{\fonttbl{\f0 Arial;}}
\viewkind4\uc1 ...
```

`\rtf1` — версия, `\ansi` — кодировка, `\fonttbl` — таблица шрифтов. Всё это — команды
форматирования. Читаемый текст идёт рядом.

## Шаг 2: ищем вложенный объект

Ключевое слово — `\object`. Оно вставляет **OLE-объект**, то есть другой файл внутрь
документа:

```
$ grep -a -o '\\object[^}]*' invoice.rtf | head
\object\objemb{\*\objclass Package}\objw0\objh0 ...
```

`\objclass Package` означает вложенный пакет — часто это исполняемый файл или документ с
макросом. Извлечь объекты можно `rtfobj`:

```
$ rtfobj -s all invoice.rtf
Object 00000000: format 'Package' -> saved to object_00000000.bin
```

## Шаг 3: распознаём обфускацию

Атакующие прячут объект за мусором:

- **миллионы пробелов/слэшей** между командами;
- **hex-escape** (`\'41\'42`) для сокрытия строк;
- **разбиение** управляющего слова комментариями.

Признак — аномально большой размер при маленьком видимом тексте и «мусорные» вставки.
Инструменты (`rtfobj`, `olevba`) умеют это разбирать.

## Шаг 4: почему RTF опасен

RTF-документ может содержать:

- **OLE-объект** с исполняемым кодом;
- **эксплойт для уязвимости** в обработчике (исторически — Equation Editor);
- **ссылку** на внешний ресурс.

При этом выглядит он как обычный текстовый файл, который «можно открыть».

## Что мы теперь знаем

- RTF — текстовый формат с управляющими словами (`\...`).
- `\object` вставляет вложенный OLE-объект.
- Обфускация скрывает объект за мусором и hex-escape.
- RTF до сих пор используется в фишинге.
- Извлекать объекты помогает `rtfobj`.

Проверь себя.

```quiz
- question: Что такое управляющее слово в RTF?

    - 'имя файла'
    - 'пароль'

  explanation: 'Команды RTF начинаются с \\ и задают форматирование или вставку.'

  options:
    - '\\fonttbl'
    - '\\object'
    - '\\ansi'
    - '\\rtf1'
  answer: 1
  explanation: '\\object вставляет OLE-объект внутрь документа.'

  answer: 1
  explanation: 'Мусор и hex-escape скрывают вложенную нагрузку.'
```
