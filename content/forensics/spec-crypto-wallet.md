## Вопрос, с которого всё начинается

Пропали криптоактивы, или кошелёк — улика. Аппаратный кошелёк (Ledger/Trezor) хранит
приватные ключи. Извлечь их — задача со звёздочкой. Разберём устройство и подходы.

## Наш пример: аппаратный кошелёк

## Шаг 1: что внутри

Устройство: защищённый микроконтроллер (secure element), флеш, экран, кнопки. Ключи
хранятся в **защищённом чипе** и никогда не покидают его в открытом виде.

## Шаг 2: seed-фраза

Основа — **seed** (12/24 слова), из которого выводятся все ключи (BIP-39/BIP-32).
Кто знает seed — владеет средствами. Устройство лишь хранит его зашифрованным PIN-ом.

```
(на экране) Abandon Ability Able ...
```

Если seed записан на бумаге/фото — это самый быстрый путь (и самая частая утечка).

## Шаг 3: PIN и защита

PIN защищает устройство. После N неверных попыток — стирание:

```
Wrong PIN. Attempts remaining: 2
```

Secure element не даёт читать память напрямую — только через API устройства.

## Шаг 4: что реально извлекают

- **адреса и балансы** (публичные данные — из блокчейна);
- **историю транзакций** (из блокчейна);
- **метаданные устройства** (прошивка, серийник);
- **seed** — только если он сохранён вне устройства (бумага, фото, менеджер паролей).

## Шаг 5: подход

- проверь **блокчейн** — все транзакции публичны;
- ищи seed/резервные копии у владельца;
- анализируй компаньон-приложение (следы адресов);
- физический взлом secure element — крайне сложен и дорог.

## Что мы теперь знаем

- Ключи хранятся в защищённом чипе.
- Seed (BIP-39) — корень всех ключей.
- PIN защищает; после попыток — стирание.
- Публичные данные берут из блокчейна.
- Seed ищут вне устройства (бумага/фото).

## Если не сработало

- Нет seed? Восстановление невозможно (это и есть защита).
- Нужны транзакции? Работай с блокчейном и приложением.
- Взлом чипа? Только специализированные лаборатории.
