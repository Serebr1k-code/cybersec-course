## Вопрос, с которого всё начинается

Нужно быстро разобрать образ: найти файлы по типу, восстановить удалённое, отфильтровать
по времени. **X-Ways Forensics** — лёгкий, но мощный инструмент для этого. Разберём
рабочий процесс.

## Наш пример: образ диска

## Шаг 1: добавляем образ

X-Ways открывает образ как диск и строит дерево:

- разделы;
- файловые системы;
- каталоги и файлы.

Он **не меняет** образ: все операции — read-only поверх снимка.

## Шаг 2: поиск и фильтры

Ключевые возможности:

- **фильтр по типу** (показать только изображения/документы);
- **фильтр по времени** (в окне инцидента);
- **фильтр по размеру**;
- **поиск по сигнатуре** (карвинг).

Фильтры резко сокращают объём: из миллиона файлов остаются десятки.

## Шаг 3: восстановление удалённого

X-Ways умеет:

- читать MFT/`$LogFile` и показывать удалённые записи;
- восстанавливать по имени (если запись цела);
- карвить по сигнатурам (если записи нет).

Восстановленные файлы помечаются как «deleted».

## Шаг 4: реестр и артефакты

Инструмент парсит:

- реестр (hives);
- `$MFT`, `$UsnJrnl`;
- prefetch, LNK;
- почту, браузеры.

Это позволяет работать без сторонних парсеров.

## Шаг 5: отчёт

X-Ways формирует отчёты с найденными файлами и метаданными — готово для сдачи.

## Что мы теперь знаем

- X-Ways открывает образ read-only.
- Фильтры по типу/времени/размеру сокращают объём.
- Восстанавливает удалённое через MFT и карвинг.
- Парсит реестр и системные артефакты.
- Формирует отчёты.

## Если не сработало

- ФС не распознана? Укажи раздел вручную.
- Нужен полный карвинг? Включи соответствующий режим.
- Нужна скорость? Ограничь фильтрами.
