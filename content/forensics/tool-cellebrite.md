## Вопрос, с которого всё начинается

Нужно снять данные с телефона — сообщения, геолокацию, приложения. **Cellebrite** —
стандарт индустрии для мобильной форензики. Разберём уровни извлечения и подход.

## Наш пример: смартфон

## Шаг 1: уровни извлечения

Cellebrite даёт несколько уровней:

- **логическое** — через ОС/API (что доступно приложению);
- **файловое** — доступ к ФС (jailbreak/root или уязвимость);
- **физическое** — полный образ памяти;
- **full file system** — современный «глубокий» уровень.

Чем глубже — тем больше данных и сложнее получить.

## Шаг 2: что извлекается

- сообщения (SMS, WhatsApp, Signal);
- контакты и звонки;
- геолокация;
- фото/видео и метаданные;
- история браузера;
- данные приложений.

Cellebrite **парсит приложения** и показывает их данные в удобном виде.

## Шаг 3: рабочий процесс

1. подключить устройство (или образ);
2. выбрать уровень извлечения;
3. дождаться обработки;
4. просмотреть артефакты в Reader;
5. экспортировать отчёт.

## Шаг 4: ограничения

- шифрование современных телефонов;
- блокировка/активация;
- версия ОС может быть не поддержана;
- юридические требования.

Часть моделей/версий «не поддерживается» — это реальное ограничение.

## Шаг 5: альтернативы

Для открытых задач используют `ALEAPP`/`iLEAPP` (парсинг извлечений), `libimobiledevice`
(iOS-бэкапы), `adb` (Android). Cellebrite выигрывает в автоматизации и глубине.

## Что мы теперь знаем

- Cellebrite — стандарт мобильной форензики.
- Уровни: логическое, файловое, физическое, full FS.
- Парсит приложения и их данные.
- Ограничен шифрованием и версией ОС.
- Открытые альтернативы — ALEAPP/iLEAPP.

## Если не сработало

- Устройство не поддержано? Пробуй логический уровень или бэкап.
- Нужен разбор извлечения? Используй ALEAPP/iLEAPP.
- Нет Cellebrite? Работай через adb/бэкапы.

## Практический разбор: извлечение и разбор

Разберём типовой цикл Cellebrite. Начинаем с логического извлечения, когда
устройство разблокировано и известно:

```bash
$ # в UFED: выбрать устройство, уровень "Logical", запустить
# результат — папка с дампом
$ ls extraction/
2026-01-14_report.html
2026-01-14_files/
```

Извлечение уровня «Full File System» даёт доступ к базам приложений, включая
удалённые записи из WAL-журналов SQLite:

```bash
$ ls extraction/files/data/com.whatsapp/databases/
msgstore.db  msgstore.db-wal
$ sqlite3 msgstore.db "SELECT key_remote_jid, timestamp FROM messages ORDER BY timestamp DESC LIMIT 3;"
```

Чтение WAL позволяет увидеть недавно удалённые сообщения — важный плюс глубоких
уровней. Дальше артефакты просматривают в UFED Reader, который раскладывает их
по приложениям.

## Уровни извлечения детально

| Уровень | Доступ | Данные | Сложность |
|---|---|---|---|
| Логический | OS/API | контакты, медиа, часть приложений | низкая |
| Файловая система | корень ФС | базы, кэш, логи | средняя |
| Full File System | ключи ФС | приложения целиком | высокая |
| Физический | сырая память | всё, включая удалённое | очень высокая |
| Cloud | API сервиса | бэкапы, переписка | зависит от сервиса |

Чем глубже уровень, тем больше данных, но и тем сильнее ограничения по
поддержке модели и версии ОС.

## Открытые альтернативы: ALEAPP и iLEAPP

Когда Cellebrite недоступен, извлечение разбирают открытыми инструментами.
ALEAPP (Android) и iLEAPP (iOS) парсят файлы дампа и строят HTML-отчёт:

```bash
$ python3 aleapp.py -t fs -i extraction/ -o aleapp_out/
$ ls aleapp_out/
index.html  artifacts/
```

Отчёт группирует артефакты по приложениям: сообщения, звонки, геолокация,
история браузера, установленные приложения. Дополнительно используют
`MVT` (Mobile Verification Toolkit) для поиска индикаторов шпионского ПО:

```bash
$ mvt-android check-androidqf --iocs stalkerware.json extraction/
```

## Что парсится и как

- **SQLite-базы.** Основной источник; читаются `sqlite3` или парсерами
  приложений.
- **WAL/SHM.** Журналы содержат недавние (в т.ч. удалённые) записи.
- **Кэш и логи.** Временные файлы, `logcat`, plist.
- **Плисты (iOS).** `Info.plist`, `com.apple.*` — настройки и история.
- **Keychain (iOS).** Токены и пароли (при наличии ключей).

Открытые инструменты выигрывают в прозрачности и скриптуемости, но требуют
ручного сопоставления с версией ОС.

## Ограничения

- **Формат извлечения.** Не все коммерческие форматы читаются открытыми
  парсерами; иногда нужен экспорт в «файловую систему».
- **Версии приложений.** Схемы БД меняются; парсер может ошибаться.
- **Шифрование.** Без ключей ФС данные недоступны.

## Чек-лист мобильной форензики

1. Зафиксируй модель, версию ОС и IMEI/серийный номер.
2. Выбери минимально достаточный уровень извлечения.
3. Проверь поддержку модели/версии инструментом.
4. Сделай извлечение, сохрани хэш результата.
5. Разбери артефакты (Cellebrite Reader / ALEAPP / iLEAPP).
6. Проверь WAL-журналы на удалённые записи.
7. Экспортируй отчёт с указанием источников.
8. Оформи цепочку сохранности.

## Ограничения метода

- **Шифрование.** Современные телефоны шифруют ФС; глубокое извлечение требует
  уязвимости или разблокировки.
- **Блокировка активации.** После сброса устройство может быть непригодно без
  аккаунта владельца.
- **Поддержка версий.** Новые ОС часто не поддержаны инструментом сразу.
- **Anti-forensics.** Root-детект, скрытые разделы, шифрованные контейнеры
  усложняют извлечение.

## Правовые аспекты

Извлечение данных с телефона — вмешательство в частную жизнь, поэтому требует
законного основания: согласия владельца, ордера или корпоративной политики.
Веди журнал: кто, когда и каким инструментом работал с устройством. Без
документированной цепочки сохранности даже полное извлечение теряет
доказательную силу.

## Практический разбор: анализ геолокации и коммуникаций

Мобильные артефакты богаты пространственно-временными данными. Извлекаем
геолокацию из системной базы (Android):

```bash
$ sqlite3 cache.cell "SELECT latitude, longitude, timestamp FROM cells ORDER BY timestamp DESC LIMIT 3;"
55.751244|37.618423|2026-01-14 03:19:58
```

Координаты и время связывают устройство с местом события. Аналогично разбирают
коммуникации — они дают социальный граф:

```bash
$ sqlite3 contacts.db "SELECT display_name FROM raw_contacts LIMIT 5;"
```

Переписка, звонки и контакты вместе показывают, с кем и когда владелец
общался. В глубоком извлечении доступны даже удалённые записи из WAL-журналов.

## Сравнение уровней извлечения

| Уровень | Удалённые данные | Полнота | Ограничение |
|---|---|---|---|
| Логический | почти нет | базовая | что отдаёт ОС |
| Файловая система | частично | высокая | нужен root |
| Full FS | да (WAL) | очень высокая | уязвимость/ключи |
| Физический | да | максимальная | поддержка модели |

Глубина извлечения напрямую определяет, увидишь ли ты удалённые сообщения и
историю локаций.

## Что записать в отчёт

- Модель, ОС, IMEI и хэш извлечения.
- Уровень извлечения и инструмент.
- Ключевые артефакты (сообщения, локации, контакты) с временем.
- Найденные удалённые записи (WAL).
- Ограничения: шифрование, поддержка версии, anti-forensics.

## Частые заблуждения

- «Логического извлечения достаточно» — оно даёт лишь то, что отдаёт ОС, без
  удалённых данных.
- «Инструмент поддерживает любой телефон» — новые модели и ОС часто не
  поддержаны сразу.
- «Cellebrite незаменим» — ALEAPP/iLEAPP и MVT покрывают многое открытыми
  средствами.
- «Данные приложений — это файлы» — чаще это SQLite-базы с журналами WAL.

## Связь с другими артефактами

- **Облачные бэкапы.** Дополняют локальные данные и переживают сброс устройства.
- **Сетевые логи.** Обращения к серверам приложений связывают аккаунт с
  устройством.
- **SIM и оператор.** Регистрация в сети даёт независимую геолокацию.
- **Персональный компьютер.** Синхронизированные данные (мессенджеры, фото)
  дублируют мобильные артефакты.

## Правовые аспекты

Мобильная форензика вторгается в частную жизнь, поэтому требует законного
основания. Веди журнал доступа к устройству, фиксируй уровень извлечения и
инструмент. Даже полное извлечение без документированной цепочки сохранности
теряет доказательную силу в суде.

## Практический разбор: построение таймлайна

Мобильные артефакты разрознены по базам, поэтому их сводят в единый таймлайн.
Соберём события из разных источников в один CSV:

```bash
$ sqlite3 msgstore.db "SELECT timestamp, 'whatsapp', key_remote_jid FROM messages;" >> tl.csv
$ sqlite3 calllog.db "SELECT date, 'call', number FROM calls;" >> tl.csv
$ sqlite3 cache.cell "SELECT timestamp, 'location', latitude||','||longitude FROM cells;" >> tl.csv
$ sort -n tl.csv | head
```

Отсортированный таймлайн показывает последовательность: кому звонили, где
находились, что писали. Наложение на карту даёт пространственно-временную
картину — где устройство было в ключевые моменты.

## Инструменты мобильной форензики

| Инструмент | Платформа | Назначение |
|---|---|---|
| Cellebrite UFED | обе | извлечение и парсинг |
| ALEAPP | Android | разбор дампа ФС |
| iLEAPP | iOS | разбор дампа/бэкапа |
| MVT | обе | индикаторы шпионского ПО |
| libimobiledevice | iOS | бэкапы |
| `adb` | Android | доступ и логи |
| `sqlite3` | обе | чтение баз напрямую |

Комбинация коммерческого извлечения и открытого разбора даёт и глубину, и
прозрачность.

## Что записать в отчёт

- Модель, ОС и хэш извлечения.
- Уровень и инструмент извлечения.
- Таймлайн ключевых событий с источниками.
- Найденные удалённые записи и их происхождение (WAL).
- Ограничения: шифрование, поддержка версий, anti-forensics.

## Правовые аспекты

Мобильная форензика вторгается в частную жизнь, поэтому требует законного
основания: согласия владельца, ордера или корпоративной политики. Фиксируй
модель, уровень извлечения, инструмент и время работы. Без документированной
цепочки сохранности даже полное извлечение теряет доказательную силу.

## Типовые индикаторы в мобильном извлечении

| Индикатор | Значение |
|---|---|
| WAL-записи | недавно удалённое |
| геолокация у события | привязка к месту |
| неизвестные приложения | возможная малварь |
| аномальные контакты | распространение |
| root/скрытые разделы | anti-forensics |
