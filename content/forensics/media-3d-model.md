## Вопрос, с которого всё начинается

Пришла 3D-модель — для печати, дизайна или как улика (например, оружие). Нужно понять
формат и что в нём. Разберём.

## Наш пример: STL

## Шаг 1: форматы

- **STL** — только геометрия (треугольники), без цвета;
- **OBJ** — геометрия + материалы;
- **GLTF/GLB** — современный (JSON + бинарь), с анимацией;
- **3MF** — ZIP-контейнер (как OOXML).

## Шаг 2: STL

```
$ file part.stl
part.stl: ASCII text
```
или бинарный:
```
$ file part.stl
part.stl: data
```

ASCII-STL читается глазами (`facet normal ...`), бинарный — 80-байтовый заголовок +
число треугольников.

```
$ head -c 80 part.stl | strings
```

Заголовок часто содержит имя/комментарий — иногда с данными.

## Шаг 3: GLTF/GLB

GLB — бинарный контейнер с JSON-чанком:

```
$ python3 -c "import json,struct;d=open('m.glb','rb').read();print(d[20:20+struct.unpack('<I',d[12:16])[0]])"
```

JSON содержит метаданные: генератор, автор, лицензию.

## Шаг 4: 3MF

3MF — ZIP:

```
$ unzip -l model.3mf
  3D/3dmodel.model
  Metadata/...
```

Внутри XML с геометрией и метаданными.

## Шаг 5: что искать

- метаданные (генератор, автор, время);
- лишние чанки/файлы;
- аномалии геометрии (скрытые объекты);
- встроенные текстуры/скрипты (GLTF может ссылаться на внешние данные).

## Шаг 6: OBJ и MTL

OBJ — текстовый формат: вершины (`v`), нормали (`vn`), грани (`f`). Материалы описаны отдельно в `.mtl`:

```
$ head -5 model.obj
# Exported by Blender 4.0
mtllib model.mtl
v 0.0 0.0 0.0
```

Комментарии начинаются с `#` — в них легко спрятать данные. `mtllib` ссылается на файл материалов; если он внешний и отсутствует, часть информации теряется.

## Шаг 7: разбор GLB

GLB — это контейнер: 12-байтовый заголовок, затем чанки JSON и BIN:

```
$ python3 -c "import struct;d=open('m.glb','rb').read();print(struct.unpack('<I',d[8:12])[0])"
```

Длина из заголовка и JSON-чанк дают метаданные (`generator`, `copyright`). Лишние или нестандартные чанки — признак встраивания. GLTF (не GLB) может ссылаться на внешние `.bin` и текстуры, которые тоже надо собрать.

## Шаг 8: стеганография в 3D

Данные прячут и в самой геометрии. Способы:

- **порядок вершин** (перестановка кодирует биты);
- **младшие биты координат** (LSB);
- **лишние/дублирующие вершины** и скрытые объекты;
- **неиспользуемые чанки/материалы**.

```
$ strings model.stl | grep -iE 'nto{|flag'
```

Полезно сравнить модель с эталоном: разница в геометрии при одинаковой форме — подозрительна.

## Шаг 9: рендер и геометрия

Чтобы увидеть содержимое и проверить аномалии, модель импортируют в Blender (можно headless):

```
$ blender -b -P inspect.py
```

Рендер показывает скрытые объекты, а статистика (число вершин/граней, bounding box) выявляет несоответствия: например, огромная координата, уводящая часть модели «за кадр».

## Шаг 10: практика

Дано: `model_meta.txt` с метаданными и комментариями модели. Действия:

1. определить формат (`file`);
2. прочитать текстовые части (заголовок STL, комментарии OBJ, JSON GLB);
3. найти метки/скрытые строки;
4. проверить контейнер на лишние чанки (`binwalk`/`unzip -l` для 3MF);
5. при необходимости отрендерить и сравнить с эталоном.

Результат — понятно, что за модель, кем создана и нет ли в ней спрятанного.

## Шаг 11: что важно запомнить

- STL — только геометрия; OBJ/GLTF/3MF богаче.
- Бинарный STL имеет 80-байтовый заголовок.
- GLB = JSON + BIN; 3MF = ZIP+XML.
- Прятать можно в комментариях, чанках и геометрии.
- Сравнение с эталоном выявляет встраивание.

## Что мы теперь знаем

- STL — только геометрия; OBJ/GLTF/3MF богаче.
- Бинарный STL имеет 80-байтовый заголовок.
- GLB — JSON+бинарь; 3MF — ZIP.
- Метаданные выдают генератор/автора.
- Скрытые объекты/чанки — признак модификации.

- STL — геометрия; OBJ/GLTF/3MF несут метаданные.
- Бинарный STL: 80-байтовый заголовок + число треугольников.
- GLB = JSON+BIN; 3MF = ZIP+XML.
- Данные прячут в комментариях, чанках и самой геометрии.
- Сравнение с эталоном выявляет встраивание.

## Если не сработало

- Формат неизвестен? Используй `file`/`binwalk`.
- Нужен рендер? Импортируй в Blender.
- Данные сжаты? Смотри контейнер.
