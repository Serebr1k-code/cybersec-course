## Вопрос, с которого всё начинается

Запускать образец опасно, а статически он обфусцирован. Компромисс — **эмуляция**:
код исполняется по инструкциям в изолированной среде, без реальной ОС. Так видно
поведение и расшифровываются строки. Разберём.

## Наш пример: эмулируем функцию

## Шаг 1: что такое эмуляция

Эмулятор исполняет машинные инструкции, но не даёт настоящих системных вызовов. Вместо
этого ты **сам решаешь**, что вернёт каждый API. Это безопасно и контролируемо.

## Шаг 2: unicorn

`unicorn` — CPU-эмулятор (x86/ARM и др.):

```python
from unicorn import Uc, UC_ARCH_X86, UC_MODE_64
mu = Uc(UC_ARCH_X86, UC_MODE_64)
mu.mem_map(0x1000, 0x1000)
mu.mem_write(0x1000, code)
mu.emu_start(0x1000, 0x1000+len(code))
```

Он даёт регистры и память после исполнения. Годится для расшифровки строк и проверок.

## Шаг 3: Qiling

`Qiling` эмулирует уже **всю ОС** — загружает PE/ELF, эмулирует API:

```python
from qiling import Qiling
ql = Qiling([r"samples/packed.exe"], r"rootfs/x8664_windows")
ql.run()
```

Он перехватывает вызовы (например, `CreateFile`), и ты можешь логировать/подменять их.
Так видно, какие файлы, ключи реестра и адреса использует образец.

## Шаг 4: извлечение поведения

- **API-логи** — какие функции вызваны;
- **сетевые адреса** — куда «звонит»;
- **файлы/ключи** — что трогает;
- **расшифрованные строки** — после прогона.

Всё это — IOC без реального заражения.

## Шаг 5: ограничения

- эмулятор не всегда поддерживает все инструкции;
- анти-эмуляция (проверка тайминга, CPUID) ломает прогон;
- сложные образцы требуют ручной настройки API.

Поэтому эмуляцию комбинируют со статикой и песочницей.

## Что мы теперь знаем

- Эмуляция исполняет код без реальной ОС.
- `unicorn` — CPU-уровень, `Qiling` — ОС-уровень.
- API можно перехватывать и подменять.
- Извлекаются строки, адреса, поведение.
- Есть ограничения (поддержка инструкций, анти-эмуляция).

## Если не сработало

- Не поддерживается инструкция? Переключи движок/пропусти.
- Анти-эмуляция? Патчь проверки.
- Нужна полная ОС? Комбинируй с песочницей.
