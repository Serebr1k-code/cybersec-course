Этот модуль — про **инструменты и автоматизацию**, а не про отдельный артефакт. Здесь мы собираем три вещи: графическую платформу Autopsy, язык правил (YARA для файлов/памяти и Sigma для логов) и скриптование на Python, когда готовые утилиты не покрывают задачу.

## Что покрывает этот модуль

- **Autopsy / The Sleuth Kit** — ingest-модули, артефакты, отчёты, работа с образами.
- **YARA и Sigma** — написание и применение правил для файлов, памяти и логов.
- **Python-форензика** — `pytsk3`, API Volatility3, `pyshark` для собственных пайплайнов.

## Рекомендуемый порядок изучения

1. `forensics-autopsy` — сначала GUI-платформа и ingest-пайплайн.
2. `forensics-yara-sigma` — затем правила: единый способ описать «плохое».
3. `forensics-python-tooling` — наконец, скрипты для нестандартных задач.

## Что вы будете уметь

- Работать в Autopsy и понимать, что делают ingest-модули.
- Писать YARA/Sigma-правила и применять их в масштабе.
- Писать Python-скрипты поверх pytsk3 и Volatility3.

## Инструмент → назначение

| Инструмент | Назначение |
|------------|------------|
| Autopsy | GUI-платформа + ingest-модули |
| The Sleuth Kit | CLI-библиотека работы с ФС |
| YARA | сигнатуры файлов и памяти |
| Sigma | сигнатуры логов (SIEM) |
| pytsk3 / volatility3 | программный доступ из Python |
