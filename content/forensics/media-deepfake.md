## Вопрос, с которого всё начинается

Видео/аудио выглядит настоящим, но может быть сгенерировано ИИ (**deepfake**). Как
отличить? Полностью надёжного метода нет, но есть набор признаков. Разберём.

## Наш пример: подозрительное видео

## Шаг 1: что такое deepfake

Синтетические медиа, созданные генеративными моделями: подмена лица, клонирование
голоса, полностью сгенерированное видео. Они оставляют **артефакты**.

## Шаг 2: визуальные артефакты

- **несоответствие границ лица** (моргание, текстура кожи);
- **артефакты вокруг волос/зубов/ушей**;
- **несогласованное освещение**;
- **дрожание/«плавание»** контуров между кадрами;
- **несоответствие синхронизации** губ и звука.

```
$ ffmpeg -i clip.mp4 -vf fps=5 frame_%04d.png
```

Покадровый просмотр выявляет дрожание.

## Шаг 3: аудио-артефакты

Клонирование голоса выдаёт:

- отсутствие естественного дыхания/пауз;
- ровный «синтетический» спектр;
- несоответствие фонового шума между фразами;
- артефакты на границах слов.

```
$ sox voice.wav -n spectrogram -o spec.png
```

## Шаг 4: метаданные и происхождение

- **C2PA/Content Credentials** — подписанное происхождение;
- метаданные устройства/софта;
- отсутствие «камерных» метаданных (EXIF);
- несоответствие encoder.

## Шаг 5: инструменты и подход

- детекторы (модели) — дают вероятность, не вердикт;
- **frequency analysis** (GAN оставляет следы в спектре);
- сопоставление с оригиналом;
- **экспертная оценка** + метаданные + контекст.

## Что мы теперь знаем

- Deepfake оставляет артефакты (лицо, освещение, синхронизация).
- Аудио-клоны выдают дыхание и спектр.
- Метаданные и C2PA дают происхождение.
- Детекторы дают вероятность, не приговор.
- Итог — комбинация методов.

## Если не сработало

- Артефактов нет? Модель могла быть качественной.
- Нет оригинала? Сравнивай контекст.
- Нужен вердикт? Привлекай экспертизу.
