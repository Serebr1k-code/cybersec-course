## Что такое решётка

**Решётка** `L` в `R^n` — множество всех целочисленных линейных комбинаций набора линейно независимых векторов `b1, ..., bm` (базис):

```
L = { Σ zi·bi : zi ∈ Z }
```

Решётка дискретна и периодична. Ключевые задачи:

- **SVP (Shortest Vector Problem):** найти кратчайший ненулевой вектор в решётке.
- **CVP (Closest Vector Problem):** найти вектор решётки, ближайший к заданной точке.

Обе задачи NP-трудны в худшем случае, но для **низких размерностей** (сотни) решаются приближённо алгоритмами редукции базиса. Именно это и делает их оружием криптоанализа: если задача сводится к SVP/CVP, а секрет «короткий», LLL/BKZ его находят.

## Редукция базиса: LLL и BKZ

**LLL** (Lenstra–Lenstra–Lovász, 1982) за полиномиальное время строит **редуцированный базис** с относительно короткими векторами. Коэффициент аппроксимации `2^(n/2)`. Это «рабочая лошадка»: для размерности ~100 вектора получаются близкими к кратчайшим.

**BKZ** (Block Korkine–Zolotarev) — сильнее LLL, с параметром «блока» `β`. Чем больше `β`, тем лучше редукция и тем медленнее. Для размерностей > 100 используют BKZ.

```python
# Sage
M = Matrix(ZZ, [[...], [...], ...])
L = M.LLL()          # LLL-редукция
L = M.BKZ(block_size=20)   # сильнее
print(L[0])          # часто = короткий вектор с секретом
```

## Embedding technique: как строить решётку

Главный навык — **построить решётку так, чтобы секрет был коротким вектором**. Общая схема (для задачи `A·x = b mod m`, где `x` мал):

1. Составить матрицу, строки которой — базис.
2. Добавить масштабирующие коэффициенты, чтобы «секретный» вектор стал коротким.
3. Применить LLL/BKZ.
4. Найти в редуцированном базисе вектор, соответствующий секрету.

**Пример: усечённый LCG.** LCG: `x_{i+1} = a·x_i + c mod m`. Если даны старшие биты `x_i`, строится решётка, где разности (неизвестные младшие биты) малы, и LLL восстанавливает их.

**Пример: knapsack (subset sum).** Даны `a_i` и `s = Σ εi·ai`, `εi ∈ {0,1}`. Строим решётку (Lagarias–Odlyzko) и находим бинарный вектор `ε`.

```python
# Sage: knapsack
n = len(a)
M = Matrix(ZZ, n+1, n+1)
for i in range(n):
    M[i,i] = 1
    M[n,i] = a[i]
M[n,n] = -s
L = M.LLL()
# ищем строку с малыми коэффициентами -> eps
```

## Coppersmith через решётки

Теорема Coppersmith (см. `crypto-rsa-coppersmith-deep`) находит **малые корни** полинома `f(x) ≡ 0 mod N`: если `|x0| < N^(1/d)` (d — степень), то `x0` находится за полиномиальное время. Реализация: строится решётка из сдвигов `f(x)` (Howgrave-Graham), LLL находит короткий вектор, из которого извлекается корень.

Применения:

- **Stereotyped message:** `m = m0 + x`, `x` мал → Coppersmith.
- **Known high bits of `p`:** `p = p_high + x`, `x < N^0.25` → факторизация.
- **Boneh-Durfee:** малый `d` через решётку (см. `crypto-rsa-wiener-bonedurfee`).
- **Franklin-Reiter:** два линейно связанных сообщения.

## NTRU и решёточная криптография

NTRU — криптосистема на решётках. Её стойкость основана на SVP в специфической решётке. Атаки: построение решётки NTRU и LLL/BKZ для поиска короткого вектора (при малых параметрах — ломается). Современные решёточные схемы (Kyber, Dilithium — пост-квантовые) основаны на LWE (Learning With Errors), где задача — найти секрет по зашумлённым линейным уравнениям; тоже решается решётками при неудачных параметрах.

## Практический пример: малый секрет из линейных уравнений

```python
# Дано: A (матрица), b = A·x mod m, x мал
# Строим решётку
from sage.all import Matrix, ZZ
n = len(A)
M = Matrix(ZZ, n+1, n+1)
for i in range(n):
    M[i,i] = 1
    for j in range(n):
        M[i,j] = A[i][j] * 1
    M[n,i] = b[i]
M[n,n] = m
L = M.LLL()
for row in L:
    if all(abs(v) < 100 for v in row):
        print("short vector -> secret:", row)
```

(Точная конструкция зависит от задачи; главное — секрет должен стать коротким.)

## Частые ошибки

- **Неверная конструкция решётки.** Секрет не станет коротким — LLL не найдёт.
- **Слишком большая размерность.** LLL тормозит; используйте BKZ или уменьшайте.
- **Забыть масштабирование.** Без коэффициентов разные «единицы» портят редукцию.
- **Проверять только первый вектор.** Секрет может быть во втором/третьем.
- **Применять LLL к полному AES/RSA.** Решётки — для задач с **малым** секретом.
- **Не проверять результат.** Короткий вектор ≠ секрет; проверьте на исходной задаче.

## CVP, Babai и «ближайший вектор»

Кроме SVP, часто нужен **CVP**: найти вектор решётки, ближайший к целевой точке `t`. Применение — когда секрет не «короткий вектор», а «близок» к известному значению. Алгоритм **Babai** (nearest plane) даёт приближённое решение за полиномиальное время, используя редуцированный (LLL) базис. Это применяется в задачах с зашумлёнными данными (LWE) и «known high bits».

```python
# Sage: CVP через Babai
M = Matrix(ZZ, basis)
L = M.LLL()          # редукция
# затем Babai nearest plane с базисом L
```

## Реальные примеры атак

- **Truncated LCG:** даны старшие биты последовательности `x_i`; строится решётка, где неизвестные младшие биты малы → LLL восстанавливает.
- **Knapsack/subset-sum:** бинарный вектор `ε` находится LLL-редукцией (Lagarias–Odlyzko).
- **Coppersmith:** малые корни полинома (см. `crypto-rsa-coppersmith-deep`).
- **RSA HNP:** известные биты `d`/`k` (ECDSA nonce) → решётка находит секрет.
- **NTRU/LWE:** восстановление секрета при неудачных параметрах.

## Полный пример: knapsack (subset-sum)

Даны `a_1..a_n` и цель `s = Σ ε_i·a_i`, `ε_i ∈ {0,1}`. Классическая атака Лагариаса–Одлыжко:

```python
# Sage
n = len(a)
M = Matrix(ZZ, n+1, n+1)
for i in range(n):
    M[i, i] = 1
    M[n, i] = a[i]
M[n, n] = -s
L = M.LLL()
# строка с нулём в последней позиции и ±1 в остальных -> eps
for row in L:
    if row[n] == 0 and all(abs(v) <= 1 for v in row[:n]):
        eps = [abs(v) for v in row[:n]]
        print(eps)
```

Если `n` мало (десятки), решётка сработает мгновенно. Для больших `n` нужен BKZ и больше данных.

## Полный пример: truncated LCG

LCG `x_{i+1} = a·x_i + c mod m`. Даны **старшие** биты `x_i` (младшие неизвестны). Строим решётку, где неизвестные младшие биты образуют короткий вектор, и LLL восстанавливает их:

```python
# Sage (схематично)
# известные старшие биты -> уравнения x_i = known_i + e_i, |e_i| мал
# строим решётку с a, c, m
# LLL -> e_i -> полные x_i -> восстанавливаем a, c или seed
```

## Практика: как строить решётку

1. **Сформулируйте задачу** как «найти малый вектор `v`, удовлетворяющий линейным связям».
2. **Составьте базис:** строки — коэффициенты связей, диагональ — масштабы.
3. **Добавьте масштаб** `C`, чтобы малые компоненты стали «короткими» относительно модуля.
4. **LLL/BKZ**, ищите вектор с ожидаемой структурой.
5. **Проверьте** найденный вектор на исходной задаче.

## Как не застрять

- **Ищите «малость».** Малый `d`, малый корень, известные старшие биты, `ε ∈ {0,1}`.
- **Стройте решётку** через embedding technique.
- **Начинайте с LLL**, при неудаче — BKZ.
- **Проверяйте все короткие векторы.**
- **Для Coppersmith** используйте готовые sage-скрипты.
- **Если размерность огромна** — упростите задачу (меньше уравнений).
