## Enigma: почему она интересна

Enigma — роторная шифровальная машина, использовавшаяся Германией во Второй мировой. Её взлом в Блетчли-Парке (Алан Тьюринг и др.) — один из самых известных эпизодов криптоанализа и ключевой вклад в победу союзников. На CTF Enigma встречается в двух видах: (а) нужно **реализовать** машину и расшифровать сообщение по известным настройкам, (б) нужно **взломать** её, используя crib (угаданный фрагмент открытого текста).

Устройство Enigma — прекрасный учебный пример того, как «сложная механическая машина» может быть сломана из-за **структурных слабостей** (отражатель, отсутствие замены буквы в себя), а не грубой силы.

## Устройство

Компоненты Enigma:

1. **Коммутационная панель (plugboard / Steckerbrett).** Попарно меняет местами буквы (до 10 пар). Добавляет огромный множитель к пространству ключей.
2. **Роторы (Walzen).** Обычно 3 из набора 5 (в M4 — 4). Каждый ротор — подстановка (перестановка алфавита), которая «вращается»: при нажатии клавиши правый ротор сдвигается на 1, при переполнении — следующий.
3. **Отражатель (reflector / Umkehrwalze).** Фиксированная инволюция (перестановка, обратная самой себе), замыкающая цепь.

Путь сигнала: клавиша → plugboard → ротор 1 → ротор 2 → ротор 3 → отражатель → ротор 3 (обратно) → ротор 2 → ротор 1 → plugboard → лампа. Именно отражатель делает машину **самообратной**: шифрование и расшифрование — одна и та же операция при одинаковых настройках.

## Ключевое свойство: буква не шифруется в себя

Из-за отражателя сигнал проходит один и тот же путь «туда и обратно», поэтому **никакая буква не может зашифроваться в саму себя**. Это свойство и было главной уязвимостью: оно позволяло исключать варианты при crib-атаке. Если в позиции `i` crib-текста стоит буква `X`, то в шифротексте на той же позиции **не может** быть `X`. Это резко сокращает пространство поиска.

Второе следствие: Enigma — **инволюция**. `E(E(m)) = m` при одинаковых настройках. Поэтому расшифрование = шифрование с теми же настройками.

## Настройки и их размерность

Пространство ключей Enigma (3 ротора из 5, ring settings, позиции, plugboard):

- Выбор и порядок роторов: `5·4·3 = 60`.
- Начальные позиции: `26^3 = 17576`.
- Ring settings: `26^3 = 17576`.
- Plugboard (10 пар из 26): ~`1.5·10^14`.

Полное пространство ~`1.6·10^20` — перебор невозможен даже сегодня для полного перебора. Но структурные слабости + crib делают атаку реальной.

## Рабочий эмулятор на Python

```python
ROTORS = {
    'I':   "EKMFLGDQVZNTOWYHXUSPAIBRCJ",
    'II':  "AJDKSIRUXBLHWTMCQGZNPYFVOE",
    'III': "BDFHJLCPRTXVZNYEIWGAKMUSQO",
}
NOTCH = {'I': 'Q', 'II': 'E', 'III': 'V'}
REFLECTOR = "YRUHQSLDPXNGOKMIEBFZCWVJAT"   # Reflector B

def plugboard(swaps):
    m = {chr(65+i): chr(65+i) for i in range(26)}
    for a, b in swaps:
        m[a], m[b] = b, a
    return m

class Enigma:
    def __init__(self, rotors, positions, rings, swaps):
        self.rotors = [ROTORS[r] for r in rotors]
        self.notches = [NOTCH[r] for r in rotors]
        self.pos = [ord(p) - 65 for p in positions]
        self.ring = [ord(r) - 65 for r in rings]
        self.pb = plugboard(swaps)
    def _fwd(self, c, i):
        shift = self.pos[i] - self.ring[i]
        idx = (ord(c) - 65 + shift) % 26
        out = (ord(self.rotors[i][idx]) - 65 - shift) % 26
        return chr(out + 65)
    def _bwd(self, c, i):
        shift = self.pos[i] - self.ring[i]
        idx = (ord(c) - 65 + shift) % 26
        out = (self.rotors[i].index(chr(idx + 65)) - shift) % 26
        return chr(out + 65)
    def _step(self):
        # упрощённое вращение (без двойного шага)
        self.pos[0] = (self.pos[0] + 1) % 26
        if chr(self.pos[0] + 65) == self.notches[0]:
            self.pos[1] = (self.pos[1] + 1) % 26
            if chr(self.pos[1] + 65) == self.notches[1]:
                self.pos[2] = (self.pos[2] + 1) % 26
    def enc(self, ch):
        self._step()
        c = self.pb[ch]
        for i in range(3): c = self._fwd(c, i)
        c = REFLECTOR[ord(c) - 65]
        for i in reversed(range(3)): c = self._bwd(c, i)
        return self.pb[c]

m = Enigma(['I','II','III'], "AAA", "AAA", [('A','B')])
ct = "".join(m.enc(c) for c in "HELLO")
print(ct)
```

Обратите внимание: `_step` должен реализовывать «двойной шаг» (double stepping) для точной эмуляции — в реальной Enigma средний ротор прокручивается дважды в определённый момент. Упрощение выше достаточно для понимания, но для точной расшифровки нужен правильный notch-механизм.

## Crib-атака: как ломали Enigma

**Crib** — угаданный фрагмент открытого текста (например, «WETTER» — прогноз погоды, или стандартное приветствие). Идея атаки:

1. Разместим crib напротив шифротекста в нескольких возможных позициях (offset).
2. Для каждого offset проверим свойство «буква не в себя»: если в crib-тексте `X` стоит там, где в шифротексте тоже `X`, — этот offset/настройки неверны.
3. Совместимые варианты проверяем на полной машине, перебирая позиции роторов.

Именно это делала **Bombe** — электромеханическое устройство Тьюринга, которое проверяло логические цепочки (меню/crib) и отбрасывало несовместимые конфигурации.

```python
def crib_check(ct, crib, offset):
    for i, ch in enumerate(crib):
        if ct[offset + i] == ch:
            return False   # буква зашифровалась в себя -> невозможно
    return True

ct = "MFQWX..."   # шифротекст
crib = "WETTER"   # угаданный фрагмент
for off in range(len(ct) - len(crib)):
    if crib_check(ct, crib, off):
        print("possible offset:", off)
```

После отбора по свойству «не в себя» остаётся перебрать `26^3 = 17576` позиций (ring/plugboard — отдельно), что вполне по силам скрипту.

## Практический пример: расшифровка с известными настройками

```python
m = Enigma(['I','II','III'], "XYZ", "AAA", [('A','B'),('C','D')])
ct = "".join(m.enc(c) for c in "ATTACKATDAWN")
# расшифровать: тот же объект с теми же настройками
m2 = Enigma(['I','II','III'], "XYZ", "AAA", [('A','B'),('C','D')])
pt = "".join(m2.enc(c) for c in ct)
print(pt)   # ATTACKATDAWN
```

## Частые ошибки

- **Забыть про plugboard.** Он меняет вход/выход и обязателен для расшифровки.
- **Перепутать ring setting и начальную позицию.** Это разные параметры.
- **Не реализовать двойной шаг.** Даёт неверную расшифровку на длинных текстах.
- **Забыть, что Enigma самообратна.** Расшифровка = шифрование.
- **Игнорировать «буква не в себя».** Это главный инструмент crib-атаки.
- **Путать отражатели B/C.** Разные перестановки.

## Как не застрять

- **Уточните модель:** сколько роторов, какой отражатель, есть ли plugboard.
- **Реализуйте эмулятор** или возьмите `py-enigma`.
- **Ищите crib** — стандартные фразы, известный формат флага.
- **Применяйте «буква не в себя»** для отсева позиций.
- **Перебирайте позиции (17576)** — это быстро.
- **Ring settings и plugboard** — отдельные этапы после позиций.
