## Теорема Coppersmith

Пусть `f(x)` — **монический** полином степени `d` с целыми коэффициентами, `N` — модуль. Если существует `x0` такой, что `f(x0) ≡ 0 (mod N)` и `|x0| < N^(1/d)`, то `x0` находится за полиномиальное время (при фиксированном `d`).

Это «малые корни» (small roots). Есть также версия для **неизвестного делителя**: если `f(x0) ≡ 0 (mod b)`, где `b | N` и `b ≥ N^beta`, то корень находится при `|x0| < N^(beta²/d)`.

## Howgrave-Graham: сведение к решётке

Coppersmith — это приложение LLL к построенной решётке. Идея (Howgrave-Graham):

1. Если `f(x0) ≡ 0 mod N`, то и `N^(m−i) · f(x)^i ≡ 0 mod N^m` для подходящих `i`.
2. Составляем решётку из векторов-коэффициентов этих полиномов (сдвиги `x^j · f(x)^i · N^...`).
3. LLL находит короткий вектор `g(x)` с `g(x0) = 0` **над целыми** (если `|x0|` достаточно мал).
4. Корень `g(x)` находится обычным способом (факторизация/roots).

Параметры `m` (число сдвигов) и `t` (число дополнительных) влияют на границу и размер решётки. Чем больше `m`, тем ближе к теоретической границе, но тем медленнее.

## Sage: small_roots

```python
# Sage
N = ...
R.<x> = PolynomialRing(Zmod(N))
f = x^2 + a*x + b           # должен быть монический
roots = f.small_roots(X=2^40, beta=1.0)
print(roots)                 # список корней
```

Параметры:

- `X` — верхняя граница `|x0|` (обязательно `X < N^(beta²/d)` примерно).
- `beta` — минимальная доля `N`, которую делит неизвестный множитель (1.0 для полного модуля, 0.4–0.5 для факторизации).
- `epsilon` — тюнинг (по умолчанию автоматически).

## Применение 1: stereotyped message

`m = m0 + x`, `m0` известен, `x` мал:

```python
# Sage
c, n, e = ...
m0 = bytes_to_long(b"CTF{") << (8*16)    # известный префикс, 16 неизвестных байт
R.<x> = PolynomialRing(Zmod(n))
f = (m0 + x)^e - c
x0 = f.small_roots(X=2^(8*16), beta=1.0)
if x0:
    m = m0 + x0[0]
    print(bytes.fromhex(hex(m)[2:]))
```

Граница: `x < n^(1/e)`. Для `e=3` и 1024-битного `n` это ~341 бит (42 байта).

## Применение 2: известны старшие биты p

`p = p_high + x`, `x` неизвестен, `p | n`:

```python
# Sage
n = ...
p_high = ...       # известные старшие биты p
R.<x> = PolynomialRing(Zmod(n))
f = p_high + x     # монический, степень 1
roots = f.small_roots(X=2^unknown_bits, beta=0.4)
p = p_high + roots[0]
q = n // p
print(p*q == n)
```

Граница: `x < n^(beta²)`, при `beta=0.5` — `x < n^0.25`. То есть достаточно знать **половину** старших бит `p`.

## Применение 3: обобщённый Håstad

Разные линейные paddings: `m_i = a_i·m + b_i`. Строим систему:

```
(a_i·x + b_i)^e ≡ c_i (mod n_i)
```

Комбинируем по CRT в полином mod `N = Π n_i`, затем `small_roots`. Это работает, даже когда простой Håstad не срабатывает из-за padding.

## Применение 4: частичный d

Если известны младшие биты `d` (`d = d0 + 2^k·x`), строится решётка (HNP-подобная) или применяется модификация Boneh-Durfee. Уровень сложности — высокий; на CTF встречается редко, но встречается.

## Частые ошибки

- **Полином не монический.** Приводите: умножьте на `inverse(leading_coeff, N)`.
- **Слишком большой `X`.** Превышение границы → корень не найдётся.
- **Не тот `beta`.** Факторизация требует `beta < 0.5`.
- **Мало неизвестных бит осталось.** Граница строгая.
- **Большой `e`.** Coppersmith работает при малом `e`/степени.
- **Нет Sage.** Реализовать вручную крайне сложно.

## Параметры решётки и их тюнинг

В `small_roots` параметры `m` (число сдвигов полинома) и `t` (число дополнительных векторов) определяют размер решётки и достижимую границу:

- Больше `m` → ближе к теоретической границе `N^(beta²/d)`, но размерность решётки растёт (`~d·m`), и LLL замедляется.
- `beta` задаёт долю `N`, которую делит неизвестный множитель: `beta=1` — полный модуль; `beta=0.5` — для факторизации (половина).
- `epsilon` управляет компромиссом; Sage подбирает автоматически, но можно задать вручную для сложных случаев.

Практическое правило: начните с `beta=1` (если корень по полному модулю) или `beta=0.5` (факторизация), `X` — чуть меньше теоретической границы, `m=3..5`. Если не находит — увеличьте `m` или проверьте границу.

## Реальные применения и инциденты

- **Утечка старших битов `p`** в smart-card/HSM (side-channel) → Coppersmith факторизует ключ.
- **Firmware-ключи** с известным префиксом сообщения → stereotyped.
- **Малый `d`** в оптимизированных реализациях → Boneh-Durfee (родственник Coppersmith).
- **SSL/TLS** с малым `e` и известным форматом сообщения (padding) → обобщённый Håstad.
- **CRT-утечки:** если известен один из `(p mod ...)`, применяется Coppersmith по модулю `p`.

## Отладка Coppersmith

Частые причины «не находит»:

1. **`X` слишком велик.** Уменьшите до `N^(beta²/d) · 0.9`.
2. **`beta` неверный.** Для факторизации — `< 0.5`.
3. **Полином не монический.** Умножьте на `inverse(lc, N)`.
4. **Мало неизвестных бит осталось.** Нужно больше утечки.
5. **`m` слишком мал.** Увеличьте (ценой времени).
6. **Ошибка в построении полинома** (не тот известный префикс/сдвиг).

Проверяйте локально: сгенерируйте ключ с известным `p`, «спрячьте» часть бит и убедитесь, что атака их возвращает.

## Разбор: полный скрипт с Coppersmith

```python
# Sage
from Crypto.Util.number import bytes_to_long, long_to_bytes

def stereotyped(n, e, c, known_prefix, unknown_bytes):
    m0 = bytes_to_long(known_prefix) << (8*unknown_bytes)
    R.<x> = PolynomialRing(Zmod(n))
    f = (m0 + x)^e - c
    f = f.monic()
    roots = f.small_roots(X=2^(8*unknown_bytes), beta=1.0)
    if roots:
        return long_to_bytes(int(m0 + roots[0]))
    return None

print(stereotyped(n, 3, c, b"flag{", 20))
```

## Разбор: факторизация по старшим битам

```python
# Sage
def factor_from_high_bits(n, p_high, unknown_bits):
    R.<x> = PolynomialRing(Zmod(n))
    f = (p_high + x).monic()
    roots = f.small_roots(X=2^unknown_bits, beta=0.4)
    if roots:
        p = p_high + roots[0]
        return int(p), int(n // p)
    return None
```

Условие: `unknown_bits < n.nbits()/4`. Если больше — нужно больше утечки.

## Когда Coppersmith НЕ сработает

- Слишком большой `X` (корень вне границы).
- `e`/степень слишком велики.
- Полином не имеет малого корня (нет структуры).
- Неверный `beta`.
- Не хватает утечки (битов).

В этих случаях переходите к другим атакам или ищите больше данных.

## Как не застрять

- **Ищите структуру:** известный префикс, старшие биты, линейная связь.
- **Определите степень `d`** полинома и границу `N^(1/d)`.
- **Для факторизации** используйте `beta < 0.5`.
- **Возьмите `coppersmith.sage`** как основу.
- **Проверяйте найденный корень** на исходном уравнении.
- **Увеличивайте `m`/`X` осторожно** — решётка растёт.

## Где пригодится

- **CTF (expert)** — самые «злые» RSA-задачи: частичный ключ, известный префикс, малый корень.
- **Академия** — Coppersmith — центральный инструмент современного криптоанализа.
- **Аудит** — оценка последствий утечки части ключевого материала.
- **Реальные инциденты** — атаки на прошивки/смарт-карты с утечкой битов.
- **Пост-квантовая** — та же решёточная техника (LWE).
