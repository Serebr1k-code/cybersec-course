## Вопрос, с которого всё начинается

Ты знаешь Виженера: `C = (P + K) mod 26`. Но это лишь **одна** из многих многоалфавитных схем. На CTF регулярно дают «Виженера-подобный» шифр с другой формулой — и попытка применить обычный сдвиг вперёд даёт мусор. Как понять, какая именно формула использована? Разберём на конкретном примере.

## Наш пример: шифр Бофора

У нас `cipher.txt`, зашифрованный с ключом `FORTUNA`, и мы хотим восстановить текст. Смотрим на подсказку.

```
$ cat notes.txt
- Beaufort: C=(K-P) mod 26; расшифровка — та же формула (инволюция).
```

## Шаг 1: три родственные формулы

Есть три близких схемы, которые часто путают:

```
Vigenère:        C = (P + K) mod 26
Beaufort:        C = (K - P) mod 26
Variant Beaufort: C = (P - K) mod 26
```

В **Виженере** ключ **прибавляется** к тексту. В **Бофоре** из ключа **вычитается** текст. В **variant Beaufort** текст минус ключ. Все три многоалфавитные, но результат разный.

## Шаг 2: почему Бофор инволютивен

Ключевое свойство Бофора: он **сам себе обратен**. Применим формулу дважды:

```
C = (K - P) mod 26
C' = (K - C) = (K - (K - P)) = P
```

То есть **шифрование и расшифровка — одна и та же операция**. Это очень удобно (и опасно: реализация не должна зависеть от направления). Для Виженера это не так — там расшифровка требует вычитания.

```
$ python3 beaufort.py
plaintext: THEFLAGISNTOBEAUFORTISITSONWINVERSE
flag: nto{b34uf0rt_1s_1ts_0wn_1nv3rs3}
```

## Шаг 3: Porta, Гронсфельд, Autokey

**Porta** — шифр Джамбаттисты делла Порта. Он использует **симметричные таблицы**: сдвиг применяется не к одной букве, а к паре (буква и «зеркальная» ей). Порта стоек к частотному анализу чуть лучше Виженера, потому что отображение инволютивно и симметрично.

**Гронсфельд** — Виженер с **цифровым** ключом (например, `3141`). Каждая цифра — сдвиг. Проще для запоминания, но ключевое пространство меньше.

**Autokey** — ключ, который «продолжает сам себя»: после короткого начального ключа в качестве следующих ключевых букв берётся **сам открытый текст**. Это устраняет повтор ключа (главную слабость Виженера), но создаёт свою: ошибка в одной букве каскадом рушит весь хвост.

## Шаг 4: running-key и VIC

**Running-key** использует в качестве ключа длинный **осмысленный текст** (например, главу книги). Ключ никогда не повторяется — но если атакующий угадает источник (ту же книгу), он получит ключ.

**VIC-шифр** — вершина ручной классики, использовался советской разведкой. Он комбинирует перестановку, подстановку по таблицам, цифровой ключ и «шаблон». Настолько сложен, что долгое время считался невзламываемым без ключа. Разбор VIC — отдельное упражнение на понимание композиции примитивов.

## Полный прогон от начала до конца

1. `cat cipher.txt notes.txt` — видим шифртекст и формулу.
2. Применяем `P = (K - C) mod 26` с циклическим ключом `FORTUNA`.
3. Получаем открытый текст.
4. `python3 beaufort.py | grep nto > found.txt`.

## Если не сработало

Первым делом **определи формулу**. Возьми известный фрагмент (например, предполагаемый заголовок `THE...`) и подбери, какая из трёх формул даёт осмысленный ключ. Если ключ повторяется и текст длинный — применяй Касиски/IC (см. `crypto-classical-statistics`). Для Autokey помни про каскад ошибок: расшифровывай последовательно, сверяя каждую букву. Для Гронсфельда проверь, что цифры не перепутаны с буквами A=1..Z=26.

## Как отличить формулы на практике

Допустим, ты не знаешь, какая из трёх формул использована. Возьми **предполагаемый** фрагмент открытого текста (например, `THE` в начале или известный шаблон `FLAG`) и вычисли, какой ключ даёт каждая формула:

```python
AL='ABCDEFGHIJKLMNOPQRSTUVWXYZ'
def k_vig(c,p): return (ord(c)-ord(p))%26
def k_beau(c,p): return (ord(c)+ord(p))%26
def k_vbeau(c,p): return (ord(p)-ord(c))%26
```

Для правильной формулы ключ будет **повторяющимся** словом; для неправильных — случайным набором букв. Это надёжный тест: перебери все три формулы и посмотри, где ключ складывается в осмысленное слово.

## Porta и таблица

Porta — почти забытый, но красивый шифр. Он использует **13 таблиц** (по числу пар букв ключа) и отображает букву на «зеркальную» ей. Отображение **инволютивно**: шифрование равно расшифровке, как у Бофора. Таблицу легко записать кодом:

```python
def porta(c, k):
    # k in 0..12: первые 13 vs вторые 13 букв алфавита
    i = AL.index(c)
    if i < 13:
        return AL[((i + k) % 13) + 13]
    return AL[(i - 13 - k) % 13]
```

Porta чуть устойчивее Виженера к частотному анализу за счёт симметрии, но по-прежнему уязвим к Касиски.

## Взлом многоалфавитных шифров

Если ключ повторяется, длина ключа определяется **индексом совпадений** или **тестом Касиски** (см. `crypto-classical-statistics`). После этого каждый столбец (позиция внутри ключа) — это обычный сдвиг Цезаря, и его ломают частотным анализом. Для Бофора всё чуть иначе: столбец восстанавливается по формуле `K = (C + P) mod 26`, но принцип тот же — сначала длина, потом по букве ключа.

Если ключ **не повторяется** (running-key, Autokey), частотный анализ не работает. Тогда атака опирается на **угадывание источника** ключевого текста или на статистические свойства Autokey (ошибка в одной букве портит хвост — это подсказка при ручном восстановлении).

## VIC-шифр подробнее

VIC — композиция четырёх операций: перестановка цифр по «шаблону», подстановка букв по таблицам, перестановка по цифровому ключу и шифрование по «шахматной доске» с NULL-символами. Он использовался советской разведкой в 1950-х и считался практически невзламываемым без ключа. Для CTF важен не сам VIC, а идея: **композиция слабых операций даёт сильный шифр**, если они чередуются и зависят от ключа.

## Итоговая шпаргалка формул

Соберём все формулы в одном месте — это удобно держать под рукой:

| Шифр | Формула шифрования | Формула расшифровки | Инволюция |
|---|---|---|---|
| Виженер | `C = (P + K) mod 26` | `P = (C - K) mod 26` | нет |
| Beaufort | `C = (K - P) mod 26` | `P = (K - C) mod 26` | да |
| Variant Beaufort | `C = (P - K) mod 26` | `P = (C + K) mod 26` | нет |
| Гронсфельд | `C = (P + d) mod 26` | `P = (C - d) mod 26` | нет |
| Porta | таблица по паре букв | та же таблица | да |

Обрати внимание: у Бофора и Porta шифрование и расшифровка — **одна операция**. Это не только удобно, но и важно при реализации: если код «знает направление», он не инволютивен, и это признак, что реализован не тот шифр.

## Autokey подробнее

Autokey решает главную проблему Виженера — повтор ключа. Ключевая последовательность формируется так: сначала идёт короткий **затравочный** ключ, а дальше — сам открытый текст. Формально:

```
K_i = seed[i]            для i < len(seed)
K_i = P_{i - len(seed)}  для i >= len(seed)
```

Шифрование — обычное `C_i = (P_i + K_i) mod 26`. Так как ключ никогда не повторяется, Касиски и индекс совпадений бесполезны. Но появляется **каскадная уязвимость**: ошибка в одной восстановленной букве `P_j` сразу портит ключ `K_{j+len(seed)}` и, значит, все последующие буквы. Поэтому Autokey расшифровывают последовательно, проверяя каждую букву по словарю. Есть и вариант **ciphertext-autokey**, где ключом служит сам шифртекст — он менее уязвим к каскаду, но всё равно ломается при известном начале.

## Running-key и его слабости

Running-key использует в качестве ключа длинный осмысленный текст. Если источник неизвестен, шифр очень крепок. Но на практике источник часто **угадывается**: Библия, Конституция, популярный роман, текст в задании. Есть и чисто статистический приём: если открытый текст и ключ — оба на одном языке, разность `C_i = P_i + K_i` имеет характерное распределение, и его можно атаковать методами **crib dragging** (подстановка предполагаемых слов и проверка читаемости ключа). Именно так ломали many-time pad и running-key на реальных соревнованиях.

## Инструменты и автоматизация

Для многоалфавитных шифров полезны:

```bash
$ pip install pycipher          # Vigenere, Beaufort, Porta, Gronsfeld
$ python3 -m pycipher.beaufort  # интерактивно
```

Для определения длины ключа используй **индекс совпадений** (IC) и **тест Касиски** — они разобраны в `crypto-classical-statistics`. Для автоматизации подбора ключа удобен скрипт на Python с таблицей частот биграмм и оценкой по χ²-критерию: правильный ключ даёт минимальное отклонение распределения от языкового. Для running-key — crib-dragging и оценка ключа по словарю.

## Что мы теперь знаем

- Виженер, Бофор и variant Beaufort различаются формулой (`P+K`, `K-P`, `P-K`).
- Бофор — инволюция: шифрование и расшифровка совпадают.
- Porta симметричен и чуть устойчивее; Гронсфельд — цифровой ключ.
- Autokey/running-key убирают повтор ключа, но имеют свои слабости.
- VIC — композиция перестановки, подстановки и цифрового ключа.
