## Вопрос, с которого всё начинается

Решётки и хэш-подписи — не единственные кандидаты в пост-квантовую эру. Есть два «экзотических» семейства: схемы на **кодах, исправляющих ошибки** (McEliece), и схемы на **изогениях эллиптических кривых** (SIKE/SIDH). Первые — одни из самых старых и устойчивых кандидатов, вторые — самые компактные по ключам и при этом потерпевшие громкий крах. Разберём оба.

## Наш пример: McEliece на кодах Гоппа

**Код** — это набор векторов, между которыми можно находить и исправлять ошибки. **Код Гоппа** — специальный алгебраический код, для которого есть эффективный алгоритм декодирования (Алгоритм Паттерсона). Идея McEliece:

1. Возьми хороший код Гоппа с матрицей `G`, умеющий исправлять `t` ошибок.
2. Замаскируй его: `G' = S · G · P`, где `S` — обратимая перемешивающая матрица, `P` — матрица перестановки. Публичный ключ — `G'`, приватный — `(S, G, P)` и декодер.
3. Чтобы зашифровать биты `m`, считаешь `c = m·G' + e`, где `e` — случайный вектор веса `t`.
4. Расшифровать может только владелец: он снимает `P`, декодирует `G` (исправляя `e`) и снимает `S`. Без знания структуры задача декодирования произвольного линейного кода — **NP-трудная**.

Публичный ключ McEliece огромен (сотни килобайт), зато стойкость держится десятилетиями. Атака — не «решить NP-трудную задачу», а **восстановить структуру кода** из `G'` (Information Set Decoding даёт практический перебор). Именно поэтому параметры McEliece большие.

## Шаг 1: посчитаем игрушечный McEliece

Возьмём крошечный код Гоппа над `GF(2)` с параметрами `[n, k, t] = [7, 4, 1]` — код Хэмминга. Матрица `G` размером `4×7`, исправляет одну ошибку. Публикуем `G' = S·G·P`. Шифруем сообщение `m = 1011`:

```
c = m·G' ⊕ e,   e = 0001000   (одна ошибка)
```

Декодирование: снять `P`, декодировать, снять `S` — получить `m`. Это и есть «игрушечный McEliece»; в реальности `n ≈ 3488`, `t = 64`.

## Шаг 2: изогении и SIKE

**Изогения** — это отображение между двумя эллиптическими кривыми, сохраняющее их групповую структуру. Для кривой `E` и подгруппы `K` можно построить изогению `φ: E → E/K` с ядром `K`. Задача: по двум кривым `E` и `E'` найти изогению между ними — считается трудной (и для квантового компьютера тоже).

**SIDH** (Supersingular Isogeny DH) строит DH-обмен так: Алиса выбирает секретную изогению `φ_A` и публикует образ своей кривой и образы точек; Боб аналогично. Общий секрет — кривая `E_AB`, полученная применением обеих изогений. **SIKE** — это SIDH, обёрнутый в KEM. Ключи крошечные (сотни байт), что делало SIKE привлекательным.

## Шаг 3: крах SIKE

В 2022 году SIKE был взломан на классическом компьютере за минуты (атака Castryck–Decru). Причина — в SIDH публикуются **образы точек** вместе с кривой, и этой дополнительной информации достаточно, чтобы восстановить секретную изогению. Это классический урок: даже если «основная» задача трудна, лишние данные могут её обвалить. SIKE исключён из стандартизации; SIDH-подобные схемы пересматриваются.

## Полный прогон

В лабе дан `mceliece.txt` с публичной матрицей `G'` и шифротекстом `c`, и скрипт `decode.py`. Скрипт декодирует игрушечный McEliece и печатает сообщение:

```
$ cat mceliece.txt
n = 7  k = 4  t = 1
G_prime = [[1,0,1,0,1,1,0], ...]
c = [1,0,1,1,0,0,1]

$ python3 decode.py
error vector e = [0,0,0,1,0,0,0]
message m = nto{mc3l13c3_g0pp4_d3c0d3d}
```

Сообщение здесь — флаг; студент видит, что декодирование реально исправляет ошибку.

## Если не сработало

Если декодирование даёт мусор, проверь `t` — сколько ошибок реально внесено. Если матрица `G'` не декодируется как код Гоппа, возможно, это не McEliece, а общая задача декодирования (тогда нужен ISD). Для SIDH-задач ищи утечку образов точек — именно она ломает SIKE.

## Куда дальше

Дальше — квантовое распределение ключей (QKD): BB84, физический, а не математический способ обмена секретом. Запомни главное: у пост-квантовой криптографии много семейств, и «экзотические» схемы могут пасть не из-за основной задачи, а из-за лишней утечки.

## Где пригодится

- **CTF Crypto:** задачи на коды, декодирование и изогении.
- **Bug bounty:** редкие баги в KEM-реализациях.
- **Пентест:** оценка пост-квантовой готовности.
- **Работа:** выбор KEM для долгосрочной защиты данных.
