## Что такое LFSR

**LFSR** (Linear Feedback Shift Register) — регистр из `L` бит, который сдвигается на 1 вправо каждый такт, а новый бит вычисляется как XOR (линейная функция) от некоторых бит регистра:

```
b_new = c1·b0 ⊕ c2·b1 ⊕ ... ⊕ cL·b_{L-1}
```

Коэффициенты `c1..cL` задают **полином обратной связи** `C(x) = 1 + c1·x + ... + cL·x^L`. LFSR генерирует битовую последовательность (keystream), которая XORится с текстом — это простейший потоковый шифр.

Свойства:

- Период максимален (`2^L − 1`) при **примитивном** полиноме.
- Регистр линеен: по любому числу выходных бит можно восстановить состояние.
- Аппаратно очень дёшев (пара триггеров и XOR) — поэтому встречается в железе/IoT.

## Почему LFSR нельзя использовать напрямую

Линейность — фатальная слабость. По **2L последовательным битам** выхода можно восстановить и полином, и состояние, а затем **предсказать всю остальную последовательность**. Это делает LFSR бесполезным как самостоятельный шифр. Поэтому в реальных потоковых шифрах LFSR комбинируют **нелинейно**.

## Berlekamp–Massey

Алгоритм Берлекэмпа–Мэсси находит **минимальный LFSR** (наименьшей длины), порождающий данную последовательность. Он берёт `2L` бит и восстанавливает полином обратной связи. **Линейная сложность** последовательности — длина минимального LFSR; для чистой LFSR длины `L` она равна `L`.

```python
def berlekamp_massey(bits):
    C = [1]; B = [1]; L = 0; m = -1
    for n in range(len(bits)):
        d = bits[n]
        for i in range(1, L+1):
            d ^= C[i] & bits[n-i]
        if d == 1:
            T = C[:]
            shift = n - m
            if len(C) < len(B) + shift:
                C += [0]*(len(B) + shift - len(C))
            for j in range(len(B)):
                C[j+shift] ^= B[j]
            if 2*L <= n:
                L = n + 1 - L; B = T; m = n
    return L, C

# пример: LFSR длины 4 -> BM найдёт L=4 по 8 битам
```

## Восстановление LFSR из задачи

Если задача даёт поток бит и говорит, что это LFSR:

1. **Соберите >= 2L бит** (если `L` неизвестен — берите с запасом).
2. **Примените BM** — получите `L` и полином.
3. **Восстановите состояние** из первых `L` бит.
4. **Сгенерируйте продолжение** и расшифруйте остальное.

```python
# после BM: симулируем LFSR с найденным полиномом
def lfsr_step(state, taps):
    fb = sum(state[i] for i in taps) % 2
    return state[1:] + [fb], state[0]
```

## Нелинейные комбинации и корреляционные атаки

Реальные генераторы комбинируют несколько LFSR через нелинейную функцию `f`. Примеры:

- **Geffe generator:** выход = `(a ∧ b) ⊕ (¬a ∧ c)` — выбирает между LFSR `b` и `c` по биту `a`.
- **Shrunk generator:** тактирует один LFSR по биту другого (нерегулярно).
- **A5/1 (GSM):** три LFSR с мажоритарным тактированием.
- **Trivium:** 288-битное состояние с нелинейной обратной связью (современный, стойкий).

**Корреляционная атака** эксплуатирует тот факт, что выход `f` коррелирует с одним из входных LFSR. Зная корреляцию `p ≠ 1/2`, атакующий подбирает состояние «связанного» LFSR (перебор `2^L`), проверяя гипотезу по потоку, и восстанавливает его независимо от остальных. Для Geffe корреляция выхода с `b` и `c` равна `1/2 + 1/4`, что делает атаку практичной.

**Алгебраические атаки** выражают выход как систему полиномиальных уравнений над GF(2) и решают её (линеаризация, XL, Gröbner).

## Практический пример: атака на Geffe

```python
# Если выход коррелирует с LFSR b (вероятность 3/4), то для каждого
# кандидата состояния b проверяем: доля совпадений с выходом > 1/2
best = None
for seed in range(2**L):
    gen = lfsr(seed, taps_b)
    matches = sum(next(gen) == out[i] for i in range(N))
    if matches / N > 0.6:
        best = seed; break
print("recovered b state:", best)
```

После восстановления одного LFSR остальные находятся проще.

## Частые ошибки

- **Мало бит.** BM нужно `2L`; берите с запасом.
- **Путать линейную сложность и длину LFSR** для нелинейных генераторов.
- **Считать, что комбинация LFSR автоматически стойка.** Корреляция — уязвимость.
- **Забыть про нерегулярное тактирование.** Shrunk/A5-1 сложнее.
- **Игнорировать полином.** Примитивный → максимальный период.
- **Неверная раскладка бит** (LSB/MSB) ломает восстановление.

## A5/1 и современные генераторы

**A5/1** (GSM) — три LFSR (19/22/23 бита) с **мажоритарным тактированием**: на каждом такте сдвигаются регистры, у которых средний бит совпадает с мажоритарным. Нелинейность слабая, и A5/1 ломается (атаки Biham–Dunkelman, rainbow tables). **A5/2** (экспортный) сломан полностью.

**Trivium** — современный (eSTREAM) потоковый шифр на 288-битном состоянии, с нелинейной обратной связью; стойкий, используется в аппаратуре.

**Grain, Rabbit, Salsa20/ChaCha20** — другие современные потоковые шифры.

## Алгебраические атаки

Выход нелинейного генератора выражается как система **полиномиальных уравнений** над GF(2) от начальных состояний. Методы решения:

- **Линеаризация:** заменить мономы новыми переменными → линейная система.
- **XL (eXtended Linearization):** расширенная система с умножением на мономы.
- **Gröbner basis:** привести систему к треугольному виду.
- **SAT/CryptoMiniSat:** свести к булевой выполнимости.

На CTF для маленьких состояний эти методы решают задачу «в лоб».

## Разбор: восстановление состояния по выходу

```python
# 1. Собираем >= 2L бит выхода
out = [int(b) for b in "10110..."]
# 2. Berlekamp-Massey
L, poly = berlekamp_massey(out)
# 3. Восстанавливаем начальное состояние из первых L бит
state = out[:L]
taps = [i for i, c in enumerate(poly) if c == 1]
# 4. Предсказываем и расшифровываем
def step(s):
    fb = sum(s[i] for i in taps) % 2
    return s[1:] + [fb]
ks = state[:]
for _ in range(len(ciphertext)):
    state = step(state)
    ks.append(state[-1])
pt = bytes(c ^ k for c, k in zip(ciphertext, ks))
print(pt)
```

## Примитивные полиномы и период

Полином обратной связи `C(x)` определяет период LFSR. Если `C(x)` **примитивен** (неприводим и порождает мультипликативную группу), период максимален `2^L − 1` (все ненулевые состояния). Таблицы примитивных полиномов есть в литературе; для `L` до 32 их легко найти.

## Разбор: сколько бит нужно

Теорема: для восстановления LFSR длины `L` нужно **`2L`** последовательных бит (для нелинейного генератора — больше). Если бит меньше, решение неединственно. Если задача даёт «недостаточно» бит — возможно, у вас несколько генераторов или известна структура.

## Шифрование с LFSR

Простейший «шифр»: keystream = выход LFSR, `C = P ⊕ keystream`. Ломается за `2L` бит known-plaintext (BM) или просто по выходу, если он наблюдается. Поэтому в реальных системах LFSR всегда комбинируют (см. A5/1, Trivium) или используют в фильтрующих генераторах с нелинейной функцией.

## Как не застрять

- **Определите тип генератора** (один LFSR, комбинация, нерегулярный).
- **Соберите достаточно бит** (≥ 2L).
- **Примените BM** — для чистой LFSR это всё.
- **Ищите корреляцию** с одним из входов для комбинаций.
- **Перебирайте состояние связанного LFSR** и проверяйте гипотезу.
- **Проверяйте предсказание** на отложенных битах.
