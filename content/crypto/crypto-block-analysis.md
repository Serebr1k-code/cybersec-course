## Вопрос, с которого всё начинается

До сих пор мы атаковали **применение** AES: ECB без сцепления, CTR с повторным
nonce, GCM с повторным nonce. Но что, если шифр используют правильно, а задача
всё равно есть? На CTF часто дают **самодельный блочный шифр** — маленький, на
2–4 раундах, со своим S-box. Ключ не утёк, режим корректный. Вопрос: можно ли
сломать **сам шифр**, зная только его структуру и умея шифровать произвольные
блоки?

Да, и для этого есть классический инструмент — **дифференциальный криптоанализ**.
Ниже мы построим маленький SPN-шифр, найдём в его S-box слабое место и
**восстановим последний подключ**, не зная ключа.

## Наш пример: самодельный 3-раундовый SPN

Шифр работает с блоком 8 бит (два ниббла). Каждый раунд — это три шага:

1. **XOR с подключом** — складываем состояние с куском ключа.
2. **Substitution** — заменяем каждый ниббл по таблице **S-box**.
3. **Permutation** — перемешиваем биты (у нас — перестановка `P`).

S-box — это таблица `4 бита → 4 бита`, единственный **нелинейный** элемент:
именно она делает шифр шифром. Наша:

```
S = [0xE,0x4,0xD,0x1,0x2,0xF,0xB,0x8,0x3,0xA,0x6,0xC,0x5,0x9,0x0,0x7]
```

Три раунда, четыре подключа `k0..k3`. Последний раунд заканчивается **XOR с
`k3`** — именно этот ключ мы и будем восстанавливать. Модель угроз —
**chosen-plaintext**: мы можем шифровать любые блоки и видеть шифротексты.

## Шаг 1: DDT — таблица «слабых» разностей S-box

Ключевая идея дифференциального анализа: смотреть не на отдельные тексты, а на
**разности** — XOR между двумя входами. Если подать на S-box два входа,
отличающихся на `Δin`, то их выходы тоже отличаются на какую-то `Δout`. Для
«идеального» S-box каждая `Δout` равновероятна, но у реальных S-box есть
**смещения**.

Строим **DDT** (Difference Distribution Table): `DDT[Δin][Δout]` — сколько входов
`x` дают `S(x) ⊕ S(x ⊕ Δin) = Δout`.

```python
DDT = [[0]*16 for _ in range(16)]
for x in range(16):
    for din in range(16):
        DDT[din][S[x] ^ S[x ^ din]] += 1
```

Смотрим на максимум вне нулевой разности:

```
DDT: максимум вне нулевой разности = 8/16 (вероятность 8/16 = 0.5)
```

У нашего S-box есть переходы с вероятностью **1/2** вместо «честной» 1/16. Это и
есть «след», по которому прослеживается ключ.

## Шаг 2: строим разностную характеристику через раунды

**Разностная характеристика** — это цепочка разностей по раундам:

```
Δ0 → Δ1 → ... → Δr
```

с вероятностью `p = Π p_i` (вероятности переходов перемножаются, потому что
раунды независимы). Перестановка `P` линейна, поэтому она просто переносит
разность на новые позиции. Мы перебираем входные разности с одним активным
нибблом и для каждого шага берём самый вероятный переход из DDT. Лучшая
двухраундовая характеристика:

```
характеристика: ΔP=0x0b -> Δu3=0x14, теоретическая prob=0.1875
```

Здесь `Δu3` — предсказанная разность **на входе последнего S-слоя** (после двух
раундов). Смысл такой: если два открытых текста отличаются на `ΔP=0x0b`, то с
вероятностью ~19% разность перед последним S-слоем будет ровно `0x14`.

## Шаг 3: атакуем последний подключ

Теперь фокус. Шифротекст — это `c = S(u3) ⊕ k3`, где `u3` — вход последнего
S-слоя. Мы **не знаем** `k3`, но можем его **перебрать**: для каждого кандидата
`k` считаем `u3 = S⁻¹(c ⊕ k)`. Для правильного `k` разность `Δu3` между парой
будет совпадать с предсказанной `0x14` **часто**, для неправильных — редко
(случайно). Считаем попадания и берём лучшего кандидата:

```python
def guess(pos, dtarget):
    best = (None, -1)
    for k in range(16):
        kk = (k << 4) if pos == 0 else k
        score = sum(1 for (p,c,p2,c2) in pairs
                    if (((isl(c^kk) ^ isl(c2^kk)) >> (4 if pos==0 else 0)) & 0xF) == dtarget)
        if score > best[1]: best = (k, score)
    return best
```

## Полный прогон от начала до конца

```
$ python3 diff_demo.py
DDT: максимум вне нулевой разности = 8/16 (вероятность 8/16 = 0.5)
характеристика: ΔP=0x0b -> Δu3=0x14, теоретическая prob=0.1875
эмпирически Δu3 совпал в 383/2000 = 0.192 пар
k3 старший ниббл = 9  (score 413/2000)
k3 младший ниббл = B  (score 470/2000)
истинный k3 = 0x9b
```

Обрати внимание на разницу счётов: правильные нибблы набирают 413 и 470
попаданий из 2000 (~20%), а любой неправильный — около 125 (случайные 1/16).
Контраст огромный, и оба ниббла `k3` восстановлены: `9` и `B`, то есть `0x9B`.
Мы сломали последний раунд, не зная ключа — только по статистике разностей.

## Что мы теперь знаем

- Блочный шифр (SPN) = XOR с подключом + нелинейный S-box + линейная перестановка.
- Дифференциальный анализ смотрит на **разности** (XOR) пар текстов и их
  вероятности; S-box с большим максимумом в DDT слабее.
- Характеристика — цепочка разностей по раундам; вероятности перемножаются.
- Атакуют последний раунд: перебирают подключ, частично расшифровывают и ищут
  предсказанную разность — правильный ключ «выстреливает» статистически.
- Чем больше раундов и меньше максимум DDT, тем атака дороже — поэтому у
  настоящего AES S-box даёт максимум `4/256 = 1/64`, а раундов десять.
- Полный AES-128 дифференциальным анализом **не ломается**: стратегия Wide Trail
  гарантирует минимум 25 активных S-box на 4 раунда.

## Дифференциальный против линейного

Линейный анализ — «зеркальный» метод: вместо разностей ищут **линейные
приближения** `a·P ⊕ b·C = c·K`, выполняющиеся с вероятностью `p ≠ 1/2`; их
смещение `ε = |p − 1/2|` накапливается по раундам (лемма Мацуи).

| Аспект | Дифференциальный | Линейный |
|---|---|---|
| Что анализирует | разности входов/выходов (XOR) | линейные комбинации битов |
| Таблица S-box | DDT | LAT (Linear Approximation Table) |
| Метрика | вероятность перехода `Δin→Δout` | смещение `ε = \|p−1/2\|` |
| Ключевая лемма | вероятности перемножаются | смещения накапливаются |
| Данные | `~1/p` выбранных пар | `~1/ε²` известных текстов |

Практическое правило: есть **chosen-plaintext** — начинайте с дифференциального
анализа; даны только готовые пары — линейный может оказаться удобнее.

## Почему DDT — рабочий инструмент

Дифференциальный криптоанализ опирается на наблюдение: у S-box (нелинейной подстановки) некоторые **входные разности** переходят в **выходные разности** чаще остальных. Таблица DDT (Difference Distribution Table) считает, сколько раз каждая пара `(Δвх, Δвых)` встречается. Если для некоторой разности `Δвх` один выход `Δвых` случается, скажем, в 4 раза чаще среднего, у нас есть **разностная характеристика** — предсказуемое поведение через раунд.

Соединяя характеристики раундов, получаем «след»: при фиксированной входной разности `ΔP` выходная разность `ΔC` после `r−1` раундов принимает нужное значение с вероятностью `p`, заметно выше `1/2^n`. Тогда последний раунд откатывают: для каждой гипотезы последнего подключa частично расшифровывают шифротексты и проверяют, попадает ли разность в предсказанную. Правильная гипотеза даёт максимальный счётчик. Вероятность характеристики падает экспоненциально с числом раундов — поэтому дифференциалы бьют редуцированные шифры (DES за 16 раундов, AES за 4–6).

Линейный криптоанализ — зеркало: вместо разностей берут **линейные приближения** (XOR входных/выходных бит), которые выполняются с вероятностью, отличной от `1/2`. Отклонение (`bias`) накапливается по раундам через лемму о накоплении, и по большому числу пар открытый-шифротекст восстанавливают бит ключа по знаку смещения.

## Если не сработало

- **Характеристика не выделяется.** Вероятность слишком мала для доступного числа пар; берите более короткий (редуцированный) шифр или более сильную характеристику.
- **Мало данных.** Число пар растёт как `1/p²` (для линейного — `1/bias²`); при `p = 2^{-20}` нужны миллионы пар.
- **Неверный откат последнего раунда.** Убедитесь, что правильно применяете инверсию S-box и порядка операций; ошибка в индексе байта даёт шум.
- **Шифр с хорошим S-box.** AES имеет сильные характеристики против дифференциалов; для него нужны 4-раундовые интегралы (Square), а не классический дифференциал.
- **Путаница DDT и LAT.** Для дифференциалов стройте DDT, для линейного — LAT (Linear Approximation Table); это разные таблицы.

## Частые вопросы

**Сколько раундов ломает дифференциальный анализ?** Для DES — 16 (полный) при определённых условиях; для AES классический дифференциал покрывает 4 раунда, дальше вероятность падает.

**Что такое усечённый дифференциал?** Характеристика, где фиксирована не точная разность, а только то, что байт активен/пассивен; удобно для байт-ориентированных шифров вроде AES.

**Как это связано с интегральным анализом?** Интегральный (Square) — частный случай высокопорядкового дифференциала: суммирование по всем значениям активных байт эквивалентно дифференциалу высокого порядка.

## Куда дальше

Мы научились статистически атаковать сам блочный шифр. В следующем уроке
(`crypto-integral-cryptanalysis`) мы разберём **интегральную (Square) атаку** —
технику, специфичную для AES-структуры: набор из 256 текстов, где байт пробегает
все значения, сохраняет «баланс», и это выдаёт последний раунд. А главное
запомни: **дифференциальный анализ — это статистика разностей; правильный подключ
отличается от неправильных резким всплеском попаданий**.

- **Академия** — дифференциальные и линейные атаки — классика литературы.
