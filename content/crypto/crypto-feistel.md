Feistel-сеть — конструкция, которая делает блочный шифр обратимым, **не требуя обратимости** round-функции: достаточно, чтобы она была любой (в том числе необратимой). Именно так устроен DES, и именно поэтому в CTF так много «самодельных» Feistel-шифров с ослабленными раундами, которые ломаются структурно, а не перебором ключа. Эта глава — устройство, DES и, главное, практические атаки на редуцированные и небрежные реализации.

## Устройство Feistel-сети

Блок делится на две половины `(L0, R0)`. Раунд `i`:

```
L_{i+1} = R_i
R_{i+1} = L_i XOR F(R_i, K_i)
```

где `F` — произвольная (возможно необратимая) round-функция, `K_i` — раундовый ключ. **Обратимость** достигается тем, что раунд сам себе обратен при обратном порядке ключей:

```
L_i = R_{i+1} XOR F(L_{i+1}, K_i)
R_i = L_{i+1}
```

Свойства: одна и та же схема (с `F`) используется и для шифрования, и для расшифрования — меняется только порядок `K_i`. AES, напротив, — substitution-permutation network (SPN), где каждый слой обязан быть обратимым. Из-за необратимости `F` Feistel-сети позволяют строить `F` из необратимых примитивов (например, криптографической хэш-функции).

## DES и key schedule

DES — 16-раундовая Feistel-сеть над 64-битным блоком (56-битный ключ + 8 бит чётности):

- **F** = расширение `E` (32→48), XOR с `K_i`, 8 S-box (6→4), перестановка `P`.
- **Key schedule:** из 64-битного ключа выбором бит (PC-1) получают 56 бит, делят на `C, D` по 28, циклически сдвигают (на 1 или 2 бита по раунду) и через PC-2 получают `K_i`.

S-box — единственный нелинейный элемент; всё остальное линейно над GF(2). Именно S-box делает DES стойким к линейному/дифференциальному анализу при полных 16 раундах. Редуцированные раунды — основная цель CTF.

## Атаки на Feistel

- **Редуцированные раунды.** 1–4 раунда часто ломаются напрямую: выражаем `R_i`/`L_i` через вход, выход и ключи, решаем систему. Для 1 раунда ключ восстанавливается прямо из пары.
- **Slide attack.** Если все раундовые ключи одинаковы (или расписание «зацикливается»), шифр распадается на «сдвинутые» копии — атака находит слайды по парам и восстанавливает ключ. Защита — различающиеся `K_i`.
- **Differential cryptanalysis.** Работает по вероятностным характеристикам S-box; на полном DES требует `2^43`–`2^47` пар, на редуцированном — намного меньше.
- **Linear cryptanalysis.** Линейные аппроксимации S-box; для полного DES ~`2^43` известных пар.
- **Related-key attacks.** Если `F` зависит от ключа предсказуемо — атака на «родственные» ключи.
- **MITM на 2 раунда/двойной Feistel.** См. `crypto-mitm`.
- **Integral/square (для SPN и некоторых Feistel)** — суммирование по всему пространству входов.

## Редуцированные Feistel в CTF

Типовые условия и подходы:

- «Шифр на 4 раундах» — инверсия раундов и подбор `K_i` по парам.
- «Round-функция — XOR с ключом» (нет S-box) — полностью линейна, ключ восстанавливается Гауссом над GF(2).
- «Round-функция — `(x + K) mod 2^32`» — ARX-структура, ломается Z3/SMT.
- «Ключи повторяются» — slide attack.
- «Дана возможность зашифровать/расшифровать произвольное» — оракул + дифференциалы.
- «Число раундов чётное, половины симметричны» — встреча посередине.

## Инструменты и код

```python
def feistel_encrypt(block, keys, F, half=32):
    mask = (1 << half) - 1
    L, R = block >> half, block & mask
    for K in keys:
        L, R = R, (L ^ F(R, K)) & mask
    return (L << half) | R

def feistel_decrypt(block, keys, F, half=32):
    mask = (1 << half) - 1
    L, R = block >> half, block & mask
    for K in reversed(keys):
        L, R = (R ^ F(L, K)) & mask, L
    return (L << half) | R
```

## Разобранный пример: 1-раундовый Feistel

Шифр: один раунд, `F(R, K) = R XOR K`. Дано `(P, C)` с `P = (L0, R0)`:

```
C = (L1, R1) = (R0, L0 XOR R0 XOR K)
```

Отсюда `K = L0 XOR R0 XOR R1` — ключ восстанавливается из одной пары напрямую. Для 2–4 раундов аналогично выражаем через промежуточные значения и подбираем `K_i` по парам (или Z3 для ARX). Для линейного Feistel над GF(2) строится матрица раундов и решается как СЛАУ.

## Варианты: unbalanced, generalized, SPN

- **Unbalanced Feistel** — половины разной длины (Format-Preserving Encryption, FF1/FF3).
- **Generalized Feistel** — `k` ветвей вместо двух; используется в CAST, CLEFIA.
- **Type-1/2/3** — разные способы перемешивания ветвей.
- **SPN (AES)** — не Feistel; обратимость каждого слоя обязательна. Полезно не путать.

## Частые ошибки и тупики

- **Забыть порядок ключей при расшифровании.** Нужен `reversed(keys)`.
- **Перепутать L и R.** Классическая ошибка: `L_{i+1}=R_i`, а не наоборот.
- **Считать round-функцию обратимой.** Feistel работает и с необратимой `F` — не пытайтесь её инвертировать.
- **Не заметить повтор ключей.** Slide attack остаётся незамеченной.
- **Игнорировать S-box.** Если он слабый (линейный/маленький), работают differential/linear, а не перебор.
- **Забыть маску половины.** Без `& mask` ARX-раунд «уезжает» за 32 бита.
- **Путать шифрование и расшифрование DES.** `pycryptodome` даёт оба, но `F` в DES-расшифровании та же.

## Что дальше (decision)

1. 1–2 раунда, линейная `F` → решайте напрямую / СЛАУ над GF(2).
2. ARX-раунды (`+`, XOR, rotate) → Z3.
3. Одинаковые раундовые ключи → slide attack.
4. 4+ раунда с S-box → differential/linear (нужно много пар) или перебор редуцированного ключа.
5. Двойной Feistel / 2DES → `crypto-mitm`.
6. Полный DES и ключ неизвестен → перебор 56 бит (hashcat/специализированный софт), см. `crypto-hashcracking`.

## Справочная таблица

| Свойство | Feistel | SPN (AES) |
|----------|---------|-----------|
| Обратимость `F` | не нужна | обязательна |
| Раунд | половина + `F` | полный блок |
| Пример | DES, 3DES, Blowfish | AES, PRESENT |
| Атаки | slide, differential, MITM | differential, integral |

## Полный разбор: 4-раундовый Feistel через Z3

Пусть шифр — 4 раунда Feistel над 32-битными половинами с round-функцией `F(R, K) = ((R << 3) ^ K) mod 2^32` и четырьмя независимыми ключами `K0..K3`. Даны две пары `(P, C)`. Кодируем раунды в Z3:

```python
from z3 import BitVec, Solver, sat

Ks = [BitVec(f'k{i}', 32) for i in range(4)]
s = Solver()

def enc(l0, r0):
    L, R = l0, r0
    for K in Ks:
        L, R = R, L ^ ((R << 3) ^ K)
    return L, R

for (p, c) in known_pairs:
    L0 = BitVecVal(p >> 32, 32); R0 = BitVecVal(p & 0xffffffff, 32)
    L, R = enc(L0, R0)
    s.add(L == BitVecVal(c >> 32, 32), R == BitVecVal(c & 0xffffffff, 32))

print(s.check())          # sat -> модель даёт ключи
if s.check() == sat:
    m = s.model()
    print([m[K].as_long() for K in Ks])
```

Двух пар обычно достаточно. Для большего числа раундов и S-box Z3 «тонет» — тогда идут differential/linear-атаки. Для линейных round-функций (без S-box) быстрее решить СЛАУ над GF(2) через Sage.
