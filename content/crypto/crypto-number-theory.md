## Вопрос, с которого всё начинается

Всё, что мы разбирали до сих пор, работало с байтами и буквами. Но RSA, Diffie-Hellman и ECC — это **целые числа и модульная арифметика**. Без неё формула `d = e⁻¹ mod φ(n)` выглядит как заклинание. Разберём её на одном сквозном примере и заодно соберём весь нужный инструментарий.

## Наш пример

Пусть у нас есть маленький RSA-ключ: два простых числа `p = 61`, `q = 53`. Из них строится модуль `n = p·q = 3233`. Открытая экспонента `e = 17`. Чтобы расшифровать сообщение, нужно найти **секретную экспоненту** `d` — число, обратное `e` по модулю `φ(n)`. Вопрос: что такое `φ(n)` и как вообще считать «обратное по модулю»?

## Шаг 1: модульная арифметика

Модуль `m` — это «арифметика остатков»: считаем как обычно, но результат берём по остатку от деления на `m`. Например, `17 · 2753 = 46801`, а `46801 mod 3120 = 1`. В Python это оператор `%`:

```python
print((17 * 2753) % 3120)   # 1
print(3233 % 61)            # 0, потому что 61 делит 3233
```

Два числа **сравнимы по модулю `m`**, если их разность делится на `m`. Запись `a ≡ b (mod m)`. Вся арифметика RSA — это уравнения такого вида.

## Шаг 2: НОД и алгоритм Евклида

**Наибольший общий делитель (НОД)** — самое большое число, делящее оба без остатка. Он нужен постоянно: и для сокращения дробей, и для проверки, что обратный элемент вообще существует.

```python
import math
print(math.gcd(48, 18))   # 6
```

Быстрый способ считать НОД — **алгоритм Евклида**: `gcd(a, b) = gcd(b, a mod b)`, пока второе число не станет нулём. Он логарифмически быстрый даже для чисел в тысячи бит.

Нам понадобится его расширенная версия — **расширенный алгоритм Евклида**. Он возвращает не только НОД, но и коэффициенты `x, y` такие, что `a·x + b·y = gcd(a, b)`:

```python
def egcd(a, b):
    if b == 0:
        return (a, 1, 0)
    g, x, y = egcd(b, a % b)
    return (g, y, x - (a // b) * y)

print(egcd(240, 46))    # (2, -9, 47)   => 240*(-9) + 46*47 = 2
print(egcd(17, 3120))   # (1, -367, 2)  => 17*(-367) + 3120*2 = 1
```

Обрати внимание на вторую строку: НОД равен **1**. Это и есть условие существования обратного элемента.

## Шаг 3: обратный элемент по модулю

**Обратный элемент** `a⁻¹ mod m` — это число `x`, при котором `a·x ≡ 1 (mod m)`. Существует он тогда и только тогда, когда `gcd(a, m) = 1`.

Из `egcd(17, 3120) = (1, -367, 2)` следует `17·(−367) + 3120·2 = 1`, то есть `17·(−367) ≡ 1 (mod 3120)`. Значит, `−367 ≡ 3120 − 367 = 2753`. Проверим:

```python
print(pow(17, -1, 3120))   # 2753  — встроенный обратный элемент
print((17 * 2753) % 3120)  # 1
```

Итого секретная экспонента нашего примера: `d = 2753`. Именно это число вычисляет RSA-генератор ключей, и именно его мы ищем в атаках, когда знаем `φ(n)`.

## Шаг 4: функция Эйлера и теоремы

`φ(n)` — **функция Эйлера**, количество чисел от 1 до `n`, взаимно простых с `n`. Для нашего `n = 61·53`:

```python
from sympy import totient
print(totient(3233))   # 3120
```

Для произведения двух простых есть простая формула: `φ(p·q) = (p−1)(q−1) = 60·52 = 3120`. Отсюда сразу видно, почему RSA держится на секретности `p` и `q`: кто знает разложение `n`, тот знает `φ(n)`, а значит и `d`.

Две теоремы, которые встречаются в задачах постоянно:

- **Малая теорема Ферма:** если `p` простое и `gcd(a, p) = 1`, то `a^(p−1) ≡ 1 (mod p)`.
- **Теорема Эйлера:** если `gcd(a, n) = 1`, то `a^φ(n) ≡ 1 (mod n)`.

Проверим вторую на нашем `n`:

```python
print(pow(2, 3120, 3233))   # 1
```

## Шаг 5: китайская теорема об остатках (CRT)

**CRT** говорит: если модули взаимно просты, систему сравнений можно свести к одному сравнению по произведению модулей. Пусть

```
x ≡ 2 (mod 3)
x ≡ 3 (mod 5)
x ≡ 2 (mod 7)
```

Тогда существует единственное решение по модулю `3·5·7 = 105`:

```python
from sympy.ntheory.modular import crt
print(crt([3, 5, 7], [2, 3, 2]))   # (23, 105)
```

Значит, `x = 23`. Зачем это в крипто? Во-первых, RSA-CRT ускоряет расшифровку в разы. Во-вторых, CRT — ключ к **атакам по ошибкам** (fault attacks): если устройство ошиблось при вычислении по одному модулю, сравнив два результата, можно восстановить простой множитель `n`.

## Шаг 6: дискретный логарифм

Симметричная часть — про `a·x ≡ b`. Асимметричная — про `a^x ≡ b (mod p)`. Задача «найти `x` по известным `a`, `b`, `p`» называется **дискретным логарифмом** (DLP). Для маленьких чисел она решается быстро:

```python
from sympy.ntheory.residue_ntheory import discrete_log
print(discrete_log(13, 8, 2))   # 3, потому что 2^3 = 8 (mod 13)
```

На DLP держатся Diffie-Hellman и ECC: возвести в степень легко, а «развернуть» — вычислительно тяжело. Именно эту сложность мы будем ломать в уроках `crypto-discrete-log` и `crypto-diffie-hellman`.

## Быстрые рецепты на Python

Держи под рукой шпаргалку — эти строки закрывают большинство рутинных операций:

```python
import math
from sympy import factorint, totient, nextprime, mod_inverse

print(pow(17, -1, 3120))        # 2753  — обратный элемент
print(math.gcd(240, 46))        # 2     — НОД
print(factorint(3233))          # {53: 1, 61: 1} — факторизация
print(totient(3233))            # 3120  — функция Эйлера
print(mod_inverse(17, 3120))    # 2753  — то же через sympy
print(nextprime(100))           # 101   — следующее простое
```

Правило: сначала попробуй решить задачу **встроенными функциями**, и только если нужна нестандартная атака (решётки, Coppersmith) — переходи к Sage.

## Что мы теперь знаем

- Модульная арифметика — это остатки от деления; запись `a ≡ b (mod m)`.
- НОД считается алгоритмом Евклида; расширенный Евклид даёт коэффициенты Безу.
- Обратный элемент `a⁻¹ mod m` существует при `gcd(a, m) = 1`; в Python — `pow(a, -1, m)`.
- `φ(p·q) = (p−1)(q−1)`; отсюда `d = e⁻¹ mod φ(n)` — сердце RSA.
- CRT сводит систему сравнений к одному по произведению модулей.
- Дискретный логарифм `a^x ≡ b` — основа DH и ECC.

## Возведение в степень: почему `pow` быстрее наивного цикла

RSA оперирует числами в тысячи бит, и «в лоб» умножать `a` сам на себя `d` раз невозможно — при 2048-битной экспоненте это ~10^600 умножений. Работает **бинарное возведение в степень** (square-and-multiply): показатель раскладывается по битам, и на каждом шаге выполняется квадрат, а при единичном бите — ещё и умножение. Сложность — `O(log d)` умножений вместо `O(d)`.

```python
def modexp(a, e, m):
    r = 1
    a %= m
    while e:
        if e & 1:          # бит показателя установлен
            r = (r * a) % m
        a = (a * a) % m    # квадрат
        e >>= 1
    return r

print(modexp(4, 13, 497))   # 445
print(pow(4, 13, 497))      # 445  — то же самое
```

Python-функция `pow(a, e, m)` реализует именно этот алгоритм, причём на C. Практический вывод: **никогда не пиши `a ** e % m`** — при больших `e` интерпретатор сначала построит гигантское число `a ** e` и только потом возьмёт остаток, съев всю память. Трёхаргументный `pow` считает по модулю на каждом шаге.

Отдельно держи в голове **trapdoor-асимметрию**: прямой ход (`a → a^x mod p`) быстрый, обратный (DLP) — медленный. Это и есть односторонняя функция. Но если модуль `p` гладкий (все множители `p−1` малы), DLP решается алгоритмом Полига–Хеллмана за секунды — типичная CTF-задача.

## Пределы факторизации: что реально ломается

Стойкость RSA держится на сложности факторизации `n = p·q`. Полезно знать практические границы:

| Метод | Когда работает | Сложность |
|-------|----------------|-----------|
| Пробный перебор | множитель ≤ 10^6 | `O(√p)` |
| Поллард `p−1` | `p−1` гладкое | зависит от гладкости |
| Поллард rho | до ~10^25 | `O(n^1/4)` |
| Метод Ферма | `p ≈ q` (близкие) | `O(p−q)` |
| Квадратичное решето | до ~100 бит | субэкспоненциально |
| GNFS | 512–829 бит (историч.) | субэкспоненциально |

```python
from sympy import factorint
from sympy.ntheory import isprime

# Разница простых мала -> Ферма ломает мгновенно
def fermat(n):
    a = int(n ** 0.5) + 1
    while True:
        b2 = a * a - n
        b = int(b2 ** 0.5)
        if b * b == b2:
            return a - b, a + b
        a += 1

p, q = 1000003, 1000033           # близнецы
n = p * q
print(fermat(n))                  # (1000003, 1000033)
```

Мораль для CTF: прежде чем брать тяжёлые решётки, проверь три дешёвые гипотезы — **малый простой множитель**, **гладкое `p−1`** и **близкие `p, q`**. Большинство учебных `n` падают уже на них. Решето Эратосфена (`sympy.primerange`) даёт быстрый доступ ко всем простым до границы и часто закрывает вопрос «найди простое такое, что…».
