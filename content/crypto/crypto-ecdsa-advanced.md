ECDSA/EdDSA стойки ровно настолько, насколько стойка **задача дискретного логарифма** на выбранной кривой. Если порядок группы «гладкий», кривая аномальная, или embedding degree мал — ECDLP решается быстро, и подпись становится небезопасной. В CTF это целый класс задач: дана «странная» кривая (или только подписи), нужно восстановить приватный ключ. Эта глава — три главные атаки и восстановление параметров по подписям.

## ECDLP и когда он ломается

ECDLP: по точкам `P` и `Q = kP` найти `k`. Для «хороших» кривых (P-256, secp256k1) лучший метод — Pollard's rho за `O(√n)`, то есть ~2^128. Он ломается, когда:

- **порядок группы гладкий** (`n = Π p_i^{e_i}` с малыми `p_i`) — Pohlig-Hellman;
- **кривая аномальная** (`#E = p`) — Smart's attack (полиномиально);
- **embedding degree мал** — MOV переносит ECDLP в конечное поле;
- **параметры известны лишь частично** — восстановление по подписям.

## Pohlig-Hellman

Если порядок `n` разлагается на малые простые `p_i`, ECDLP сводится к ECDLP в подгруппах порядка `p_i` и собирается по CRT:

1. Разложить `n = Π p_i^{e_i}`.
2. Для каждой `p_i^{e_i}` решить ECDLP в подгруппе порядка `p_i^{e_i}` (полный перебор при малом `p_i`, BSGS при среднем).
3. Собрать `k` по CRT.

Сложность — `O(√(max p_i))`, а не `O(√n)`. Если `n` — «гладкое» число, ECDLP ломается мгновенно.

```python
# Sage: Pohlig-Hellman
E = EllipticCurve(GF(p), [a, b])
P, Q = E(Px, Py), E(Qx, Qy)
k = discrete_log(Q, P, ord=n, operation='+')   # Sage сам применяет PH при гладком n
```

## Smart's attack (аномальные кривые)

Если `#E(F_p) = p` (кривая «аномальная»), ECDLP решается за полиномиальное время через подъём кривой к `p`-адическим числам (`Q_p`) и формальный логарифм. Критерий: порядок группы равен характеристике поля.

```python
# Sage: Smart's attack (упрощённо, использует подъём в Q_p)
def smart_attack(P, Q, p):
    E = P.curve()
    Eqp = EllipticCurve(Qp(p, 2), [ZZ(t) for t in E.a_invariants()])
    P_Qp = Eqp.lift_x(ZZ(P.xy()[0]))
    Q_Qp = Eqp.lift_x(ZZ(Q.xy()[0]))
    p_times_P = p * P_Qp
    p_times_Q = p * Q_Qp
    x_P, y_P = p_times_P.xy()
    x_Q, y_Q = p_times_Q.xy()
    phi_P = -(x_P / y_P)
    phi_Q = -(x_Q / y_Q)
    k = (phi_Q / phi_P).lift()
    return ZZ(k) % p
```

## MOV и supersingular-кривые

При малом embedding degree `k` (например, supersingular-кривые с `k=2`) спаривание переносит ECDLP в мультипликативную группу `F_{p^k}`, где работает субэкспоненциальный index calculus. Для обычных кривых `k` огромно — MOV неприменима (см. `crypto-pairing`).

## Восстановление параметров кривой по подписям

Иногда даны только подписи `(r, s)` и сообщения, а параметры `(a, b, p)` неизвестны. Подход: по подписям строятся уравнения на `a, b, p` (через `y² = x³ + ax + b` и соотношение `r = x(kG)`), затем решается система. Типично для «custom curve» задач.

```python
# Идея: r-координата даёт точку R = kG; s-уравнение связывает r, s, z, d
# неизвестные a, b, p, d -> строим систему и решаем
```

Также возможен **fault/biased nonce**: если `k` не равномерный (утечка старших бит), применяют решётки — см. `crypto-ecdsa-nonce`.

## Разобранный пример: гладкий порядок

Дано: кривая над `F_p`, точка `P`, `Q = dP`, порядок `n` гладкий. Цель — `d`.

1. Факторизуем `n` (например, `n = 2^10 · 3^5 · 7^3 · ...`).
2. `discrete_log(Q, P, ord=n, operation='+')` в Sage (автоматически PH) — или вручную по подгруппам + CRT.
3. Получаем `d` за секунды.

Проверка: `d*P == Q`.

## Варианты и edge cases

- **Порядок — простое близко к 2^k** — PH не поможет, только Pollard rho.
- **Кривая задана над GF(2^m)** — другие атаки (FR-reduction), иной код в Sage.
- **Точка порядка с малым простым множителем** — комбинируйте PH с перебором.
- **Порядок не задан** — вычислите `#E` (Schoof/SEA в Sage: `E.order()`).
- **Аномальная кривая с `#E=p`** — Smart.
- **Biased nonce** — решёточные методы (`crypto-ecdsa-nonce`).

## Частые ошибки и тупики

- **Забыть проверить порядок.** PH работает только при гладком `n`.
- **Перепутать аддитивную и мультипликативную нотацию.** В ECC `discrete_log(..., operation='+')`.
- **Не поднять кривую корректно для Smart.** Нужен правильный подъём в `Q_p` (p-адические).
- **Считать любую custom-кривую ломаемой.** Нужно конкретное слабое свойство.
- **Игнорировать cofactor.** Порядок базовой точки и порядок группы — разные вещи.
- **Путать MOV и Smart.** MOV — спаривание при малом `k`; Smart — аномальность `#E=p`.

## Что дальше (decision)

1. Порядок гладкий → Pohlig-Hellman (+ CRT).
2. `#E == p` → Smart's attack.
3. Малый embedding degree → MOV.
4. Только подписи, параметры неизвестны → восстановление кривой.
5. Nonce переиспользован/смещён → `crypto-ecdsa-nonce`.
6. Всё «хорошее» → перебор нереален, ищите ошибку реализации.

## Полный разбор: восстановление кривой по подписям

Иногда даны только подписи `(r_i, s_i)` и сообщения, а параметры `(a, b, p)` кривой неизвестны. Идея: `r_i` — это x-координата точки `R_i = k_i·G`, лежащей на кривой; значит, `y_i² = r_i³ + a·r_i + b` для каждого `i`. Дополнительно уравнение подписи `s_i = k_i^{-1}(z_i + r_i·d)` связывает `k_i` и `d`. Строим систему и решаем.

Практический путь для «custom curve» задач:

1. Собрать несколько `(r_i, s_i, z_i)`.
2. Для каждой подписи ввести неизвестные `y_i` (координата точки `R_i`).
3. Записать `y_i² = r_i³ + a·r_i + b` — это уравнения на `a, b`.
4. Записать `R_i = k_i·G` и `s_i` — уравнения на `k_i, d`.
5. Решить систему (Sage, идеалы/полиномиальные системы).

Часто задача упрощается: если `p` известен, а `a, b` — нет, то трёх точек достаточно, чтобы восстановить `a, b` через разности уравнений. Затем — обычный `discrete_log` или biased-nonce атака.

## Чек-лист: слабая кривая

- порядок группы `n` гладкий → Pohlig-Hellman;
- `#E == p` (аномальная) → Smart's attack;
- embedding degree `k` мал (supersingular) → MOV;
- параметры `a, b, p` нестандартные/самодельные;
- даны только подписи без описания кривой → восстановление параметров;
- cofactor большой и не проверяется → малые подгруппы.

Начните с `E.order()` и `factor(E.order())`. Если порядок гладкий — `discrete_log` решит мгновенно. Если `E.order() == p` — применяйте Smart. Если `k` мал — MOV. Для «custom curve» — восстанавливайте `a, b` по точкам.
