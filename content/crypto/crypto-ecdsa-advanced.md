## Вопрос, с которого всё начинается

В CTF дают эллиптическую кривую, точку `P` и `Q = d·P`, и просят найти `d`. На «хорошей» кривой это невозможно — дискретный логарифм (ECDLP) требует ~2^128 операций. Но если параметры кривой выбраны слабо, задача решается за секунды. Разберём самый частый случай — гладкий порядок группы — и покажем, как это выглядит на маленькой кривой.

## Наш пример

Возьмём кривую `y² = x³ + x + 1` над `F_101`. Найдём точку порядка 105 и зашифруем ею «приватный ключ» `d = 17`:

```python
p, a, b = 101, 1, 1
# P — точка порядка 105; Q = 17*P
print("P order:", 105, "Q = dP")
```

Вопрос: как восстановить `d`, не перебирая 105 вариантов «в лоб»? Ответ — **Pohlig-Hellman**.

## Шаг 1: ECDLP и когда он ломается

ECDLP: по точкам `P` и `Q = k·P` найти `k`. Для хороших кривых лучший метод — Pollard's rho за `O(√n)`. Он ломается, когда:

- **порядок группы гладкий** (`n = Π p_i^{e_i}` с малыми `p_i`) — Pohlig-Hellman;
- **кривая аномальная** (`#E = p`) — Smart's attack (полиномиально);
- **embedding degree мал** — MOV переносит ECDLP в конечное поле;
- **параметры известны частично** — восстановление по подписям.

## Шаг 2: Pohlig-Hellman

Если порядок `n` разлагается на малые простые, ECDLP сводится к ECDLP в каждой подгруппе. У нас `105 = 3·5·7`:

```python
from sympy import factorint
from sympy.ntheory.modular import crt
n = 105; fac = factorint(n)
res, mods = [], []
for prime, e in fac.items():
    pe = prime**e
    Pi = mul(n // pe, P)     # проекция в подгруппу порядка pe
    Qi = mul(n // pe, Q)
    for r in range(pe):      # перебор внутри маленькой подгруппы
        if mul(r, Pi) == Qi:
            res.append(r); mods.append(pe); break
D, M = crt(mods, res)
print("recovered d:", D)
```

```
recovered d: 17
```

Сложность стала `O(√(max p_i))` вместо `O(√n)`. Если `n` — гладкое число, ECDLP ломается мгновенно: чем меньше простые множители, тем быстрее. В Sage то же самое делает одна строка:

```python
k = discrete_log(Q, P, ord=n, operation='+')
```

Ключевой момент — `operation='+'`: в эллиптических кривых группа **аддитивная**, и это частая ошибка новичков.

## Шаг 3: Smart's attack на аномальных кривых

Если `#E(F_p) = p` (кривая «аномальная»), ECDLP решается за полиномиальное время. Идея: поднять кривую к `p`-адическим числам (`Q_p`), взять формальный логарифм и восстановить `k`:

```python
# Sage: подъём в Q_p и формальный логарифм
Eqp = EllipticCurve(Qp(p, 2), [ZZ(t) for t in E.a_invariants()])
P_Qp = Eqp.lift_x(ZZ(P.xy()[0]))
Q_Qp = Eqp.lift_x(ZZ(Q.xy()[0]))
x_P, y_P = (p * P_Qp).xy()
x_Q, y_Q = (p * Q_Qp).xy()
k = ZZ((-(x_Q / y_Q) / -(x_P / y_P)).lift()) % p
```

Критерий применения прост: **порядок группы равен характеристике поля**. Найти такие кривые легко: `E.order() == p` в Sage сразу показывает аномальность, и тогда достаточно нескольких строк кода для восстановления ключа.

## Шаг 4: MOV и supersingular-кривые

При малом **embedding degree** `k` спаривание (см. `crypto-pairing`) переносит ECDLP в мультипликативную группу `F_{p^k}`, где работает субэкспоненциальный index calculus. Для supersingular-кривых `k` часто равно 2 — это ломает ECDLP. Для обычных кривых `k` огромно, и MOV неприменима.

## Шаг 5: восстановление параметров кривой по подписям

Иногда даны только подписи `(r_i, s_i)` и сообщения, а параметры `(a, b, p)` неизвестны. `r_i` — это x-координата точки `R_i = k_i·G`, лежащей на кривой, значит `y_i² = r_i³ + a·r_i + b`. Плюс уравнение подписи `s_i = k_i^{-1}(z_i + r_i·d)` связывает `k_i` и `d`. Строим систему и решаем:

1. Собрать несколько `(r_i, s_i, z_i)`.
2. Ввести неизвестные `y_i` для каждой точки `R_i`.
3. Записать `y_i² = r_i³ + a·r_i + b` — уравнения на `a, b`.
4. Записать `s_i` — уравнения на `k_i, d`.
5. Решить систему (Sage, идеалы).

Часто задача упрощается: если `p` известен, трёх точек достаточно, чтобы восстановить `a, b` через разности уравнений. Если же параметры известны, а nonce переиспользован или смещён (утекают старшие биты `k`), применяют решёточные методы — см. `crypto-ecdsa-nonce`. Обе техники часто комбинируются: сначала восстанавливают кривую, затем атакуют nonce.

## Шаг 6: MOV подробнее

**MOV-атака** (Menezes-Okamoto-Vanstone) использует спаривание (см. `crypto-pairing`), чтобы свести ECDLP к дискретному логарифму в конечном поле. Если у кривой малый embedding degree `k`, существует спаривание `e: E(F_p) → F_{p^k}`, и мы переносим задачу: вместо `Q = d·P` решаем `e(P, ·)`-образ. В поле `F_{p^k}` работает субэкспоненциальный index calculus, и `d` находится быстро. Практический критерий: для supersingular-кривых `k` часто равно 2 — они ломаются. Для обычных кривых `k` огромно (десятки-сотни), и MOV неприменима. Поэтому «безопасные» кривые специально выбирают так, чтобы `k` был велик.

## Шаг 7: чек-лист слабой кривой

- порядок группы гладкий → **Pohlig-Hellman**;
- `#E == p` (аномальная) → **Smart**;
- embedding degree `k` мал (supersingular) → **MOV**;
- параметры `a, b, p` нестандартные/самодельные → возможно, восстановление по подписям;
- cofactor большой и не проверяется → малые подгруппы (`crypto-invalid-curve`);
- nonce переиспользован или смещён → `crypto-ecdsa-nonce`.

Начните с `E.order()` и `factor(E.order())`. Гладкий порядок → `discrete_log` решит мгновенно; `E.order() == p` → Smart; малый `k` → MOV.

## Что мы теперь знаем

- ECDLP ломается при слабых параметрах кривой, а не при хорошей кривой.
- **Pohlig-Hellman:** гладкий порядок → решение по подгруппам + CRT.
- **Smart:** аномальная кривая (`#E = p`) → полиномиальное время.
- **MOV:** малый embedding degree → перенос в `F_{p^k}`.
- По подписям можно **восстановить параметры** кривой.
- В Sage `discrete_log(..., operation='+')` — аддитивная группа.

## На что смотреть дальше

- **Забыть проверить порядок** — PH работает только при гладком `n`.
- **Перепутать аддитивную и мультипликативную нотацию** — в ECC `operation='+'`.
- **Неверный подъём кривой для Smart** — нужен корректный `Q_p`.
- **Считать любую custom-кривую ломаемой** — нужно конкретное слабое свойство.
- **Игнорировать кофактор** — порядок точки и порядок группы разные.
- **Путать MOV и Smart** — MOV это спаривание при малом `k`, Smart — аномальность `#E=p`.
