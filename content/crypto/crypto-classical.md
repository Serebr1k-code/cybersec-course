## Зачем изучать классические шифры

Классические шифры (до-компьютерной эпохи) регулярно появляются на CTF — иногда как разминочная задача, иногда как часть многослойной головоломки. Они важны не столько сами по себе, сколько потому, что на них отрабатываются **базовые принципы криптоанализа**: частотный анализ, избыточность языка, определение длины ключа. Эти принципы потом работают и в современных атаках.

## Шифр Цезаря (Caesar / ROT)

Сдвиг каждой буквы на фиксированное число позиций. ROT13 — частный случай со сдвигом 13.

```python
def caesar(text, k, decode=False):
    if decode: k = -k
    out = []
    for ch in text:
        if ch.isalpha():
            base = ord('A') if ch.isupper() else ord('a')
            out.append(chr((ord(ch) - base + k) % 26 + base))
        else:
            out.append(ch)
    return ''.join(out)

print(caesar("KubSTU", 3))         # NxeVWX
print(caesar("NxeVWX", 3, True))   # KubSTU
```

**Взлом:** всего 26 ключей — переберите все и выберите читаемый. На CTF — мгновенно.

```bash
# ROT13 в shell
echo "KubSTU" | tr 'A-Za-z' 'N-ZA-Mn-za-m'
```

**ROT47** — сдвиг по всему печатному ASCII (33..126), используется для символов, не только букв.

## Atbash и другие аффинные шифры

**Atbash** — обратный алфавит (`A↔Z`, `B↔Y`). Аффинный шифр: `E(x) = (a·x + b) mod 26`, где `gcd(a,26)=1`.

```python
def atbash(s):
    return ''.join(chr(ord('z') - (ord(c)-ord('a'))) if c.islower()
                   else chr(ord('Z') - (ord(c)-ord('A'))) if c.isupper() else c
                   for c in s)
```

## Шифр Виженера (Vigenère)

Полиалфавитный шифр: ключевое слово повторяется, каждая буква сдвигается на свою величину. Это уже серьёзно — частотный анализ «в лоб» не работает.

```python
def vigenere(text, key, decode=False):
    out, ki = [], 0
    for ch in text:
        if ch.isalpha():
            k = ord(key[ki % len(key)].lower()) - ord('a')
            if decode: k = -k
            base = ord('A') if ch.isupper() else ord('a')
            out.append(chr((ord(ch) - base + k) % 26 + base))
            ki += 1
        else:
            out.append(ch)
    return ''.join(out)
```

**Взлом в три шага:**

1. **Найти длину ключа.** Два метода:
   - **Индекс совпадений (IC).** Для каждой предполагаемой длины ключа считаем средний IC по колонкам. Английский текст имеет IC ≈ 0.066, случайный ≈ 0.038. Правильная длина даёт максимум IC.
   - **Тест Касиски.** Ищем повторяющиеся последовательности в шифротексте; расстояния между ними кратны длине ключа. GCD расстояний = длина ключа.

2. **Разбить шифротекст на колонки** по длине ключа. Каждая колонка — это шифр Цезаря.

3. **Для каждой колонки** найти сдвиг частотным анализом (самая частая буква ≈ `E` в английском; в русском ≈ `О`).

```python
from collections import Counter

def index_of_coincidence(s):
    s = [c for c in s.lower() if c.isalpha()]
    n = len(s)
    if n < 2: return 0
    freq = Counter(s)
    return sum(v*(v-1) for v in freq.values()) / (n*(n-1))

def find_keylen(ct, maxlen=20):
    best = []
    for L in range(1, maxlen+1):
        cols = [ct[i::L] for i in range(L)]
        ics = [index_of_coincidence(c) for c in cols if len(c) > 3]
        best.append((sum(ics)/len(ics), L))
    best.sort(reverse=True)
    return best[:5]   # наиболее вероятные длины

def break_column(col, lang='en'):
    ref = 'etaoinshrdlucmfwypvbgkjqxz' if lang=='en' else 'оеаинтсрвлкмдпуяыьгзбчйхжшюцщэфъ'
    col = [c.lower() for c in col if c.isalpha()]
    freq = Counter(col)
    common = freq.most_common(1)[0][0]
    shift = (ord(common) - ord(ref[0])) % 26
    return shift
```

## Моноалфавитная подстановка (substitution)

Каждая буква заменяется произвольной другой — ключ это перестановка алфавита. Ключевое пространство огромно (26!), но **частотный анализ ломает её легко**.

**Порядок действий:**
1. Считаем частоты букв. Топ: `E T A O I N S H R D L U...` (англ.) / `О Е А И Н Т С Р В Л К М Д П...` (рус.).
2. Смотрим на биграммы/триграммы: `THE`, `AND`, `ING`, `ION` (англ.); `СТ`, `НО`, `ТО`, `НА` (рус.).
3. Одинарные буквы `A`/`I` (англ.) или `И`/`В`/`О` (рус.) — подсказки.
4. Двойные буквы: `LL`, `SS`, `EE`; в русском `НН`, `СС`.
5. Итерируем, уточняя гипотезы.

Инструмент: **quipqiup** (онлайн) решает такие задачи автоматически. Или `subbreaker`, `pycipher`.

```python
# pip install pycipher
from pycipher import SimpleSubstitution
key = 'phqgiumeaylnofdxjkrcvstzwb'  # 26-буквенный ключ
ct = SimpleSubstitution(key).encipher('the quick brown fox')
SimpleSubstitution(key).decipher(ct)
```

## Транспозиции

Здесь буквы не заменяются, а **переставляются**.

**Rail Fence (зигзаг):** текст пишется зигзагом по `k` строкам, читается построчно.

```python
def railfence_decrypt(ct, k):
    n = len(ct)
    pattern = list(range(k)) + list(range(k-2, 0, -1))
    rows = [[] for _ in range(k)]
    idx = 0
    for i in range(n):
        rows[pattern[i % len(pattern)]].append(ct[i])
    # теперь распределяем символы обратно
    rail = [['' for _ in range(n)] for _ in range(k)]
    r = 0; d = 1
    for i in range(n):
        rail[r][i] = '*'
        if r == 0: d = 1
        elif r == k-1: d = -1
        r += d
    out = []
    for row in range(k):
        for i in range(n):
            if rail[row][i] == '*':
                out.append(rows[row].pop(0))
    return ''.join(out)
```

**Столбцовая транспозиция:** текст пишется по строкам в таблицу, читается по столбцам в порядке ключа. Взлом — перебор длин и восстановление порядка столбцов.

## Матричные шифры: Playfair и Hill

**Playfair** — шифрует парами букв по матрице 5×5, построенной из ключа. Ломается, если есть достаточный объём текста (биграммный частотный анализ).

**Hill** — блочный линейный шифр над `Z_26`: `C = K·P mod 26`. Если известна структура, ключ восстанавливается решением линейной системы (обратная матрица по модулю 26). Часто ломается атакой «known plaintext».

## Как не застрять

- **Сначала исключите простые.** Попробуйте ROT1–25, Atbash, ROT47, reverse, base64. Половина «классических» задач решается этим.
- **Язык важен.** Русский и английский дают разные частотные профили. Определите язык по длине слов и наличию частых букв.
- **Пробелы могли убрать.** Если текст без пробелов — попробуйте вставить их по частотным триграммам.
- **Проверяйте гипотезу флага.** Часто формат `KubSTU{...}` или `FLAG{...}` угадывается по позиции и даёт known-plaintext атаку.
- **Используйте quipqiup** для моноалфавитной подстановки — он экономит часы.

## Где пригодится

- **CTF** — разминочные и многослойные задачи, крипто-квесты.
- **История и образование** — понимание эволюции криптографии.
- **Основы криптоанализа** — частотный анализ, IC, определение длины ключа лежат в основе анализа и современных систем.
- **Пазлы и игры** — квесты, ARG, эскейп-румы часто используют классические шифры.
- **Пентест** — распознавание «самодельной криптографии» в приложениях (часто это ROT/Vigenère/XOR, а не AES).
