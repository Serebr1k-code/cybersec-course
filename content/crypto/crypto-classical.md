## Вопрос, с которого всё начинается

Мы уже умеем превращать строку из условия в осмысленный текст. Но что, если после снятия кодировок текст остаётся **бессмысленным набором латинских букв**? Обычно это классический шифр — подстановка или перестановка. Как его распознать и вскрыть, если ключа у нас нет?

Разберём две задачи на одном принципе: сначала простой сдвиг, потом сдвиг, который меняется от буквы к букве.

## Наш пример

Задача даёт строку с фигурными скобками и подчёркиваниями:

```
NxeVWX{fdhvdu_lv_zhdn}
```

Скобки и подчёркивания — это **формат флага**, они не шифруются. Значит, зашифрованы только буквы, и скорее всего это простой сдвиг алфавита. Проверим.

## Шаг 1: перебираем сдвиг

У шифра Цезаря всего 26 возможных ключей — сдвигов алфавита. Перебрать их быстрее, чем думать:

```python
ct = "NxeVWX{fdhvdu_lv_zhdn}"
def caesar(t, k):
    out = []
    for c in t:
        if c.isalpha():
            b = ord('A') if c.isupper() else ord('a')
            out.append(chr((ord(c) - b + k) % 26 + b))
        else:
            out.append(c)
    return ''.join(out)

for k in range(26):
    print(k, caesar(ct, k))
```

Вывод (фрагмент) — при сдвиге 23 получается читаемое:

```
23 KubSTU{caesar_is_weak}
```

Проверим: `N` → `K` — это сдвиг на 3 назад. Флаг найден перебором из 26 вариантов, без всякого ключа.

## Шаг 2: как понять, что это сдвиг

Признак шифра Цезаря — **сохраняется форма слов**: пробелы, скобки, длина, но буквы «съезжают». Если убрать сдвиг 23, весь текст становится осмысленным. Частный случай — ROT13 (сдвиг 13), его часто применяют прямо в цепочке с base64. В shell его удобно делать так:

```bash
$ echo 'NxeVWX{fdhvdu_lv_zhdn}' | tr 'A-Za-z' 'N-ZA-Mn-za-m'
AkrJKL{squiqh_yi_muqa}
```

`tr` заменяет каждую букву на парную через 13 позиций. Есть и **Atbash** — «зеркальный» алфавит (`A↔Z`), и **аффинный** шифр `E(x) = (a·x + b) mod 26`. Все они относятся к подстановкам и перебираются так же легко.

## Шаг 3: Vigenère — сдвиг не один

Теперь задача сложнее. Дана строка без пробелов и подсказка «ключ — английское слово»:

```
LXFOPVEFRNHR
```

Если применить перебор сдвига, читаемого текста не получится: здесь каждая буква сдвинута на **свою** величину — на сколько, зависит от буквы ключа. Это шифр Виженера: ключевое слово повторяется, и каждый его символ задаёт сдвиг для очередной буквы текста.

Знакомый пример: текст `ATTACKATDAWN` с ключом `LEMON` даёт `LXFOPVEFRNHR`.

```python
def vigenere(t, key, dec=False):
    out, ki = [], 0
    for c in t:
        if c.isalpha():
            k = ord(key[ki % len(key)].lower()) - ord('a')
            if dec: k = -k
            b = ord('A') if c.isupper() else ord('a')
            out.append(chr((ord(c) - b + k) % 26 + b)); ki += 1
        else:
            out.append(c)
    return ''.join(out)

print(vigenere("ATTACKATDAWN", "LEMON"))          # LXFOPVEFRNHR
print(vigenere("LXFOPVEFRNHR", "LEMON", True))    # ATTACKATDAWN
```

Но у нас ключа нет. Ломаем в три шага.

## Шаг 4: находим длину ключа

Ключевая идея: если мы **угадали длину ключа**, то буквы на позициях `0, L, 2L, …` зашифрованы **одним и тем же сдвигом** — то есть каждая «колонка» становится обычным шифром Цезаря. А в осмысленном языке буквы распределены неравномерно (чаще всего `E`, `T`, `A`). Меру «неравномерности» даёт **индекс совпадений (IC)** — вероятность того, что две случайно взятые буквы совпадут:

- у английского текста IC ≈ 0.066–0.075;
- у случайного набора букв IC ≈ 0.038.

Проверим на настоящем английском тексте:

```python
from collections import Counter
def ic(s):
    s = [c for c in s.lower() if c.isalpha()]
    n = len(s); f = Counter(s)
    return sum(v*(v-1) for v in f.values()) / (n*(n-1)) if n > 1 else 0

eng = "it was the best of times it was the worst of times it was the age of wisdom"
print(round(ic(eng), 4))   # ~0.075
```

Стратегия: для каждой предполагаемой длины `L` считаем **средний IC по колонкам**. Правильная длина даёт заметно больший IC, потому что колонки — это «сдвинутый английский», а не случайность.

Второй способ — **тест Касиски**: ищем повторяющиеся куски текста; расстояния между ними кратны длине ключа, а их НОД и есть длина.

## Шаг 5: восстанавливаем ключ

Когда длина `L` известна, каждая колонка — это Цезарь. Для неё находим сдвиг частотным анализом: самая частая буква колонки соответствует самой частой букве языка (`E` в английском, `О` в русском). Собираем сдвиги обратно в ключ — и расшифровываем.

На практике для длинных текстов это отлично делают `vigenere-solver` (guballa.de) или библиотека `pycipher`, а для коротких текстов быстрее перебрать словарь ключей (`rockyou`) и искать «читаемый» результат.

## Шаг 6: моноалфавитная подстановка

Если после перебора сдвигов и Виженера ничего не вышло, а текст — осмысленной длины, скорее всего перед нами **моноалфавитная подстановка**: каждая буква заменена произвольной другой, ключ — перестановка алфавита. Ключевое пространство огромно (26!), но частотный анализ ломает её легко:

1. Считаем частоты букв: `E T A O I N S H R D L U…` (англ.) / `О Е А И Н Т С Р В Л…` (рус.).
2. Смотрим биграммы/триграммы: `THE`, `AND`, `ING` (англ.); `СТ`, `НО`, `ТО` (рус.).
3. Одиночные буквы `A`/`I` — подсказки; двойные `LL`, `SS`.
4. Итерируем, уточняя гипотезы.

Онлайн-инструмент **quipqiup** решает такие задачи за секунды — но принцип нужно понимать самому.

## Транспозиции: буквы не меняют, а переставляют

Отдельное семейство — **перестановки**. Здесь алфавит сохраняется, но буквы меняются местами.

**Rail Fence (зигзаг):** текст пишется зигзагом по `k` строкам, затем читается построчно. Взлом — перебор числа строк (обычно 2–10).

**Столбцовая транспозиция:** текст пишется в таблицу по строкам, читается по столбцам в порядке ключа. Взлом — перебор длин и восстановление порядка столбцов.

Матричные шифры (**Playfair** 5×5, **Hill** над `Z_26`) ломаются при достаточном объёме текста: Playfair — биграммным частотным анализом, Hill — атакой «известный открытый текст» (решение линейной системы).

## Что мы теперь знаем

- Шифр Цезаря (сдвиг) вскрывается перебором 26 ключей.
- ROT13/Atbash/аффинный — тоже подстановки, ломаются так же просто.
- У Виженера сначала находят длину ключа (IC или Касиски), затем каждую колонку ломают как Цезаря.
- Моноалфавитная подстановка ломается частотным анализом, а не перебором `26!`.
- Транспозиции переставляют буквы; их взлом — перебор числа строк/столбцов.
- Формат флага `{…}` даёт готовую «известную подсказку» для проверки гипотез.

## Куда дальше

Мы вскрыли сдвиг и подстановку, опираясь на **частоты букв в языке**. В следующем уроке **crypto-xor-otp** мы возьмём тот же принцип избыточности, но применим его к байтам: увидим, почему XOR с повторяющимся ключом ломается так же, как Виженер, и что такое crib-dragging. А пока главное: **классика — это тренировка интуиции криптоанализа, которая работает и на современных схемах**.

## Где пригодится

- **CTF** — разминочные и многослойные задачи, крипто-квесты.
- **Основы криптоанализа** — частотный анализ и определение длины ключа лежат в основе анализа современных систем.
- **Пентест** — распознавание «самодельной криптографии» в приложениях (часто это ROT/Vigenère, а не AES).
- **Пазлы и игры** — квесты, ARG, эскейп-румы постоянно используют классические шифры.
