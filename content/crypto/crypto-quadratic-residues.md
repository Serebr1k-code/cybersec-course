## Вопрос, с которого всё начинается

Мы умеем складывать, умножать и брать обратный элемент по модулю. Но в задачах появляется уравнение `x² ≡ a (mod n)` — и базовая арифметика молчит: не всякий `a` вообще имеет корень, а если имеет — корней несколько. Вопрос новичка: «Как узнать, есть ли корень, и как его найти?» Научимся и тому, и другому — и тут же сломаем на этом криптосистему.

## Наш пример

Дана криптосистема Rabin: `n = 1763`, шифротекст `c = 699`, и известно, что `n = 41 · 43`. Шифрование — это просто `c = m² mod n`. Задача: восстановить `m`. Мы проведём этот пример через весь урок: научимся проверять «есть ли корень», извлекать его по каждому простому и собирать ответ.

## Шаг 1: что такое квадратичный вычет

Пусть `p` — нечётное простое. Число `a` называется **квадратичным вычетом** (QR), если существует `x` с `x² ≡ a (mod p)`. Иначе это невычет (QNR). Ровно половина ненулевых остатков — вычеты: это `1², 2², …, ((p−1)/2)²`, и все они различны.

Проверить это мгновенно помогает **критерий Эйлера**:

```
a^((p-1)/2) ≡  1  (mod p)  →  a — вычет
a^((p-1)/2) ≡ -1  (mod p)  →  a — невычет
```

```python
def is_qr(a, p):
    return pow(a, (p-1)//2, p) == 1

print(is_qr(4, 7), is_qr(3, 7), pow(3, 3, 7))
```

```
True False 6
```

`4 = 2²` — вычет. А `3³ mod 7 = 6 = −1` — значит, `3` невычет. Критерий стоит `O(log p)` и работает даже для огромных `p`.

## Шаг 2: символы Лежандра и Якоби

**Символ Лежандра** `(a|p)` — это то же значение критерия Эйлера, приведённое к `{1, −1, 0}`. Его считают не возведением в степень, а по свойствам: мультипликативность, квадратичная взаимность, `(2|p) = (−1)^((p²−1)/8)`. Это быстрее.

**Символ Якоби** `(a|n)` для составного `n = p₁·p₂·…` — произведение символов Лежандра и вычисляется алгоритмом, похожим на НОД, **не зная факторизации `n`**. Но здесь важная ловушка: если символ Якоби равен `−1`, то `a` точно невычет. А если `+1` — это **не значит**, что `a` вычет по модулю `n`! Для составного `n` это необходимое, но не достаточное условие. Именно на этом различии держится криптосистема Голдвассера–Микали.

## Шаг 3: извлечение корня

Если `p ≡ 3 (mod 4)` и `a` — вычет, корень даётся одной формулой:

```
x = a^((p+1)/4) mod p
```

Потому что `x² = a^((p+1)/2) = a · a^((p−1)/2) = a · 1 = a`. Для общего случая `p ≡ 1 (mod 4)` работает **алгоритм Тонелли–Шанкса**: выделяем `p−1 = q·2^s` с нечётным `q`, находим невычет `z` и итерируем, пока не получим корень.

```python
print(tonelli_shanks(5, 41))
```

```
13
```

Проверка: `13² = 169`, `169 − 4·41 = 5`. Верно. Обратите внимание: корней **два** — `13` и `28 = 41 − 13`, потому что `x` и `−x` оба подходят.

## Шаг 4: корни по составному модулю — ломаем Rabin

Теперь наш пример. По каждому простому множителю корней два, а их комбинации через CRT дают **четыре** корня по `n = p·q`:

```python
from sympy.ntheory.residue_ntheory import sqrt_mod
from sympy.ntheory.modular import crt

p, q, n = 41, 43, 41*43
c = 699
rp = sqrt_mod(c % p, p)      # 17  (и 24 = p-rp)
rq = sqrt_mod(c % q, q)      # 21  (и 22 = q-rq)
roots = set()
for a in (rp, p-rp):
    for b in (rq, q-rq):
        x, _ = crt([p, q], [a, b])
        roots.add(int(x) % n)
print(sorted(roots))
```

```
[65, 796, 967, 1698]
```

Четыре корня. Какой из них исходное сообщение? Только один осмысленный:

```
65 -> b'A'          796 -> b'\x03\x1c'
967 -> b'\x03\xc7'  1698 -> b'\x06\xa2'
```

Восстановили `m = 65 = 'A'`. В реальной задаче «правильный» корень выбирают по читаемости (флаг, ASCII-текст) или по избыточности, заложенной в сообщение. Ключевой факт: извлечение корня по составному `n` **так же сложно, как факторизация** — поэтому схемы на квадратичных вычетах доказуемо стойки, а CTF-задачи специально дают слабый `n`.

## Шаг 5: где это в криптографии и как не застрять

**Rabin** шифрует как `m² mod n`; его взлом эквивалентен факторизации `n`. **Blum–Goldwasser** — потоковый шифр на той же идее. **QR-протоколы** используют «знание корня» как zero-knowledge-доказательство.

Частые ошибки: в Python критерий Эйлера возвращает `p−1`, а не `−1` — сравнивайте с `p−1`; корней всегда несколько (два по простому модулю, четыре по `p·q`); формула `a^((p+1)/4)` не работает при `p ≡ 1 (mod 4)` (показатель не целый) — нужен Тонелли–Шанкс; и символ Якоби `= 1` **не** означает вычет для составного `n`. Если модуль составной и не факторизуется, а корень нужен — почти наверняка в задаче спрятана утечка (`p` и `q` близки, общий простой множитель), и решать надо факторизацию, а не QR.

## Символ Якоби в тестах простоты

Символ Якоби пригодится не только для вычетов. Если дано `n` и утверждение «`a` — вычет», а факторизации нет, честно проверить это нельзя. Но символ Якоби считается быстро, и это даёт **тест Соловея–Штрассена** на простоту: если `(a|n)` не согласован с `a^((n−1)/2)`, то `n` составное. Так строятся вероятностные тесты простоты. Практический вывод для CTF: увидев в условии «Якоби-символ равен 1, значит это вычет» — не верьте. Для составного `n` это лишь необходимое условие, и настоящий вычет ищут либо перебором с проверкой `x² mod n == a`, либо через факторизацию.

## Что мы теперь знаем

- **Критерий Эйлера** проверяет вычет за `O(log p)`; в Python сравниваем с `p−1`.
- **Символы Лежандра/Якоби** дают быструю проверку; Якоби `= 1` для составного `n` — не гарантия.
- Корень при `p ≡ 3 (mod 4)`: `a^((p+1)/4)`; иначе — **Тонелли–Шанкс**.
- По `n = p·q` корней **четыре**, собираются через CRT.
- Извлечение корня по составному `n` эквивалентно факторизации — основа стойкости Rabin.
- Если модуль составной и не факторизуется, а корень нужен — ищите утечку параметров (`p` и `q` близки, общий простой множитель), а не QR-метод.
