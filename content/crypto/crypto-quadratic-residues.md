## Зачем это нужно

Модульная арифметика умеет складывать, умножать и брать обратный элемент. Но как только в задаче появляется уравнение вида `x^2 ≡ a (mod n)`, базовая арифметика молчит: не всякий `a` вообще имеет корень, а если имеет — корней может быть несколько, и их нужно уметь находить. Это ядро целого класса задач: криптосистема Rabin (безопасность которой эквивалентна факторизации), генератор Blum–Goldwasser, проверка «квадратичности» в протоколах и подъём корней в Coppersmith-атаках.

Ключевой факт: извлечение квадратного корня по модулю **составного** числа так же сложно, как факторизация. Именно поэтому схемы на квадратичных вычетах считаются доказуемо стойкими — и именно поэтому CTF-задачи дают слабый модуль (например, `n = p*q` с маленькими `p`, `q`), чтобы корни можно было найти.

## Квадратичные вычеты и критерий Эйлера

Пусть `p` — нечётное простое. Число `a` (не делящееся на `p`) называется **квадратичным вычетом (QR)** по модулю `p`, если существует `x` с `x^2 ≡ a (mod p)`. Иначе `a` — квадратичный невычет (QNR).

Ровно половина ненулевых вычетов по модулю `p` — квадратичные: это `1^2, 2^2, ..., ((p-1)/2)^2`, и они все различны.

**Критерий Эйлера** даёт мгновенную проверку:

```
a^((p-1)/2) ≡  1  (mod p)   →  a — квадратичный вычет
a^((p-1)/2) ≡ -1  (mod p)   →  a — невычет
a^((p-1)/2) ≡  0  (mod p)   →  a ≡ 0 (mod p)
```

Код на Python:

```python
def is_qr(a, p):
    return pow(a, (p - 1) // 2, p) == 1

print(is_qr(4, 7))   # 4 = 2^2 → True
print(is_qr(3, 7))   # 3^3 = 27 = 6 ≡ -1 → False
```

Вывод:

```
True
False
```

Критерий Эйлера стоит `O(log p)` модульных возведений — быстро даже для больших простых.

## Символ Лежандра и Якоби

**Символ Лежандра** `(a|p)` — это просто значение критерия Эйлера, приведённое к `{1, -1, 0}`:

```
(a|p) = a^((p-1)/2) mod p,  приведённое к -1 вместо p-1
```

Свойства, которые делают его вычислимым без возведения в степень:

- `(a|p) = (b|p)`, если `a ≡ b (mod p)`;
- `(a*b|p) = (a|p) * (b|p)`;
- квадратичная взаимность: `(p|q)*(q|p) = (-1)^(((p-1)/2)*((q-1)/2))`;
- `(2|p) = (-1)^((p^2-1)/8)`.

**Символ Якоби** `(a|n)` для составного `n = p1*p2*...` определяется как произведение символов Лежандра: `(a|n) = ∏ (a|pi)`. Его можно вычислить алгоритмом, похожим на НОД, **не зная факторизации `n`**.

Важная ловушка: если символ Якоби равен `-1`, то `a` точно невычет. Но если он равен `+1`, это **не** значит, что `a` — вычет по модулю `n`! Якоби-символ `+1` для составного `n` — необходимое, но не достаточное условие. Именно на этом различии строится различие «квадратичный вычет» и «псевдовычет» (квадратичная неразрешимость — QR-задача, на которой держится криптосистема Голдвассера–Микали).

## Извлечение корня: p ≡ 3 (mod 4) и Тонелли–Шанкс

Если `p ≡ 3 (mod 4)` и `a` — вычет, корень находится одной формулой:

```
x = a^((p+1)/4) mod p
```

Потому что `x^2 = a^((p+1)/2) = a * a^((p-1)/2) = a * 1 = a`.

Для общего случая `p ≡ 1 (mod 4)` работает **алгоритм Тонелли–Шанкса**:

1. Выделяем `p - 1 = q * 2^s` с нечётным `q`.
2. Если `s = 1` (то есть `p ≡ 3 mod 4`) — используем формулу выше.
3. Находим квадратичный невычет `z` (перебором, обычно 2-3 попытки).
4. Итерируем, поддерживая инварианты `m`, `c`, `t`, `r`, пока `t` не станет `1`.

Реализация на Python:

```python
def tonelli_shanks(n, p):
    if pow(n, (p - 1) // 2, p) != 1:
        return None  # невычет
    if p % 4 == 3:
        return pow(n, (p + 1) // 4, p)
    q, s = p - 1, 0
    while q % 2 == 0:
        q //= 2; s += 1
    z = 2
    while pow(z, (p - 1) // 2, p) != p - 1:
        z += 1
    m, c, t, r = s, pow(z, q, p), pow(n, q, p), pow(n, (q + 1) // 2, p)
    while t != 1:
        i, t2 = 0, t
        while t2 != 1:
            t2 = pow(t2, 2, p); i += 1
        b = pow(c, 1 << (m - i - 1), p)
        m, c = i, pow(b, 2, p)
        t, r = (t * c) % p, (r * b) % p
    return r

print(tonelli_shanks(5, 41))   # 13, потому что 13^2 = 169 = 5 (mod 41)
```

Вывод:

```
13
```

Проверка: `13*13 = 169`, `169 - 4*41 = 169 - 164 = 5`. Верно.

## Инструменты и команды

- **SageMath** — `sqrt_mod`, `Mod(a,p).sqrt()`, `nth_root`, `is_square`. Основной инструмент.
- **sympy** — `sympy.ntheory.residue_ntheory.sqrt_mod(a, p, all_roots=True)`.
- **Python** — `pow` для критерия Эйлера и формулы `p ≡ 3 mod 4`.
- **RsaCtfTool** — автоматически применяет Rabin/QR-атаки по сигнатуре задачи.

Пример в Sage:

```sage
sage: Mod(5, 41).sqrt()
13
sage: Mod(5, 41).sqrt(all=True)
[13, 28]
sage: sqrt_mod(5, 41, all_roots=True)
[13, 28]
```

Как видим, корней два: `13` и `28 = 41 - 13`. Это ожидаемо: `x` и `-x` — оба корни.

## Разобранный пример: Rabin и корни по составному модулю

Криптосистема Rabin шифрует как `c = m^2 mod n`, где `n = p*q`. Расшифровка требует извлечь корень по модулю `n`, а это, как мы сказали, эквивалентно факторизации. Но если даны `p` и `q`, всё просто:

1. Находим корни по модулю `p`: `rp ∈ {x, p-x}`.
2. Находим корни по модулю `q`: `rq ∈ {y, q-y}`.
3. Собираем четыре комбинации через CRT: `(rp, rq)`, `(rp, q-y)`, `(p-rp, rq)`, `(p-rp, q-y)`.

```python
from sympy.ntheory.modular import crt
p, q, n = 41, 43, 41 * 43
c = 1763  # какое-то c
rp = tonelli_shanks(c % p, p)
rq = tonelli_shanks(c % q, q)
roots = set()
for a in (rp, p - rp):
    for b in (rq, q - rq):
        x, _ = crt([p, q], [a, b])
        roots.add(int(x) % n)
print(sorted(roots))
```

Четыре корня — и только один из них осмысленный текст (остальные — «мусор»). На CTF это проверяют по флагу/читаемости.

## Символ Якоби для вероятностной проверки

Если дано `n` и утверждение «`a` — вычет по модулю `n`», а факторизации нет, честно проверить это нельзя. Но символ Якоби вычисляется быстро, и это даёт **тест Якоби** (Solovay–Strassen): если `(a|n) ≠ ±1`-согласованности с `a^((n-1)/2)`, то `n` — составное. Так строятся вероятностные тесты простоты.

Практический вывод для CTF: увидев в задаче «Якоби-символ равен 1, значит это вычет» — не верьте. Для составного `n` это лишь необходимое условие, и настоящий вычет ищут перебором с проверкой `x^2 mod n == a` или через факторизацию.

## Частые ошибки и подводные камни

- **Путать вычет и невычет**: критерий Эйлера возвращает `p-1`, а не `-1` в Python — сравнивайте с `p-1`, не с `-1`.
- **Считать, что корень один**: их два по простому модулю и четыре по `n = p*q`.
- **Забыть про `p ≡ 1 mod 4`**: формула `a^((p+1)/4)` там не работает (показатель не целый) — нужен Тонелли–Шанкс.
- **Символ Якоби = 1 ≠ вычет**: классическая ошибка, на которой строятся ловушки в задачах.
- **Ноль по модулю**: если `a ≡ 0`, корень `x = 0`, а не «невычет».

## Контрмеры и защита

- Не публикуйте `p`, `q` — безопасность Rabin держится на сложности факторизации.
- Для схем на QR используйте **Blum-числа** (`p ≡ q ≡ 3 mod 4`), чтобы у каждого `c` был ровно один «главный» корень (квадратный корень с символом Якоби 1).
- Добавляйте избыточность в сообщение, чтобы отличить правильный корень от мусора.
- В реальных протоколах QR-задачи комбинируют с zero-knowledge-доказательствами знания корня.

## Что дальше / решение

После этого урока логично перейти к `crypto-finite-fields` (обобщение на `GF(2^m)`), затем к `crypto-lattice` (подъём корней в Coppersmith использует извлечение корней по модулю). Для CTF держите под рукой шаблон `tonelli_shanks` и `crt` — они закрывают большинство задач на QR. Если в условии модуль составной и не факторизуется, а корень всё же нужен — почти наверняка в задаче спрятана утечка (`p` и `q` близки, `p-1` гладкое, общий простой множитель), и решать надо не QR, а факторизацию.
