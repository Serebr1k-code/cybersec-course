1-Wire (OneWire) — шина, которой достаточно одного провода (плюс земля) для питания и данных. Её придумала Dallas Semiconductor; классические применения — датчики температуры DS18B20 и ключи-таблетки iButton. Протокол простой, но с особым таймингом. Урок — практическое введение.

## Теория

1-Wire использует:
- **DQ** — линия данных (open-drain, подтянута к Vcc резистором ~4.7 кОм),
- **GND**,
- опционально **Vcc** (паразитное питание позволяет без него).

Особенности:
- **Адресация по ROM**: каждое устройство имеет уникальный 64-битный ROM (8 бит family + 48 бит серийник + 8 бит CRC).
- **Мастер-один**: только мастер инициирует обмен; устройства отвечают.
- **Строгий тайминг**: слоты по 60–120 мкс; бит кодируется длительностью низкого уровня.
- **Паразитное питание**: устройство заряжается от линии, когда она высокая.

Ключевые ROM-команды:
| Команда | Код | Назначение |
|---------|-----|-----------|
| READ ROM | 0x33 | прочитать ROM (только если одно устройство) |
| MATCH ROM | 0x55 | адресовать конкретное устройство |
| SKIP ROM | 0xCC | обратиться ко всем |
| SEARCH ROM | 0xF0 | найти все устройства на шине |
| CONVERT T | 0x44 | запустить измерение (DS18B20) |
| READ SCRATCHPAD | 0xBE | прочитать результат |

Family-коды: `0x28` — DS18B20, `0x01` — iButton DS1990A, `0x10` — DS18S20.

## Инструменты и команды

- **owfs / owserver** — Linux-стек для 1-Wire.
- **USB-1-Wire адаптер** (DS9490R, LinkUSB) или самодельный на DS2480.
- **Bus Pirate** — умеет 1-Wire.
- **Логический анализатор** — декодер 1-Wire в sigrok.
- **Flipper Zero** — чтение/эмуляция iButton.

```bash
# owfs: монтируем шину как ФС
sudo modprobe w1-gpio
sudo modprobe w1-therm
# или через USB-адаптер
owserver -d /dev/ttyUSB0 -p 4304 &
owfs -s localhost:4304 /mnt/1wire
ls /mnt/1wire
cat /mnt/1wire/28.1234567890ab/temperature

# Или напрямую через sysfs (если GPIO)
ls /sys/bus/w1/devices/
cat /sys/bus/w1/devices/28-*/w1_slave
```

```text
# Bus Pirate: чтение ROM
1-Wire mode
> (1)                       # включить
> { 0x33 0xFF x8 }          # READ ROM
```

## Разобранный пример: чтение и клонирование iButton-ключа

**Дано:** ключ-таблетка iButton (DS1990A) от домофона, Flipper Zero или Bus Pirate.

**Шаг 1 — подключение.** Прикладываем iButton к считывателю (контактная площадка — DQ, корпус — GND). На Flipper: `iButton Read`.

**Шаг 2 — чтение ROM.** Отправляем `READ ROM` (0x33) — получаем 8 байт: family (0x01) + 6 байт серийника + CRC. Это и есть «код» ключа.

**Шаг 3 — проверка CRC.** Считаем CRC8 (Dallas) и сверяем с последним байтом. Если не совпало — плохой контакт.

**Шаг 4 — эмуляция/клонирование.** Flipper/Proxmark эмулируют прочитанный ROM. Записываем в перезаписываемую iButton (DS1990A-RW) или используем эмуляцию.

**Шаг 5 — ограничения.** Многие СКУД принимают только ROM — клон сработает. Некоторые используют challenge-response (DS1961S) — простой клон не пройдёт.

**Шаг 6 — правовые рамки.** Клонирование чужого ключа — преступление. Только свой ключ/авторизованный тест.

## Частые ошибки

- **Нет подтягивающего резистора.** Без 4.7 кОм линия не поднимается — обмен не работает.
- **Слишком быстрый/медленный тайминг.** Софтверный 1-Wire чувствителен к прерываниям ОС. Используйте аппаратный адаптер.
- **READ ROM при нескольких устройствах.** Коллизия — все отвечают одновременно. Сначала SEARCH ROM, потом MATCH ROM.
- **Путаница DQ и GND.** Питание/данные на одном проводе; неправильное подключение = отсутствие связи.
- **Паразитное питание с нагрузкой.** При активных операциях DS18B20 может не хватать паразитного питания — подайте Vcc.
- **Клонирование без проверки типа.** Крипто-ключи (challenge-response) не клонируются простым ROM-клоном.

## Теория: 1-Wire и iButton

1-Wire — шина с одним сигнальным проводом (плюс земля), используется для iButton (DS1990), датчиков температуры (DS18B20) и ключей доступа. iButton содержит 64-битный ROM: 8 бит family code + 48 бит serial + CRC. Считывание тривиально, клонирование — при наличии болванки (DS1990RW или эмулятор).

## Инструменты

```bash
# Arduino/OneWire + DS1990
# чтение ROM
# Proxmark3 (для некоторых iButton)
# Flipper Zero (iButton read/emulate)
# клон: записать ROM на DS1990RW
```

Пины: data, GND. Питание паразитное (parasite power) для DS18B20.

## Разобранный пример 2: чтение и клон iButton

1. Подключаем iButton к считывателю (Arduino + OneWire).
2. Читаем ROM: `01 23 45 67 89 AB CD EF`.
3. Family code `01` — DS1990 (ключ доступа).
4. Записываем ROM на перезаписываемый iButton или эмулируем (Flipper).
5. Проверяем на своём считывателе — клон работает.

Криптографические iButton (DS1961S/DS1963S с SHA-1), challenge-response, второй фактор.

## DS18B20 и датчики

DS18B20 (family `28`) — цифровой термодатчик на 1-Wire. Подключение: VDD, GND, DQ (+ pull-up 4.7 кОм). Может питаться паразитно. Чтение через Arduino:

```cpp
#include <OneWire.h>
#include <DallasTemperature.h>
OneWire ow(2); DallasTemperature s(&ow);
s.begin(); s.requestTemperatures();
Serial.println(s.getTempCByIndex(0));
```

## Практика

1. Соберите 1-Wire-схему (Arduino + iButton или DS18B20).
2. Считайте ROM/температуру.
3. Для iButton — запишите ROM на болванку и проверьте клон.
4. Сформулируйте, почему статические ключи 1-Wire уязвимы и как криптографические версии (DS1961S) это исправляют.

## Итог

1-Wire/iButton передают статический ROM — клонирование тривиально при физическом доступе. Криптографические версии (DS1961S, SHA-1 challenge-response) закрывают вектор. Для защиты — криптографические ключи и второй фактор.

## Криптографические iButton и почему они закрывают вектор

DS1990 и подобные передают статический ROM, который легко считать и воспроизвести. Криптографические версии (DS1961S, DS1963S) реализуют SHA-1 challenge-response: считыватель посылает случайный challenge, ключ вычисляет ответ с использованием секрета, хранящегося в устройстве, и без знания секрета ответ подделать нельзя. Даже считав ROM, вы не сможете пройти аутентификацию, потому что для этого нужен секрет внутри iButton.

Практически это означает: при аудите системы доступа определите, какой тип ключа используется. Если это DS1990 (family code `01`) — система уязвима к клонированию, и рекомендация — миграция на криптографические ключи или добавление второго фактора (PIN). Если это DS1961S/DS1963S — атака существенно сложнее и требует компромисса секрета, а не простого копирования ROM.

Инструментально работа с 1-Wire проста: Arduino + библиотека OneWire, либо Flipper Zero (режимы read/emulate iButton), либо специализированные считыватели. Для датчиков (DS18B20) важнее корректность шины и pull-up-резистор. Как и везде в hardware, ключевой вывод — статические идентификаторы не являются секретом и не защищают; защиту даёт только криптография.
