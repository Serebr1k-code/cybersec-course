## Вопрос, с которого всё начинается

Отопление, вентиляция, кондиционирование, доступ в здание, лифты — всем управляет **BMS** (Building Management System). Протокол, на котором она работает десятки лет, — **BACnet**. И у него по умолчанию почти нет аутентификации.

Вопрос урока: как устроен BACnet и как записать «точку» в чужом здании.

## Наш пример: BACnet-трафик BMS

У нас есть дамп BACnet-трафика: обнаружение устройств и команда записи. Разберём объектную модель и найдём записываемую точку.

## Шаг 1: объектная модель

BACnet описывает всё как **объекты**. У каждого объекта есть **instance number** и набор **properties**. Примеры типов объектов:

- **Analog Input** — датчик (температура, влажность).
- **Analog Output** — управляющее значение (положение заслонки).
- **Binary Input/Output** — дискретные (включено/выключено).
- **Device** — само устройство.

```text
$ grep -m2 'object' bacnet.log
object: type=AnalogInput instance=1 present_value=21.5 units=C
object: type=AnalogOutput instance=2 present_value=45.0 units=percent
```

## Шаг 2: сервисы

BACnet — это сервисы поверх объектов. Ключевые:

- **Who-Is / I-Am** — discovery: кто есть в сети.
- **ReadProperty** — прочитать свойство.
- **WriteProperty** — записать свойство.
- **SubscribeCOV** — подписка на изменения.

```text
$ grep -n 'WriteProperty' bacnet.log
WriteProperty: dev=1001 obj=AnalogOutput:2 prop=Present_Value value=100.0
```

Вот она — запись. Если WriteProperty не защищён, любой в сети меняет уставку.

## Шаг 3: discovery по broadcast

BACnet широковещательно рассылает **Who-Is**, устройства отвечают **I-Am**. Это значит, что достаточно оказаться в том же L2-сегменте, чтобы увидеть всю BMS.

```text
$ grep -n 'Who-Is\|I-Am' bacnet.log
Who-Is: broadcast
I-Am: device=1001 vendor=Acme name=AHU-1
```

Порт BACnet/IP — **47808/UDP** (`0xBAC0`). Скан по нему быстро находит устройства.

## Шаг 4: чтение и запись

Читать состояние можно без пароля — многие BMS отдают всё открыто. Запись критичных точек (уставки, режимы, двери) — то, что превращает «прочитал» в «управляю».

```text
$ python3 -c "print('BACnet/IP: BVLC 0x81 0x0A + NPDU + APDU WriteProperty')"
BACnet/IP: BVLC 0x81 0x0A + NPDU + APDU WriteProperty
```

Инструменты: `BACnet Stack`, `bacnet-tools`, YABE, `nmap --script bacnet-info`.

## Шаг 5: атаки

1. **Запись уставок** — изменить температуру, режим вентиляции.
2. **Разблокировка дверей** — записать в Binary Output доступа.
3. **DoS** — залить устройства WriteProperty.
4. **Ложные датчики** — подделать ReadProperty-ответы (спуфинг).

Ограничение: современные BMS иногда используют BACnet/SC (Secure Connect) с TLS. Но legacy-устройств с открытым BACnet — огромное количество.

## Объектная модель BACnet глубже

BACnet описывает устройство как набор **объектов** (Analog Input/Output/Value, Binary Input/Output/Value, Device, Schedule и др.). У каждого объекта есть `Object_Identifier` (тип + номер), набор **свойств** (`Present_Value`, `Description`, `Units`, `Priority_Array`) и поддерживаемые **сервисы**. Значение `Present_Value` — то, что читают и пишут. Для инженера это «точка»: датчик температуры, уставка, команда вентилятора.

```text
ReadProperty  → object: analogInput:1  property: present-value
WriteProperty → object: analogValue:5   value: 99.0
```

Ключевой момент безопасности: `WriteProperty` на `Present_Value` меняет физическое состояние (открыть клапан, перевести вентиляцию в аварийный режим). Аутентификации в базовом BACnet нет.

## Инструменты и практика

Разведка начинается с broadcast-запроса `Who-Is`, на который устройства отвечают `I-Am` со своим `Device_ID` и адресом. Дальше читают список объектов через `ReadProperty` на `object-list`.

```bash
# bacnet-tools / bacnet-stack
bacwi                      # Who-Is
bacrp 1234 0 77 85         # ReadProperty object-list
bacwp 1234 2 85 85 4 3 1 1.0  # WriteProperty (в тестовой среде!)
```

Альтернативы: `BAC0` (Python, поверх `bacpypes`), `YABE` (графический сканер), Wireshark-диссектор BACnet для разбора дампов. Для анализа перехваченного трафика достаточно `tshark -Y bacnet`.

## Атаки и защита

Основные атаки: **запись точек** (изменить уставку, отключить датчик), **спуфинг** (поддельный `I-Am` создаёт фантомное устройство), **DoS** (лавина `Who-Is`), **replay** (повтор команды). На объектах жизнеобеспечения (HVAC, доступ, пожарная сигнализация) запись может иметь физические последствия.

Защита: сегментация сети (BMS в отдельном VLAN), BACnet/SC (Secure Connect — TLS), шлюзы с фильтрацией, запрет записи для неизвестных устройств, мониторинг аномальных `WriteProperty`. Для пентеста — сначала только чтение (`ReadProperty`), запись только с разрешения и на стенде.

## Разбор BACnet-дампа шаг за шагом

Возьмём захваченный трафик BMS и разберём его вручную, чтобы понять, как читается протокол без готового сканера.

Первый шаг — отфильтровать BACnet в Wireshark (`bacnet` или `bacapp`). Ты увидишь три основных типа сообщений: `Who-Is` (broadcast, порт 47808), `I-Am` (ответ устройства), и `ReadProperty`/`WriteProperty` (запросы к конкретному объекту). Первые два — разведка, третьи — работа с точками.

Второй шаг — собрать инвентарь. По `I-Am` ты узнаёшь `Device_Instance` каждого устройства и его адрес. По `object-list` (свойство 76 объекта Device) — какие объекты есть. Из имён объектов (`Description`) часто видно назначение: «Chiller_1_Setpoint», «Fire_Door_Status». Это уже модель здания.

Третий шаг — понять значения. `Present_Value` объекта `analogInput:3` — текущая температура; `analogValue:5` — уставка, которую можно записать. `Priority_Array` показывает, кто сейчас управляет точкой (ручной режим, расписание, аварийный приоритет). Именно приоритеты определяют, что произойдёт при записи.

## Что значит «запись» на физическом уровне

Самое важное для понимания импакта: BACnet-запись не «сохраняет число в базе» — она меняет поведение оборудования. Запись `Present_Value` в `binaryOutput` открывает клапан или включает насос; в `analogOutput` задаёт положение заслонки; в объекте `Schedule` меняет расписание работы систем.

Приоритеты (priority array) определяют, кто «побеждает». Записывая значение с высоким приоритетом (например, 8 — manual operator), ты перекрываешь автоматику и расписание. Это и есть способ взять точку под контроль. Обратная сторона: некоторые точки защищены — запись отклоняется, если устройство в режиме `out-of-service` или приоритет занят более высоким уровнем.

Поэтому при аудите сначала только читай (`ReadProperty`) и строй карту приоритетов. Любая запись — потенциальное физическое воздействие, а на объектах жизнеобеспечения (пожарная сигнализация, доступ, лифты) она опасна для людей. Проверять запись можно только на стенде с разрешения владельца.

## Инвентаризация и оценка поверхности

Для системного аудита BMS начни с инвентаризации: `nmap -sU -p 47808 --script bacnet-info` найдёт BACnet-устройства и их базовые свойства. Дополнительно сканируй порты 47808 (BACnet/IP), 47809 и связанные сервисы (Modbus 502, SNMP 161) — BMS часто использует несколько протоколов.

```bash
nmap -sU -p 47808 --script bacnet-info 192.168.10.0/24
tshark -r bms.pcap -Y bacapp -T fields -e ip.src -e bacapp.instance_number | sort -u
```

Оценка поверхности: сколько устройств отвечает, есть ли среди них контроллеры жизнеобеспечения, разрешена ли запись анонимно, есть ли BACnet/SC (шифрование). Отдельно проверь, не «смотрят» ли BMS-устройства в общую сеть: часто BMS и корпоративная сеть не сегментированы, и тогда компромисс офисного компьютера открывает путь к управлению зданием. Это ключевой вывод для отчёта: скомпрометировать BMS — значит получить физический доступ к инфраструктуре.

## Инвентарь здания и приоритеты

Полный аудит BMS начинается с инвентаря. Через `Who-Is`/`I-Am` ты получаешь список устройств: контроллеры, VAV-боксы, чиллеры, насосы, панели доступа. Каждое устройство имеет `Device_Instance` и набор объектов. Прочитав `object-list` и `Description` каждого объекта, ты собираешь карту здания: какие системы есть, кто ими управляет, какие точки критичны.

Особое внимание — точкам жизнеобеспечения: пожарная сигнализация, дымоудаление, системы доступа, лифты. Их объекты (`binaryInput`/`binaryOutput` с именами вида `FireAlarm`, `DoorRelease`) — самые опасные для записи. Именно их нельзя трогать без разрешения.

Далее — `Priority_Array` критичных точек: она показывает, кто сейчас управляет (автоматика, расписание, оператор). Записывая с высоким приоритетом, ты перехватываешь управление. Для отчёта достаточно показать, что запись технически возможна и что приоритет позволяет её применить — без реального воздействия.

## Итог по BACnet

BACnet даёт полный контроль над зданием при отсутствии аутентификации. Ключевые выводы: `Who-Is`/`I-Am` — бесплатная разведка; `ReadProperty` — модель здания; `WriteProperty` — физическое воздействие; приоритеты определяют, что произойдёт при записи. Безопасный аудит — только чтение и карта приоритетов. Защита — сегментация, BACnet/SC, шлюзы с фильтрацией и мониторинг записей.

## Быстрый чек-лист BACnet

Порядок: `Who-Is` → `I-Am` (инвентарь) → `ReadProperty` на `object-list` → чтение `Present_Value` и `Priority_Array` → классификация точек (жизнеобеспечение?). Инструменты: `bacnet-stack`, `BAC0`, `YABE`, Wireshark. Ключевая находка — анонимная запись в критичную точку. Активные действия — только с разрешения.

## Как превратить карту здания в отчёт

Собрав инвентарь и карту точек, сведи всё в отчёт по критичности. Раздели объекты на группы: комфорт (температура, освещение, вентиляция) — низкий риск; эксплуатация (насосы, чиллеры, питание) — средний; жизнеобеспечение (пожарная сигнализация, дымоудаление, контроль доступа, лифты) — высокий. Для каждой группы укажи, доступна ли запись анонимно и какие приоритеты позволяют её применить. Покажи, что даже без реальной записи наличие такой возможности — самостоятельная находка.

Рекомендации: сегментировать BMS в отдельный VLAN, не маршрутизируемый в офисную сеть; внедрить BACnet/SC (TLS) там, где поддерживается; поставить шлюз с фильтрацией `WriteProperty` для неизвестных устройств; включить мониторинг аномальных записей и изменений приоритетов; вести аудит доступа к критичным точкам. В отчёте подчеркни связку «офисная сеть → BMS»: если сегментации нет, обычный фишинг в офисе может привести к физическому доступу в здание.

## Что мы теперь знаем

- BACnet — протокол BMS, порт 47808/UDP.
- Всё описывается объектами с instance и properties.
- Сервисы: Who-Is/I-Am, ReadProperty, WriteProperty.
- По умолчанию аутентификации нет; запись точек = управление зданием.
- BACnet/SC добавляет TLS, но применяется не везде.
