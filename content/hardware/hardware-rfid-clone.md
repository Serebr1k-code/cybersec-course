Низкочастотные RFID-карты (125 кГц) — самая простая цель в физической безопасности. EM4100 и HID Prox не имеют криптографии: карта просто передаёт свой ID. Считать его и записать на «болванку» — дело минут. Урок — практическое клонирование с Proxmark3 и Flipper Zero.

## Почему 125 кГц так просто

LF-карты (125 кГц) передают статичный ID без аутентификации:

- **EM4100** — 40-битный ID, дешёвые брелоки/карты;
- **HID Prox** — 26/35/37-битные форматы, распространён в офисах;
- **T5577** — перезаписываемая болванка (эмулирует EM4100/HID).

Нет challenge-response → нет защиты от клона. Именно поэтому многие организации переходят на HF-карты с криптографией.

| Карта | Частота | Криптография | Клонируется |
|-------|---------|--------------|-------------|
| EM4100 | 125 кГц | нет | Да, тривиально |
| HID Prox | 125 кГц | нет | Да |
| Mifare Classic | 13.56 МГц | Crypto1 (сломан) | Да (autopwn) |
| Mifare DESFire | 13.56 МГц | AES | Нет (релей/иное) |
| EMV | 13.56 МГц | крипто | Нет |

## Инструменты

| Инструмент | Назначение |
|------------|-----------|
| Proxmark3 | Чтение/запись/эмуляция LF и HF |
| Flipper Zero | Удобное чтение/эмуляция LF |
| ChameleonMini | Эмуляция нескольких карт |
| T5577-болванки | Перезаписываемые карты |
| `lf` команды Proxmark | LF-операции |

## Чтение карты (Proxmark3)

```bash
proxmark3 /dev/ttyACM0
> hw tune
> lf search          # определить тип LF-карты
# EM4100 -> "EM 410x ID <hex>"
# HID -> "HID Prox TAG ID: <...>"
> lf em 410x_read    # явное чтение EM4100
> lf hid read        # чтение HID Prox
```

## Запись на болванку и эмуляция

```bash
# Записать EM4100-ID на T5577-болванку
> lf em 410x_write 1122334455 1
# Записать HID (указать формат)
> lf hid clone --r 26 --id 2006ec1234
# Эмуляция без болванки
> lf em 410x sim 1122334455
> lf hid sim --r 26 --id 2006ec1234
```

С Flipper Zero: `125 kHz RFID → Read` → `Save` → `Emulate` или `Write to T5577`.

## Расширенный разобранный пример: клон пропуска в офис

**Дано:** авторизованный пентест, есть доступ к чужому пропуску на несколько секунд.

1. Считываем карту Proxmark'ом:

```bash
> lf search
# -> EM 410x ID 0F00A1B2C3
```

2. Записываем ID на T5577-болванку:

```bash
> lf em 410x_write 0F00A1B2C3 1
```

3. Проверяем клон у турникета (в рамках разрешения) — проходит.
4. Альтернативно — эмуляция с Flipper/Proxmark, если болванки нет.
5. Для HID — уточняем формат (`--r 26/35/37`) и клонируем так же.

## Частые ошибки

- **Путать LF и HF.** 125 кГц и 13.56 МГц — разное оборудование и антенны.
- **Неверный формат HID.** HID бывает 26/35/37 бит — указывайте `--r`.
- **Забыть `hw tune`.** Без настройки антенны чтение нестабильно.
- **Использовать не ту болванку.** Нужен T5577 для LF; HF — другие метки.
- **Считать, что все карты клонируются.** DESFire/EMV — нет.
- **Правовые рамки.** Клонирование пропусков — только авторизованно.
- **Не проверять клон.** Иногда нужно повторить запись (битые блоки).
- **Игнорировать парольные биты.** У части T5577 есть защита от перезаписи.

## Что дальше / решение

- LF (125 кГц) → Proxmark/Flipper + T5577.
- HF без крипто (Mifare Classic) → `hf mf autopwn`.
- HF с крипто (DESFire) → релей (`hardware-nfc-relay`).
- Смежные уроки: `hardware-rfid-nfc`, `hardware-nfc-relay`, `hardware-smartcards`.

## Типы карт 125 кГц

| Карта | Модуляция | Длина ID | Клонируется |
|-------|-----------|----------|-------------|
| EM4100/EM4102 | ASK/Manchester | 40 бит | да, тривиально |
| HID Prox (H10301) | FSK | 26 бит | да |
| HID Prox (Corporate 1000) | FSK | 35+ бит | сложнее |
| Indala | PSK | 32+ бит | зависит |
| T5577 (болванка) | перезаписываемая | любая | для клона |

125 кГц-карты не имеют криптографии: они просто передают ID. Отсюда — тривиальность клонирования. Считыватель не отличает оригинал от копии, потому что нечем.

## Proxmark3: команды детально

```bash
proxmark3 /dev/ttyACM0
hw tune                     # проверить антенны
lf search                   # автоопределение карты
lf em 410x_read             # прочитать EM4100 → ID
lf hid read                 # прочитать HID Prox
lf em 410x_write <ID> 1     # записать ID на T5577
lf em 410x_sim              # эмулировать EM4100
lf hid sim -w H10301 --fc 118 --cn 1234   # эмулировать HID
```

Флаги: `-w` — формат, `--fc` — facility code, `--cn` — card number. `lf search` — самый быстрый старт: он перебирает все протоколы.

## Митигации

- Перейти на карты с криптографией (Mifare DESFire, SEOS).
- Использовать двухфакторный доступ (карта + PIN).
- Мониторить аномалии использования (одна карта в двух местах).
- Не полагаться на «секретность» ID.

## Практическое задание

На своей карте прочитайте ID через `lf search`, запишите на T5577-болванку и убедитесь, что считыватель (свой) принимает клон. Затем объясните, почему считыватель не может отличить копию: в протоколе нет challenge-response.

## 125 кГц против 13.56 МГц

| Параметр | 125 кГц (LF) | 13.56 МГц (HF) |
|----------|--------------|----------------|
| Протоколы | EM4100, HID Prox | Mifare Classic/Desfire, iClass |
| Криптография | нет | есть (Desfire), слабая (Mifare Classic) |
| Клонирование | тривиально | зависит от карты |
| Дальность | больше | меньше |
| Инструменты | Proxmark3 LF | Proxmark3 HF, ACR122U |

Ключевой вывод: LF-карты клонируются по определению, потому что передают статический ID. HF-карты можно усилить криптографией, но Mifare Classic (Crypto1) взломан и тоже клонируется после извлечения ключей.

## Защита пропускной системы

Практические меры:

1. Перейти на DESFire EV2/EV3 или SEOS.
2. Ввести PIN или биометрию как второй фактор.
3. Антипассбэк (запрет повторного входа без выхода).
4. Мониторинг: одна карта в двух точках одновременно — сигнал клонирования.
5. Ротация ключей и централизованный аудит.

Ни одна из мер по отдельности не защищает от клона LF-карты; нужна комбинация (криптография + второй фактор + мониторинг).

## Быстрая проверка

```bash
proxmark3 /dev/ttyACM0
hw tune
lf search
lf em 410x_read
```

`lf search` определяет карту, `lf em 410x_read` читает EM4100, `lf hid read` — HID Prox. Если карта 125 кГц и без криптографии — клон делается за минуты.

## Итог по клонированию

LF-карты (125 кГц) передают статический ID без криптографии — клонируются тривиально (Proxmark3: `lf search` → `lf em 410x_write`). Защита — переход на криптографические карты (DESFire/SEOS) и второй фактор. HF-карты (Mifare Classic) требуют извлечения ключей Crypto1.
