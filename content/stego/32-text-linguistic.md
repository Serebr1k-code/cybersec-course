Лингвистическая стеганография прячет сообщение в самом тексте так, что он выглядит естественным. Это не про невидимые символы, а про выбор слов, структуру, орфографию. Классика: null-шифры (использовать только часть слов/букв), acrostic (первые буквы), mimic-функции (генерация «естественного» текста, несущего данные), кодирование через синонимы/порядок.

## Null-шифры

Идея: берётся «текст-носитель» (null text), и сообщение извлекается по правилу из части слов. Примеры:
- каждое N-е слово;
- первое/последнее слово предложения;
- слова с определённым свойством (длина, первая буква);
- первая буква каждого слова (акростих);
- заглавные буквы (первые буквы заглавных слов).

```bash
# акростих: первые буквы слов
python3 -c "print(''.join(w[0] for w in open('text.txt').read().split()))"
# каждое 5-е слово
awk '{for(i=5;i<=NF;i+=5) printf \"%s \", $i}' text.txt
```

## Кодирование через выбор

- **Синонимы:** одно из двух слов → бит.
- **Порядок слов:** перестановка → бит.
- **Орфография/пунктуация:** запятая vs тире → бит.
- **Форматирование:** курсив/жирный (в HTML/DOCX) → бит.

## Mimic-функции

Mimic-функции генерируют текст, статистически похожий на естественный (например, «spam-mimic» — как спам-письмо), но несущий данные. Декодер знает модель и извлекает биты из отклонений. Трудно распознать без знания схемы.

## Как распознавать

- Текст «выглядит нормально», но странный/неестественный по смыслу.
- Есть подсказка на схему (первая буква, N-е слово).
- В CTF часто дают текст + вопрос «что тут скрыто».
- Проверяйте акростих, первые/последние буквы, каждое N-е слово, заглавные.

## Разобранный пример

CTF: дан абзац «случайного» текста. Пентестер:
1. Пробует акростих → бессмыслица.
2. Пробует первое слово каждого предложения → читается.
3. Пробует заглавные буквы → флаг.

## Частые ошибки

- Искать только невидимые символы, пропуская структуру текста.
- Не пробовать несколько схем (акростих, N-е слово, заглавные).
- Игнорировать форматирование (курсив/жирный как канал).
- Считать «неестественность» субъективной и не проверять системно.

## Что делать дальше

- **Акростих** → первые буквы слов/строк.
- **N-е слово/буква** → перебор N.
- **Заглавные/пунктуация** → карта в биты.
- **Mimic** → ищите подсказку о модели/словаре.

## Полный набор лингвистических каналов

Лингвистическая стего прячет данные не в байтах, а в **структуре и выборе** текста. Полный чек-лист каналов:

| Канал | Правило извлечения | Пример |
|-------|--------------------|--------|
| Акростих | первые буквы слов/строк | `Т**очно** ...` → «То...» |
| N-е слово | каждое N-е слово | 5-е слово каждого предложения |
| Заглавные | первые буквы заглавных слов | `The **F**ox **L**eaps` → «FL» |
| Первая/последняя буква | буква по позиции | последние буквы слов |
| Пунктуация | тип знака → бит | запятая=0, тире=1 |
| Синонимы | выбор слова → бит | «big»=0, «large»=1 |
| Порядок | перестановка → бит | порядок пары |
| Формат | курсив/жирный → бит | HTML `<i>`/`<b>` |
| Невидимые символы | zero-width, пробелы | U+200B/U+200C |
| Длина | длина слова → бит | чётная/нечётная |

## Акростихи и null-шифры: скрипты

```bash
# акростих: первые буквы слов
python3 -c "import sys;print(''.join(w[0] for w in open('text.txt').read().split()))"
# первые буквы строк
python3 -c "print(''.join(l.strip()[0] for l in open('text.txt') if l.strip()))"
# каждое N-е слово (перебор N)
for n in 2 3 4 5 6 7 8; do
  echo -n "N=$n: "; awk -v n=$n '{for(i=n;i<=NF;i+=n) printf "%s",$i}' text.txt; echo
done
# первая буква каждого предложения
python3 -c "import re;print(''.join(s.strip()[0] for s in re.split(r'[.!?]', open('text.txt').read()) if s.strip()))"
# заглавные буквы (первые буквы слов, начинающихся с заглавной не в начале предложения)
python3 -c "
import re
t=open('text.txt').read()
print(''.join(w[0] for w in t.split() if w[:1].isupper()))"
```

## Кодирование выбором: реализация

```python
# Синонимы → биты: заранее известен словарь пар
pairs = {'big':('big','large'), 'fast':('fast','quick')}
# декодирование: для каждого целевого слова выбираем бит по тому, какой синоним в тексте
# Пунктуация → биты
import re
t = open('text.txt').read()
bits = ''.join('1' if c == '—' else '0' for c in t if c in ',—;')
# Формат → биты (HTML)
import re
bits = ''.join('1' if m == 'b' else '0' for m in re.findall(r'<(b|i)>', open('text.html').read()))
```

## Mimic-функции и статистика

Mimic-функции (Wayner) генерируют текст, статистически похожий на естественный (спам, техническая документация), но несущий данные. Отклонения от «идеальной» модели кодируют биты. Признаки: текст грамматически/семантически «почти» нормальный, но странный; длина/распределение слов необычны. Декодирование требует знания модели и контекста — в CTF обычно есть подсказка.

## Распознавание: чек-лист

1. Текст выглядит естественно, но задача просит «найти скрытое» → структурный канал.
2. Проверьте акростих (слова и строки).
3. Переберите N-е слово/букву.
4. Соберите заглавные и первые/последние буквы.
5. Проверьте пунктуацию и форматирование (курсив/жирный/цвет).
6. Ищите невидимые символы: `xxd`, `cat -A`, `unicode`-анализ.

```bash
cat -A text.txt | head            # показать невидимые/спецсимволы
python3 -c "print([hex(ord(c)) for c in open('text.txt').read() if ord(c)>127][:50])"
```

## Инструменты

| Инструмент | Назначение | Пример |
|------------|-----------|--------|
| Python | любые скрипты извлечения | см. выше |
| `awk` | N-е слово | `awk -v n=5 '{for(i=5;i<=NF;i+=5)printf \"%s\",$i}'` |
| `cat -A`/`xxd` | невидимые символы | `cat -A text.txt` |
| `grep -P` | zero-width/unicode | `grep -P '\x{200b}' text.txt` |
| online-декодеры | акростих/нуль-шифры | — |

## Разобранные примеры

**1. Акростих.** Первые буквы строк читаются как `flag{...}`.

**2. N-е слово.** Перебор N даёт осмысленную фразу только при N=7.

**3. Невидимые символы.** `cat -A` показывает zero-width символы; их двоичная карта → ASCII.

## Частые ошибки и отладка

- **Искать только невидимые символы**, пропуская структуру.
- **Не перебирать N** — «правильное» N даёт текст.
- **Игнорировать формат** (курсив/жирный/цвет как канал).
- **Считать «неестественность» субъективной** и не проверять системно.
- **Отладка:** если акростих даёт мусор — попробуйте первые буквы **строк**, последние буквы, каждое N-е.

## Что делать дальше / дерево решений

1. Акростих (слова/строки) → читается? → готово.
2. Нет → перебор N-го слова/буквы.
3. Нет → заглавные/первые/последние буквы.
4. Нет → пунктуация/формат/синонимы.
5. Нет → невидимые символы (`cat -A`, unicode-анализ).

## Шпаргалка: чек-лист извлечения

```bash
# акростих слов/строк
python3 -c "print(''.join(w[0] for w in open('t.txt').read().split()))"
python3 -c "print(''.join(l.strip()[0] for l in open('t.txt') if l.strip()))"
# каждое N-е слово
for n in 2 3 4 5 6 7 8; do echo -n "N=$n "; awk -v n=$n '{for(i=n;i<=NF;i+=n)printf \"%s\",$i}' t.txt; echo; done
# заглавные + невидимые символы
python3 -c "print(''.join(w[0] for w in open('t.txt').read().split() if w[:1].isupper()))"
cat -A t.txt | head; python3 -c "print([hex(ord(c)) for c in open('t.txt').read() if ord(c)>127][:40])"
```

Рабочий процесс: начните с акростиха (самый частый), затем переберите N-е слово/букву, затем заглавные/первые/последние буквы, пунктуацию, формат (курсив/жирный в HTML/DOCX) и, наконец, невидимые символы (zero-width). Если ничего не выходит, но текст «неестественный» — это mimic-функция: ищите подсказку о модели/словаре в условии. В отчёте фиксируйте правило извлечения (акростих/N-е слово/…) — без него результат невоспроизводим.
