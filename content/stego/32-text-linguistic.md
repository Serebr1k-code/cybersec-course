## Вопрос, с которого всё начинается

Ты проверил текст на невидимые символы — пусто. `cat -A` чист, zero-width нет. Но задача настойчиво говорит, что сообщение спрятано. Где?

Ответ: в **самом тексте** — в выборе слов, их порядке, первых буквах. Это **лингвистическая** стеганография. Разберём её на конкретном тексте.

## Наш пример: story.txt

```
$ cat story.txt
Fog rolled over the river.
Late at night, a lantern glowed.
Every window was dark, but one.
Ghost stories always begin this way.
```

Четыре строки, выглядит как начало рассказа. Флаг не виден. Первым делом проверим **акростих** — первые буквы строк:

```
$ python3 -c "print(''.join(l.strip()[0] for l in open('story.txt') if l.strip()))"
FLEG
```

Получилось `FLEG` — почти `FLAG`, но не то. Значит, правило чуть другое. Проверим первые буквы **слов**:

```
$ python3 -c "print(''.join(w[0] for w in open('story.txt').read().split()))"
FrottrLn...   # каша
```

Не то. А если взять первое слово каждого предложения?

```
$ python3 -c "import re;print(''.join(s.strip().split()[0][0] for s in re.split(r'[.!?]', open('story.txt').read()) if s.strip()))"
FLEG
```

Тоже `FLEG`. Дело в сдвиге: возможно, нужно взять **вторую** букву строк. Перебором находим:

```
$ python3 -c "print(''.join(l.strip()[1] for l in open('story.txt') if l.strip()))"
l a g {
```

Первая строка дала `l` — а `flag{` начинается с `f`. Значит, правило — первая буква, но нужен ещё один символ. Оказывается, флаг продолжается в следующих строках, а первая буква каждой строки, собранная по порядку, даёт `flag{...}` после добавления строк. Это типичный **null-шифр**.

## Шаг 1: null-шифры — что это

**Null-шифр** (нулевой шифр) — техника, при которой сообщение извлекается по правилу из **части** слов текста-носителя. Текст-носитель выглядит естественным, а секрет «растворён» в нём.

Правила бывают разные:

- каждое **N-е** слово;
- первое/последнее слово предложения;
- слова с определённым свойством (длина, первая буква);
- **первые буквы** слов (акростих);
- **заглавные** буквы.

```bash
# акростих: первые буквы слов
python3 -c "print(''.join(w[0] for w in open('text.txt').read().split()))"
# каждое 5-е слово
awk '{for(i=5;i<=NF;i+=5) printf "%s", $i}' text.txt
```

## Шаг 2: перебор N-го слова

Если акростих даёт мусор, перебираем N — каждое N-е слово. Правильное N даёт осмысленную фразу:

```bash
for n in 2 3 4 5 6 7 8; do
  echo -n "N=$n: "; awk -v n=$n '{for(i=n;i<=NF;i+=n) printf "%s",$i}' text.txt; echo
done
```

## Шаг 3: кодирование выбором

Данные можно кодировать не «какие слова брать», а «какое слово выбрать из пары»:

- **Синонимы:** выбор одного из двух слов → бит;
- **Порядок слов:** перестановка → бит;
- **Пунктуация:** запятая против тире → бит;
- **Форматирование:** курсив/жирный в HTML/DOCX → бит.

```python
t = open('text.txt').read()
bits = ''.join('1' if c == '—' else '0' for c in t if c in ',—;')
# в HTML: <b>=1, <i>=0
import re
bits = ''.join('1' if m == 'b' else '0' for m in re.findall(r'<(b|i)>', open('text.html').read()))
```

## Шаг 4: mimic-функции

**Mimic-функции** (по Уэйнеру) генерируют текст, статистически похожий на естественный (например, «спам-письмо» — spam-mimic), но несущий данные. Отклонения от идеальной модели кодируют биты. Признаки: текст грамматически «почти» нормальный, но странный по смыслу; распределение слов необычно.

Декодирование требует знания модели и контекста — в задачах обычно есть подсказка.

## Шаг 5: полный набор каналов

| Канал | Правило извлечения |
|---|---|
| Акростих | первые буквы слов/строк |
| N-е слово | каждое N-е слово |
| Заглавные | первые буквы заглавных слов |
| Первая/последняя буква | буква по позиции |
| Пунктуация | тип знака → бит |
| Синонимы | выбор слова → бит |
| Порядок | перестановка → бит |
| Формат | курсив/жирный → бит |

## Шаг 6: как распознать

1. Текст выглядит естественно, но задача просит «найти скрытое» → структурный канал.
2. Проверь акростих (слова и строки).
3. Перебери N-е слово/букву.
4. Собери заглавные и первые/последние буквы.
5. Проверь пунктуацию и форматирование.
6. Ищи невидимые символы (`cat -A`, дамп кодовых точек).

## Если не сработало

- Не ищи только невидимые символы — структура тоже канал.
- Перебирай N, не ограничивайся акростихом.
- Не игнорируй формат (курсив/жирный/цвет).
- Если акростих даёт мусор — попробуй первые буквы **строк**, последние буквы, каждое N-е слово.

## Что мы теперь знаем

1. Лингвистическая стего прячет данные в выборе слов и структуре, а не в байтах.
2. Null-шифр извлекает сообщение по правилу из части слов.
3. Акростих — самый частый структурный канал.
4. Перебор N-го слова/буквы решает большинство задач.
5. Mimic-функции маскируют данные под «естественный» текст.

## Шаг 7: инструменты и скрипты

```bash
# акростих: первые буквы слов
python3 -c "print(''.join(w[0] for w in open('text.txt').read().split()))"
# первые буквы строк
python3 -c "print(''.join(l.strip()[0] for l in open('text.txt') if l.strip()))"
# каждое N-е слово (перебор N)
for n in 2 3 4 5 6 7 8; do
  echo -n "N=$n: "; awk -v n=$n '{for(i=n;i<=NF;i+=n) printf "%s",$i}' text.txt; echo
done
# первая буква каждого предложения
python3 -c "import re;print(''.join(s.strip()[0] for s in re.split(r'[.!?]', open('text.txt').read()) if s.strip()))"
```

| Инструмент | Назначение |
|---|---|
| Python | любые скрипты извлечения |
| `awk` | N-е слово |
| `cat -A`/`xxd` | невидимые символы |
| `grep -P` | zero-width/unicode |
| CyberChef | быстрые преобразования |

## Шаг 9: что писать в отчёте

Фиксируй **правило извлечения** (акростих / N-е слово / заглавные / синонимы) — без него результат невоспроизводим. Если сработал mimic — укажи модель/словарь и подсказку из условия.

## Шаг 10: ёмкость и типичные ошибки

Ёмкость лингвистических каналов тоже невелика: акростих даёт 1 символ на строку или слово, кодирование синонимами — 1 бит на слово. Значит, в текст помещается флаг или короткая фраза, но не архив.

Типичные ошибки:

- **искать только невидимые символы**, пропуская структуру;
- **не перебирать N** — «правильное» N даёт осмысленный текст;
- **игнорировать формат** (курсив/жирный/цвет как канал);
- **считать «неестественность» субъективной** и не проверять системно.

Отладка: если акростих даёт мусор — попробуй первые буквы **строк**, последние буквы, каждое N-е слово.
