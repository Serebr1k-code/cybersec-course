## Вопрос, с которого всё начинается

В задаче дали файл `poem.txt` — обычное стихотворение из четырёх строк. Ни картинок, ни архивов, ни метаданных. Но сказано, что «сообщение внутри». Где его искать в простом тексте?

Ответ: в самом тексте. **Null-шифр** (null cipher) прячет сообщение так, что открытый текст выглядит осмысленным, а данные извлекаются по правилу: первые буквы строк, каждая N-я буква, выбор слов. Разберём это на нашем стихотворении.

## Наш пример: poem.txt

Смотрим файл:

```
Фонарь дрожал в ночной тиши,
Луна скользила по воде,
А ветер пел едва слышно,
Гроза придёт — и нет беде.
```

Четыре строки, каждая начинается с заглавной буквы. Прочитаем эти буквы подряд:

```python
lines = [l for l in open("poem.txt", encoding="utf-8").read().splitlines() if l.strip()]
acro = "".join(l.strip()[0] for l in lines)
print(acro)
```

```
ФЛАГ
```

Вот и сообщение. Первые буквы строк складываются в **ФЛАГ** — это классический **акростих**.

## Шаг 1: акростих, телестих, мезостих

Акростих — лишь один из семейства. Правило может брать разные позиции:

- **Акростих** — первые буквы строк.
- **Телестих** — последние буквы строк.
- **Мезостих** — буквы в фиксированной позиции внутри каждой строки.

Проверим телестих на том же файле:

```python
tele = "".join(l.strip()[-1] for l in lines)
print(tele)
```

```
,,,.
```

Здесь ничего — только знаки препинания. Это нормально: одно стихотворение несёт один канал, и его надо угадать. Часто акростих комбинируют с **регистром**: заглавные буквы внутри строки (а не в начале) отмечают значимые символы.

## Шаг 2: каждая N-я буква — перебор

Второе по частоте правило — «каждая N-я буква». Возьмём прозу и переберём N:

```python
s = "Мой друг обещал приехать к ужину ровно в семь"
letters = [c for c in s if c.isalpha()]      # только буквы, без пробелов
for n in range(1, 6):
    print(n, "".join(letters[n-1::n]))
```

```
1 Мойдругобещалприехатькужинуровновсемь
2 одуоеапихткжнрвосм
3 йубархьжуввм
4 доаитжром
5 рертиве
```

Осмысленного слова не видно — значит, для этого текста правило не «каждая N-я буква» (или N больше 5). Приём перебора N важен: правило заранее неизвестно, и `letters[n-1::n]` — быстрый способ проверить все варианты сразу. Обрати внимание: мы сначала убрали всё, кроме букв (`c.isalpha()`), иначе пробелы и знаки сбивали бы счёт.

## Шаг 3: первые буквы слов

Ещё одно правило — первые буквы **слов** (не строк):

```python
import re
words = re.findall(r"\w+", s, re.UNICODE)
print("".join(w[0] for w in words))
```

```
Мдопкрувс
```

Тоже нечитаемо — но в задачах, где акростих построен по словам, именно этот приём срабатывает. Перебирай оба уровня: строки и слова.

## Шаг 4: книжный шифр

**Книжный шифр** кодирует сообщение указателями: номер строки, номер слова (или страница, строка, буква). Ключ — сама книга, известная и отправителю, и получателю. Если даны координаты `(строка, слово)`, собираем буквы так:

```python
book = open("book.txt", encoding="utf-8").read().splitlines()
coords = [(3, 2), (5, 7), (8, 1)]          # (номер строки, номер слова)
msg = "".join(book[r-1].split()[w-1] for r, w in coords)
print(msg)
```

Здесь `book[r-1]` берёт строку (нумерация с нуля), `.split()[w-1]` — слово в ней. Без той же самой книги (или её копии) сообщение не прочитать — это и есть «ключ».

## Шаг 5: лингвистическое сокрытие

Самый тонкий вариант: текст генерируется так, что выбор **каждого слова** кодирует биты, но предложение остаётся грамматичным. Например, автор постоянно выбирает между синонимами «большой»/«крупный», и выбор кодирует `0`/`1`.

Признаки такого **стеготекста**:

- **Неестественная синонимия** — навязчивое чередование пар синонимов.
- **Регулярные вставки** — «собственно», «как известно» появляются ритмично.
- **Слишком ровный стиль** — нет естественных вариаций длины предложений.

Детект — статистика: частоты синонимичных пар, распределение длин предложений.

## Шаг 6: подводные камни

- **Не перебрать N.** Неизвестно, какая буква/слово несёт данные — пробуй N = 1…15.
- **Игнорировать регистр.** Заглавные буквы могут быть маркерами, а не частью сообщения.
- **Забыть про пунктуацию.** Позиции запятых и точек — тоже канал.
- **Считать текст простым.** Возможно, он ещё и зашифрован — тогда нужен частотный анализ.
- **Путать акростих и телестих.** Первые и последние буквы — разные каналы.
- **Не проверить обратный порядок.** Читать можно справа налево и снизу вверх.

## Шаг 7: инструменты и исторический контекст

Инструменты для null-шифра простые — почти всё делается парой строк на Python:

- **Python + `re`** — универсальный разбор любого правила (первые буквы слов, N-я буква, координаты).
- **`grep`/`awk`/`sed`** — извлечение позиций прямо из командной строки. Например, первые буквы слов через `awk`:
  ```bash
  awk '{for(i=1;i<=NF;i++) printf substr($i,1,1)}' poem.txt
  ```
- **CyberChef** — визуальные операции над текстом («Extract every Nth character»).
- **Частотный анализ** — если текст ещё и зашифрован.

Null-шифр — одна из древнейших техник сокрытия. В античности сообщения прятали в первых буквах строк (акростих), в Спарте применяли скиталу (перестановку букв по стержню), а в Новое время — «книжные» шифры, где ключом служил общий текст. Классический null-шифр из криптографии — это сообщение, спрятанное в «пустых» словах-заполнителях (nulls), которые не несут смысла, но несут буквы.

Математика перебора проста: если правило «каждая N-я буква», N перебирается от 1 до ~15 — этого хватает почти для всех случаев. Для слов — то же самое. Скрипт печатает все варианты, и глазами выбирается осмысленный.

## Шаг 8: акроверс и комбинированные правила

Помимо букв, правило может брать первые **слова** строк — это **акроверс**:

```python
first_words = "".join(l.strip().split()[0] for l in lines)
print(first_words)
```

Правила часто комбинируют. Например, регистр отмечает, какие строки «значат», а акростих берёт из них буквы; или N-я буква считается только внутри слов длиннее трёх букв. Поэтому полезно держать в голове список каналов и проверять их по очереди: первые/последние буквы строк и слов, N-я буква, регистр, пунктуация, обратный порядок.

Ограничения метода тоже стоит помнить: без знания схемы приходится перебирать; одна опечатка ломает всё сообщение; акростих заметен, если специально искать. Но в CTF и в истории это — самый «человеческий» способ сокрытия, не требующий ни файлов, ни инструментов.

## Что мы теперь знаем

1. Null-шифр прячет сообщение в осмысленном тексте; носитель — сам текст.
2. Акростих — первые буквы строк; телестих — последние; мезостих — фиксированная позиция.
3. «Каждая N-я буква/слово» — правило перебирается (`letters[n-1::n]`).
4. Книжный шифр — указатели (строка, слово) по известной книге-ключу.
5. Лингвистическое сокрытие кодирует биты выбором слов; детект — статистика.
6. Сначала убирай не-буквы, потом перебирай правила и регистр.

## Куда дальше

Мы научились вытаскивать сообщение из обычного текста. Дальше посмотрим на **текстовые носители посложнее**: пробелы, невидимые Unicode-символы и гомоглифы — там данные прячутся уже не в буквах, а в их невидимых деталях. А пока запомни: дали текст — перебирай первые/последние буквы строк и слов и разные N.

## Где пригодится

- **CTF:** задачи с текстом или стихом, где сообщение спрятано в буквах.
- **OSINT:** исторические методы сокрытия и тайные сообщения.
- **Криптография:** переход к частотному анализу, когда текст ещё и зашифрован.
