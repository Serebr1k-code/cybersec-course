Null-шифр (null cipher) прячет сообщение в открытом тексте так, что сам текст выглядит осмысленным. Классика: читать каждую N-ю букву, первые буквы слов или строк, последние буквы предложений. Родственные методы — акростих (первые буквы строк образуют слово), книжный шифр (указатели «страница–строка–слово») и лингвистическое сокрытие (выбор синонимов кодирует биты). Это «стеганография без контейнера»: носителем служит сам текст.

## Основные варианты

- **Каждая N-я буква.** «Мой друг обещал приехать к ужину ровно в семь» — берём каждую 3-ю букву.
- **Первые буквы слов.** «Котёнок Иван Ловит Муху» → `КИЛМ`.
- **Первые/последние буквы строк.** Акростих/телестих.
- **Каждое N-е слово.** По номеру слова в предложении.
- **Знаки препинания.** Тип/позиция запятых кодирует биты.
- **Регистр.** Выбор заглавной буквы в слове кодирует бит.
- **Синонимы.** Выбор между «большой»/«крупный» кодирует `0`/`1`.
- **Книжный шифр.** Последовательность (страница, строка, слово) указывает буквы.

## Инструменты и команды

- **`grep`/`awk`/`sed`** — извлечение позиций.
- **Python** — гибкий разбор любого правила.
- **`cyberchef`** — визуальные операции над текстом.
- **`quipqiup`/частотный анализ** — когда текст ещё и зашифрован.

Извлечь каждую N-ю букву:

```python
text = "Мой друг обещал приехать к ужину ровно в семь"
n = 3
letters = [c for c in text if c.isalpha()]
print("".join(letters[n-1::n]))
```

Первые буквы слов:

```python
import re
text = "Котёнок Иван Ловит Муху"
print("".join(w[0] for w in re.findall(r"\w+", text, re.UNICODE)))
```

## Разобранный пример: акростих

Дано стихотворение. Первые буквы строк:

```python
lines = open("poem.txt", encoding="utf-8").read().splitlines()
print("".join(l.strip()[0] for l in lines if l.strip()))
```

Если получается осмысленное слово (`flag`/`ctf`) — это и есть сообщение. Часто акростих комбинируют с регистром: заглавные буквы в середине строки отмечают нужные символы.

## Книжный шифр

Сообщение кодируется указателями: номер страницы, номер строки, номер слова. Получатель берёт те же самые страницы книги и читает указанные слова. Ключ — сама книга.

Пример разбора, когда даны пары (строка, слово):

```python
book = open("book.txt", encoding="utf-8").read().splitlines()
coords = [(3, 2), (5, 7), (8, 1)]   # (номер строки, номер слова)
msg = "".join(book[r-1].split()[w-1] for r, w in coords)
print(msg)
```

## Лингвистическое сокрытие

Более тонкий вариант: автор пишет осмысленный текст, но каждый выбор (синоним, порядок слов, наличие «что») кодирует бит. Детектировать сложно, потому что текст естественный. Признаки: неестественная плотность определённых конструкций, повторяющиеся пары синонимов, подозрительно «ровный» стиль.

## Сравнение методов

| Метод | Носитель | Автоматизация | Заметность |
|---|---|---|---|
| Каждая N-я буква | текст | тривиальная | средняя |
| Акростих | текст | тривиальная | низкая |
| Каждое N-е слово | текст | тривиальная | низкая |
| Знаки препинания | текст | средняя | очень низкая |
| Синонимы | текст | сложная | очень низкая |
| Книжный шифр | текст + книга | средняя | средняя |

## Частые ошибки и подводные камни

- **Не перебрать N.** Неизвестно, какая буква/слово «несёт» данные — пробуйте N = 1..10.
- **Игнорировать регистр.** Заглавные буквы могут быть маркерами.
- **Забыть про пунктуацию.** Позиции запятых/точек — канал.
- **Считать текст простым.** Возможно, он ещё и зашифрован (тогда — частотный анализ).
- **Не проверить обратный порядок.** Читать можно справа налево/снизу вверх.
- **Путать акростих и телестих.** Первые vs последние буквы.

## Что дальше / решение

- Попробуйте первые/последние буквы строк и слов.
- Переберите N (каждая N-я буква/слово) и регистр.
- Проверьте пунктуацию и позиции как маркеры.
- Если есть внешний ключ (книга) — используйте книжный шифр.
- Если текст ещё и зашифрован — примените частотный анализ.

## Исторический контекст

Null-шифр — одна из древнейших техник сокрытия. В античности сообщения прятали в первых буквах строк (акростих), в Спарте использовали скиталу (перестановка), а в Новое время — «книжные» шифры, где ключом служил общий текст. Знаменитый пример — акростихи в письмах и стихах, где первые буквы складывались в имя или приказ. Классический null-шифр из криптографии — сообщение в «пустых» словах-заполнителях (nulls).

## Математика: перебор позиций

Если правило «каждая N-я буква», неизвестно N. Перебор N от 1 до ~15 покрывает почти все случаи. Аналогично для слов. Скрипт печатает все варианты — глазами выбирается осмысленный.

```python
text = open("poem.txt", encoding="utf-8").read()
letters = [c for c in text if c.isalpha()]
for n in range(1, 16):
    print(n, "".join(letters[n-1::n])[:60])
```

```python
import re
words = re.findall(r"\w+", text)
for n in range(1, 16):
    print(n, "".join(w[0] for w in words[n-1::n]))
```

## Акростих, телестих, мезостих

- **Акростих** — первые буквы строк.
- **Телестих** — последние буквы строк.
- **Мезостих** — буквы в фиксированной позиции внутри строк.
- **Акроверс** — первые слова строк.

Комбинация с регистром: заглавные буквы внутри строки отмечают значимые символы. Часто именно регистр, а не позиция, несёт данные.

```python
lines = [l for l in text.splitlines() if l.strip()]
acro = "".join(l.strip()[0] for l in lines)
tele = "".join(l.strip()[-1] for l in lines)
print(acro, tele)
```

## Книжный шифр: варианты

- **(строка, слово)** — координаты в общем тексте.
- **(страница, строка, буква)** — классический вариант.
- **Индексы в собственном тексте** — сообщение кодируется позициями слов.
- **Отсылки к словарю** — номера слов по частоте.

```python
book = open("book.txt", encoding="utf-8").read().splitlines()
coords = [(3,2), (5,7), (8,1)]
print("".join(book[r-1].split()[w-1] for r,w in coords))
```

## Лингвистическое сокрытие и стеготекст

Наиболее изощрённый вариант: текст генерируется так, что выбор каждого слова кодирует биты, но предложение остаётся грамматичным. Признаки:

- **Неестественная синонимия** — автор постоянно выбирает между «большой»/«крупный».
- **Регулярные вставки** — «собственно», «как известно» появляются ритмично.
- **Слишком ровный стиль** — нет естественных вариаций.

Детект — статистика: частоты синонимичных пар, распределение длин предложений.

## Инструменты и приёмы

- **`cyberchef`** — визуальные операции (извлечь каждый N-й символ).
- **Python/regex** — универсальный разбор.
- **Частотный анализ** — если текст ещё и зашифрован.
- **`strings`/`xxd`** — если текст в бинарном файле.

```bash
# извлечь первые буквы слов через awk
awk '{for(i=1;i<=NF;i++) printf substr($i,1,1)}' poem.txt
```

## Практический чек-лист

1. Попробовать первые/последние буквы строк и слов.
2. Перебрать N для букв и слов (1..15).
3. Проверить регистр как маркер.
4. Проверить пунктуацию и её позиции.
5. Попробовать обратный порядок и транспозиции.
6. Если текст выглядит зашифрованным — частотный анализ.
7. Если есть внешний ключ — книжный шифр.

## Ограничения

- **Зависимость от «правила»**: без знания схемы приходится перебирать.
- **Хрупкость**: одна опечатка ломает сообщение.
- **Языковая зависимость**: акростихи работают по-разному в разных языках.
- **Обнаружимость**: акростих заметен, если специально искать.
