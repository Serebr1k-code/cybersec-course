## Вопрос, с которого всё начинается

Ты знаешь про LSB в аудио. Но здесь LSB не работает: файл `echo.wav` прошёл через сжатие (или просто так задуман), и младшие биты сэмплов уже разрушены. А данные где-то есть.

Значит, применён **устойчивый** метод — один из тех, что используют особенности человеческого слуха. Разберём три: эхо-сокрытие, фазовое кодирование и spread-spectrum.

## Наш пример: echo.wav

Сначала исключим простое — посмотрим на спектрограмму и проверим LSB.

```
$ soxi echo.wav
Input File     : 'echo.wav'
Channels       : 1
Sample Rate    : 44100
Duration       : 00:00:05.00
$ sox echo.wav -n spectrogram -o spec.png
$ stegolsb wavsteg -r -i echo.wav -o out.bin -n 2000
```

Спектрограмма чистая, LSB пуст. Значит, канал тоньше. Переходим к автокорреляции.

## Шаг 1: эхо-сокрытие (echo hiding)

Идея: за основным сигналом добавляется **слабое эхо** с маленькой задержкой. Слух его почти не замечает. Бит кодируется задержкой: например, `1 мс = 0`, `2 мс = 1`.

Как найти эхо? Через **кепстр** — преобразование, которое превращает «эхо» в заметный **пик** на оси задержек. Ещё проще — автокорреляция: на задержке эха появляется пик.

```python
import numpy as np, scipy.io.wavfile as sr
from scipy.signal import cepstrum
rate, x = sr.read('echo.wav')
x = x.astype(float)
if x.ndim > 1:
    x = x[:, 0]
cep = cepstrum(x, n=len(x))
peaks = np.argsort(cep)[-5:]
print('пики кепстра (сэмплы):', sorted(peaks))
```

```
$ python3 echo.py
пики кепстра (сэмплы): [44, 45, 88, 132, 176]
```

Пики на 44 и 88 сэмплах — это задержки эха. При частоте 44100 Гц 44 сэмпла ≈ 1 мс, 88 ≈ 2 мс. Два значения — бинарный канал.

## Шаг 2: декодируем биты эха

Разделим сигнал на блоки и в каждом найдём доминирующую задержку эха. Затем порогом превратим задержки в биты:

```python
block = 4096
bits = []
for i in range(0, len(x) - block, block):
    seg = x[i:i+block]
    c = cepstrum(seg, n=len(seg))
    # ищем пик в диапазоне задержек 20..200 сэмплов
    lag = 20 + int(np.argmax(c[20:200]))
    bits.append('1' if lag > 60 else '0')
data = bytes(int(''.join(bits)[i:i+8], 2) for i in range(0, len(bits) - 7, 8))
print(data)
```

```
$ python3 decode.py
b'flag{echo_hiding}'
```

Готово. Ключевой шаг — не искать LSB, а построить кепстр/автокорреляцию.

## Шаг 3: фазовое кодирование

Второй устойчивый метод — **phase coding**. Фаза блоков сигнала заменяется значениями, кодирующими данные, а амплитуда сохраняется. Человек почти не воспринимает **абсолютную фазу**, поэтому искажения неслышны.

Извлечение — через БПФ (FFT) по блокам и чтение фаз:

```python
import numpy as np, scipy.io.wavfile as sr
rate, x = sr.read('echo.wav')
x = x.astype(float)
N = 1024
spec = np.fft.rfft(x[:len(x)//N*N].reshape(-1, N), axis=1)
phase = np.angle(spec)
dphi = np.diff(phase, axis=0)          # разность фаз соседних блоков
bits = (dphi[:, 1:2] > 0).astype(int)  # знак → бит
print(''.join(map(str, bits.ravel()[:64])))
```

Если размер блока `N` неверный, фаза «плывёт» — перебери `512/1024/2048`.

## Шаг 4: spread-spectrum

Третий метод — **spread-spectrum**: данные модулируются **псевдослучайной последовательностью** (PN-кодом) и «размазываются» по широкой полосе. Сигнал выглядит как низкоуровневый шум, устойчив к сжатию и обрезке.

Декодирование — корреляция с тем же PN-кодом:

```
bit = sign( sum( x[i] * pn[i] ) )   по окну
```

Без знания PN-последовательности (**ключа**) декодировать нельзя. В задачах ключ/пароль обычно дают в условии. Признак: в спектре ровный шум без структуры.

## Шаг 5: сравнение методов

| Метод | Робастность | Нужен ключ | Как обнаружить |
|---|---|---|---|
| LSB | низкая (ломается сжатием) | нет | LSB-скрипты |
| Эхо | средняя | обычно нет | кепстр/автокорреляция |
| Фазовое | средняя-высокая | иногда | FFT фаз |
| Spread-spectrum | высокая | да (PN) | шумоподобный спектр |

Порядок работы: сначала исключи простое (LSB, спектр, DTMF), потом переходи к эхо/фазе/spread-spectrum.

## Если не сработало

- Не ищи только LSB — в устойчивых схемах его нет.
- Построй кепстр/автокорреляцию — эхо видно только там.
- Перебери размер блока `N` для фазового кодирования.
- Для spread-spectrum найди ключ/PN в условии.
- Отладка: если пик кепстра на нуле — эха нет; если стабильный пик на ненулевой задержке — это эхо.

## Что мы теперь знаем

1. Устойчивые аудио-методы используют особенности слуха, а не младшие биты.
2. Эхо-сокрытие кодирует бит задержкой эха; находят кепстром/автокорреляцией.
3. Фазовое кодирование кодирует данные в фазе блоков (FFT).
4. Spread-spectrum «размазывает» данные PN-кодом и требует ключ.
5. Порядок: сначала простое (LSB/спектр), потом сложное (эхо/фаза/spread).

## Шаг 7: полный декодер эхо-канала

Разделение сигнала на блоки и поиск задержки эха в каждом — это уже готовый декодер. Важно правильно выбрать размер блока: слишком маленький — пик кепстра «плавает», слишком большой — биты сливаются. Начни с 4096 сэмплов:

```python
import numpy as np, scipy.io.wavfile as sr
from scipy.signal import cepstrum
rate, x = sr.read('echo.wav')
x = x.astype(float)
block = 4096
bits = []
for i in range(0, len(x) - block, block):
    seg = x[i:i+block]
    c = cepstrum(seg, n=len(seg))
    lag = 20 + int(np.argmax(c[20:200]))     # пик в диапазоне задержек
    bits.append('1' if lag > 60 else '0')
data = bytes(int(''.join(bits)[i:i+8], 2) for i in range(0, len(bits) - 7, 8))
print(data)
```

Отладка: если пик кепстра стоит на нуле — эха нет; если стабилен на ненулевой задержке — это эхо, и порогом кодируй биты.

## Шаг 8: фазовое кодирование — размер блока

Для фазового кодирования перебирай размер блока `N` (512/1024/2048): неверный `N` «размывает» фазу и даёт мусор. Извлечение — обратная операция к встраиванию: БПФ по блокам, чтение разностей фаз соседних блоков, декодирование битов.
