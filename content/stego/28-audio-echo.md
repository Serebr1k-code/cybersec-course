LSB в аудио ломается при сжатии. Устойчивые методы используют свойства восприятия: эхо (человек не замечает слабого эха), фазу (слух к ней малочувствителен) и spread-spectrum (данные размазаны по спектру как шум). Их применяют для watermarking и скрытых каналов; в CTF они встречаются реже, но требуют понимания, где искать.

## Эхо-сокрытие (echo hiding)

Идея: за основным сигналом добавляется слабое эхо с малой задержкой. Бит кодируется задержкой эха (например, 1 мс = 0, 2 мс = 1). Эхо маскируется сигналом и почти не слышно.

Извлечение — через кепстр (cepstrum): автокорреляция/кепстр выявляет пик на задержке эха.

```python
import numpy as np, scipy.io.wavfile as w
sr, x = w.read('audio.wav')
# автокорреляция для поиска эха
ac = np.correlate(x[:,0] if x.ndim>1 else x, x[:,0] if x.ndim>1 else x, 'full')
# искать пики на малых задержках (0.5–5 мс)
```

## Фазовое кодирование (phase coding)

Фаза блоков сигнала заменяется на значения, кодирующие данные; амплитуда сохраняется. Слух нечувствителен к абсолютной фазе, поэтому искажения незаметны. Извлечение — через FFT блоков и чтение фаз.

## Spread-spectrum

Данные модулируются псевдослучайной последовательностью и «размазываются» по широкой полосе; сигнал выглядит как низкоуровневый шум. Устойчив к сжатию и обрезке. Декодирование требует знания PN-последовательности (ключа).

## Инструменты и практика

- **Sonic Visualiser** + плагины (спектрограмма, кепстр) — визуальный анализ.
- **Audacity** — спектрограмма, инверсия, фильтры.
- **Python (numpy/scipy)** — автокорреляция, FFT, кепстр.
- **Stegdetect/стего-аудио-скрипты** — для известных схем.

## Разобранный пример

CTF: WAV, «обычный» на слух. Пентестер строит спектрограмму (не видно), затем автокорреляцию → находят два пика эха → декодируют задержки в биты → флаг.

## Частые ошибки

- Искать только LSB (в устойчивых схемах его нет).
- Не смотреть кепстр/автокорреляцию (эхо).
- Игнорировать спектрограмму (spread-spectrum может быть виден как ровный шум).
- Забывать про ключ (PN-последовательность) для spread-spectrum.

## Что делать дальше

- **Пики автокорреляции** → эхо-декодирование.
- **Аномальная фаза** → фазовое кодирование.
- **Ровный шум в спектре** → spread-spectrum (нужен ключ).
- **Пусто** → вернитесь к LSB/спектрограмме/метаданным.

## Эхо-сокрытие: полный декодер (кепстр)

Эхо-сокрытие прячет биты в задержке слабого эха. Извлечение — через кепстр (обратное преобразование логарифма спектра) или автокорреляцию: на задержке эха появляется пик.

```python
import numpy as np, scipy.io.wavfile as sr
from scipy.signal import cepstrum

rate, x = sr.read('audio.wav')
x = x.astype(float)
if x.ndim > 1:
    x = x[:, 0]                      # левый канал

# Кепстр: пик в районе задержки эха (обычно 0.5–5 мс)
cep = cepstrum(x, n=len(x))
qs = np.arange(len(cep))
peaks = qs[np.argsort(cep)[-10:]]     # крупнейшие пики (в сэмплах)
print('кандидаты задержек (сэмплы):', sorted(peaks))

# Бит = короткая/длинная задержка; сегментируйте сигнал по блокам,
# для каждого блока найдите задержку пика → 0/1 → байты.
```

Практический приём: разделить сигнал на блоки (например, 1000 сэмплов), в каждом найти доминирующую задержку эха, порогом превратить в биты, собрать байты и поискать `flag{`.

## Фазовое кодирование: реализация

Фаза блоков заменяется значениями, кодирующими данные; амплитуда сохраняется — искажение неслышно.

```python
import numpy as np, scipy.io.wavfile as sr
rate, x = sr.read('audio.wav')
x = x.astype(float)
N = 1024                                   # размер блока
spec = np.fft.rfft(x.reshape(-1, N), axis=1)
mag = np.abs(spec)
phase = np.angle(spec)
# данные кодируются в разности фаз соседних блоков (дифференц. фазовое кодирование)
dphi = np.diff(phase, axis=0)
bits = (dphi[:, 1:2] > 0).astype(int)      # пример: знак → бит
print(''.join(map(str, bits.ravel()[:64])))
```

Извлечение — обратная операция: FFT по блокам, чтение фаз, декодирование битов.

## Spread-spectrum: принцип и декод

Данные модулируются псевдослучайной последовательностью (PN) и «размазываются» по спектру — сигнал выглядит как шум, устойчив к сжатию и обрезке.

```python
# псевдокод корреляционного декодера
# bit = sign( sum( x[i] * pn[i] ) )  по окну
# нужно ЗНАТЬ pn (ключ) — иначе декодировать нельзя
```

Без ключа задача сводится к криптоанализу — ищите подсказку/пароль в условии CTF.

## Сравнение методов

| Метод | Робастность | Нужен ключ | Как обнаружить |
|-------|-------------|-----------|----------------|
| LSB | низкая (ломается сжатием) | нет | LSB-скрипты |
| Эхо | средняя | обычно нет | кепстр/автокорреляция |
| Фазовое | средняя-высокая | иногда | FFT фаз |
| Spread-spectrum | высокая | да (PN) | шумоподобный спектр |

| Инструмент | Назначение | Пример |
|------------|-----------|--------|
| Sonic Visualiser | спектр/кепстр, слои | GUI |
| Audacity | спектрограмма, фильтры | GUI |
| `numpy`/`scipy` | FFT, кепстр, автокорреляция | см. скрипты |

| `stegolsb` | LSB (для сравнения) | `stegolsb wavsteg -r ...` |

## Разобранные примеры

**1. Эхо.** Спектрограмма чистая; автокорреляция/кепстр даёт два пика → задержки → биты → флаг.

**2. Фазовое.** FFT по блокам показывает аномальные разности фаз → декодируем биты.

**3. Spread-spectrum.** Спектр — ровный низкоуровневый шум; в условии есть ключ/пароль → корреляция.

## Частые ошибки и отладка

- **Искать только LSB** — в устойчивых схемах его нет.
- **Не строить кепстр** — эхо видно только там.
- **Забыть про ключ** для spread-spectrum.
- **Неверный размер блока/окна** — фаза «плывёт»; перебирайте N.
- **Отладка:** если кепстр даёт пик на нуле — эха нет; если пик стабилен — это эхо, порогом кодируйте биты.

## Что делать дальше / дерево решений

1. Спектрограмма → текст/DTMF/SSTV? → `stego-audio-spec`.
2. Нет → кепстр/автокорреляция → пик эха? → декодируйте задержки.
3. Нет → FFT фаз по блокам → фазовое кодирование.
4. Ровный шум + ключ? → spread-spectrum.
5. Ничего → вернитесь к LSB (`stego-audio-lsb`) и метаданным.

## Шпаргалка и рабочий процесс

```bash
# 1) сначала исключить простое
soxi audio.wav && sox audio.wav -n spectrogram -o spec.png
multimon-ng -a DTMF -a MORSE_CW -t wav audio.wav
stegolsb wavsteg -r -i audio.wav -o out.bin -n 2000 2>/dev/null
# 2) кепстр/автокорреляция для эха
python3 -c "
import numpy as np, scipy.io.wavfile as sr
from scipy.signal import cepstrum
r,x=sr.read('audio.wav'); x=x.astype(float)
if x.ndim>1: x=x[:,0]
c=cepstrum(x,n=len(x)); q=np.argsort(c)[-5:]
print('пики кепстра (сэмплы):', sorted(q))"
```

Рабочий процесс: сначала исключите LSB/спектр/DTMF (простое), затем переходите к эхо/фазе/spread-spectrum (сложное). Эхо-канал редок, но когда он есть — LSB и спектрограмма чисты, а кепстр даёт устойчивый пик. Если пик на нулевой задержке — эха нет. Для фазового кодирования переберите размер блока N (512/1024/2048): неверный N «размывает» фазу. Для spread-spectrum ищите ключ/пароль в условии — без PN-последовательности декодирование невозможно. В отчёте укажите метод и параметры (N, порог), иначе результат не воспроизвести.
