## Вопрос, с которого всё начинается

В задаче даны два файла: `decoder.pt` (веса нейросети) и `stego.png`. Ты прогоняешь картинку через все классические инструменты — `zsteg`, `steghide`, хи-квадрат — и получаешь полную пустоту. Но подсказка говорит: «данные извлекает модель». Как нейросеть может прятать и доставать данные, если в пикселях «ничего нет»?

Ответ: сеть **распределила** сообщение по всему изображению так, что статистически оно неотличимо от обычного. Разберём, как это устроено и как решать такие задачи.

## Наш пример: decoder.pt и stego.png

Классическая стеганография меняет носитель по фиксированному правилу (LSB, DCT). Нейросетевая идёт дальше: **сеть учится** и прятать, и извлекать так, чтобы контейнер оставался статистически неотличим от естественных данных. Это направление называют deep steganography.

## Шаг 1: архитектура «энкодер–декодер»

Базовая схема обучаемой стегосистемы:

- **Encoder** — принимает контейнер и секретное сообщение, выдаёт **stego-изображение**;
- **Decoder** — принимает stego-изображение, восстанавливает сообщение;
- **Обучающий сигнал** — комбинация потерь: точность извлечения + незаметность.

Такая схема известна как «HiDDeN» и её развитие. Сеть учится распределять данные по всему изображению, а не в конкретные биты, поэтому классические детекторы (RS-анализ, хи-квадрат) дают мало сигнала.

## Шаг 2: генеративная стеганография на GAN

Здесь добавляется **дискриминатор** — сеть, которая пытается отличить stego от настоящих изображений. Это состязательная игра:

- **Generator/Encoder** прячет сообщение, минимизируя детектируемость;
- **Discriminator** пытается поймать stego;
- **Decoder** извлекает сообщение.

Результат — контейнеры, почти неотличимые от обычных. Обратная сторона: высокая вычислительная стоимость и чувствительность к постобработке.

## Шаг 3: метрики

- **Точность извлечения** (bit accuracy) — доля верно восстановленных битов;
- **PSNR/SSIM** — визуальная близость stego и оригинала;
- **Стегоаналитическая стойкость** — вероятность, что детектор распознает stego (чем ближе к 50%, тем лучше);
- **Устойчивость к атакам** — сжатие, шум, перекодирование.

```python
from skimage.metrics import peak_signal_noise_ratio as psnr
from skimage.metrics import structural_similarity as ssim
import imageio.v2 as iio
a = iio.imread("cover.png"); b = iio.imread("stego.png")
print("PSNR:", psnr(a, b), "SSIM:", ssim(a, b, channel_axis=2))
```

## Шаг 4: извлекаем сообщение в CTF

Обычно задача даёт готовые веса и скрипт. Путь такой:

1. Установить зависимости (`torch`, `numpy`, `Pillow`);
2. Загрузить веса и stego-изображение;
3. Прогнать декодер, получить битовую строку;
4. Собрать биты в байты (учесть порядок: MSB/LSB, длину-префикс).

```python
import torch
model = torch.load("decoder.pt", map_location="cpu").eval()
img = load_image("stego.png")          # тензор [1,3,H,W], нормирован
with torch.no_grad():
    bits = model(img).round().clamp(0,1).byte().squeeze().tolist()
msg = bytes(int("".join(map(str, bits[i:i+8])), 2)
            for i in range(0, len(bits)//8*8, 8))
print(msg)
```

Часто длина сообщения кодируется первыми битами — читайте префикс, чтобы отрезать padding. **Главная ловушка** — неверная нормировка входа: если модель обучалась на `[-1,1]`, а вы подаёте `[0,255]`, извлечение провалится.

## Шаг 5: состязательный стегоанализ

С другой стороны — обученные детекторы: CNN (SRNet, Zhu-Net), которые по одному изображению решают «cover или stego». Их обучают на больших парах и проверяют на новых алгоритмах. Гонка «детектор против генератора» — двигатель области. Для практика вывод простой: классические детекторы на нейросетевом стего бесполезны, нужен обученный.

```python
pred = detector(image)          # вероятность, что это stego
accuracy = ((pred > 0.5) == labels).mean()
```

## Шаг 6: обучение и устойчивость

Качество системы определяется комбинацией потерь: ошибка извлечения, отличие stego от cover, ошибка детектора, регуляризация. Балансировка — главная сложность: давишь на незаметность — страдает извлечение, и наоборот.

```python
for cover, msg in loader:
    stego = encoder(cover, msg)
    rec   = decoder(stego)
    l = loss_msg(rec, msg) + 0.5 * loss_cover(stego, cover)
    l.backward(); opt.step()
```

Устойчивость к атакам (JPEG, шум, кроп) тренируют, прогоняя stego через случайные искажения между энкодером и декодером.

## Если не сработало

- **Пытаешься LSB-анализом взломать нейросетевой стего** — сигнала не будет.
- **Перекодируешь stego** — постобработка разрушает канал.
- **Игнорируешь порядок битов** — MSB/LSB и длина-префикс критичны.
- **Забыл про нормировку входа** — модель ждёт конкретный диапазон.
- **Считаешь модель универсальной** — нужен тот самый чекпойнт.
- **Не проверил версии фреймворков** — несовпадение PyTorch ломает загрузку.

## Сравнение с классикой

| Свойство | LSB/классика | Нейросетевая |
|---|---|---|
| Правило встраивания | фиксированное | обученное |
| Незаметность | средняя | высокая |
| Стойкость к стегоанализу | низкая | высокая |
| Стойкость к сжатию | низкая | зависит от метода |

## Архитектуры

- **HiDDeN** — базовая end-to-end сеть «энкодер–декодер–шумы», обучается с аугментациями;
- **UDH** (Universal Deep Hiding) — обобщение на разные типы контейнеров;
- **StegaStamp** — watermarking, устойчивый к печати и фотосъёмке;
- **GAN-based** — генератор прячет, дискриминатор ловит;
- **Invertible networks** — обратимая сеть, где скрытие и извлечение — прямое и обратное преобразование.

## Ограничения

- **Вычислительная стоимость** — обучение требует GPU и данных;
- **Хрупкость к постобработке** — многие методы не переживают перекодирование;
- **Зависимость от чекпойнта** — без точных весов извлечение невозможно;
- **Отсутствие стандарта** — каждый метод своя архитектура и формат.

## Практика: измеряем незаметность вложения

Прежде чем гонять декодер, полезно численно оценить, насколько stego отличается от исходного cover. Две стандартные метрики — **PSNR** (пиковое отношение сигнал/шум, в дБ; чем больше, тем незаметнее) и **SSIM** (структурное сходство, от 0 до 1; ближе к 1 — лучше). Обе считаются на numpy/skimage, без всякой модели:

```python
import numpy as np
from skimage.metrics import structural_similarity as ssim
rng = np.random.default_rng(0)
cover = rng.integers(0, 256, (64, 64, 3), dtype=np.uint8)
stego = cover.copy()
flat = stego.reshape(-1)
flat[:200] ^= 1                       # перевернули младший бит в 200 значениях
mse = np.mean((cover.astype(float) - stego.astype(float)) ** 2)
print("PSNR = %.2f dB" % (10 * np.log10(255 ** 2 / mse)))
print("SSIM = %.4f" % ssim(cover, stego, channel_axis=2))
```

```bash
$ python3 metrics.py
PSNR = 66.02 dB
SSIM = 1.0000
```

Мораль простая: даже заметное для статистики вложение (мы перевернули 200 значений) визуально неразличимо — SSIM округляется до 1.0, а PSNR высок. Именно поэтому нейросетевой стего не ловят глазами; нужен обученный детектор, а не PSNR.

⚠️ **Безопасность загрузки весов.** `torch.load` по умолчанию идёт через pickle и может исполнить код из чекпойнта. В CTF это ожидаемо (файл от организаторов), но на реальных данных грузи с `weights_only=True` или сперва прогони `pickletools.dis` по файлу.

## Что мы теперь знаем

1. Нейросетевая стеганография **обучается** прятать и извлекать, а не следует фиксированному правилу.
2. Схема — **энкодер → stego → декодер**; в GAN добавляется дискриминатор.
3. Метрики: **bit accuracy, PSNR/SSIM, стойкость к детектору**.
4. В CTF главное — воспроизвести окружение и **нормировку входа**.
5. Классические детекторы на нейросетевом стего бесполезны.
