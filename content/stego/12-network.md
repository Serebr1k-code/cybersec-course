## Covert channels в сетевых протоколах

Сетевые протоколы — идеальный носитель для скрытых каналов, потому что у них есть поля, которые принимающая сторона либо игнорирует, либо не проверяет, а также свободные «степени свободы» вроде порядка и тайминга пакетов. Стеганография в сети (network steganography) делится на три большие группы: **модификация полей** заголовков, **кодирование во времени** (тайминги, интервалы) и **туннелирование** (DNS/ICMP/HTTP-туннели). В CTF это задачи с PCAP-файлами, где нужно найти и извлечь скрытые данные.

Ключевое отличие сетевой стеганографии от файловой: носитель — **последовательность пакетов**, а не статичный файл. Поэтому «оригинал» для сравнения — нормальный трафик, а аномалии ищутся по статистике (частоты, интервалы, размеры) и по нестандартным значениям полей.

## Поля IP как канал

У IP-заголовка есть несколько полей, удобных для сокрытия:

- **IP ID** (16 бит) — при фрагментации должен меняться предсказуемо; его младшие биты можно использовать.
- **TTL** — значение обычно фиксировано (64/128); его изменения кодируют данные.
- **ToS/DSCP** — редко проверяется; подходит для битов.
- **Флаги и offset фрагментации** — комбинации, не влияющие на доставку.

Пример извлечения младших бит IP ID:

```python
from scapy.all import rdpcap, IP
bits = ''.join(str(p[IP].id & 1) for p in rdpcap('cap.pcap') if IP in p)
out = bytes(int(bits[i:i+8],2) for i in range(0,len(bits)-7,8))
print(out)
```

TTL как канал — аналогично: `bits = ''.join('1' if p[IP].ttl > 64 else '0' for p in pkts)`.

## Поля TCP и UDP

TCP даёт ещё больше возможностей:

- **Sequence/Acknowledgment numbers** — младшие биты.
- **Флаги TCP** — редкие комбинации (например, установленные «лишние» флаги).
- **TCP options** — неиспользуемые опции и их значения.
- **Window size** — кодирование в размере окна.
- **Порты** — выбор портов из допустимого диапазона.

UDP проще: можно играть длиной payload, портом назначения и полем checksum.

## Порядок и тайминги пакетов

Даже если все поля «нормальные», данные можно спрятать в **порядке** пакетов или в **интервалах** между ними. Порядок: перестановка пакетов с одинаковым смыслом кодирует биты. Тайминги: задержка между пакетами кодирует 0/1 (короткая пауза = 0, длинная = 1). Тайминговые каналы сложно детектировать и они устойчивы к переупаковке, но требуют синхронного приёмника.

```python
from scapy.all import rdpcap, IP
pkts = [p for p in rdpcap('cap.pcap') if IP in p]
times = [float(p.time) for p in pkts]
deltas = [times[i+1]-times[i] for i in range(len(times)-1)]
bits = ''.join('1' if d > 0.01 else '0' for d in deltas)   # порог подбирается
```

## ICMP- и DNS-туннели

**ICMP-туннели** прячут данные в payload эхо-запросов/ответов (ping). Признак: необычно большой или «случайный» payload, постоянные запросы к одному хосту. Инструмент — `ptunnel`/`icmptunnel`.

**DNS-туннели** кодируют данные в поддоменах или TXT-записях (см. отдельный урок). Признак: длинные высокоэнтропийные поддомены, много запросов к одному домену.

## Анализ PCAP: tshark и scapy

```bash
tshark -r cap.pcap -Y 'ip' -T fields -e ip.id -e ip.ttl | head
tshark -r cap.pcap -Y 'icmp' -T fields -e data | head
tshark -r cap.pcap -q -z io,stat,0
```

`tshark` удобен для быстрых выборок по полям, `scapy` — для произвольной логики извлечения (порядок, тайминги, младшие биты).

## Инструменты

- **`tshark`/`wireshark`** — разбор и фильтрация.
- **`scapy`** — программируемое извлечение.
- **`ptunnel`/`icmptunnel`** — ICMP-туннели.
- **`iodine`/`dnscat2`** — DNS-туннели.
- **`networkMiner`** — быстрый обзор трафика.

## Разобранный пример

Задача: `hidden.pcap`. Смотрим поля IP:

```bash
$ tshark -r hidden.pcap -Y ip -T fields -e ip.id | head
$ python3 - <<'PY'
from scapy.all import rdpcap, IP
bits=''.join(str(p[IP].id & 1) for p in rdpcap('hidden.pcap') if IP in p)
print(bytes(int(bits[i:i+8],2) for i in range(0,len(bits)-7,8))[:40])
PY
b'flag{ip_id_lsb}'
```

Маршрут: посмотреть поля (`tshark`), затем извлечь младшие биты (`scapy`). Если пусто — проверить TTL, тайминги, ICMP/DNS payload.

## Частые ошибки и подводные камни

- **Смотреть только payload** — данные часто в заголовках.
- **Не проверять порядок/тайминги** — там самый скрытный канал.
- **Путать с шифрованием** — если payload «случайный», возможно, он сжат/зашифрован.
- **Игнорировать ICMP/DNS** — классические туннели.
- **Неверный порог таймингов** — перебирайте значения.
- **Забыть про фрагментацию** — данные могут быть в IP ID фрагментов.

## Итог

Сетевая стеганография опирается на «свободные» поля и временные характеристики трафика. В CTF это всегда PCAP + извлечение через `tshark`/`scapy`. Освоив извлечение из IP ID, TTL, TCP-флагов и таймингов, вы закрываете большинство задач категории.

## Таблица полей-каналов и их характеристик

| Уровень | Поле | Ёмкость | Заметность | Комментарий |
|---|---|---|---|---|
| IP | IP ID | 1–16 бит/пакет | низкая | меняется при фрагментации |
| IP | TTL | 1 бит/пакет | низкая | обычно фиксирован |
| IP | ToS/DSCP | несколько бит | низкая | редко проверяется |
| TCP | seq/ack | много бит | средняя | ломает сборку при ошибке |
| TCP | flags/options | 1–4 бита | низкая | редкие комбинации |
| TCP/UDP | window/port | несколько бит | средняя | выбор из диапазона |
| любой | порядок | log2(n!) | низкая | перестановка пакетов |
| любой | тайминг | 1 бит/пакет | очень низкая | требует синхронизации |

Стратегия: начинать с полей с низкой заметностью (IP ID, TTL, тайминги), затем переходить к TCP.

## Практические скрипты scapy

Извлечение из TTL и TCP-флагов:

```python
from scapy.all import rdpcap, IP, TCP
pkts = rdpcap('cap.pcap')
# TTL как бит
bits = ''.join('1' if p[IP].ttl % 2 else '0' for p in pkts if IP in p)
print(bytes(int(bits[i:i+8],2) for i in range(0,len(bits)-7,8))[:40])
# TCP-флаги (например, PSH как бит)
bits = ''.join('1' if (p[TCP].flags & 0x08) else '0' for p in pkts if TCP in p)
```

Порядок пакетов как данные: возьмите список идентификаторов, отсортируйте по времени и по значению — разница кодирует перестановку.

## Детект сетевых covert channels

Признаки (для blue team и для поиска задачи):

- Необычные значения IP ID/TTL в потоке.
- Тайминги с «ступеньками» (бимодальное распределение интервалов).
- ICMP с большим/энтропийным payload.
- DNS с длинными поддоменами (см. DNS-туннели).
- Постоянные потоки к одному хосту с «пустым» payload.

```bash
tshark -r cap.pcap -Y ip -T fields -e ip.id | sort | uniq -c | sort -rn | head
```

## Чек-лист сетевой задачи

1. `tshark -r cap.pcap -q -z io,stat,0` — общий обзор.
2. Поля: IP ID, TTL, TCP flags/seq, порты.
3. Тайминги и порядок пакетов.
4. ICMP/DNS payload.
5. Извлечь биты `scapy` и проверить сигнатуры.
6. «Случайные» данные — снять XOR/распаковать.

## Практические тонкости сетевого извлечения

Три вещи чаще всего ломают извлечение из PCAP. Первое — **фильтрация**: если взять все пакеты подряд, в биты попадут служебные (ARP, DNS-ответы), и поток «съедет». Всегда фильтруйте по нужному протоколу/направлению (`-Y 'ip.src==... && ip.dst==...'`). Второе — **порядок**: сортируйте пакеты по времени (`scapy` хранит их в порядке захвата, но при слиянии файлов порядок может сбиться). Третье — **выбор бита/поля**: если младший бит одного поля даёт мусор, попробуйте другой бит, другое поле (TTL, ToS, seq) или комбинацию.

```bash
tshark -r cap.pcap -Y 'ip.src==10.0.0.5 && tcp' -T fields -e ip.id > ids.txt
python3 -c "
bits=''.join(str(int(x)&1) for x in open('ids.txt'))
print(bytes(int(bits[i:i+8],2) for i in range(0,len(bits)-7,8)))
"
```

## Инструменты для сетевой стеганографии

- **`tshark`/`wireshark`** — выборки по полям, статистика.
- **`scapy`** — программируемое извлечение.
- **`ptunnel`/`icmptunnel`** — ICMP-туннели (для понимания трафика).
- **`iodine`/`dnscat2`/`dns2tcp`** — DNS-туннели.
- **`tcpreplay`/`tcpprep`** — переупорядочивание/реплей.

## Чек-лист и порядок действий

1. Обзор: `tshark -q -z io,stat,0`.
2. Поля заголовков: IP ID, TTL, ToS, TCP flags/seq/options.
3. Тайминги и порядок пакетов.
4. ICMP/DNS payload.
5. Извлечь биты, проверить сигнатуры.
6. «Случайные» данные — снять XOR/распаковать.

## Что делать дальше / решение

- `tshark -T fields` — быстро посмотреть поля заголовков.
- `scapy` — извлечь младшие биты полей (IP ID, TTL, seq).
- Пусто — проверить тайминги и порядок пакетов.
- ICMP/DNS payload — отдельные классические туннели.
- Данные «случайные» — снять XOR/распаковать.
