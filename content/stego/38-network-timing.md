Тайминговый covert channel прячет данные не в содержимом пакетов, а в их **времени**: интервалы между пакетами, задержки ответов, порядок отправки. Такие каналы невидимы для DPI, потому что payload «нормальный»; детект требует анализа временных меток. В CTF их дают как PCAP, где нужно извлечь биты из межпакетных задержек.

## Способы кодирования

- **Межпакетный интервал:** короткая задержка = 0, длинная = 1.
- **Порядок пакетов:** последовательность двух типов пакетов кодирует биты.
- **Задержка ответа:** время между запросом и ответом.
- **Размер пакета + тайминг:** комбинация.
- **Порядок/выбор:** какие из нескольких возможных пакетов отправлены.

## Извлечение из PCAP

```bash
# временные метки пакетов
tshark -r capture.pcap -T fields -e frame.time_epoch -e ip.src -e ip.dst -e tcp.len
# разница между последовательными пакетами
tshark -r capture.pcap -T fields -e frame.time_delta_displayed
```

```python
# интервалы → биты (порог подбирается)
import dpkt
times = []
with open('capture.pcap','rb') as f:
    for ts, buf in dpkt.pcap.Reader(f):
        times.append(ts)
deltas = [times[i+1]-times[i] for i in range(len(times)-1)]
thr = sum(deltas)/len(deltas)
bits = ''.join('1' if d > thr else '0' for d in deltas)
print(bytes(int(bits[i:i+8],2) for i in range(0,len(bits)-7,8)))
```

## Пороговые значения

Порог — ключевая сложность. Пробуйте: среднее, медиану, кластеризацию на два интервала, визуализацию гистограммы задержек. Часто видно два «горба» (короткий/длинный) — между ними порог.

```bash
# гистограмма задержек (пример через python)
python3 -c "import dpkt,statistics; ..." # или tshark + sort | uniq -c
```

## Детект в IR

- Аномальная регулярность/дисперсия таймингов.
- Несоответствие задержек нормальному протоколу.
- Периодические «паттерны» в интервалах.
- Малая нагрузка + строгое время (туннель «дышит»).

## Разобранный пример

CTF: PCAP с ICMP-эхо. Пентестер считает интервалы между запросами, видит два кластера задержек, ставит порог, извлекает биты → ASCII → флаг.

## Частые ошибки

- Смотреть только payload, игнорируя тайминги.
- Не подбирать порог (единое среднее может не разделить кластеры).
- Не учитывать ретрансмиссии/шум в PCAP.
- Забывать про порядок/выбор пакетов как канал.

## Что делать дальше

- **Два кластера задержек** → порог → биты → байты.
- **Порядок пакетов** → карта в биты.
- **Не сходится** → визуализируйте гистограмму, переберите пороги.
- **Детект** → анализируйте дисперсию/регулярность.

## Как устроен тайминговый канал

Тайминговый (covert timing) канал передаёт биты через **время**, а не через содержимое пакетов. Модуляции:

| Схема | Кодирование | Пример |
|-------|-------------|--------|
| Интервальная | короткий/длинный интервал = 0/1 | паузы между ICMP |
| Порядковая | порядок двух типов пакетов | ACK/SYN как биты |
| Задержка ответа | время request→response | RTT-модуляция |
| Размер+время | комбинация | малый/большой + пауза |
| Выбор из N | какой из N отправлен | 4 варианта = 2 бита |

Преимущество: payload пакетов «чистый», поэтому DPI не видит данных. Недостаток: канал чувствителен к джиттеру, требует точных меток времени.

## Извлечение из PCAP: tshark + dpkt

```bash
# метки времени и длины
tshark -r capture.pcap -T fields -e frame.time_epoch -e ip.src -e ip.dst -e tcp.len
# дельта между отображаемыми пакетами
tshark -r capture.pcap -T fields -e frame.time_delta_displayed
# только ICMP
tshark -r capture.pcap -Y icmp -T fields -e frame.time_epoch
```

```python
import dpkt
times = []
with open('capture.pcap','rb') as f:
    for ts, buf in dpkt.pcap.Reader(f):
        times.append(ts)
deltas = [times[i+1]-times[i] for i in range(len(times)-1)]
# порог по медиане
deltas_sorted = sorted(deltas)
thr = deltas_sorted[len(deltas_sorted)//2]
bits = ''.join('1' if d > thr else '0' for d in deltas)
data = bytes(int(bits[i:i+8], 2) for i in range(0, len(bits) - 7, 8))
print(data)
```

```python
# scipy-кластеризация интервалов на 2 группы
import numpy as np
from scipy.cluster.vq import kmeans2
d = np.array(deltas).reshape(-1,1)
cent, lab = kmeans2(d, 2, minit='++')
order = np.argsort(cent.ravel())
bits = ''.join(str(order[l]) for l in lab)
```

## Выбор порога: методы

Порог — самая частая точка отказа. Методы по возрастанию надёжности:

1. **Среднее/медиана** интервалов — быстрый старт.
2. **K-means (2 кластера)** — устойчив к «размытым» данным.
3. **Гистограмма** — если видны два горба, порог между ними.
4. **Otsu** (автопорог по дисперсии) — если кластеры близки.

```bash
# гистограмма интервалов
python3 -c "
import dpkt
ts=[t for t,_ in dpkt.pcap.Reader(open('capture.pcap','rb'))]
d=[round((ts[i+1]-ts[i])*1000,1) for i in range(len(ts)-1)]
print(sorted(d)[:20])"
```

## Каналы: интервалы/порядок/размер/выбор

- **Интервалы:** классика; порог разделяет 0/1.
- **Порядок:** например, ICMP-echo-reply → 1, другой тип → 0.
- **Размер:** малый пакет = 0, большой = 1 (или N уровней).
- **Выбор:** если есть 4 типа пакетов — 2 бита на пакет.
- **Комбинация:** время + размер дают больше бит на пакет.

## Детект в IR

| Метрика | Аномалия-признак |
|---------|------------------|
| Дисперсия интервалов | необычно регулярна или бимодальна |
| Средний RTT | не соответствует протоколу |
| Периодичность | строгие «паттерны» пауз |
| Полезная нагрузка | мала, а пакетов много |
| Энтропия таймингов | низкая (структурированный канал) |

```bash
# распределение интервалов по хосту
tshark -r capture.pcap -Y "ip.addr==10.0.0.5" -T fields -e frame.time_delta_displayed | sort -n | uniq -c | tail
```

## Разобранные примеры

**1. ICMP-тайминг.** `tshark` извлекает метки ICMP-эхо; интервалы дают два кластера; порог → биты → `flag{...}`.

**2. Порядковый канал.** Чередование типов пакетов (echo vs timestamp) кодирует биты.

**3. Детект.** В PCAP трафик к «мёртвому» хосту идёт регулярными паузами с малым payload → подозрение на covert timing.

## Частые ошибки и отладка

- **Смотреть только payload** — данные в таймингах.
- **Единый средний порог** может не разделить близкие кластеры — используйте k-means.
- **Не учитывать ретрансмиссии/шум** — фильтруйте по хосту/протоколу.
- **Игнорировать порядок/размер** как канал.
- **Отладка:** если биты не дают ASCII — инвертируйте (0↔1), попробуйте MSB-first, уберите первый/последний интервал (служебные).

## Что делать дальше / дерево решений

1. `tshark` → метки времени, интервалы.
2. Два кластера? → порог → биты → байты.
3. Не сходится → k-means/Otsu, инверсия бит.
4. Нет кластеров → проверьте порядок/размер/выбор пакетов.
5. Детект → анализ дисперсии и периодичности.

## Шпаргалка: извлечение за 4 шага

```bash
# 1) времена пакетов
tshark -r c.pcap -T fields -e frame.time_epoch -e ip.src -e ip.dst
# 2) интервалы → биты (порог по медиане)
python3 -c "
import dpkt
ts=[t for t,_ in dpkt.pcap.Reader(open('c.pcap','rb'))]
d=[ts[i+1]-ts[i] for i in range(len(ts)-1)]; m=sorted(d)[len(d)//2]
b=''.join('1' if x>m else '0' for x in d)
print(bytes(int(b[i:i+8],2) for i in range(0,len(b)-7,8)))"
# 3) если не ASCII — k-means и инверсия
# 4) гистограмма для выбора порога
```

Рабочий процесс: извлеките метки времени, посчитайте интервалы, постройте гистограмму (два горба = порог между ними), декодируйте биты. Если текст не выходит — инвертируйте биты, попробуйте MSB-first, отбросьте первый/последний интервал (служебные), используйте k-means вместо медианы. Проверьте также каналы «порядок/размер/выбор пакетов». В отчёте фиксируйте: канал (интервалы/порядок), метод порога и результат.
