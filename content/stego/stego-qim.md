До сих пор мы меняли значение пикселя «на единицу» или прятали в текстуре. QIM (Quantization Index Modulation) меняет саму логику: значение округляется к ближайшей точке из одного из нескольких наборов (репёток) квантования, и номер набора кодирует данные. Меняя решётку, вы кодируете биты; восстанавливая номер набора из стего-значения — декодируете. Это делает схему устойчивой к шуму и сжатию: даже если значение слегка «поехало», оно остаётся ближе к той же решётке. QIM — основа многих watermarking-систем и встречается в CTF, где нужна робастность.

## Принцип: квантование вместо бита

Классическое скалярное квантование: `Q(x) = Δ · round(x/Δ)`, где `Δ` — шаг. QIM использует несколько квантователей, сдвинутых друг относительно друга. Простейший случай — два квантователя:

- `Q_0(x) = Δ · round(x/Δ)` — решётка для бита 0;
- `Q_1(x) = Δ · round(x/Δ − 0.5) + Δ/2` — решётка для бита 1, сдвинутая на `Δ/2`.

Чтобы записать бит `b`, значение `x` заменяется на ближайшую точку решётки `Q_b(x)`. Извлечение: сравниваем расстояния до `Q_0(x')` и `Q_1(x')` и берём ближайшую — её индекс и есть бит. Никакого младшего бита: кодируется «в какой половине интервала квантования» сидит значение.

## Dither modulation

Чтобы схема не была детерминированной и не создавала паттернов, решётки сдвигают на псевдослучайную величину (dither): `Q_b(x) = Δ · round((x − d_b)/Δ) + d_b`, где `d_b` — ключевой сдвиг. Без dither атакующий может угадать решётки по гистограмме; с ним — нужен ключ. DM-QIM (Dither Modulation QIM) — стандартная форма.

## Почему QIM устойчив к сжатию и шуму

После QIM значение лежит ровно на решётке. Если применить JPEG или добавить шум, значение сместится на небольшую величину `ε`. Декодер ищет ближайшую точку решётки, и пока `|ε| < Δ/4`, решение не меняется. То есть QIM имеет «запас прочности» порядка `Δ/4`. Чем больше `Δ`, тем устойчивее схема, но тем сильнее искажение носителя. Это классический размен «робастность ↔ незаметность», и `Δ` — ручка управления.

Сравните с LSB: там изменение одного бита шума полностью разрушает данные. QIM «квантует» это искажение и переживает его.

## Инструменты и команды

- **Python + `numpy`** — основная реализация; QIM элементарен в коде.
- **`Pillow`** — чтение/запись изображений.
- **`scipy`** — преобразования, если QIM применяется в DCT/DWT-области.
- **`zsteg`/`stegsolve`** — для QIM в пространственной области почти бесполезны (данные не в младших битах).
- **`exiftool`** — на всякий случай проверьте метаданные.
- **Оригинальная схема Chen & Wornell (1998)** — первоисточник QIM; полезна для понимания dither.

## Разобранный пример: QIM end-to-end

```python
import numpy as np
from PIL import Image

DELTA = 16.0

def q0(x): return DELTA * np.round(x / DELTA)
def q1(x): return DELTA * np.round((x - DELTA/2) / DELTA) + DELTA/2

def embed(img, msg):
    a = np.array(img).astype(np.float64)
    flat = a.reshape(-1)
    bits = np.unpackbits(np.frombuffer(msg, dtype=np.uint8))
    for i, b in enumerate(bits):
        flat[i] = q1(flat[i]) if b else q0(flat[i])
    return Image.fromarray(np.clip(flat,0,255).reshape(a.shape).astype(np.uint8))

def extract(path, n_bits):
    a = np.array(Image.open(path)).astype(np.float64).reshape(-1)[:n_bits]
    bits = (np.abs(a - q1(a)) < np.abs(a - q0(a))).astype(np.uint8)
    return np.packbits(bits).tobytes()

img = Image.open("cover.png").convert("L")
embed(img, b"flag{qim_ok}").save("stego.png")
print(extract("stego.png", len(b"flag{qim_ok}")*8))
```

Вывод:

```
b'flag{qim_ok}'
```

Проверим устойчивость: пересохраним в JPEG с качеством 90 и извлечём снова.

```bash
convert stego.png -quality 90 stego.jpg   # ImageMagick
python3 - <<'PY'
# ... extract("stego.jpg", ...) с тем же DELTA=16
PY
```

При `Δ=16` данные обычно выживают JPEG-q90; при `Δ=8` — часто ломаются, при `Δ=32` — выживают, но заметны «полосы» квантования. Это наглядно демонстрирует размен.

## Spread-spectrum vs QIM

Spread-spectrum (SSIS) размазывает один бит по многим пикселям и декодирует корреляцией — это даёт робастность к обрезке и геометрии. QIM, наоборот, локальна: один бит — одно значение. Поэтому QIM проще и точнее при отсутствии геометрических искажений, но уязвима к ним (сдвиг изображения сломает соответствие пиксель↔бит). На практике QIM применяют в watermarking, а spread-spectrum — в радиоканалах и «жёстких» водяных знаках.

## Параметры: шаг квантования Δ

Выбор `Δ` — центральное решение. Ориентиры:

- `Δ ≈ 2–4` — почти незаметно, но данные гибнут при любом сжатии.
- `Δ ≈ 8–16` — компромисс для watermarking, переживает лёгкий шум.
- `Δ ≥ 32` — робастно, но видны артефакты (полосы, «ступеньки»).
- `Δ` может быть разным по каналам: в синем канале глаз менее чувствителен, туда можно взять больше.

## Крайние случаи и подводные камни

- **Насыщение.** `q1` для значений у границы 0/255 может выйти за диапазон — клиппинг ломает декодирование; обрабатывайте границы.
- **Двойное квантование.** Если изображение уже проходило QIM-подобную обработку (например, JPEG), решётки «накладываются» и данные портятся.
- **Порядок обхода и каналы.** Как и в LSB, важно, в каком порядке идут значения.
- **Dither обязателен** для стойкости; без него решётки угадываются.
- **Не используйте `zsteg`** для детекта QIM — он смотрит на младшие биты, которых тут нет.
- **Ключ.** Если dither зависит от ключа, без него извлечение невозможно — ищите ключ в условии.

## Что дальше / решение

- Данные переживают JPEG — подозревайте QIM/частотные схемы, а не LSB.
- Нашли «полосы» квантования в гистограмме — оцените `Δ` по расстоянию между пиками и декодируйте.
- Нужна робастность к обрезке/сдвигу — переходите к spread-spectrum (см. `stego-spread-spectrum`).
- Для watermarking в продакшене — комбинируйте QIM с DCT/DWT.

## QIM в частотной области

В пространственной области QIM даёт умеренную незаметность; гораздо чаще его применяют к DCT/DWT-коэффициентам. Это сочетает робастность частотного встраивания с точностью квантования. Схема: применить DCT/DWT, выбрать коэффициенты, квантовать их решёткой, применить обратное преобразование.

```python
import pywt, numpy as np
from PIL import Image

DELTA = 8.0
def q_b(x, b):
    return DELTA*np.round((x - b*DELTA/2)/DELTA) + b*DELTA/2

img = np.array(Image.open("cover.png").convert("L")).astype(float)
LL,(LH,HL,HH) = pywt.dwt2(img, "haar")
bits = np.unpackbits(np.frombuffer(b"flag{qim_dwt}", dtype=np.uint8))
flat = LL.reshape(-1)
for i,b in enumerate(bits):
    flat[i] = q_b(flat[i], b)
out = pywt.idwt2((flat.reshape(LL.shape),(LH,HL,HH)),"haar")
Image.fromarray(np.clip(out,0,255).astype(np.uint8)).save("stego.png")
```

Извлечение — сравнение расстояний до двух решёток, как и в пространственном случае. Такая схема переживает JPEG лучше, чем пространственная QIM.

## Оценка шага Δ по гистограмме

После QIM значения «прилипают» к решётке, и гистограмма становится периодичной: пики на расстоянии `Δ`. Это позволяет оценить `Δ` даже без знания схемы.

```python
import numpy as np
from PIL import Image
h,_ = np.histogram(np.array(Image.open("stego.png").convert("L")).ravel(),
                   bins=256, range=(0,256))
# автокорреляция гистограммы покажет период
ac = np.correlate(h - h.mean(), h - h.mean(), mode="full")[len(h)-1:]
peaks = [i for i in range(2,64) if ac[i] > ac[i-1] and ac[i] > ac[i+1]]
print("candidate periods:", peaks[:8])
```

Первый устойчивый период ≈ `Δ`. Зная `Δ` и порядок обхода, можно декодировать QIM-данные.

## Практический чек-лист QIM

1. Проверьте, нет ли в гистограмме периодических пиков (признак квантования).
2. Оцените `Δ` по автокорреляции гистограммы.
3. Определите область (пространственная или DCT/DWT) — попробуйте обе.
4. Восстановите решётки (с dither — нужен ключ) и декодируйте.
5. Проверьте устойчивость к JPEG — QIM её переживает.
6. Ищите `Δ` и ключ dither в условии задачи.

QIM редко встречается в «чистом» CTF, но комбинация «данные переживают JPEG + периодическая гистограмма» — почти всегда про квантование.

## QIM и детектирование

QIM сложнее обнаружить, чем LSB, но не невозможно. Ключевые признаки: периодичность гистограммы (пики на расстоянии Δ) и «выравнивание» значений по решётке. Стегоаналитики используют спектральный анализ гистограммы: пик на частоте `1/Δ` выдаёт квантование. Защита — dither (случайный сдвиг решёток по ключу), который «размывает» периодичность. В CTF, если гистограмма показывает период, попробуйте оценить Δ и восстановить решётки; если не выходит — ищите ключ dither в условии. Помните: пространственная QIM даёт видимые «ступеньки» при большом Δ, а частотная — почти незаметна.

## Связь QIM с watermarking-стандартами

QIM — база многих промышленных watermarking-схем, потому что даёт предсказуемую робастность при известном Δ. В стандартах защиты медиа (например, для отслеживания копий) используют именно квантование в частотной области: оно переживает перекодирование и лёгкую обработку. Для аналитика это значит: обнаружив периодическую гистограмму и устойчивость к JPEG, почти наверняка имеете дело с QIM/DM-схемой, а не с LSB.
