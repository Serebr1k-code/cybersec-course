## Обзор текстовых каналов

Текст — самый «нематериальный» носитель: он не содержит пикселей или сэмплов, зато богат структурой и символами. Все текстовые каналы делятся на три группы: **невидимые символы** (пробелы, табы, zero-width, Unicode-модификаторы), **структурные** (регистр, пунктуация, порядок слов, акростих) и **семантические** (синонимы, выбор слов). Понимание групп помогает выбрать метод поиска.

Главный практический принцип: **начните с невидимых символов** (их видно через `cat -A` и дамп кодовых точек), затем проверьте структурные, и только потом — семантические (они самые «дорогие» в анализе).

## Пробелы и табы

Пробел = 0, таб = 1. Данные в хвостах строк или отступах. Обнаружение — `cat -A`.

```bash
cat -A text.txt
python3 -c "
lines=open('text.txt').read().split(chr(10))
bits=''.join('1' if l.endswith(chr(9)) else '0' for l in lines if l)
print(bytes(int(bits[i:i+8],2) for i in range(0,len(bits)-7,8)))
"
```

## Zero-width символы

U+200B (ZWSP), U+200C (ZWNJ), U+200D (ZWJ), U+FEFF (BOM), U+2060 (WJ) — невидимы, но хранят данные. Два вида → бит; четыре → 2 бита; восемь → байт.

```python
s = open('t.txt', encoding='utf-8').read()
zw = [c for c in s if c in '\u200b\u200c\u200d\ufeff\u2060']
bits = ''.join('1' if c == '\u200b' else '0' for c in zw)
print(bytes(int(bits[i:i+8],2) for i in range(0,len(bits)-7,8)))
```

## Регистр и пунктуация

Заглавная/строчная буква = 1/0. Пунктуация (запятая/точка, наличие точки) тоже кодирует биты. Эти каналы видны в тексте, но выглядят как стилистика.

```python
bits = ''.join('1' if w[0].isupper() else '0'
               for w in open('t.txt').read().split())
```

## Синонимы и семантические каналы

Лингвистическая стеганография использует **выбор синонимов**: каждое слово из пары синонимов кодирует бит. Ещё тоньше — mimic-функции и null-шифры (данные в «лишних» словах). Эти каналы требуют словаря синонимов и семантического анализа; в CTF встречаются реже, но существуют.

## Акростих и структурные приёмы

- **Акростих** — первые буквы слов/строк.
- **Первая/последняя буква** слова.
- **Число слов в строке** (унарный канал).
- **Порядок слов** — перестановки.

```python
print(''.join(l[0] for l in open('poem.txt').read().splitlines() if l))
```

## Инструменты

- **`cat -A`/`xxd`** — невидимое.
- **CyberChef** — `Extract Zero-Width`, `From Unicode`.
- **Python** — универсальный перебор каналов.
- **`stegoveritas`** — часть текстовых трюков.

## Разобранный пример

Задача: абзац, флаг не виден.

```bash
$ cat -A msg.txt | head
$ python3 -c "
s=open('msg.txt',encoding='utf-8').read()
zw=[c for c in s if c in '\u200b\u200c']
bits=''.join('1' if c=='\u200b' else '0' for c in zw)
print(bytes(int(bits[i:i+8],2) for i in range(0,len(bits)-7,8)))
"
b'flag{text_zerowidth}'
```

## Частые ошибки и подводные камни

- **Смотреть только видимое** — невидимые символы пропускаются.
- **Копировать через веб/чат** — канал разрушается.
- **Не проверять оба порядка бит.**
- **Пропускать структурные каналы** (регистр/пунктуация).
- **Игнорировать семантику** — синонимы кодируют данные.
- **Забыть про BOM** — иногда это не канал, а метка.

## Итог

Текстовые каналы делятся на невидимые, структурные и семантические. В CTF 90 % задач решаются дампом кодовых точек и бинарным маппингом; остальные — акростих/регистр/синонимы. Держите под рукой скрипт-перебор всех каналов.

## Сравнительная таблица текстовых каналов

| Канал | Носитель данных | Заметность | Ёмкость | Как ловить |
|---|---|---|---|---|
| Пробел/таб в хвосте | 1 бит на строку | средняя | низкая | `cat -A`, скрипт |
| Пробел/таб в отступе | 1 бит на строку | средняя | низкая | подсчёт отступов |
| Zero-width | 1–2 бита на символ | очень низкая | средняя | дамп кодовых точек |
| Регистр | 1 бит на букву | средняя | высокая | `.isupper()` |
| Пунктуация | 1 бит на знак | низкая | средняя | разбор предложений |
| Акростих | 1 символ на строку | высокая | низкая | первые буквы |
| Синонимы | 1 бит на слово | очень низкая | средняя | словарь синонимов |
| Порядок слов | log2(n!) | низкая | средняя | перестановки |

Таблица помогает выбрать порядок проверок: сначала невидимые (zero-width, пробелы), затем структурные, затем семантические.

## Ёмкость текстовых каналов и её последствия

Ёмкость текстовых каналов невелика, и это важный ориентир. Zero-width даёт ~1 бит на символ, то есть абзац из 2000 символов — около 250 байт. Регистр — похоже. Хвостовой пробел — 1 бит на строку, то есть 100 строк = ~12 байт.

Практический вывод: **флаг помещается, архив — почти нет**. Если после извлечения вы получили ссылку, base64-строку или команду, значит дальше идёт второй этап (скачать/декодировать). Не ищите в текстовом канале большой бинарный блоб — его там быть не может.

## Автоматизация перебора текстовых каналов

Когда правила неизвестны, быстрее прогнать все каналы одним скриптом:

```python
import re, unicodedata as u
raw = open('text.txt', encoding='utf-8').read()
def b2b(bits): return bytes(int(bits[i:i+8],2) for i in range(0,len(bits)-7,8))
zw = [c for c in raw if c in '\u200b\u200c\u200d\ufeff\u2060']
if zw:
    print('zw', b2b(''.join('1' if c=='\u200b' else '0' for c in zw)))
letters = [c for c in raw if u.category(c).startswith('L')]
print('homoglyph', b2b(''.join('1' if u.name(c).startswith('CYRILLIC') else '0' for c in letters)))
words = re.findall(r'\b[A-Za-zА-Яа-я]+\b', raw)
print('case', b2b(''.join('1' if w[0].isupper() else '0' for w in words)))
print('acrostic', ''.join(l[0] for l in raw.splitlines() if l))
```

Такой «веер» закрывает большинство текстовых задач за один прогон.

## Гомоглифы: смешанные алфавиты

Гомоглифы — символы разных алфавитов, визуально неотличимые: латинская `a` и кириллическая `а`. Автор заменяет часть букв «двойниками», а выбор алфавита кодирует бит. Обнаружение — через `unicodedata.name`:

```python
names = [u.name(c) for c in raw if u.category(c).startswith('L')]
from collections import Counter
print(Counter(n.split()[0] for n in names))   # LATIN vs CYRILLIC vs GREEK
```

Если смешаны ровно два алфавита — это бинарный канал.

## Практический чек-лист текстовой задачи

1. `cat -A` и `xxd | head` — невидимые пробелы/табы.
2. Дамп кодовых точек — zero-width, модификаторы, теги.
3. Смешанные алфавиты — гомоглифы.
4. Регистр и пунктуация — структурные биты.
5. Акростих/первые буквы — структурный канал.
6. Синонимы/порядок слов — семантический канал.
7. Всё пусто — текст как контейнер (base64, URL, документ).

## Гомоглифы и IDN-спуфинг

Гомоглифы не ограничены текстом — они лежат в основе IDN-спуфинга: домены с символами разных алфавитов выглядят идентично (`аpple.com` с кириллической `а`). В стеганографии тот же приём: выбор алфавита для каждой буквы кодирует бит. Обнаружение — сравнение `unicodedata.name` каждой буквы; смешение `LATIN`/`CYRILLIC`/`GREEK` — признак канала.

```python
import unicodedata as u
from collections import Counter
s = open('t.txt', encoding='utf-8').read()
print(Counter(u.name(c).split()[0] for c in s if u.category(c).startswith('L')))
```

## Регистр, пунктуация и «стилистические» каналы

Каналы, использующие уже видимую структуру:

- **Регистр**: `CaSeD` текст — заглавная = 1.
- **Пунктуация**: запятая vs точка, наличие точки в конце строки.
- **Пробелы между словами**: один vs два.
- **Первая/последняя буква** слова.
- **Число слов в строке** (унарный код).

```python
words = open('t.txt').read().split()
bits = ''.join('1' if w[0].isupper() else '0' for w in words if w[0].isalpha())
```

## Семантические каналы: синонимы и порядок

Лингвистическая стеганография кодирует биты **выбором синонима** из заранее заданной пары. Требуется словарь синонимов; в CTF встречается реже, но существует. Ещё тоньше — **null-шифры** (сообщение читается по «лишним» словам) и mimic-функции (текст маскируется под другой текст). Эти каналы самые «дорогие» в анализе, поэтому проверяйте их последними.

## Практический чек-лист текстовой задачи

1. `cat -A` — хвостовые пробелы/табы.
2. Дамп кодовых точек — zero-width, модификаторы.
3. Смешанные алфавиты — гомоглифы.
4. Регистр/пунктуация — структурные биты.
5. Акростих/первые буквы.
6. Синонимы/порядок слов — семантический канал.
7. Пусто — текст как контейнер (base64/URL/документ).

## Что делать дальше / решение

- `cat -A` + дамп кодовых точек — первый шаг.
- Невидимые два вида → биты; четыре → 2 бита; теги → ASCII.
- Нет невидимых — регистр/пунктуация/акростих.
- Нет структурных — синонимы/порядок слов.
- Пусто — текст носитель другого формата (base64, QR, документ).

## Где пригодится

- Текстовая стего встречается в задачах с письмами, логами, README, исходниками.
- Навык поиска невидимых символов полезен в security-ревью (обфускация кода, фишинговые письма).
- Извлечение zero-width пригодится и в OSINT (метки в документах).
- Дальше — видеостеганография и стего в сетевых протоколах.
