## Как устроен LSB

Каждый пиксель изображения — это несколько байт (каналов R, G, B, иногда A), значения 0–255. Младший бит каждого байта (LSB, bit 0) почти не влияет на цвет: замена 0↔1 меняет значение на 1 из 255, что глазу незаметно. Поэтому младшие биты — идеальное место для данных. LSB-стеганография пишет биты сообщения в младшие биты подряд идущих каналов: 8 каналов = 1 байт сообщения.

Это базовый метод, на котором построены `zsteg`, `stegsolve` и большинство CTF-задач. Понимание LSB нужно, чтобы: (1) извлекать данные стандартными инструментами, (2) писать скрипты для нестандартных схем, (3) понимать стегоанализ (хи-квадрат ловит именно LSB).

## Порядок обхода и каналы

Порядок обхода критичен. Варианты:

- по пикселям (слева-вправо, сверху-вниз), внутри пикселя — R, G, B (или B, G, R);
- по столбцам (`yx`);
- только один канал (только R или только B);
- с alpha (RGBA);
- MSB вместо LSB (редко).

Неверный порядок — «почти текст» или мусор. Инструменты перебирают варианты, но для нестандартных схем нужен скрипт.

## Извлечение через zsteg

`zsteg` перебирает десятки комбинаций и печатает найденное:

```bash
zsteg image.png                 # базовый скан
zsteg -a image.png              # все комбинации
zsteg -E 'b1,rgb,lsb,xy' image.png > out.bin   # извлечь конкретный канал
```

Строка канала: `b1` (1 бит), `rgb` (каналы), `lsb`, `xy` (порядок). Если видите `text:` — это строка; `file:` — вложенный файл.

## Извлечение вручную (Python)

```python
from PIL import Image
import numpy as np
img = np.array(Image.open('image.png').convert('RGB'))
flat = img.reshape(-1, 3)
bits = ''.join(str(int(v) & 1) for v in flat.flatten())
out = bytes(int(bits[i:i+8],2) for i in range(0,len(bits)-7,8))
print(out[:60])
```

Проверяйте сигнатуры (`flag`, `PK`, `MZ`). Если мусор — переберите порядок каналов и MSB/LSB.

## Признаки LSB-стеганографии

- Младшая битовая плоскость выглядит как **шум** вместо структуры.
- Доля единиц в младших битах близка к 0.5.
- Размер файла «необъяснимо» больше.
- `zsteg` находит `text:`/`file:`.

Стегоанализ (хи-квадрат) основан именно на выравнивании частот пар `2k`/`2k+1` при LSB-встраивании.

## Ёмкость и незаметность

Ёмкость: 1 бит на канал → для 24-битного RGB это ~1/8 от числа пикселей. Для 512×512 это ~98 КБ. Незаметность высокая при 1 бите, падает при мультибитных схемах. LSB неустойчив к сжатию (JPEG уничтожит данные), поэтому применяется к lossless-форматам (PNG/BMP).

## Инструменты

- **`zsteg`** — перебор каналов PNG/BMP.
- **`stegsolve`** — визуальный просмотр плоскостей.
- **Pillow/numpy** — собственные схемы.
- **`stegoveritas`** — комплексный анализ.

## Разобранный пример

```bash
$ zsteg -a flag.png | grep -iE 'text|file' | head
[?] 0 b1,rgb,lsb,xy  .. text: "flag{lsb_basic}"
$ zsteg -E 'b1,rgb,lsb,xy' flag.png | head -c 40
flag{lsb_basic}
```

Маршрут: `zsteg -a` → нашли текст → извлекли `-E`. Если пусто — скрипт и перебор порядка.

## Частые ошибки и подводные камни

- **Неверный порядок каналов** (RGB/BGR, xy/yx).
- **MSB vs LSB** — проверяйте оба.
- **Открыть и пересохранить** — LSB погибнет.
- **Применять к JPEG** — LSB там не работает.
- **Игнорировать alpha-канал**.
- **Не проверить мультибитные схемы** (`b2`, `b4`).

## Итог

LSB — фундамент стеганографии изображений. Освоив извлечение через `zsteg` и вручную, вы закрываете большинство beginner-задач. Понимание порядка обхода и стегоанализа помогает и в сложных случаях.

## Сравнение LSB с другими битовыми схемами

| Схема | Биты/канал | Ёмкость | Заметность |
|---|---|---|---|
| LSB-1 | 1 | низкая | очень низкая |
| LSB-2 | 2 | средняя | низкая |
| LSB-4 | 4 | высокая | средняя |
| MSB | 1 (старший) | низкая | высокая |
| 2-3-3 | 2+3+3 | средняя | средняя |
| Alpha-LSB | 1 (альфа) | низкая | очень низкая |

Выбор схемы — компромисс ёмкости и незаметности. В задачах схему часто задают подсказкой («2-3-3», «alpha», «4 бита»).

## Стегоанализ LSB на практике

Хи-квадрат по парам значений:

```python
import numpy as np
from PIL import Image
from scipy.stats import chisquare
img = np.array(Image.open('x.png').convert('L')).flatten()
obs = [img[img==2*k].size for k in range(128)]
exp = [(img[img==2*k].size + img[img==2*k+1].size)/2 for k in range(128)]
chi2, p = chisquare(obs, exp)
print('p =', p)     # p → 1 означает «слишком ровно» = признак LSB
```

Доля единиц в младших битах, близкая к 0.5, — тоже признак встраивания.

## Практический чек-лист LSB-задачи

1. `file` — убедиться, что формат lossless (PNG/BMP).
2. `zsteg -a` — автоматический перебор.
3. Нашли `text`/`file` — извлечь `-E`.
4. Пусто — скрипт с перебором порядка/бит/каналов/alpha.
5. Визуально — битовые плоскости (младшие).
6. Не PNG/BMP — переходить к DCT/аудио.

## Ёмкость и примеры

Для изображения 512×512 RGB (786432 байта пикселей) LSB-1 даёт ~98304 байт (96 КБ) — достаточно для целого архива. Для 1024×768 RGBA — ~393 КБ. Поэтому в LSB-канал часто прячут ZIP с флагом. Проверяйте результат `file`: если `Zip archive` — распакуйте.

## LSB в аудио и видео: тот же принцип

Тот же приём «запись в младший бит» работает и за пределами изображений. В **WAV** данные пишутся в младшие биты сэмплов; в **несжатых кадрах видео** — в младшие биты пикселей; в **альфа-канале** PNG — в прозрачность. Поэтому, освоив LSB на изображениях, вы переносите навык на аудио и видео с минимальными правками скрипта.

```python
# WAV: младшие биты сэмплов
import wave, struct
w = wave.open('x.wav'); raw = w.readframes(w.getnframes())
s = struct.unpack('<%dh' % (len(raw)//2), raw)
bits = ''.join(str(v & 1) for v in s)
print(bytes(int(bits[i:i+8],2) for i in range(0,len(bits)-7,8))[:40])
```

## Почему LSB неустойчив к сжатию

LSB-данные живут в младших битах, которые при lossy-сжатии (JPEG, MP3, H.264) отбрасываются или меняются. Поэтому LSB применяют только к lossless-носителям: PNG, BMP, WAV, несжатое видео. Если задача даёт JPEG и просит «LSB» — это ошибка либо данные прячут иначе (DCT). Понимание этого спасает от бесплодных попыток.

## Ёмкость LSB по носителям

| Носитель | Ёмкость LSB-1 |
|---|---|
| PNG 512×512 RGB | ~96 КБ |
| PNG 1024×768 RGBA | ~393 КБ |
| WAV 44.1 кГц 16 бит стерео, 1 мин | ~1.3 МБ |
| BMP 1920×1080 | ~780 КБ |

Огромная ёмкость объясняет, почему в LSB прячут целые архивы. Всегда проверяйте результат `file` — возможно, это ZIP.

## Практический вывод

LSB — универсальный и мощный метод, но требует lossless-носителя и правильного порядка обхода. Комбинация «`zsteg` + скрипт + проверка сигнатур» покрывает большинство задач. Не забывайте про мультибитные схемы и alpha-канал — они часто остаются незамеченными.

## Что делать дальше / решение

- `zsteg -a` — первый шаг для PNG/BMP.
- Нашли текст/файл — извлеките `-E`.
- Пусто — скрипт с перебором порядка/бит/каналов.
- Не PNG — переходите к JPEG (DCT) или аудио.
- Проверьте метаданные и дописанное как альтернативу.

- Базовая техника для ~30–40% задач Stego с PNG/BMP.
