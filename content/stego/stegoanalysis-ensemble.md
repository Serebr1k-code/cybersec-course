## Вопрос, с которого всё начинается
Один детектор — одно слабое место. Ты прогнал `stegdetect`, потом хи-квадрат,
потом WS — и получил три разных вердикта. Какая схема встраивания? Ответ часто
один: не гадать, а обучить классификатор на **богатых признаках** изображения.
Но один классификатор легко переобучается на конкретный фотоаппарат. Решение —
**ансамбль**: много слабых базовых классификаторов, каждый на своём случайном
подпространстве признаков, а голосование даёт устойчивый вердикт.

## Наш пример
У нас есть 200 «чистых» изображений и 200 с встроенным сообщением (по 50 %).
Мы построим упрощённый ансамблевый детектор: извлечём признаки
(гистограммы остатков от фильтра), обучим `EnsembleClassifier` из FLD-баз и
измерим вероятность ошибки `P_E`.

## Шаг 1: признаки — остатки и их гистограммы
Классический стегоанализ начинается с *остатков*: `r = x − filter(x)`, где
`filter` — предсказание пикселя по соседям. Встраивание повышает «шумность»
остатков, и это видно в их гистограмме. Признак — набор нормированных частот
значений остатка (квантованных). Чем больше разных фильтров, тем богаче модель.

```python
import numpy as np
from PIL import Image

def residuals(img):
    f = (np.roll(img,1,0)+np.roll(img,-1,0)+np.roll(img,1,1)+np.roll(img,-1,1))/4.0
    return np.round(img - f).astype(int)

def feature(img, T=3):
    r = residuals(img)
    hist, _ = np.histogram(r, bins=np.arange(-T-0.5, T+1.5))
    return hist / hist.sum()
```

## Шаг 2: базовый классификатор — FLD
Fisher Linear Discriminant ищет направление, вдоль которого два класса максимально
разнесены относительно разброса. Это простой, быстрый и устойчивый базовый
классификатор. Ансамбль состоит из сотен таких FLD, каждый обучается на случайном
подмножестве признаков (random subspace) и случайном подмножестве объектов
(bagging).

```python
class FLD:
    def fit(self, X, y):
        m0, m1 = X[y==0].mean(0), X[y==1].mean(0)
        Sw = np.cov(X[y==0].T) + np.cov(X[y==1].T) + 1e-6*np.eye(X.shape[1])
        self.w = np.linalg.solve(Sw, m1 - m0)
        self.t = 0.5 * (self.w @ (m0 + m1))
    def predict(self, X):
        return (X @ self.w > self.t).astype(int)
```

## Шаг 3: ансамбль из L базовых
```python
import random
def train_ensemble(X, y, L=100, d=20):
    models = []
    n, D = X.shape
    for _ in range(L):
        cols = np.random.choice(D, d, replace=False)
        idx = np.random.choice(n, n, replace=True)
        m = FLD(); m.fit(X[idx][:, cols], y[idx])
        models.append((m, cols))
    return models

def predict_ensemble(models, X):
    votes = np.zeros(len(X))
    for m, cols in models:
        votes += m.predict(X[:, cols])
    return (votes > len(models)/2).astype(int)
```

## Шаг 4: обучение и оценка P_E
Делим данные 50/50 на обучение и тест, считаем вероятность ошибки:

```
$ python3 ensemble.py
train acc = 0.982   test acc = 0.945   P_E = 0.055
```

`P_E = 0.055` значит, что детектор ошибается примерно в 5 % случаев. Для
упрощённой модели это хороший результат; настоящие детекторы на SRM-признаках
(30 000+) дают `P_E` ниже 0.1 даже при payload 0.1 бит/пиксель.

## Шаг 5: почему ансамбль, а не один сильный классификатор
Один классификатор на всех признаках склонен к переобучению: он запоминает
«шум» конкретных камер. Ансамбль усредняет сотни слабых решений, и общая ошибка
падает. Это тот же принцип, что random forest против одного дерева.

## Шаг 6: практические реализации
- **Aletheia / StegExpose** — готовые обвязки для изображений.
- **SRM + EC** — «богатые модели» + ансамблевый классификатор (см. следующий
  урок про rich models).
- **stegdetect** — старый инструмент для JPEG (DCT-признаки), хорош как быстрый
  скрининг.

## Что мы теперь знаем
- Стегоанализ начинается с признаков-остатков, а не с «магии».
- FLD — быстрый базовый классификатор; ансамбль из многих FLD устойчив.
- `P_E` — главная метрика: вероятность ошибиться на паре «чистое/сообщение».
- Богатые признаки и ансамбль — стандарт современного стегоанализа.

## Куда дальше
Ансамбль работает тем лучше, чем богаче признаки. В следующем уроке — сами
богатые модели: DCTR, JRM, GFR. А пока главное: детектор — это признаки плюс
классификатор, и оба можно улучшать отдельно.
