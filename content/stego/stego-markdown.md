## Вопрос, с которого всё начинается
Markdown — «текст как есть»: заголовки, списки, ссылки. Но у него есть
синтаксические элементы, которые **не отображаются** в готовом виде: HTML-комментарии,
определения ссылок, хвостовые пробелы, alt-текст. Идеальное место для данных.
Ты получил `README.md`; на странице — чистый текст, а в исходнике — сообщение.

## Наш пример
Возьмём `README.md`. Разберём, как спрятать строку в HTML-комментарии и
reference-link, и как это выглядит после рендера.

## Шаг 1: HTML-комментарии
Markdown пропускает inline HTML. Комментарий `<!-- ... -->` не рендерится
вовсе:

```markdown
# Проект

<!-- TODO: fix later -->
```

В `README.md` внутри такого комментария может лежать base64 или метка.

## Шаг 2: reference-style ссылки
Ссылка может быть «ссылочной»: в тексте `[текст][id]`, а определение —
в другом месте файла: `[id]: https://example.com "title"`. Определение не видно
на странице (оно «поглощается»), но остаётся в исходнике. Длинные URL и title —
свободное место.

## Шаг 3: хвостовые пробелы
Два пробела в конце строки — это `<br>` в Markdown. Один или три пробела —
«ничего», но байты в файле есть. Количество хвостовых пробелов на строку кодирует
биты: ноль пробелов = 0, один пробел = 1, либо группы по 1..4 пробела = 2 бита.

## Шаг 4: alt-текст, title и URL картинок
`![alt](url "title")` — alt и title почти никто не читает. А `url` может быть
`data:`-URI с base64, который отрендерится как картинка (или не отрендерится, если
это не картинка) — и данные уедут вместе с файлом.

## Шаг 5: извлечение вручную
```python
import re, base64
text = open('README.md', encoding='utf-8').read()
m = re.search(r'<!--\s*(nto\{[^}]*\})\s*-->', text)
print(m.group(1))
```

Вывод:

```
nto{markdown_hidden_comment}
```

## Шаг 6: инструменты
- `markdown README.md` или `pandoc` — рендер (скрытое исчезнет из вывода).
- `grep -n '<!--' README.md` — комментарии.
- `grep -nE '^\s*\[[^]]+\]:' README.md` — определения ссылок.
- `cat -A README.md` — показать хвостовые пробелы (`$` в конце строк).

## Что мы теперь знаем
- HTML-комментарии и reference-ссылки не рендерятся, но остаются в файле.
- Хвостовые пробелы и alt/title/URL — каналы разметки.
- Рендер (`markdown`/`pandoc`) — нормализация, убивающая каналы.
- `cat -A` — быстрый способ увидеть «невидимое».
