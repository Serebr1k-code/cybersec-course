Физическая стеганография прячет информацию в самом носителе, а не в его цифровом представлении. Классические примеры: невидимые чернила, микроточки, рельеф бумаги, магнитные метки. В CTF и forensics это встречается реже, но такие задачи проверяют умение думать за пределами файла: ответ может быть «на ощупь», при косом освещении или при измерении магнитного состояния.

## Бумага как носитель

Бумага даёт несколько каналов:

- **Рельеф/тиснение.** Выдавленные или вдавленные знаки видны при косом освещении или на отражении.
- **Микроперфорация.** Рядом маленьких отверстий кодируют биты (считываются на просвет).
- **Толщина/водяные знаки.** Просвечивание выявляет узор.
- **Невидимые чернила.** УФ-флуоресценция или проявление реагентом.
- **Крапинки/волокна.** Случайный рисунок волокон бумаги — «физический отпечаток» (paper fingerprint).

Приёмы анализа: косое освещение (фонарик под углом), просвет (на окне или лайтбоксе), УФ-фонарь, микроскоп.

## Термальные и магнитные носители

- **Термобумага.** Чековая лента: повторное нагревание может проявить «скрытые» метки; наоборот, термостеганография прячет данные в слабых нагревах.
- **Магнитные носители.** Лента, дискета, магнитная полоса карты: остаточная намагниченность между дорожками, нестандартное кодирование, «стёртые» но восстанавливаемые данные (data remanence).
- **Магнитооптика/флоппи.** Слабые магнитные метки между секторами.

Инструмент для магнитных карт — **магнитный декодер** (например, MSR-ридер) плюс анализ сырых дорожек. Для ленты/дискет — магнитный микроскоп или считыватель с анализом сигнала.

## Механические носители и машинки

- **Печатная машинка.** Различия в нажиме, дефекты литер, износ ленты создают «подпись» устройства; микроскопический анализ оттисков связывает текст с конкретной машинкой.
- **Пишущая ручка.** Давление, наклон, состав чернил — баллистика письма.
- **Механические счётчики/перфокарты.** Отверстия в перфокарте — прямой двоичный код.

Для перфокарт и перфолент «считывание» — просто интерпретация позиций отверстий как битов.

## Инструменты и команды

- **`ImageMagick`** — усиление контраста/каналов фото физического объекта.
- **`GIMP`/`Photoshop`** — каналы, уровни, высокочастотная фильтрация.
- **`OpenCV`** — детект рельефа через градиенты, анализ микротекстуры.
- **Магнитный считыватель** — для карт и лент.
- **УФ-фонарь/микроскоп** — аппаратная часть.

Усиление рельефа на фото бумаги:

```bash
convert paper.jpg -colorspace Gray -lat 15x15+5% relief.png
```

Градиентный анализ в Python (рельеф даёт сильные градиенты):

```python
import cv2, numpy as np
img = cv2.imread("paper.jpg", 0)
gx = cv2.Sobel(img, cv2.CV_32F, 1, 0)
gy = cv2.Sobel(img, cv2.CV_32F, 0, 1)
mag = np.hypot(gx, gy)
cv2.imwrite("relief.png", np.clip(mag, 0, 255).astype("uint8"))
```

## Разобранный пример: микроперфорация

Дано фото листа на просвет. Шаги:

1. Инвертировать изображение, чтобы отверстия стали яркими.
2. Убрать неравномерность фона (деление на размытие).
3. Порог → бинарная маска → координаты отверстий.
4. Интерпретировать позиции как биты (например, 8 отверстий = байт).

```python
import cv2, numpy as np
img = cv2.imread("backlit.jpg", 0)
bg = cv2.GaussianBlur(img, (51,51), 0)
norm = cv2.divide(img, bg, scale=255)
_, mask = cv2.threshold(norm, 200, 255, cv2.THRESH_BINARY)
print("отверстий:", int(mask.sum()/255))
```

## Частые ошибки и подводные камни

- **Пытаться решить физическую задачу только цифровыми инструментами.** Нужны освещение, угол, УФ.
- **Игнорировать рельеф.** При обычном освещении его не видно.
- **Путать дефект печати с меткой.** Нужна регулярность/согласованность.
- **Забыть про остаточные данные.** «Стёртая» магнитная лента восстанавливаема.
- **Не фиксировать условия съёмки.** Для повторяемости нужны одинаковые свет/угол.
- **Считать бумагу однородной.** Волокна — уникальный отпечаток.

## Что дальше / решение

- Определите тип носителя и подберите освещение/считыватель.
- Для бумаги: косой свет, просвет, УФ, микроскопия.
- Для магнитных: считыватель + анализ сырого сигнала (data remanence).
- Для перфоносителей: позиции отверстий → биты → байты.
- Зафиксируйте методику, чтобы результат был воспроизводим.

## Бумага: волокна как физический отпечаток

Помимо рельефа и перфорации, бумага обладает случайной микроструктурой волокон. При сканировании на просвет эти волокна дают уникальный «отпечаток» — paper fingerprint. Он позволяет идентифицировать конкретный лист: сравнение двух сканов одного листа даёт высокую корреляцию, а разных листов — низкую. Это применяется для защиты документов (связывание подписи с листом) и в forensics.

```python
import cv2, numpy as np
a = cv2.imread("scan1.png", 0).astype(np.float32)
b = cv2.imread("scan2.png", 0).astype(np.float32)
a -= a.mean(); b -= b.mean()
corr = (a*b).sum()/np.sqrt((a*a).sum()*(b*b).sum())
print("correlation:", corr)   # ~1.0 для одного листа
```

Высокая корреляция (>0.9) между двумя сканами одного участка — признак того же листа.

## Невидимые чернила и УФ

Невидимые чернила флуоресцируют под УФ или проявляются реагентом. В CTF и forensics это встречается как «напишите фонариком»: сфотографировать лист под УФ-фонарём, где проявится скрытый текст. Аналогично работают «симпатические» чернила (лимонный сок, молоко), проявляющиеся нагревом.

Практический приём: снять объект в нескольких режимах (видимый, УФ, ИК) и сравнить. ИК-съёмка иногда выявляет замазанный текст (разница в поглощении чернил).

## Термостеганография

Термобумага меняет цвет при нагреве. Слабым точечным нагревом можно нанести «скрытый» узор, который не виден при комнатной температуре, но проявляется при повторном нагреве или имеет низкий контраст. Для анализа чеков: контролируемый нагрев (фен, термостол) может проявить дополнительные метки или, наоборот, показать, что поверх печатали.

## Магнитные носители и остаточные данные

Магнитная запись не стирается идеально: при перезаписи остаётся слабый «призрак» старого сигнала (data remanence). Восстановление:

- **Аналоговый анализ сигнала** считывающей головки (для лент/дискет).
- **MFM/RLL-декодирование** сырых дорожек.
- **Магнитный микроскоп** — визуализация доменов.

Для магнитных карт (MSR) анализируют сырые дорожки: помимо стандартных Track1/2/3, в нестандартных битах могут быть данные.

```bash
# пример чтения магнитной полосы
msr -r          # сырые дорожки
```

## Перфокарты и перфоленты

Исторические носители: перфокарты (80 колонок × 12 строк) и перфоленты. Данные читаются напрямую — позиции отверстий = биты. Для перфокарты каждая колонка кодирует символ (Hollerith). Считывание: подсветить и распознать отверстия.

```python
# колонка как битовая маска строк
cols = ["100000100000", "010000100000"]   # пример масок
```

## Стеганография в механических дефектах

Печатная машинка и пишущая ручка оставляют «подпись»: износ литер, разный нажим, состав чернил. Микроскопический анализ оттисков позволяет связать текст с конкретным устройством. В CTF это редко, но в forensics — стандартный метод (questioned documents).

## Сводная методика анализа физического объекта

1. Определить тип носителя (бумага, термо, магнит, перфо).
2. Подобрать освещение/считыватель (косой свет, УФ, backlight, магнитная головка).
3. Зафиксировать условия съёмки (свет, угол, разрешение).
4. Усилить контраст и выделить регулярные структуры.
5. Декодировать: отверстия → биты, точки → решётка, волокна → отпечаток.

Такой порядок покрывает большинство «физических» задач и не даёт упустить простые каналы.

## Ограничения и предостережения

- **Разрушающие методы**: нагрев/реагенты могут уничтожить объект — работайте с копией или фото.
- **Зависимость от условий**: рельеф виден только при определённом свете.
- **Субъективность**: дефект vs метка — нужна статистика.
- **Хранение**: физические носители деградируют (термо выцветает, лента размагничивается).
