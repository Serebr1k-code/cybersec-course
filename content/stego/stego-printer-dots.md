Цветные лазерные принтеры и копиры многих производителей печатают на каждом листе почти невидимый узор из жёлтых точек — Machine Identification Code (MIC), он же «жёлтые точки», он же printer steganography. Этот узор кодирует серийный номер устройства и дату/время печати. Формально это не «сокрытие данных» ради секретности, а маркировка, но технически это самая настоящая физическая стеганография, и в forensics она позволяет связать документ с конкретным принтером.

## Что кодирует MIC

Узор жёлтых точек строится по решётке, наложенной на страницу. В типовой схеме:

- Группа точек кодирует **серийный номер** принтера (в десятичном виде, по колонкам/строкам).
- Другая часть узора — **дата и время** печати.
- Иногда добавляется **код модели/производителя**.

Точки размещаются в жёлтом цветовом канале с очень низкой контрастностью: при обычном просмотре лист выглядит белым. Кодировка у разных вендоров (Xerox, Canon, HP, Epson, Brother) различается, но общий принцип один: решётка + позиции точек = цифры.

## Как извлечь жёлтые точки

Нужен скан или фото высокого разрешения (не менее 300–600 dpi, лучше 1200 dpi). Методика:

1. Отсканировать лист в цвете без сжатия (TIFF/PNG).
2. Разделить изображение на каналы R, G, B.
3. Усилить жёлтый канал: в CMYK жёлтый = `(R+G)/2 - B` (упрощённо), либо вычесть синий канал из среднего по красному и зелёному.
4. Повысить контраст, чтобы решётка точек стала видимой.

Разделение каналов через ImageMagick:

```bash
convert scan.tiff -channel R -separate r.png
convert scan.tiff -channel G -separate g.png
convert scan.tiff -channel B -separate b.png
```

Усиление жёлтого:

```bash
convert scan.tiff -colorspace CMYK -channel Y -separate -negate yellow.png
```

Python (Pillow + numpy):

```python
from PIL import Image
import numpy as np
im = np.asarray(Image.open("scan.tiff").convert("RGB")).astype(int)
yellow = (im[:,:,0] + im[:,:,1])//2 - im[:,:,2]   # жёлтый выделяется
yellow = np.clip(yellow, 0, 255).astype("uint8")
Image.fromarray(yellow).save("yellow.png")
```

## Разобранный пример: декодирование узора

После усиления на изображении видна сетка точек. Далее:

1. Определить шаг решётки (расстояние между колонками/строками).
2. Для каждой позиции решётки решить, есть ли точка (порог по яркости).
3. Считать группы точек как цифры серийного номера и даты.

Простой детектор точек по порогу:

```python
from PIL import Image
import numpy as np
img = np.asarray(Image.open("yellow.png").convert("L"))
mask = img > 128            # точки ярче фона
ys, xs = np.where(mask)
print("точек найдено:", len(xs))
# кластеризация по координатам даёт позиции; шаг решётки — мода разностей
```

Далее позиции сопоставляются с таблицей кодировки конкретного вендора. В CTF часто достаточно визуально увидеть в усиленном жёлтом канале цифры или QR-подобный узор.

## Готовые инструменты

- **`didierstevens` / MIC-decoder скрипты** — исследовательские декодеры.
- **`ImageMagick`** — канальные операции.
- **`GIMP`** — визуальное усиление каналов.
- **`OpenCV`** — детект точек (`SimpleBlobDetector`).

Детект точек через OpenCV:

```python
import cv2
img = cv2.imread("yellow.png", 0)
det = cv2.SimpleBlobDetector_create()
pts = det.detect(img)
print("blobs:", len(pts))
```

## Частые ошибки и подводные камни

- **Слишком низкое разрешение скана.** Точки сливаются; нужен 300+ dpi.
- **Сжатие JPEG.** Артефакты маскируют узор; сканируйте в TIFF/PNG.
- **Игнорировать жёлтый канал.** Точки видны только в нём.
- **Путать MIC с шумом печати.** Нужна регулярная решётка.
- **Ожидать единую кодировку.** У вендоров разные таблицы.
- **Забыть про дату/время.** Помимо серийника, MIC даёт время печати.

## Таблица: что даёт MIC

| Поле | Что кодирует | Ценность в forensics |
|---|---|---|
| Серийный номер | уникальный ID принтера | привязка документа к устройству |
| Дата | день/месяц/год | установление времени печати |
| Время | часы/минуты | сужение окна печати |
| Модель/вендор | тип устройства | сужение круга моделей |

## Что дальше / решение

- Отсканируйте лист в цвете, 600–1200 dpi, без сжатия.
- Разделите каналы и усильте жёлтый (`convert -colorspace CMYK`).
- Визуально проверьте сетку точек; при необходимости детектируйте блобы.
- Сопоставьте узор с таблицей вендора для серийника и даты.
- Если точек нет — принтер может быть струйным/чёрно-белым (MIC печатают в основном цветные лазерные).

## История и правовая сторона

Технология жёлтых точек появилась как средство борьбы с подделкой банкнот и документами: принтеры обязали маркировать отпечатки серийным номером. Публично она стала известна после исследований проекта «Seeing Yellow» (2005) и работ по декодированию MIC у Xerox. В ряде юрисдикций маркировка обязательна для цветных устройств; в других — вопрос приватности (скрытая маркировка без уведомления) вызывал споры. Для специалиста по forensics это значит: MIC — легитимный, документированный артефакт, и его анализ допустим при расследовании.

## Точная структура узора

Типовая схема MIC (на примере Xerox): на странице наложена решётка с шагом примерно 1/100 дюйма (0.1 мм). В каждой ячейке может стоять точка или нет. Узор образует блоки, повторяющиеся по странице. Внутри блока:

- Часть ячеек кодирует **серийный номер** устройства (в десятичной кодировке, по 2–3 цифры в строке).
- Часть — **дату** в формате `YYMMDD` и время.
- Иногда — **код модели**.

Точки крошечные (диаметр ~0.1 мм), поэтому нужен скан 600–1200 dpi и хорошая оптика. Струйные и чёрно-белые устройства обычно MIC не печатают.

## Точный алгоритм извлечения

1. Скан в TIFF/PNG, 1200 dpi, без сжатия, цвет.
2. Разделение на R/G/B, вычисление «жёлтости»: `Y = (R+G)/2 − B`.
3. Нормализация фона (деление на размытие), порог.
4. Детект точек (blob detection), восстановление решётки по периодичности.
5. Декодирование битов решётки в цифры по таблице вендора.

```python
import cv2, numpy as np
img = cv2.imread("scan.tiff")
b, g, r = cv2.split(img.astype(np.int16))
yellow = np.clip((r + g)//2 - b, 0, 255).astype(np.uint8)
cv2.imwrite("yellow.png", yellow)
```

Дальше — `SimpleBlobDetector` или порог + поиск локальных максимумов.

## Работа с шумом и артефактами

Реальные сканы шумные. Приёмы очистки:

- **Медианный фильтр** — убирает соль-перец, сохраняя точки.
- **Морфология** — открытие/закрытие для выделения круглых точек.
- **Нормализация освещения** — деление на размытое изображение.
- **Подсчёт периодов** через FFT — устойчивое определение шага решётки.

```python
blur = cv2.GaussianBlur(yellow, (0,0), 3)
norm = cv2.divide(yellow, blur, scale=255)
```

## Связь с другими видами физической маркировки

MIC — не единственная скрытая маркировка. Аналогично работают:

- **Microdots** — микроскопические точки с текстом, наносимые на документы.
- **Barcodes/QR, напечатанные «на просвет»** — низкоконтрастные.
- **Стелс-водяные знаки в банкнотах** — для защиты от подделки.

Все они эксплуатируют одно: невооружённый глаз не различает, а сканер/микроскоп — да.

## Практический кейс

В forensics документ изъят у подозреваемого. Задача — связать его с принтером. Порядок:

1. Скан документа 1200 dpi.
2. Усиление жёлтого канала.
3. Декодирование серийного номера и даты.
4. Сопоставление серийника с базой устройств организации.
5. Вывод: документ напечатан на конкретном принтере в конкретное время.

Это стандартный, юридически значимый артефакт — именно поэтому MIC изучают в forensics, а не только в CTF.

## Ошибки и типичные заблуждения

- **«Точки видны на глаз»** — нет, они почти неразличимы.
- **«MIC есть у всех принтеров»** — нет, в основном у цветных лазерных.
- **«Достаточно низкого разрешения»** — нет, нужно 600+ dpi.
- **«Кодировка универсальна»** — нет, у вендоров разные таблицы.
- **«MIC можно убрать печатью»** — частично; повторная печать добавит свой MIC.
