## Что такое бит-плоскости

Каждый байт пикселя (значение канала 0–255) состоит из 8 бит. Если «вырезать» из всех пикселей бит номер `k` и нарисовать его как чёрно-белое изображение, получится **бит-плоскость** `k`. Младшие плоскости (bit 0–1) выглядят как шум, старшие (bit 6–7) — как грубая копия изображения. Стеганография живёт в младших плоскостях: изменение бита 0 незаметно глазу.

Бит-плоскости — фундаментальное понятие: любой LSB-метод — это запись данных в одну или несколько младших плоскостей. Понимание плоскостей позволяет не только извлекать данные, но и **визуально** их находить (например, надпись или QR-код прямо в плоскости).

## Мультибитный LSB

Вместо одного младшего бита можно использовать 2 или 4 — тогда ёмкость выше, но заметность растёт. Запись 2 бит в канал:

```python
from PIL import Image
import numpy as np
img = np.array(Image.open('cover.png').convert('RGB')).astype(np.uint8)
msg = b'flag{2bit}'
bits = ''.join(f'{b:08b}' for b in msg)
# по 2 бита на канал
k = 0
flat = img.reshape(-1)
for i in range(len(flat)):
    if k >= len(bits): break
    two = bits[k:k+2].ljust(2,'0')
    flat[i] = (flat[i] & 0b11111100) | int(two,2)
    k += 2
Image.fromarray(img).save('stego.png')
```

Извлечение — обратная операция: собираем по 2 младших бита с каждого канала. Важно помнить порядок: обычно идут каналы R,G,B внутри пикселя, затем следующий пиксель.

## Схема 2-3-3 по каналам RGB

Особый приём: распределить биты сообщения **неравномерно** по каналам. Человеческий глаз менее чувствителен к синему каналу, поэтому в схемах распределения (например, «2-3-3») в каналы R/G/B кладут разное число бит. Часто это 2 бита в один канал и 3 в другие, либо все 8 бит сообщения распределяются как 2+3+3.

Пример распределения 8 бит на пиксель (R←2 бита, G←3, B←3):

```python
bits = ''.join(f'{b:08b}' for b in b'flag{233}')
i = 0
out = []
for px in img.reshape(-1,3):
    r,g,b = int(px[0]),int(px[1]),int(px[2])
    if i+8 <= len(bits):
        r = (r & 0b11111100) | int(bits[i:i+2],2)
        g = (g & 0b11111000) | int(bits[i+2:i+5],2)
        b = (b & 0b11111000) | int(bits[i+5:i+8],2)
        i += 8
    out.append((r,g,b))
```

Извлечение требует знания точной схемы — её часто дают в описании задачи или подсказкой (например, «2-3-3» в тексте).

## Визуализация плоскостей

Генерация всех восьми плоскостей скриптом:

```python
from PIL import Image
import numpy as np
img = np.array(Image.open('cat.png').convert('RGB'))
for bit in range(8):
    plane = ((img >> bit) & 1) * 255
    Image.fromarray(plane.astype('uint8')).save(f'plane_{bit}.png')
```

Затем просмотрите `plane_0.png` … `plane_3.png` глазами: часто в одной из них видна надпись, QR-код или схема. Это самый быстрый способ найти **визуальный** канал, который инструменты не «видят».

## Извлечение вручную

```python
def extract(img, nbits=1, order='rgb'):
    idx = {'rgb':[0,1,2], 'bgr':[2,1,0]}[order]
    bits = ''
    for px in img.reshape(-1,3):
        for c in idx:
            bits += format(int(px[c]) & ((1<<nbits)-1), f'0{nbits}b')
    out = bytes(int(bits[i:i+8],2) for i in range(0,len(bits)-7,8))
    return out
```

Проверяйте результат на сигнатуры (`flag`, `PK`, `MZ`). Если мусор — переберите `nbits` (1,2,4) и `order`.

## Инструменты

- **`stegsolve`** — визуальный просмотр плоскостей и каналов (Java).
- **`zsteg -a`** — автоматический перебор (в т.ч. мультибитных).
- **`Pillow`/`numpy`** — точный контроль над битами и схемами.
- **`binwalk`** — если в плоскости «виден» вложенный файл.

## Разобранный пример

Задача: в описании сказано «2-3-3». Значит, схема распределения известна.

```python
from PIL import Image
import numpy as np
img = np.array(Image.open('task.png').convert('RGB'))
bits = ''
for px in img.reshape(-1,3):
    r,g,b = [int(v) for v in px]
    bits += format(r & 0b11, '02b')      # 2 бита из R
    bits += format(g & 0b111, '03b')     # 3 бита из G
    bits += format(b & 0b111, '03b')     # 3 бита из B
out = bytes(int(bits[i:i+8],2) for i in range(0,len(bits)-7,8))
print(out[:40])   # b'flag{rgb_233_scheme}'
```

Ключ — точно воспроизвести схему из подсказки. Без неё перебирайте варианты распределения.

## Частые ошибки и подводные камни

- **Считать, что LSB всегда 1 бит** — бывает 2/4 бита и схемы 2-3-3.
- **Неверный порядок каналов** (RGB vs BGR) — «почти текст» вместо текста.
- **Игнорировать визуальные плоскости** — данные могут быть картинкой, а не строкой.
- **Открыть в редакторе** — плоскости перезапишутся.
- **Не проверить interlace/палитру** — меняет порядок пикселей.
- **Забыть про alpha** — данные могут быть в четвёртом канале.

## Ёмкость и незаметность мультибитных схем

Ёмкость растёт линейно с числом используемых младших бит: 1 бит на канал — 1/8 размера, 2 бита — 1/4, 4 бита — 1/2. Но незаметность падает: при 4 битах в канал изменение значения на ±15 может стать видимым как лёгкий шум. Компромисс зависит от носителя: в гладких областях (небо, стена) мультибитный LSB заметнее, в шумных — незаметен.

Схемы распределения (2-3-3, 2-2-4 и т. п.) пытаются спрятать данные в **наименее чувствительные** каналы. Глаз хуже всего различает изменения в синем канале, поэтому часто больше бит отдают в B. Знание этой эвристики помогает угадывать схему, когда в описании задачи дана лишь подсказка «цвет».

## Связь с битовыми плоскостями и стегоанализом

Мультибитный LSB эквивалентен записи в несколько младших плоскостей одновременно. Стегоанализ это видит: младшие плоскости перестают быть «белым шумом» и приобретают структуру. Тесты:

- **Хи-квадрат**: распределение пар значений (2k, 2k+1) выравнивается при LSB-встраивании.
- **RS-анализ**: оценивает долю изменённых пикселей.
- **Визуальный осмотр плоскостей**: структура в младшей плоскости — почти верный признак данных.

```python
# быстрая «шумность» плоскости 0
import numpy as np
from PIL import Image
p = np.array(Image.open('plane_0.png').convert('L'))
print('mean', p.mean(), 'std', p.std())   # std ~0 → плоскость пустая/структурная
```

## Практический чек-лист

1. Сгенерировать 8 битовых плоскостей, просмотреть 0–3 глазами.
2. `zsteg -a` — автоматический перебор, включая `b2`/`b4`.
3. Если есть подсказка про схему — реализовать её точно (2-3-3 и т. п.).
4. Перебрать `order` (rgb/bgr), `msb/lsb`, `xy/yx`.
5. Учесть alpha-канал (4-й канал) — там тоже бывают данные.
6. Проверить сигнатуры результата (`flag`, `PK`, `MZ`).
7. Нет результата — переходить к IDAT/чанкам/хвосту.

## Инструменты глубоко

- **`stegsolve`**: переключение каналов/бит/режимов (LSB, XOR, AND, OR, subtract), сохранение плоскости.
- **`zsteg -a -E 'b2,rgb,lsb,xy'`**: точечное извлечение мультибитного канала.
- **Pillow/numpy**: полный контроль — единственный способ реализовать нестандартную схему.
- **`binwalk`**: если в плоскости «виден» файл, извлечь его.

Мультибитные задачи обычно дают подсказку о схеме, иначе пространство перебора велико. Поэтому первым делом ищите в описании задачи слова «2-3-3», «каналы», «RGB», «LSB» — они задают параметры извлечения.

## Итог по битовым плоскостям

Битовые плоскости — базовый язык всей LSB-стеганографии: любой метод сводится к записи в одну или несколько младших плоскостей. Отсюда два практических следствия. Во-первых, визуализация плоскостей — самый быстрый способ найти визуальный канал (надпись, QR) без инструментов. Во-вторых, понимание плоскостей объясняет, почему мультибитные схемы и распределения вроде 2-3-3 работают и почему они заметны для стегоанализа. Держите под рукой скрипт генерации восьми плоскостей и переборный экстрактор — вместе они закрывают практически весь класс задач на младшие биты, включая нестандартные схемы распределения.

## Связь с альфа-каналом и другими носителями

Тот же принцип (запись в младшие биты) работает в альфа-канале RGBA: данные прячут в прозрачности, а полностью прозрачные пиксели визуально невидимы, что даёт особенно скрытный канал. Аналогично битовые плоскости существуют у аудио (младшие биты сэмплов) и у видео (младшие биты кадров). Поэтому, освоив битовые плоскости на изображениях, вы получаете универсальный инструмент: тот же скрипт с минимальными правками переносится на WAV и на несжатые кадры. Это одна из причин, почему битовые плоскости — фундамент всей стеганографии. Держите единый скрипт-шаблон и меняйте в нём лишь источник данных (массив пикселей, сэмплов или кадров): так один навык покрывает сразу три больших класса задач.

## Что делать дальше / решение

- Сгенерируйте 8 битовых плоскостей и просмотрите младшие глазами.

- Пусто — переберите `nbits`, `order`, MSB/LSB и alpha.
