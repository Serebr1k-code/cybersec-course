## Что такое стегоанализ

Стегоанализ — наука об **обнаружении** скрытых данных. Его задача обратна стеганографии: не извлечь сообщение, а ответить на вопрос «есть ли оно вообще». Это важно, потому что иногда данных слишком мало для извлечения без ключа, но сам факт встраивания детектируется статистически. В CTF стегоанализ встречается в двух видах: как отдельная задача («определите, есть ли стего») и как инструмент — когда он подсказывает, в каком канале искать.

Ключевая идея: встраивание **нарушает естественную статистику** носителя. Пиксели, коэффициенты или сэмплы перестают подчиняться типичному распределению. Задача стегоанализа — найти это отклонение и, по возможности, оценить его величину (ёмкость).

## Хи-квадрат-анализ (Pairs of Values)

Классический тест для LSB-встраивания. Наблюдение: в естественном изображении значения пикселей `2k` и `2k+1` встречаются **с разной** частотой (поскольку младший бит не случаен). LSB-встраивание делает младший бит равновероятным, поэтому частоты `2k` и `2k+1` **выравниваются**. Тест хи-квадрат измеряет, насколько наблюдаемое распределение пар отличается от ожидаемого при встраивании.

```python
import numpy as np
from PIL import Image
from scipy.stats import chisquare
img = np.array(Image.open('x.png').convert('L')).flatten()
pairs = [(img[img==2*k].size, img[img==2*k+1].size) for k in range(128)]
obs = [a for a,b in pairs]; exp = [(a+b)/2 for a,b in pairs]
chi2, p = chisquare(obs, exp)
print('p-value', p)   # p близко к 1 → похоже на LSB-встраивание
```

Высокий `p-value` (распределение «слишком ровное») — признак встраивания.

## RS-анализ

RS (Regular-Singular) анализирует, как меняется «гладкость» изображения при флипе младших битов. Пиксели группируются в маски; для каждой группы считается функция гладкости `f`. Группы делятся на **Regular** (гладкость растёт при флипе) и **Singular** (падает). В чистом изображении числа R и S связаны определённым образом; встраивание нарушает это соотношение, что позволяет **оценить долю изменённых пикселей** (то есть ёмкость).

RS-анализ мощнее хи-квадрата, потому что даёт количественную оценку и работает для больших сообщений.

## SPA (Sample Pair Analysis)

SPA анализирует пары соседних сэмплов и их переходы. Встраивание LSB оставляет характерный след в матрице переходов между значениями. Метод позволяет оценить длину сообщения и обнаружить стего, даже когда хи-квадрат «молчит». SPA особенно полезен для изображений с большим объёмом встраивания.

## Калибровка для JPEG

Для JPEG стегоанализ сложнее: коэффициенты DCT коррелированы, а инструменты вроде OutGuess 0.2 активно «маскируют» след. Подход **калибровки**: изображение перекодируется/обрезается, из него извлекается «эталонная» статистика, и она сравнивается с фактической. Разница — оценка встроенных данных. Так работают детекторы JSteg/F5/OutGuess.

## Визуальный стегоанализ

Простейший и часто самый быстрый метод — **посмотреть** на младшие битовые плоскости. Если плоскость 0 содержит структуру (надпись, контур, QR) вместо белого шума — данные почти наверняка там. Это не строгий тест, но в CTF он решает задачи мгновенно.

```python
from PIL import Image
import numpy as np
img = np.array(Image.open('x.png').convert('RGB'))
for b in (0,1,2):
    p = ((img >> b) & 1)*255
    Image.fromarray(p.astype('uint8')).save(f'plane{b}.png')
```

## Инструменты

- **`stegdetect`** — детектор JPEG-методов (JSteg/JPHide/OutGuess/F5).
- **`stegoveritas`** — комплексный анализ с отчётом.
- **`Aletheia`** — продвинутый стегоанализ (RS, SPA, хи-квадрат).
- **Python (`scipy`, `numpy`)** — собственные тесты.
- **`zsteg`** — косвенно: печатает каналы с «аномальными» данными.

## Разобранный пример

Задача: «определите, есть ли в изображении скрытые данные».

```bash
$ stegdetect image.jpg
image.jpg: negative
# но визуально плоскость 0 показывает структуру:
$ python3 - <<'PY'
from PIL import Image
import numpy as np
img=np.array(Image.open('image.jpg').convert('RGB'))
Image.fromarray((((img>>0)&1)*255).astype('uint8')).save('p0.png')
PY
# открываем p0.png — виден QR-код → данные есть
```

Вывод: автоматический детектор может дать «negative», но визуальный анализ плоскости — «positive». Детекторы не универсальны.

## Частые ошибки и подводные камни

- **Считать «нет аномалий» = «нет данных»** — OutGuess 0.2 статистически прозрачен.
- **Применять хи-квадрат к JPEG напрямую** — нужна калибровка.
- **Игнорировать визуальные плоскости** — быстрый и надёжный путь.
- **Путать стегоанализ с извлечением** — они решают разные задачи.
- **Доверять одному тесту** — комбинируйте хи-квадрат, RS, SPA и визуал.
- **Забыть про ёмкость** — оценка длины сообщения помогает извлечению.

## Итог

Стегоанализ даёт язык для разговора о «незаметности» и «ёмкости». Его практическая ценность в CTF — быстро подсказать, **есть ли** данные и **где** они (по аномалиям), до того как вы потратите время на извлечение. Визуальный анализ плоскостей + один-два статистических теста покрывают большинство ситуаций.

## Формальное определение и метрики

Стегоанализ формализуется как проверка гипотез. Нулевая гипотеза `H0`: в контейнере нет встроенных данных. Альтернатива `H1`: данные есть. Детектор — решающее правило, которое по наблюдениям (пикселям, коэффициентам) выдаёт ответ. Метрики качества: вероятность пропуска (`false negative`) и ложной тревоги (`false positive`). Чем больше сообщение, тем легче его обнаружить; чем меньше — тем выше риск пропуска.

Из этого следует практический вывод для CTF: **маленькое сообщение (флаг) может быть статистически невидимым**, поэтому «чистый» результат теста не доказывает отсутствие данных. Всегда комбинируйте статистику с прямым перебором каналов и визуальным анализом.

## Практические реализации тестов на Python

Хи-квадрат по парам значений и быстрая оценка «случайности» младших битов:

```python
import numpy as np
from PIL import Image
img = np.array(Image.open('x.png').convert('L')).flatten()
lsb = img & 1
# доля единиц в младших битах должна быть ~0.5 при LSB-встраивании
print('lsb ones ratio:', lsb.mean())
# энтропия младшей плоскости
p = lsb.mean()
import math
H = -(p*math.log2(p) + (1-p)*math.log2(1-p)) if 0 < p < 1 else 0
print('entropy:', H)   # ~1.0 → похоже на встраивание
```

Для «чистого» фотографического изображения доля единиц в младших битах отклоняется от 0.5 (структура), а при LSB-встраивании стремится к 0.5.

## Почему стегоанализ «проигрывает» современной стеганографии

Современные методы (модельная стеганография, синтез текстуры, нейросетевые подходы) целенаправленно сохраняют статистику контейнера. Например, метод **HUGO** минимизирует «стоимость» изменения с учётом стегоаналитических признаков, а **S-UNIWARD** распределяет изменения по «дорогим» для детектора местам. В результате стегоанализ не может надёжно отличить контейнер от чистого изображения.

Для CTF это означает: не полагайтесь на «стегоанализ ничего не нашёл». Ищите **по каналам** (LSB, IDAT, чанки, хвост, метаданные), а не только статистически. Статистика — вспомогательный инструмент, а не окончательный вердикт.

## Итог по стегоанализу

Стегоанализ даёт ценные подсказки (где искать, сколько данных), но не является «детектором истины». В реальной задаче его роль — быстро сузить пространство поиска: если младшая плоскость выглядит как шум и энтропия близка к 1, вероятен LSB-канал; если статистика «чистая», возможен OutGuess 0.2 или модельный метод. Окончательный ответ даёт **извлечение**.

## Связь стегоанализа и ёмкости

Оценка ёмкости — практический мостик между «есть ли данные» и «сколько их». Методы вроде RS и SPA дают не только бинарный ответ, но и **оценку длины сообщения** в битах. Это полезно: зная примерный размер, вы понимаете, какого рода данные искать (короткий флаг или целый архив), и в каком канале их искать. Например, оценка в несколько килобайт при JPEG-носителе подсказывает, что дело не в DCT-методе (там ёмкость мала), а в дописанном хвосте или метаданных. Так стегоанализ превращается из «академического теста» в навигационный инструмент.

## Что делать дальше / решение

- Визуальный анализ младших плоскостей — первый шаг.
- Хи-квадрат/RS/SPA для PNG/BMP, калибровка для JPEG.
- `stegdetect`/`Aletheia` для автоматической оценки.
- Данные есть, но не извлекаются — ищите ключ или нестандартный порядок.
- Детектор «молчит» — не исключайте стего, проверьте все каналы вручную.
